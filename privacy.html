Complete Privacy Clauses & Operating Terms.

01
Hosting & Infrastructure · GitHub Pages
Server Log Files & Telemetry

Like any web service deployed on modern content distribution networks (such as GitHub Pages and Cloudflare), incoming web requests automatically process server log files. These include IP addresses, browser versions, operating systems, referring URLs, and timestamps strictly to defend against DDoS attacks and maintain system uptime.

02
Cookies & Browser Preferences · Storage
How We Use Browser Storage

We use localStorage purely to remember your chosen aesthetic palette (e.g., Notebook, Chalkboard, Blueprint, Sunset) so the website renders in your favorite theme each time you open a new chapter. No personal identifiers or marketing profiles are written to storage.

03
Third-Party Scripts & Advertising · Strict Limits
AdSense & Verification Tags

Where verified services or site verification headers are implemented, standard privacy disclosures apply. We do not run aggressive behavioral tracking, auto-playing video popups, or deceptive redirect links on any Class 12 notes page.

04
Security & Updates · Continuous Audit
Security & Policy Revisions

Founder Jatin Sandilya conducts regular security audits of all HTML markup and client scripts. This Privacy Policy is updated periodically to reflect architectural evolutions. Revisions take effect immediately upon being posted on this URL.
