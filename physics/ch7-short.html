Class 12 Physics • Quick Mind Map & Notations

Purely Inductive (L) Circuit

i = im sin(ωt - π/2)

यहाँ, peak current im = vm / XL

• XL = ωL : Inductive Reactance (प्रेरकीय प्रतिघात)

• Phase difference (φ) = π/2 (Voltage leads current by 90°)

• Average power over a complete cycle = 0

अक्षरों का मतलब (Notations):

• i = Instantaneous Current (तात्क्षणिक धारा)

• im = Peak Current / Maximum Current (शिखर धारा)

• ω = Angular Frequency (कोणीय आवृत्ति)

• t = Time (समय)

• L = Self-Inductance (स्व-प्रेरकत्व)

Purely Resistive (R) Circuit

i = im sin(ωt)

यहाँ, im = Vm / R

• Phase difference (φ) = 0 (Same phase)

Power (P) = (1/2) * (im^2) * R

Current & voltage both are in the same phase.

अक्षरों का मतलब (Notations):

• R = Resistance (प्रतिरोध)

• Vm = Peak Voltage (शिखर वोल्टेज)

• P = Average Power (औसत शक्ति)

Series LCR Circuit

im = vm / √[ R² + (Xc - XL)² ]

Impedance (Z) = √[ R² + (Xc - XL)² ]

Phase angle (tan φ) = (Xc - XL) / R

Note: Current (I) is the same for R, L, and C in series.

अक्षरों का मतलब (Notations):

• Z = Impedance / Total Opposition (प्रतिबाधा)

• Xc = Capacitive Reactance (धारतीय प्रतिघात)

• XL = Inductive Reactance (प्रेरकीय प्रतिघात)

• φ = Phase Angle (कला कोण)

Purely Capacitive (C) Circuit

i = im sin(ωt + π/2)

यहाँ, im = vm / Xc

• Xc = 1 / (ωC) : Capacitive Reactance

• Phase difference (φ) = π/2

Instantaneous Power (Pc) = (Im Vm sin 2ωt) / 2

Current leads the voltage by π/2 (90°).

अक्षरों का मतलब (Notations):

• C = Capacitance (धारिता)

• Pc = Instantaneous Power in Capacitor

Power Factor (शक्ति गुणांक)

P = (vm im / 2) cos φ = V * I * cos φ = I² Z cos φ

यहाँ, cos φ = Power Factor (शक्ति गुणांक) = R / Z

  • Case 1 (Resistive): φ = 0, cos φ = 1 (Maximum Power)
  • Case 2 (Pure L or C): φ = 90°, cos φ = 0 (No power consumed, called Wattless Current / हीन शक्ति धारा)
  • Case 3 (LCR Series): cos φ = R / Z
  • Case 4 (Resonance): cos φ = 1 (Maximum power dissipation)

अक्षरों का मतलब (Notations):

• V & I = RMS Voltage and RMS Current (आरएमएस मान)

• cos φ = Power Factor (शक्ति गुणांक)

Resonance (अनुनाद) in LCR

जब सर्किट की प्रेरकिय बाधा और धारतीय बाधा बराबर हो जाती है (XL = Xc)।

Resonant Frequency (ω0) = 1 / √(LC)

At Resonance: XL = Xc, Impedance Z = R (Minimum), Current becomes Maximum.

अक्षरों का मतलब (Notations):

• ω0 = Resonant Angular Frequency (अनुनादी कोणीय आवृत्ति)

• L = Inductance, C = Capacitance

Transformer (ट्रांसफॉर्मर)

कम वोल्टेज को उच्च वोल्टेज (या इसके विपरीत) बदलने की युक्ति।

Induced EMF: ε = - (dΦ / dt)

Voltage Ratio: (εs / εp) = (Ns / Np)

For 100% Efficiency: Is Vs = Ip Vp => (Is / Ip) = (Np / Ns)

Step-up Transformer (उचायी)

• Voltage बढ़ाता है

• Ns > N_p , Vs > Vp

Step-down Transformer (अपचायी)

• Voltage घटाता है

• Ns < Np , Vs < Vp

अक्षरों का मतलब (Notations):

• εs & εp = Secondary & Primary EMF (द्वितीयक और प्राथमिक विद्युत वाहक बल)

• Ns & Np = Number of Turns in Secondary & Primary Coil (कुंडली के फेरों की संख्या)

• Is & Ip = Secondary & Primary Current (धारा)

Chapter 7: Alternating Current

Quick Revision Notes • Concepts, Definitions & Derivations

01

Alternating Current (AC)

It is that current which varies in magnitude continuously and reverses its direction periodically. Its value at any instant is given by:

I = I0 sin(ωt) = I0 sin(2πft)

Notations:

• I0 = Peak value of a.c. or Current Amplitude (शिखर मान या आयाम)

• f = Frequency of a.c. supplied to homes is 50 cps (हर्ट्ज)

• Note: The average value of a.c. over a complete cycle is always zero.

02

Direct Current (DC)

It is that electric current which flows with a constant magnitude in the same fixed direction without changing polarity over time.

03

Average or Mean Value of A.C. (Iav)

It is that value of direct current which sends the same charge in a circuit in the same time as is sent by the given alternating current in its half time period.

Iav = (2 / π) I0 = 0.637 I0
04

Effective, RMS, or Virtual Value of A.C. (Irms)

It is that value of direct current which produces the same heating effect in a given resistor as is produced by the given alternating current when passed for the same time.

Irms = Ieff = Iv = (1 / √2) I0 = 0.707 I0
05

Alternating Voltage

It is that voltage whose magnitude varies continuously and direction reverses periodically with time. Its equations are:

ε = ε0 sin(ωt)   |   εav = 0.637 ε0   |   εrms = (1 / √2) ε0

Notations:

• ε0 = Peak value of alternating voltage (शिखर वोल्टेज)

06

Phasors and Phasor Diagrams

A rotating vector that represents a sinusoidally varying quantity is called a phasor. A diagram representing alternating current and voltage of the same frequency as rotating vectors with proper phase angle between them is a phasor diagram or Argand diagram.

07

A.C. Circuit Containing Resistor Only

An alternating voltage ε = ε0 sin(ωt) applied to a resistor R drives a current I = I0 sin(ωt) in it. The current is in phase with the applied voltage.

Peak value of current: I0 = ε0 / R
08

A.C. Circuit Containing Inductor Only

An alternating voltage applied to a pure inductor L drives a current that lags behind the voltage in phase by π/2 radian (90°).

I = I0 sin(ωt - π/2)    |    I0 = ε0 / XL = ε0 / (ωL)
Irms = εrms / XL = εrms / (ωL) = ε0 / (√2 · ωL)
09

Reactance

The non-resistive opposition to the flow of a.c. is called reactance. It may be inductive reactance (XL) or capacitive reactance (Xc).

10

Inductive Reactance (XL)

It is the effective resistance or opposition offered by an inductor to the flow of a.c. through it.

XL = ωL = 2πfL

Key Points:

• SI unit is ohm (Ω).

• For a.c.: XL ∝ f (Frequency ke direct proportional).

• For d.c.: f = 0, so XL = 0 (Direct current ke liye inductor zero resistance deta hai).

11

A.C. Circuit Containing Only a Capacitor

When an alternating voltage ε = ε0 sin(ωt) is applied across a pure capacitor C, it drives an alternating current. Here, the current leads the voltage in phase by a precise angle of π/2 radians (90°).

I = I0 sin(ωt + π/2)   |   Peak Current: I0 = ε0 / Xc = ε0 / (1 / ωC)
RMS Current: Irms = εrms / Xc = εrms / (1 / ωC) = ε0 / (√2 · (1 / ωC))
12

Capacitive Reactance (Xc)

It is defined as the effective resistance or opposition offered by a capacitor to the smooth flow of alternating current (a.c.) through it.

Xc = 1 / (ωC) = 1 / (2πfC)

Deep Insights & Behavior:

• SI Unit: ohm (Ω)

• For A.C.: Xc ∝ (1 / f) (Frequency ke inverse proportional hota hai).

• For D.C.: Frequency f = 0, hence Xc = ∞ (Infinity). यानी capacitor direct current (d.c.) को पूरी तरह से block कर देता है और a.c. को आसानी से पास होने देता है।

13

Impedance (Z) & Impedance Triangle

Impedance is the total effective opposition offered by an a.c. circuit (containing R, L, or C in various combinations) to the flow of alternating current.

Z2 = R2 + X2   &implies;   Z = √(R2 + X2)

Impedance Triangle Concept:

It is a right-angled triangle where the base represents Resistance (R), the perpendicular represents Reactance (X), and the hypotenuse represents Total Impedance (Z) of the circuit. The phase angle (φ) between voltage and current is given by:

tan(φ) = X / R   OR   cos(φ) = R / Z

14

A.C. Through a Series LR Circuit

In an alternating circuit containing a resistor (R) and an inductor (L) connected in series, the alternating voltage leads the current by a definite phase angle (φ).

Voltage: ε = ε0 sin(ωt)   |   Current: I = I0 sin(ωt - φ)
Peak Current: I0 = ε0 / Z   |   Impedance: Z = √(R2 + XL2) = √(R2 + ω2L2)

Phase Angle Relationship:

tan(φ) = XL / R   OR   cos(φ) = R / Z

15

A.C. Through a Series CR Circuit

In a circuit containing a capacitor (C) and a resistor (R) in series, the alternating voltage lags behind the current by a specific phase angle (φ).

Voltage: ε = ε0 sin(ωt)   |   Current: I = I0 sin(ωt + φ)
Peak Current: I0 = ε0 / Z   |   Impedance: Z = √(R2 + Xc2) = √(R2 + (1 / ω2C2))

Phase Angle Relationship:

tan(φ) = Xc / R   OR   cos(φ) = R / Z

16

The Complete Series LCR Circuit

When a resistor (R), an inductor (L), and a capacitor (C) are connected in series across an a.c. source ε = ε0 sin(ωt), the net opposition (Impedance Z) combines all three components.

Z = √[ R2 + (XL - Xc)2 ] = √[ R2 + (ωL - (1 / ωC))2 ]
Phase Angle: tan(φ) = (XL - Xc) / R   |   Power Factor: cos(φ) = R / Z

Nature of Circuit (Leads/Lags):

• If XL > Xc, voltage leads the current (inductive nature).

• If XL < Xc, voltage lags behind the current (capacitive nature).

17

Resonance Condition of LCR Circuit

Resonance occurs in a series LCR circuit when the inductive reactance equals the capacitive reactance (XL = Xc).

At Resonance: Z = √(R2 + 0) = R (Impedance is minimum, Current is maximum!)
Resonant Frequency (fr): fr = 1 / (2π√LC)

Core Characteristics at Resonance:

• The circuit behaves as a purely resistive circuit.

• Voltage and current are completely in the same phase (φ = 0, cos(φ) = 1).

• Current amplitude reaches its absolute maximum value.

18

Q-Factor (Quality Factor)

It indicates the sharpness of resonance in a series LCR circuit. It is fundamentally defined as the ratio of the resonant frequency to the bandwidth.

Q-factor = Resonant Frequency / Bandwidth = (ωr / (ω2 - ω1)) = (ωr L / R) = (1 / R) √(L / C)

Core Meaning:

• Higher the Q-factor, sharper is the resonance curve and better is the selectivity of the circuit.

• ωr = Resonant frequency, (ω2 - ω1) = Bandwidth (half-power frequencies difference).

19

Average Power in an A.C. Circuit

The true average power consumed per complete cycle in an a.c. circuit depends not just on voltage and current, but also on the phase angle between them.

Pav = εrms · Irms · cos(φ) = (ε0 I0 / 2) cos(φ)

Power Factor & Special Cases:

• Power Factor (cos φ): It is the ratio of true power (Pav) to the apparent power (εrms Irms). Formula: cos(φ) = R / Z = R / √(R2 + (ωL - 1/ωC)2)

• (i) Pure Resistive Circuit: φ = 0  &implies;  Pav = εrms Irms (Maximum power).

• (ii) Pure Inductive Circuit: φ = π/2  &implies;  Pav = 0 (Zero power consumption).

• (iii) Pure Capacitive Circuit: φ = -π/2  &implies;  Pav = 0 (Zero power consumption).

20

Wattless Current (हीन शक्ति धारा)

The current in an a.c. circuit is said to be wattless if the average power consumed by it over a complete cycle is zero.

Wattless Component = Irms sin(φ)

Condition: In a purely inductive or purely capacitive circuit, the phase difference is φ = ±π/2. Since cos(π/2) = 0, the power factor becomes zero, resulting in a completely wattless current.

21

Magnetic Energy Stored in an Inductor

When the electric current flowing through an inductor grows from zero to a peak value I0, work is done against the back-EMF, which gets stored as magnetic potential energy inside the inductor field.

U = (1 / 2) L I02

Notations: L = Self-inductance (स्व-प्रेरकत्व), I0 = Maximum current.

22

Electrostatic Energy Stored in a Capacitor

When a capacitor is charged from 0 to V volts, electrical energy is stored within its electric field between the conducting plates.

U = (1 / 2) C V2 = (1 / 2) Q V = (1 / 2) · (Q2 / C)

Notations: C = Capacitance, V = Potential difference, Q = Stored charge.

23

LC-Oscillations & Free Frequency

When a charged capacitor is connected across an inductor, electrical oscillations of constant amplitude and frequency are produced. The charge (q) on the capacitor satisfies the simple harmonic motion (SHM) differential equation:

(d2q / dt2) + (1 / LC) q = 0
Instantaneous Charge: q = q0 cos(ω0t)   |   Current: I = - (dq / dt) = ω0q0 sin(ω0t)

Frequencies of Free Oscillations:

• Angular Frequency (ω0): ω0 = 1 / √(LC)

• Linear Frequency (f0): f0 = ω0 / (2π) = 1 / (2π √(LC))

• Note: Total electromagnetic energy in an ideal LC circuit remains strictly constant, oscillating back and forth between the capacitor and inductor.

24

Choke Coil (चोक कुंडली)

A choke coil is a specialized inductor possessing a very large self-inductance and negligible resistance. It is primarily used to control or reduce current in an a.c. circuit without any significant loss of power (since its power factor cos(φ) ≈ 0).

25

Transformer (ट्रांसफॉर्मर)

It is a static electrical device used to convert low alternating voltage at high current into high alternating voltage at low current (or vice-versa) based on mutual induction.

For an Ideal Transformer: (ε2 / ε1) = (I1 / I2) = (N2 / N1) = k

Core Parameters & Types:

• k = Transformation ratio or turns ratio. Suffix 1 represents the primary coil and 2 represents the secondary coil.

• (i) Step-up Transformer (उचायी): k > 1 or N2 > N1  &implies;  ε2 > ε1 and I2 < I1 (Voltage badhata hai).

• (ii) Step-down Transformer (अपचायी): k < 1 or N2 < N1  &implies;  ε2 < ε1 and I2 > I1 (Voltage ghataata hai).

26

A.C. Generator / Alternator

It is an electromechanical device used to convert mechanical energy into electrical energy in the form of alternating current. It works on the principle of Electromagnetic Induction.

Magnetic Flux Linked: φ = N B A cos(ωt)   |   Induced EMF: ε = N B A ω sin(ωt) = ε0 sin(ωt)
Generated Current: I = (N B A ω / R) sin(ωt) = I0 sin(ωt)

Notations:

• N = Number of turns in the rotating armature coil.

• B = Uniform magnetic field strength, A = Area of the coil face.

• ω = Angular velocity of rotation, R = Total circuit resistance, ε0 = Peak EMF (= NBAω).
