Open Chapter 02: Inverse Trigonometric Functions

Chapter Overview

Inverse Trigonometric Functions are essential tools in higher mathematics, providing a way to find angles when the trigonometric ratios are known. Unlike trigonometric functions which output a ratio for a given angle, inverse trigonometric functions take a ratio as input and return the corresponding angle. Since trigonometric functions are periodic, their inverses are multi-valued. To make them functions, their domains are restricted to their 'principal value branches'. This chapter explores these functions, their properties, graphs, and applications, crucial for CBSE board examinations.

Key Definitions & Principal Value Branches

1. Inverse Sine Function ($\sin^{-1}x$)

The function $f(x) = \sin^{-1}x$ (also written as $\arcsin x$) is the inverse of the sine function. Its domain is $[-1, 1]$ and its principal value branch (range) is $[-\frac{\pi}{2}, \frac{\pi}{2}]$.

i.e., if $\sin y = x$, then $y = \sin^{-1}x$, where $y \in [-\frac{\pi}{2}, \frac{\pi}{2}]$ and $x \in [-1, 1]$.

2. Inverse Cosine Function ($\cos^{-1}x$)

The function $f(x) = \cos^{-1}x$ (or $\arccos x$) is the inverse of the cosine function. Its domain is $[-1, 1]$ and its principal value branch (range) is $[0, \pi]$.

i.e., if $\cos y = x$, then $y = \cos^{-1}x$, where $y \in [0, \pi]$ and $x \in [-1, 1]$.

3. Inverse Tangent Function ($\tan^{-1}x$)

The function $f(x) = \tan^{-1}x$ (or $\arctan x$) is the inverse of the tangent function. Its domain is $(-\infty, \infty)$ and its principal value branch (range) is $(-\frac{\pi}{2}, \frac{\pi}{2})$.

i.e., if $\tan y = x$, then $y = \tan^{-1}x$, where $y \in (-\frac{\pi}{2}, \frac{\pi}{2})$ and $x \in \mathbb{R}$.

4. Inverse Cosecant Function ($\csc^{-1}x$)

The domain of $f(x) = \csc^{-1}x$ is $(-\infty, -1] \cup [1, \infty)$ and its principal value branch (range) is $[-\frac{\pi}{2}, \frac{\pi}{2}] - \{0\}$.

5. Inverse Secant Function ($\sec^{-1}x$)

The domain of $f(x) = \sec^{-1}x$ is $(-\infty, -1] \cup [1, \infty)$ and its principal value branch (range) is $[0, \pi] - \{\frac{\pi}{2}\}$.

6. Inverse Cotangent Function ($\cot^{-1}x$)

The domain of $f(x) = \cot^{-1}x$ is $(-\infty, \infty)$ and its principal value branch (range) is $(0, \pi)$.

Essential Formulas & Theorems

Properties of Inverse Trigonometric Functions

I. Inverse Identities with Negative Arguments:

  • $\sin^{-1}(-x) = -\sin^{-1}x$, for $x \in [-1, 1]$
  • $\tan^{-1}(-x) = -\tan^{-1}x$, for $x \in \mathbb{R}$
  • $\csc^{-1}(-x) = -\csc^{-1}x$, for $|x| \ge 1$
  • $\cos^{-1}(-x) = \pi - \cos^{-1}x$, for $x \in [-1, 1]$
  • $\sec^{-1}(-x) = \pi - \sec^{-1}x$, for $|x| \ge 1$
  • $\cot^{-1}(-x) = \pi - \cot^{-1}x$, for $x \in \mathbb{R}$

II. Complementary Identities:

  • $\sin^{-1}x + \cos^{-1}x = \frac{\pi}{2}$, for $x \in [-1, 1]$
  • $\tan^{-1}x + \cot^{-1}x = \frac{\pi}{2}$, for $x \in \mathbb{R}$
  • $\csc^{-1}x + \sec^{-1}x = \frac{\pi}{2}$, for $|x| \ge 1$

III. Conversion Identities:

  • $\sin^{-1}x = \csc^{-1}\frac{1}{x}$, for $x \in [-1, 1], x \ne 0$
  • $\cos^{-1}x = \sec^{-1}\frac{1}{x}$, for $x \in [-1, 1], x \ne 0$
  • $\tan^{-1}x = \cot^{-1}\frac{1}{x}$, for $x > 0$
  • $\tan^{-1}x = \sin^{-1}\left(\frac{x}{\sqrt{1+x^2}}\right) = \cos^{-1}\left(\frac{1}{\sqrt{1+x^2}}\right)$

IV. Sum and Difference Formulas (for $\tan^{-1}x$):

  • $\tan^{-1}x + \tan^{-1}y = \tan^{-1}\left(\frac{x+y}{1-xy}\right)$, for $xy < 1$
  • $\tan^{-1}x - \tan^{-1}y = \tan^{-1}\left(\frac{x-y}{1+xy}\right)$, for $xy > -1$
  • $2\tan^{-1}x = \tan^{-1}\left(\frac{2x}{1-x^2}\right)$, for $|x| < 1$
  • $2\tan^{-1}x = \sin^{-1}\left(\frac{2x}{1+x^2}\right)$, for $|x| \le 1$
  • $2\tan^{-1}x = \cos^{-1}\left(\frac{1-x^2}{1+x^2}\right)$, for $x \ge 0$

Important CBSE Board Exam Standard Questions

Question 1: Prove that $2\tan^{-1}\frac{1}{2} + \tan^{-1}\frac{1}{7} = \tan^{-1}\frac{31}{17}$.

Solution:

We use the formula $2\tan^{-1}x = \tan^{-1}\left(\frac{2x}{1-x^2}\right)$ and $\tan^{-1}x + \tan^{-1}y = \tan^{-1}\left(\frac{x+y}{1-xy}\right)$.

LHS $= 2\tan^{-1}\frac{1}{2} + \tan^{-1}\frac{1}{7}$

First, apply the double angle formula for $\tan^{-1}x$ with $x = \frac{1}{2}$:

$$2\tan^{-1}\frac{1}{2} = \tan^{-1}\left(\frac{2 \times \frac{1}{2}}{1 - (\frac{1}{2})^2}\right)$$ $$ = \tan^{-1}\left(\frac{1}{1 - \frac{1}{4}}\right)$$ $$ = \tan^{-1}\left(\frac{1}{\frac{3}{4}}\right)$$ $$ = \tan^{-1}\frac{4}{3}$$

Now substitute this back into the LHS:

$$\text{LHS} = \tan^{-1}\frac{4}{3} + \tan^{-1}\frac{1}{7}$$

Next, apply the sum formula for $\tan^{-1}x + \tan^{-1}y$ with $x = \frac{4}{3}$ and $y = \frac{1}{7}$. Since $xy = \frac{4}{3} \times \frac{1}{7} = \frac{4}{21} < 1$, the formula is applicable:

$$ = \tan^{-1}\left(\frac{\frac{4}{3} + \frac{1}{7}}{1 - \frac{4}{3} \times \frac{1}{7}}\right)$$ $$ = \tan^{-1}\left(\frac{\frac{28+3}{21}}{1 - \frac{4}{21}}\right)$$ $$ = \tan^{-1}\left(\frac{\frac{31}{21}}{\frac{21-4}{21}}\right)$$ $$ = \tan^{-1}\left(\frac{\frac{31}{21}}{\frac{17}{21}}\right)$$ $$ = \tan^{-1}\frac{31}{17}$$

Thus, LHS = RHS. Hence Proved.

Question 2: Solve for $x$: $\tan^{-1}(2x) + \tan^{-1}(3x) = \frac{\pi}{4}$.

Solution:

Given equation is $\tan^{-1}(2x) + \tan^{-1}(3x) = \frac{\pi}{4}$.

Apply the formula $\tan^{-1}A + \tan^{-1}B = \tan^{-1}\left(\frac{A+B}{1-AB}\right)$:

$$\tan^{-1}\left(\frac{2x + 3x}{1 - (2x)(3x)}\right) = \frac{\pi}{4}$$ $$\tan^{-1}\left(\frac{5x}{1 - 6x^2}\right) = \frac{\pi}{4}$$

Take $\tan$ on both sides:

$$\frac{5x}{1 - 6x^2} = \tan\left(\frac{\pi}{4}\right)$$ $$\frac{5x}{1 - 6x^2} = 1$$

Cross-multiply:

$$5x = 1 - 6x^2$$ $$6x^2 + 5x - 1 = 0$$

This is a quadratic equation. We can solve it by factoring:

$$6x^2 + 6x - x - 1 = 0$$ $$6x(x+1) - 1(x+1) = 0$$ $$(6x-1)(x+1) = 0$$

This gives two possible solutions for $x$:

$$6x - 1 = 0 \Rightarrow x = \frac{1}{6}$$ $$x + 1 = 0 \Rightarrow x = -1$$

We must check these solutions in the original equation to ensure they are valid (i.e., satisfy the condition $AB < 1$ for the formula used, and the arguments of $\tan^{-1}$ are within their domains, which is always true for real numbers). The condition for $\tan^{-1}A + \tan^{-1}B = \tan^{-1}\left(\frac{A+B}{1-AB}\right)$ is $AB < 1$. Here $A=2x, B=3x$, so $AB=6x^2$.

For $x = \frac{1}{6}$:

$$6x^2 = 6\left(\frac{1}{6}\right)^2 = 6 \times \frac{1}{36} = \frac{1}{6}$$ Since $\frac{1}{6} < 1$, $x = \frac{1}{6}$ is a valid solution.

For $x = -1$:

$$6x^2 = 6(-1)^2 = 6$$ Since $6 \not< 1$, $x = -1$ is not a valid solution for the principal value branch application of the formula which results in $\pi/4$. Alternatively, plugging $x=-1$ into the original equation: $\tan^{-1}(-2) + \tan^{-1}(-3) = -\tan^{-1}(2) - \tan^{-1}(3)$, which is a negative angle, not $\pi/4$.

Therefore, the only valid solution is $x = \frac{1}{6}$.

Question 3: Find the principal value of $\cos^{-1}\left(-\frac{1}{2}\right)$.

Solution:

Let $y = \cos^{-1}\left(-\frac{1}{2}\right)$.

By definition, this means $\cos y = -\frac{1}{2}$.

The principal value branch of $\cos^{-1}x$ is $[0, \pi]$.

We know that $\cos\left(\frac{\pi}{3}\right) = \frac{1}{2}$.

Since $\cos y$ is negative, $y$ must lie in the second quadrant where cosine is negative. We use the property $\cos^{-1}(-x) = \pi - \cos^{-1}x$.

So, $\cos^{-1}\left(-\frac{1}{2}\right) = \pi - \cos^{-1}\left(\frac{1}{2}\right)$.

Since $\cos^{-1}\left(\frac{1}{2}\right) = \frac{\pi}{3}$, we have:

$$y = \pi - \frac{\pi}{3}$$ $$y = \frac{3\pi - \pi}{3}$$ $$y = \frac{2\pi}{3}$$

Since $\frac{2\pi}{3} \in [0, \pi]$, this is the principal value.

The principal value of $\cos^{-1}\left(-\frac{1}{2}\right)$ is $\frac{2\pi}{3}$.

Quick Revision Summary

  • Principal Value Branches: Remember the restricted ranges for each inverse trigonometric function. These are crucial for solving problems and finding principal values.
  • Negative Argument Identities: Pay attention to the difference between $\sin^{-1}(-x) = -\sin^{-1}x$ type identities and $\cos^{-1}(-x) = \pi - \cos^{-1}x$ type identities.
  • Complementary & Conversion Formulas: Understand how $\sin^{-1}x + \cos^{-1}x = \pi/2$ and how to convert between different inverse functions (e.g., $\tan^{-1}x$ to $\sin^{-1}$ or $\cos^{-1}$ using a right-angled triangle).
  • Sum/Difference Formulas: The $\tan^{-1}x \pm \tan^{-1}y$ formulas are frequently tested. Always check the condition $xy < 1$ (or $xy > -1$) for these formulas to directly yield the principal value.
  • Solving Equations: When solving equations involving inverse trigonometric functions, remember to verify the solutions against the domain restrictions and conditions for the formulas used.
  • $2\tan^{-1}x$ Formulas: Know the three equivalent forms for $2\tan^{-1}x$ in terms of $\tan^{-1}$, $\sin^{-1}$, and $\cos^{-1}$.
