Definition and principal values of inverse trigonometric functions

Definition and Principal Values of Inverse Trigonometric Functions

The inverse trigonometric functions are defined as the inverse relations of the trigonometric functions restricted to intervals where they are one‑to‑one. For a real number $x$ in the domain of the function, the principal value is the unique $y$ in the specified range satisfying the defining equation.

Principal Value Intervals (SI units – radians)

  • $\arcsin x$ : $x\in[-1,1]$, $y\in[-\frac{\pi}{2},\frac{\pi}{2}]$
  • $\arccos x$ : $x\in[-1,1]$, $y\in[0,\pi]$
  • $\arctan x$ : $x\in\mathbb{R}$, $y\in(-\frac{\pi}{2},\frac{\pi}{2})$

Derivation of $\arcsin x$

Let $y=\arcsin x$. By definition, $\sin y=x$ and $y\in[-\frac{\pi}{2},\frac{\pi}{2}]$. Differentiating implicitly gives $\frac{dy}{dx}=\frac{1}{\sqrt{1-x^{2}}}$, valid for $x\in(-1,1)$. The domain restriction ensures the square root is real and the function is monotonic.

Edge Cases

  • $x=\pm1$ : $\arcsin(\pm1)=\pm\frac{\pi}{2}$, $\arccos(\pm1)=0,\pi$ respectively.
  • $x\notin[-1,1]$ : inverse functions are undefined in the real domain.

Example

Find $\arcsin\frac{1}{2}$ and $\arccos\frac{1}{2}$.

1. $\sin y=\frac{1}{2}$ with $y\in[-\frac{\pi}{2},\frac{\pi}{2}]$. The only solution is $y=\frac{\pi}{6}$. Hence $\arcsin\frac{1}{2}=\frac{\pi}{6}$.

2. $\cos y=\frac{1}{2}$ with $y\in[0,\pi]$. The solution is $y=\frac{\pi}{3}$. Thus $\arccos\frac{1}{2}=\frac{\pi}{3}$.

These values satisfy the principal value ranges and illustrate the one‑to‑one restriction.

Domain, range and restrictions for each inverse function

Definition of Inverse Trig Functions

For a function $f$ that is one‑to‑one on an interval $I$, its inverse $f^{-1}$ satisfies $f(f^{-1}(y))=y$ for $y\in f(I)$. For trigonometric functions we restrict the domain to make them bijective.

Derivation of Restrictions

  • Arcsin: $\sin x$ is bijective on $[-\frac{\pi}{2},\frac{\pi}{2}]$. Hence $\arcsin x$ maps $[-1,1]$ to this interval.
  • Arccos: $\cos x$ is bijective on $[0,\pi]$. Thus $\arccos x$ has range $[0,\pi]$.
  • Arctan: $\tan x$ is strictly increasing on $(-\frac{\pi}{2},\frac{\pi}{2})$ and covers $\mathbb{R}$, giving the stated range.
  • Arccot: $\cot x$ is decreasing on $(0,\pi)$ and covers $\mathbb{R}$.
  • Arcsec: $\sec x$ is bijective on $[0,\pi]\setminus\{\frac{\pi}{2}\}$ with $\sec x\ge1$ or $\le-1$; its inverse therefore has the indicated domain and range.
  • Arccsc: Similar reasoning using $\csc x$ on $[-\frac{\pi}{2},\frac{\pi}{2}]\setminus\{0\}$.

Example

Find $\arcsin\frac{1}{2}$.

Since $\sin\frac{\pi}{6}=\frac{1}{2}$ and $\frac{\pi}{6}\in[-\frac{\pi}{2},\frac{\pi}{2}]$, we have $\arcsin\frac{1}{2}=\frac{\pi}{6}$.

Check: $\sin\frac{\pi}{6}=\frac{1}{2}$, confirming the result.

  1. Start with $y=\sin x$ on $[-\frac{\pi}{2},\frac{\pi}{2}]$, where the function is one‑to‑one.
  2. Swap the roles of $x$ and $y$ (reflection about the line $y=x$).
  3. The resulting curve passes through $(-1,-\frac{\pi}{2})$, $(0,0)$ and $(1,\frac{\pi}{2})$ and is monotonic increasing.

Similar reflections give the graphs of the other inverses. Key features:

  • All graphs are continuous on their domains.
  • Endpoints correspond to the extreme values of the original trig function.
  • Vertical asymptotes appear for $\csc^{-1}x$, $\sec^{-1}x$, $\cot^{-1}x$ at $x=0$ after reflection.

  • At $x=\pm1$, $\sin^{-1}x$ and $\cos^{-1}x$ attain their maximum/minimum values.
  • For $\tan^{-1}x$, as $x\to\pm\infty$, $y\to\pm\frac{\pi}{2}$ (horizontal asymptotes).

Example

Solve $\sin^{-1}x+\cos^{-1}x=\frac{\pi}{2}$.

  1. Let $\theta=\sin^{-1}x$, then $\sin\theta=x$ and $\theta\in\left[-\frac{\pi}{2},\frac{\pi}{2}\right]$.
  2. Using the definition of inverse cosine, $\cos^{-1}x=\frac{\pi}{2}-\theta$ because $\cos(\frac{\pi}{2}-\theta)=\sin\theta=x$.
  3. Substituting, $\theta+\left(\frac{\pi}{2}-\theta\right)=\frac{\pi}{2}$, which holds for every $\theta$ in the domain.
  4. Hence the original equation is an identity; the solution set is $x\in[-1,1]$.

All inverse trigonometric graphs are plotted in radians (SI unit for angle). The symmetry and monotonicity derived above help in sketching accurate curves for examination.

Relations between trigonometric and inverse trigonometric functions

Definition

For a real number $x$ in the interval $[-1,1]$, the inverse sine function is defined as the unique angle $y$ in $[-\frac{\pi}{2},\frac{\pi}{2}]$ such that $\sin y = x$. Symbolically, $y = \arcsin x$. Similarly, $\arccos x$ is defined for $x\in[-1,1]$ with range $[0,\pi]$, and $\arctan x$ is defined for all real $x$ with range $(-\frac{\pi}{2},\frac{\pi}{2})$.

Derivation of Derivatives

Let $y = \arcsin x$. Then $\sin y = x$. Differentiating implicitly: $\cos y\,\frac{dy}{dx} = 1$, hence $\displaystyle \frac{dy}{dx} = \frac{1}{\cos y} = \frac{1}{\sqrt{1-\sin^2 y}} = \frac{1}{\sqrt{1-x^2}}$. Thus, $$\frac{d}{dx}\arcsin x = \frac{1}{\sqrt{1-x^2}}.$$ Analogous steps give $$\frac{d}{dx}\arccos x = -\frac{1}{\sqrt{1-x^2}},\qquad \frac{d}{dx}\arctan x = \frac{1}{1+x^2}.$$

SI Units and Edge Cases

All angles are measured \in radians. The domain and range restrictions ensure continuity and single‑valuedness. At the endpoints $x=\pm1$ for $\arcsin$ and $\arccos$, the derivative tends \to $\pm\infty$, reflecting vertical tangents.

Relations Between Trigonometric and Inverse Functions

For any $x$ \in the domain, the following identities hold:

$\sin(\arcsin x)$$=x$
$\cos(\arcsin x)$$=\sqrt{1-x^2}$
$\tan(\arcsin x)$$=\frac{x}{\sqrt{1-x^2}}$

Example

Find $\arcsin\frac{1}{2}$.

Since $\sin\frac{\pi}{6}=\frac{1}{2}$ and $\frac{\pi}{6}\in[-\frac{\pi}{2},\frac{\pi}{2}]$, we have $\arcsin\frac{1}{2}=\frac{\pi}{6}$. Using the derivative, the slope at this point is $\displaystyle \frac{1}{\sqrt{1-(\frac{1}{2})^2}}=\frac{2}{\sqrt{3}}$.

Derivatives of inverse trigonometric functions

Definition: The inverse trigonometric function $y=\sin^{-1}x$ (principal value) is defined for $x\in[-1,1]$ such that $\sin y = x$ and $y\in[-\frac{\pi}{2},\frac{\pi}{2}]$. Similar definitions hold for $\cos^{-1}x$ ($y\in[0,\pi]$) and $\tan^{-1}x$ ($y\in(-\frac{\pi}{2},\frac{\pi}{2})$).

Derivative Derivation (General Method):

  • Let $y=\sin^{-1}x$. Then $\sin y = x$.
  • Differentiate implicitly w.r.t. $x$: $\cos y\,\frac{dy}{dx}=1$.
  • Using $\cos y = \sqrt{1-\sin^{2}y}=\sqrt{1-x^{2}}$ (positive root in the principal range), we obtain $$\frac{dy}{dx}=\frac{1}{\sqrt{1-x^{2}}}.$$

Repeating the same steps for the other inverses gives the standard results:

FunctionDerivativeDomain of $x$
$\sin^{-1}x$$\frac{1}{\sqrt{1-x^{2}}}$$-1\le x\le 1$
$\cos^{-1}x$$-\frac{1}{\sqrt{1-x^{2}}}$$-1\le x\le 1$
$\tan^{-1}x$$\frac{1}{1+x^{2}}$$-\infty
$\cot^{-1}x$$-\frac{1}{1+x^{2}}$$-\infty
$\sec^{-1}x$$\frac{1}{|x|\sqrt{x^{2}-1}}$$|x|\ge1$
$\csc^{-1}x$$-\frac{1}{|x|\sqrt{x^{2}-1}}$$|x|\ge1$

Units: Since the argument $x$ is dimensionless (ratio of lengths), the derivative has units of $\text{rad}^{-1}$, i.e., change \in \angle per unit change \in $x$.

Edge Cases & Remarks:

  • At $x=\pm1$, $\frac{d}{dx}\sin^{-1}x$ and $\frac{d}{dx}\cos^{-1}x$ become infinite \because the denominator $\sqrt{1-x^{2}}$ vanishes.
  • For $\sec^{-1}x$ and $\csc^{-1}x$, the absolute value $|x|$ ensures the derivative is positive for $x>1$ and negative for $x<-1$, respecting the principal branches.
  • Chain rule can be applied: if $y=\sin^{-1}(u(x))$, then $\frac{dy}{dx}=\frac{u'(x)}{\sqrt{1-u^{2}(x)}}$, provided $|u(x)|<1$.

Example: Find $\frac{d}{dx}\big[\sin^{-1}\left(\frac{2x}{1+x^{2}}\right)\big]$.

Solution:

  1. Let $u=\frac{2x}{1+x^{2}}$. Then $y=\sin^{-1}u$.
  2. Compute $u'$: $u' = \frac{2(1+x^{2})-2x(2x)}{(1+x^{2})^{2}} = \frac{2-2x^{2}}{(1+x^{2})^{2}} = \frac{2(1-x^{2})}{(1+x^{2})^{2}}$.
  3. Apply the chain rule: $\frac{dy}{dx}=\frac{u'}{\sqrt{1-u^{2}}}$.
  4. Note that $1-u^{2}=1-\left(\frac{2x}{1+x^{2}}\right)^{2}=\frac{(1-x^{2})^{2}}{(1+x^{2})^{2}}$.
  5. Thus $\sqrt{1-u^{2}}=\frac{|1-x^{2}|}{1+x^{2}}$. In the principal interval $-10$, so $\sqrt{1-u^{2}}=\frac{1-x^{2}}{1+x^{2}}$.
  6. Finally, $\frac{dy}{dx}=\frac{\frac{2(1-x^{2})}{(1+x^{2})^{2}}}{\frac{1-x^{2}}{1+x^{2}}}=\frac{2}{1+x^{2}}$.

Hence, $\displaystyle \frac{d}{dx}\sin^{-1}\left(\frac{2x}{1+x^{2}}\right)=\frac{2}{1+x^{2}}$, which matches the derivative of $\tan^{-1}x$ after simplification.

Integration formulas involving inverse trigonometric functions

Definition of Inverse Trigonometric Functions

For $-1\le x\le 1$, the principal values are defined as:

  • $\arcsin x$ is the unique $\theta\in[-\frac{\pi}{2},\frac{\pi}{2}]$ such that $\sin\theta=x$.
  • $\arccos x$ is the unique $\theta\in[0,\pi]$ such that $\cos\theta=x$.
  • $\arctan x$ is the unique $\theta\in(-\frac{\pi}{2},\frac{\pi}{2})$ such that $\tan\theta=x$.

Integration Formulas

Using integration by parts ($u$–$dv$) one obtains:

  • $\int\arcsin x\,dx = x\arcsin x + \sqrt{1-x^{2}} + C$.
  • $\int\arccos x\,dx = x\arccos x - \sqrt{1-x^{2}} + C$.
  • $\int\arctan x\,dx = x\arctan x - \tfrac{1}{2}\ln(1+x^{2}) + C$.

Derivation of the first formula: let $u=\arcsin x$, $dv=dx$. Then $du=\frac{1}{\sqrt{1-x^{2}}}dx$ and $v=x$. Hence $\int\arcsin x\,dx = x\arcsin x - \int\frac{x}{\sqrt{1-x^{2}}}dx$. Substituting $t=1-x^{2}$ gives $\int\frac{x}{\sqrt{1-x^{2}}}dx = -\sqrt{1-x^{2}}$. Adding the terms yields the stated result.

SI Units & Edge Cases

  • Variable $x$ is dimensionless; the integral has the same unit as $x$ (e.g., radians).
  • Domain restrictions: $-1\le x\le 1$ for arcsin and arccos; all real $x$ for arctan.
  • At the endpoints $x=\pm1$, the square‑root term vanishes, simplifying the expressions.

Example

Compute $\int\arcsin(2x)\,dx$ for $|x|\le\tfrac{1}{2}$.

Let $u=\arcsin(2x)$, $dv=dx$. Then $du=\frac{2}{\sqrt{1-4x^{2}}}dx$, $v=x$. Thus $\int\arcsin(2x)dx = x\arcsin(2x) - \int\frac{2x}{\sqrt{1-4x^{2}}}dx$. With substitution $t=1-4x^{2}$, $dt=-8x,dx$, we get $\int\frac{2x}{\sqrt{1-4x^{2}}}dx = -\tfrac{1}{2}\sqrt{1-4x^{2}}$. Finally, $\int\arcsin(2x)dx = x\arcsin(2x) + \tfrac{1}{2}\sqrt{1-4x^{2}} + C$.

Solving equations using inverse trigonometric functions

Definition: The inverse trigonometric function $\\sin^{-1}x$ (also written $\\arcsin x$) gives the principal angle $\\theta$ whose sine equals $x$, i.e., $\\sin\\theta = x$ with $-\\frac{\\pi}{2}\\le\\theta\\le\\frac{\\pi}{2}$. Similar definitions hold for $\\cos^{-1}x$ ($\\arccos x$) and $\\tan^{-1}x$ ($\\arctan x$) with their respective principal ranges.

General solution of a basic trig equation:

  • For $\\sin\\theta = k$, $\\theta = \\sin^{-1}k + 2n\\pi$ or $\\theta = \\pi - \\sin^{-1}k + 2n\\pi$, $n\\in\\mathbb{Z}$.
  • For $\\cos\\theta = k$, $\\theta = \\cos^{-1}k + 2n\\pi$ or $\\theta = -\\cos^{-1}k + 2n\\pi$.
  • For $\\tan\\theta = k$, $\\theta = \\tan^{-1}k + n\\pi$, $n\\in\\mathbb{Z}$.

Derivation using inverse functions: Starting from $\\sin\\theta = k$, apply $\\sin^{-1}$ on both sides: $\\sin^{-1}(\\sin\\theta)=\\sin^{-1}k$. Because $\\sin^{-1}(\\sin\\theta)=\\theta$ only when $\\theta$ lies in the principal range, we add the necessary $2\\pi$ multiples to capture all solutions, leading to the two families shown above.

SI unit: Angles obtained from inverse trigonometric functions are expressed in radians (rad), the SI unit for angular measure.

Edge cases and restrictions:

  • The argument $k$ must satisfy $|k|\\le 1$ for real solutions of $\\sin^{-1}k$ and $\\cos^{-1}k$.
  • If $|k|>1$, the equation has no real solution; complex solutions can be obtained using hyperbolic functions.
  • When $k=0$, $\\sin^{-1}0=0$, $\\cos^{-1}0=\\frac{\\pi}{2}$, $\\tan^{-1}0=0$.
  • Multiple solutions arise because trigonometric functions are periodic.

Example: Solve $2\\sin\\theta - 1 = 0$ for $0\\le\\theta<2\\pi$.

  1. Rewrite: $\\sin\\theta = \\frac{1}{2}$.
  2. Principal value: $\\theta_1 = \\sin^{-1}\\left(\\frac{1}{2}\\right)=\\frac{\\pi}{6}$.
  3. Second family: $\\theta_2 = \\pi - \\theta_1 = \\frac{5\\pi}{6}$.
  4. Both lie in $[0,2\\pi)$, so the solutions are $\\theta = \\frac{\\pi}{6},\\;\\frac{5\\pi}{6}$.

Applications in geometry and real‑world problems

Definition: An inverse trigonometric function returns the angle whose trigonometric value is known. For a real number $x$, the principal values are defined as
$\sin^{-1}x=\theta\;\text{such that}\;\sin\theta=x,\; -\frac{\pi}{2}\le\theta\le\frac{\pi}{2}$;
$\cos^{-1}x=\theta\;\text{such that}\;\cos\theta=x,\;0\le\theta\le\pi$;
$\tan^{-1}x=\theta\;\text{such that}\;\tan\theta=x,\; -\frac{\pi}{2}<\theta<\frac{\pi}{2}$.

Geometrical Application: In any right‑angled triangle, if the lengths of the sides are known, the unknown acute angle can be obtained directly using the inverse functions. For example, given opposite side $a$ and hypotenuse $c$, the angle $\alpha$ is $\alpha=\sin^{-1}\left(\frac{a}{c}\right)$.

Real‑World Problem: Determining the height of a tower using the angle of elevation. Let $d$ be the horizontal distance from the observer to the foot of the tower (in metres) and $\theta$ the measured angle of elevation (in degrees or radians). The height $h$ (in metres) is obtained from
$$h=d\,\tan\theta.$$

SI Units: Lengths are expressed \in metres (m); angles may be measured \in radians (rad) for calculus‑based derivations, but degrees (°) are common \in practical geometry.

Edge Cases & Domain Restrictions:

  • The domain of $\sin^{-1}x$ and $\cos^{-1}x$ is $[-1,1]$; values outside this interval have no real inverse.
  • $\tan^{-1}x$ is defined for all real $x$, but its range is limited \to $(-\frac{\pi}{2},\frac{\pi}{2})$.
  • When $\theta=0°$ or $180°$, $\tan\theta$ becomes $0$ or undefined, so height calculations must avoid vertical lines.

$\tan^{-1}x$$\mathbb{R}$$(-\frac{\pi}{2},\frac{\pi}{2})$

Solved Example: An observer stands $50\,\text{m}$ from a building and measures the \angle of elevation as $30°$. Find the building’s height.

  1. Convert the \angle \to radians if required: $30°=\frac{\pi}{6}\,\text{rad}$.
  2. Apply the height formula: $h=50\,\tan30°$.
  3. Since $\tan30°=\frac{1}{\sqrt{3}}$, $h=50\times\frac{1}{\sqrt{3}}\approx28.9\,\text{m}$.

Thus the building is approximately $28.9\,\text{m}$ tall. This demonstrates how inverse trigonometric functions translate measured angles into practical dimensions in geometry and engineering contexts.

Important identities and transformations

Inverse Trig Functions – Important Identities & Transformations

In CBSE Class 12, inverse trigonometric functions are defined as the inverses of the restricted trigonometric functions. For an angle $ heta$ measured in radians, the principal values are:

  • $\sin^{-1}xin[-\frac{\pi}{2},\frac{\pi}{2}]$
  • $\cos^{-1}xin[0,\pi]$
  • $ an^{-1}xin(-\frac{\pi}{2},\frac{\pi}{2})$

Key identities (derived from $\sin^2x+\cos^2x=1$ and $ an x=\frac{\sin x}{\cos x}$):

IdentityExpression
$\sin^{-1}x+\cos^{-1}x$$=\frac{\pi}{2}$
$\tan^{-1}x+\tan^{-1}y$$=\tan^{-1}\left(\frac{x+y}{1-xy}\right)$ if $xy<1$
$\tan^{-1}x-\tan^{-1}y$$=\tan^{-1}\left(\frac{x-y}{1+xy}\right)$ if $xy>-1$

Derivation of $\sin^{-1}x+\cos^{-1}x=\frac{\pi}{2}$

Let $\alpha=\sin^{-1}x$ so $\sin\alpha=x$ and $\alpha\in[-\frac{\pi}{2},\frac{\pi}{2}]$. Then $\cos\alpha=\sqrt{1-x^2}$. Define $\beta=\cos^{-1}x$; by definition $\cos\beta=x$ and $\beta\in[0,\pi]$. Since $\cos\beta=x=\sin\alpha$, we have $\beta=\frac{\pi}{2}-\alpha$. Hence $\alpha+\beta=\frac{\pi}{2}$.

Edge Cases

  • Domain restrictions: $x\in[-1,1]$ for $\sin^{-1}$ and $\cos^{-1}$; $x\in\mathbb{R}$ for $ an^{-1}$.
  • Range limits: values at endpoints give $\sin^{-1}(\pm1)=\pm\frac{\pi}{2}$, $\cos^{-1}(\pm1)=\{0,\pi\}$, $\tan^{-1}(\pm\infty)=\{\pm\frac{\pi}{2}\}$.

Example

Find $\tan\bigl(\sin^{-1}\frac{3}{5}\bigr)$.

Let $\theta=\sin^{-1}\frac{3}{5}$, so $\sin\theta=\frac{3}{5}$. Using the Pythagorean identity, $\cos\theta=\sqrt{1-\frac{9}{25}}=\frac{4}{5}$. Therefore $\tan\theta=\frac{\sin\theta}{\cos\theta}=\frac{\frac{3}{5}}{\frac{4}{5}}=\frac{3}{4}$. Hence $\tan\bigl(\sin^{-1}\frac{3}{5}\bigr)=\frac{3}{4}$.
