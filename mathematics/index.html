Chapter 01: Relations and Functions

Unit Weightage: 08 Marks Target: Theory, Equivalence & Invertibility Curator: Jatin Sandilya

1. Types of Relations

A relation $R$ in a non-empty set $A$ is a subset of the Cartesian product $A \times A$ ($R \subseteq A \times A$).

Key Classifications

1. Empty Relation: $R = \phi \subset A \times A$
2. Universal Relation: $R = A \times A$
3. Reflexive: $(a, a) \in R$ for every $a \in A$.
4. Symmetric: If $(a, b) \in R \implies (b, a) \in R$ for all $a, b \in A$.
5. Transitive: If $(a, b) \in R$ and $(b, c) \in R \implies (a, c) \in R$ for all $a, b, c \in A$.
Equivalence Relation: A relation $R$ is termed an Equivalence Relation if and only if it is simultaneously Reflexive, Symmetric, and Transitive.

2. Function Classifications (Injective, Surjective & Bijective)

Consider a mapping function $f: X \to Y$:

1. One-One (Injective Function)

Different elements of set $X$ have distinct images in set $Y$.

$$f(x_1) = f(x_2) \implies x_1 = x_2 \quad \forall x_1, x_2 \in X$$

2. Onto (Surjective Function)

Every element in the co-domain $Y$ must be the image of at least one element in domain $X$.

$$\forall y \in Y, \; \exists x \in X \quad \text{such that} \quad f(x) = y \quad (\text{Range} = \text{Co-domain})$$

3. Bijective Function

A function $f: X \to Y$ is Bijective if it is both One-One and Onto. A function is invertible if and only if it is bijective.

3. Most Repeated CBSE Board Questions

3 Marks
Q1. Show that the relation $R$ in the set of real numbers $\mathbb{R}$ defined as $R = \{(a, b) : a \le b^2\}$ is neither reflexive, symmetric, nor transitive.
Step-by-Step Proof:
1. Reflexive: Take $a = \frac{1}{2}$. Then $\frac{1}{2} \le (\frac{1}{2})^2 \implies \frac{1}{2} \le \frac{1}{4}$, which is false. $\therefore R$ is not reflexive.
2. Symmetric: Take $(1, 4)$. $1 \le 4^2 = 16$ is true. But for $(4, 1)$, $4 \le 1^2 \implies 4 \le 1$, which is false. $\therefore R$ is not symmetric.
3. Transitive: Take $a = 3, b = -2, c = -1$. $3 \le (-2)^2 = 4$ (True) and $-2 \le (-1)^2 = 1$ (True). But $3 \le (-1)^2 \implies 3 \le 1$ is false. $\therefore R$ is not transitive.
4 Marks
Q2. Prove that $f: \mathbb{R} \setminus \{3\} \to \mathbb{R} \setminus \{1\}$ defined by $f(x) = \frac{x - 2}{x - 3}$ is Bijective.
Proof:
* Injective (One-One): Let $f(x_1) = f(x_2)$.
$$\frac{x_1 - 2}{x_1 - 3} = \frac{x_2 - 2}{x_2 - 3} \implies (x_1 - 2)(x_2 - 3) = (x_2 - 2)(x_1 - 3)$$ $$x_1 x_2 - 3x_1 - 2x_2 + 6 = x_1 x_2 - 3x_2 - 2x_1 + 6 \implies -x_1 = -x_2 \implies x_1 = x_2$$ Hence, $f$ is strictly injective.

* Surjective (Onto): Let $y \in \mathbb{R} \setminus \{1\}$. Then $y = \frac{x - 2}{x - 3} \implies y(x - 3) = x - 2 \implies x(y - 1) = 3y - 2$.
$$x = \frac{3y - 2}{y - 1}$$ Since $y \ne 1$, $x \in \mathbb{R} \setminus \{3\}$ always exists. Hence, $f$ is surjective and bijective.

4. Quick Revision Mind-Map

  • Total number of relations from set $A$ to set $B$ = $2^{n(A) \times n(B)}$.
  • Total number of reflexive relations on set $A$ of $n$ elements = $2^{n(n-1)}$.
  • An equivalence class $[a]$ consists of all elements $x \in A$ such that $(x, a) \in R$.
  • Always test with fractions ($0 < x < 1$) and negative numbers to disprove reflexivity/transitivity in board exams.
