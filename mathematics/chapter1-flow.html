Relations and Functions

Relation and its representation

  • A relation $R$ from set $A$ to set $B$ is a subset of the Cartesian product $A\times B$, i.e., $R\subseteq A\times B$.
  • Each element of $R$ is an ordered pair $(a,b)$ where $a\in A$ and $b\in B$; the set of all first components is the domain and the set of all second components is the range.
  • Relations can be visualised using a mapping (arrow) diagram: arrows are drawn from elements of $A$ to their related elements in $B$.
  • A relation can be represented by a matrix $M_{R}$ of size $|A|\times|B|$, where $M_{ij}=1$ if $(a_i,b_j)\in R$, otherwise $0$.
  • For relations on a single set, a directed graph (digraph) can be used, where vertices are the elements and a directed edge $a\rightarrow b$ indicates $(a,b)\in R$.

Function and its types (one-one, onto, bijective)

  • A function $f$ maps each element of a set $A$ (domain) to a unique element of a set $B$ (codomain).
  • One-one (injective): $f(a_1)=f(a_2)\Rightarrow a_1=a_2$ for all $a_1,a_2\in A$.
  • Onto (surjective): For every $b\in B$ there exists $a\in A$ such that $f(a)=b$.
  • Bijective: The function is both one-one and onto; consequently an inverse function $f^{-1}:B\to A$ exists.

Composition of functions

  • If $f:A\to B$ and $g:B\to C$, the composition $g\circ f:A\to C$ is defined by $(g\circ f)(x)=g(f(x))$ for every $x\in A$.
  • The domain of $g\circ f$ consists of all $x\in A$ such that $f(x)$ lies in the domain of $g$.
  • If $f$ and $g$ are one‑to‑one (injective), then $g\circ f$ is also one‑to‑one; similarly, if both are onto (surjective), $g\circ f$ is onto.
  • The identity function $I_A$ satisfies $I_B\circ f=f$ and $f\circ I_A=f$ for any function $f:A\to B$.
  • Composition is associative: $(h\circ g)\circ f = h\circ (g\circ f)$ whenever the functions are composable.

Inverse of a function

  • A function $f$ has an inverse $f^{-1}$ iff it is one‑to‑one (injective) and onto (surjective) on its domain and codomain.
  • The graph of $f^{-1}$ is the reflection of the graph of $f$ about the line $y=x$.
  • If $y=f(x)$, then $x=f^{-1}(y)$; algebraically, interchange $x$ and $y$ and solve for $y$ to obtain $f^{-1}(x)$.
  • Domain of $f^{-1}$ = range of $f$, and range of $f^{-1}$ = domain of $f$.
  • For composite functions, $fig(f^{-1}(x)ig)=x$ and $f^{-1}ig(f(x)ig)=x$ for all $x$ in the respective domains.

Binary operations

  • A binary operation on a set $S$ is a rule that assigns to every ordered pair $(a,b)$ in $S\times S$ a unique element $a\star b$ in $S$.
  • The operation is closed on $S$; i.e., $a\star b\in S$ for all $a,b\in S$.
  • Associativity: $(a\star b)\star c = a\star (b\star c)$ for all $a,b,c\in S$; if true, the operation is associative.
  • Commutativity: $a\star b = b\star a$ for all $a,b\in S$; if true, the operation is commutative.
  • Identity element $e$ satisfies $e\star a = a\star e = a$ for every $a\in S$, and an element $a'$ is inverse of $a$ if $a\star a' = a'\star a = e$.

Algebra of functions (sum, difference, product, quotient)

  • If $f$ and $g$ are defined on a common domain $D$, the sum function is $(f+g)(x)=f(x)+g(x)$ for all $x\in D$.
  • The difference function is $(f-g)(x)=f(x)-g(x)$, defined wherever both $f$ and $g$ exist.
  • The product function is $(fg)(x)=f(x)\cdot g(x)$, useful for combining ranges via multiplication.
  • The quotient function is $(\frac{f}{g})(x)=\frac{f(x)}{g(x)}$, defined for $x$ where $g(x)\neq0$.
  • Domain of the combined function is the intersection of the individual domains, further restricted by $g(x)\neq0$ for the quotient.

Domain and range of composite functions

  • Domain of $f\circ g$ is $\{x\in D_g\mid g(x)\in D_f\}$, i.e., all $x$ in the domain of $g$ whose images lie in the domain of $f$.
  • Range of $f\circ g$ is a subset of the range of $f$, given by $\{f(g(x))\mid x\in D_{f\circ g}\}$.
  • If $g$ is onto the domain of $f$, then $D_{f\circ g}=D_g$, so the composite inherits the whole domain of $g$.
  • When $f$ and $g$ are one‑to‑one and inverses exist, $(f\circ g)^{-1}=g^{-1}\circ f^{-1}$.

Graphical representation of functions

  • Domain and range are read directly from the $x$‑ and $y$‑axes of the graph.
  • A function is represented by a single $y$ value for each $x$; the vertical line test confirms this property.
  • Intercepts are obtained where the graph meets the axes: $x$‑intercept at $y=0$, $y$‑intercept at $x=0$.
  • Monotonicity (increasing/decreasing) is identified by the slope of the curve; positive slope ⇒ increasing, negative ⇒ decreasing.
  • Symmetry about the $y$‑axis indicates an even function ($f(-x)=f(x)$), while symmetry about the origin indicates an odd function ($f(-x)=-f(x)$).

Types of functions (polynomial, rational, exponential, logarithmic, trigonometric)

  • Polynomial function: $f(x)=a_nx^n+a_{n-1}x^{n-1}+\dots +a_1x+a_0$, where $n\in\mathbb{N}$ and $a_i$ are constants.
  • Rational function: ratio of two polynomials, $f(x)=\dfrac{P(x)}{Q(x)}$, with $Q(x)\neq0$.
  • Exponential function: $f(x)=a\,b^{x}$, $b>0$, $b\neq1$, showing constant relative growth; logarithmic function: inverse, $f(x)=\log_b x$.
  • Trigonometric function: defined using angles, e.g., $f(x)=\sin x$, $\cos x$, $\tan x$, periodic with fundamental period $2\pi$ (or $\pi$ for $ an$).

Even, odd and periodic functions

  • A function $f$ is even if $f(-x)=f(x)$ for all $x$ in its domain (symmetric about the $y$‑axis).
  • A function $f$ is odd if $f(-x)=-f(x)$ for all $x$ in its domain (symmetric about the origin).
  • If $f$ is even and $g$ is odd, then $f+g$ is neither even nor odd in general; however, $f\cdot g$ is odd.
  • A function $f$ is periodic with period $T>0$ if $f(x+T)=f(x)$ for every $x$; the smallest such $T$ is called the fundamental period.
