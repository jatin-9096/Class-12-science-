Definition of relation and types of relations

Definition: A relation $R$ from a set $A$ to a set $B$ is a subset of the Cartesian product $A\times B$.

For $x\in A$ and $y\in B$, we write $xRy$ if $(x,y)\in R$.

  • Reflexive: $R$ on $A$ is reflexive if $\forall x\in A,\;xRx$.
  • Irreflexive: $R$ is irreflexive if $\forall x\in A,\;\neg(xRx)$.
  • Symmetric: $R$ is symmetric if $\forall x,y\in A,\;xRy\Rightarrow yRx$.
  • Antisymmetric: $R$ is antisymmetric if $\forall x,y\in A,\;(xRy\land yRx)\Rightarrow x=y$.
  • Transitive: $R$ is transitive if $\forall x,y,z\in A,\;(xRy\land yRz)\Rightarrow xRz$.
  • Equivalence relation: A relation that is reflexive, symmetric and transitive simultaneously.
  • Partial order: A relation that is reflexive, antisymmetric and transitive.
PropertyCondition
Reflexive$\forall x\in A,\;xRx$
Symmetric$\forall x,y\in A,\;xRy\Rightarrow yRx$
Antisymmetric$\forall x,y\in A,\;(xRy\land yRx)\Rightarrow x=y$
Transitive$\forall x,y,z\in A,\;(xRy\land yRz)\Rightarrow xRz$

Edge cases:

  • Empty relation: $\emptyset\subseteq A\times B$; it is vacuously symmetric and transitive but never reflexive (unless $A=\emptyset$).
  • Universal relation: $A\times A$; it is reflexive, symmetric and transitive, hence an equivalence relation.

Example (Solved):

Let $A=\{1,2,3\}$ and $R=\{(1,1),(2,2),(3,3),(1,2)\}$.

Check the properties:

  • Reflexive? All $(x,x)$ for $x\in A$ are present, so $R$ is reflexive.
  • Symmetric? $(1,2)\in R$ but $(2,1)\notin R$; therefore $R$ is not symmetric.
  • Antisymmetric? The only pair with both directions would be $(x,x)$, which satisfies $x=y$. No counter‑example, so $R$ is antisymmetric.
  • Transitive? The only non‑trivial chain is $1R2$ and $2R2$, giving $1R2$ which already exists. No violation, so $R$ is transitive.

Hence $R$ is a reflexive, antisymmetric and transitive relation – a partial order on $A$.

Definition of function and types of functions

Definition of Function

A relation $f$ from a set $A$ to a set $B$ is called a function if for every $x\in A$ there exists a unique $y\in B$ such that $(x,y)\in f$. The set $A$ is called the domain and $B$ the codomain. The set of all actual outputs is the range.

Types of Functions (CBSE Class 12)

  • Linear: $f(x)=mx+b$ where $m,b\in\mathbb{R}$.
  • Quadratic: $f(x)=ax^2+bx+c$, $a\neq0$.
  • Polynomial: $f(x)=\sum_{k=0}^{n}a_kx^k$, $a_n\neq0$.
  • Rational: $f(x)=\dfrac{P(x)}{Q(x)}$, $Q(x)\neq0$.
  • Exponential: $f(x)=a\,b^x$, $a\neq0$, $b>0$, $b\neq1$.
  • Logarithmic: $f(x)=\log_b x$, $b>0$, $b\neq1$, $x>0$.
  • Trigonometric: $f(x)=\sin x,\cos x,\tan x$, etc.
  • Inverse: $f^{-1}(x)$ satisfies $f(f^{-1}(x))=x$.
  • Piecewise: Defined by different expressions on sub‑domains.
  • Constant: $f(x)=c$, $c\in\mathbb{R}$.

Derivation of Domain & Range

1. Identify restrictions: denominators $\neq0$, square roots $\ge0$, logarithms $>0$.

2. Solve inequalities to find admissible $x$ values.

3. For range, solve $y=f(x)$ for $x$ and apply domain restrictions.

SI Units

When $f$ represents a physical quantity, the dependent variable inherits the unit of the measured quantity. Example: $f(x)=\dfrac{\text{distance (m)}}{\text{time (s)}}$ gives velocity in $\text{m/s}$.

Edge Cases

• Vertical asymptotes: $x$ values where $Q(x)=0$ but $P(x)\neq0$.

• Removable discontinuities: common factors in $P$ and $Q$ cancel, but domain excludes the root.

• End behaviour: limits as $x\to\pm\infty$ determine horizontal asymptotes.

Example

Find domain, range and type of $f(x)=\dfrac{x^2-1}{x-1}$.

Factor numerator: $x^2-1=(x-1)(x+1)$. Thus $f(x)=\dfrac{(x-1)(x+1)}{x-1}=x+1$, $x\neq1$ (removable discontinuity).

Domain: $\mathbb{R}\setminus\{1\}$.

Range: $\mathbb{R}\setminus\{2\}$ because $f(1)$ is undefined, so $y=2$ is not attained.

Type: Polynomial (degree 1) with a hole at $(1,2)$.

Domain, range and codomain of a function

Definition of a Function: A relation $f$ from a set $A$ to a set $B$ is called a function if every element $x\\in A$ is associated with exactly one element $y\\in B$, denoted $y=f(x)$. The set $A$ is the domain, $B$ the codomain, and the set of all actual images $\{f(x)\\mid x\\in A\}$ is the range (or image).

TermSymbolic RepresentationExplanation
Domain$A$All permissible inputs $x$ for which $f(x)$ is defined.
Codomain$B$Superset of all possible outputs; declared when $f$ is defined.
Range$R_f$$R_f=\{f(x)\mid x\\in A\}$, actual outputs, always $R_f\\subseteq B$.

Theorem: For any function $f:A\\to B$, the range satisfies $R_f\\subseteq B$. Proof follows directly from the definition of $f$; each $f(x)$ belongs to $B$ by construction, hence the collection of all such $f(x)$ cannot exceed $B$.

Edge Cases:

  • If $A=\emptyset$, the function is the empty function; its range is also $\emptyset$.
  • For a constant function $f(x)=c$, the range is the singleton $\{c\}$ regardless of the size of $A$.
  • If the declared codomain $B$ is larger than the actual range, the function is not onto (surjective).

Example:

Let $f:\\mathbb{R}\\to\\mathbb{R}$ be defined by $f(x)=\\sqrt{x-2}$.

  1. Domain: require $x-2\\ge0\\Rightarrow x\\ge2$, so $\text{Dom}(f)=[2,\\infty)$.
  2. Codomain: given as $\\mathbb{R}$.
  3. Range: $y=\\sqrt{x-2}\\ge0$, and every $y\\ge0$ is attained by choosing $x=y^2+2$. Hence $\text{Range}(f)=[0,\\infty)$.

This illustrates that the range is a proper subset of the codomain, i.e., $[0,\\infty)\\subset \\mathbb{R}$.

Composite functions and their properties

Composite Function

A composite function is formed by applying one function after another. If $f:A\to B$ and $g:B\to C$, the composite $g\circ f$ is defined by $$(g\circ f)(x)=g(f(x)),\quad x\in A.$$ The domain of $g\circ f$ is the set of all $x\in A$ for which $f(x)\in B$ and $g$ is defined at $f(x)$.

Basic Properties

  • Associativity: For $f:A\to B$, $g:B\to C$, $h:C\to D$, $$h\circ(g\circ f)=(h\circ g)\circ f.$$
  • Identity: The identity function $I_A(x)=x$ satisfies $f\circ I_A=I_B\circ f=f$ for all $f:A\to B$.
  • Inverse: If $f$ is bijective with inverse $f^{-1}$, then $f^{-1}\circ f=I_A$ and $f\circ f^{-1}=I_B$.

Derivation of Domain

Let $D_f$ and $D_g$ denote domains of $f$ and $g$. Then the domain of $g\circ f$ is $$D_{g\circ f}=\{x\in D_f\mid f(x)\in D_g\}.$$ This restriction often leads \to edge cases: if $f$ maps an element outside $D_g$, the composite is undefined at that element.

Physical Units

When $f$ and $g$ represent physical quantities, their units must be compatible: if $f$ outputs meters and $g$ takes meters as input, the composite preserves the unit of $g$’s output.

Example

Let $f(x)=2x+3$ (units: meters) and $g(x)=x^2$ (units: square meters). Compute both composites.

1. $(g\circ f)(x)=g(f(x))=\bigl(2x+3\bigr)^2=4x^2+12x+9$ (units: $\text{m}^2$). Domain: all real numbers.

2. $(f\circ g)(x)=f(g(x))=2x^2+3$ (units: meters). Domain: all real numbers.

Both composites are defined for all $x\in\mathbb{R}$ \because $f$ and $g$ are defined everywhere. However, if $g$ were defined only for $x\ge0$, then $(g\circ f)$ would be undefined for $x<\tfrac{-3}{2}$.

Inverse functions and conditions for existence

Definition of Inverse Function: If a function $f:\,A\rightarrow B$ assigns each element $x\in A$ a unique element $y=f(x)\in B$, then the function $g:\,B\rightarrow A$ defined by $g(y)=x$ is called the inverse of $f$ and is denoted $f^{-1}$. The relation $g\circ f=I_{A}$ and $f\circ g=I_{B}$ must hold, where $I$ denotes the identity mapping.

Necessary and Sufficient Condition for Existence:

  • The function $f$ must be bijective (both one‑to‑one and onto) on its domain.
  • One‑to‑one (injective): $f(x_{1})=f(x_{2})\Rightarrow x_{1}=x_{2}$ for all $x_{1},x_{2}\in A$.
  • Onto (surjective): For every $y\in B$ there exists $x\in A$ such that $f(x)=y$.

These conditions guarantee that each $y$ in the codomain has a unique pre‑image, allowing the construction of $f^{-1}$.

Derivation of Inverse Formula: Suppose $y=f(x)$ can be solved explicitly for $x$ in terms of $y$. Then replace $y$ by $x$ and $x$ by $y$ to obtain $f^{-1}(x)$. Symbolically, if $y=\phi(x)$, solve $x=\phi^{-1}(y)$ and write $f^{-1}(x)=\phi^{-1}(x)$.

Edge Cases:

  • If $f$ is not injective, $f^{-1}$ is not a function (multiple $x$ map to same $y$).
  • If $f$ is injective but not onto, $f^{-1}$ exists only on the image $f(A)$, not on the whole codomain $B$.
  • Vertical line test for $f^{-1}$: the graph of $f^{-1}$ is the reflection of the graph of $f$ about the line $y=x$.

Table: Conditions for Inverse

PropertyRequirement
Injective$f(x_{1})=f(x_{2})\Rightarrow x_{1}=x_{2}$
SurjectiveFor every $y\in B$, $\exists x\in A$ such that $f(x)=y$
BijectiveBoth injective and surjective → inverse exists on $B$

Example: Find the inverse of $f(x)=\frac{2x-3}{5}$, $x\in\mathbb{R}$.

Solution:

  1. Write $y=\frac{2x-3}{5}$.
  2. Swap $x$ and $y$: $x=\frac{2y-3}{5}$.
  3. Solve for $y$: $5x=2y-3\Rightarrow 2y=5x+3\Rightarrow y=\frac{5x+3}{2}$.
  4. Hence $f^{-1}(x)=\frac{5x+3}{2}$.

Since $f$ is linear with non‑zero slope, it is bijective on $\mathbb{R}$, confirming the existence of the inverse.

One‑one (injective), onto (surjective) and bijective functions

Definitions

  • One‑one (injective) function: A function $f:A\\to B$ is injective if $\\forall x_{1},x_{2}\\in A$, $f(x_{1})=f(x_{2})\\Rightarrow x_{1}=x_{2}$.
  • Onto (surjective) function: $f$ is surjective if $\\forall y\\in B$, $\\exists x\\in A$ such that $f(x)=y$.
  • Bijective function: $f$ is both injective and surjective; i.e., it satisfies the two conditions above simultaneously.

Key Theorems

  • If $f:A\\to B$ and $g:B\\to C$ are injective, then $g\circ f:A\\to C$ is injective.
  • If $f:A\\to B$ and $g:B\\to C$ are surjective, then $g\circ f:A\\to C$ is surjective.
  • A function has an inverse $f^{-1}$ iff it is bijective. The inverse satisfies $f^{-1}(f(x))=x$ for all $x\\in A$ and $f(f^{-1}(y))=y$ for all $y\\in B$.

Edge Cases

  • If the domain $A$ is empty, the function is vacuously injective but not surjective unless $B$ is also empty.
  • For finite sets, $|A|=|B|$ is a necessary (but not sufficient) condition for bijectivity.

Illustrative Example (Solved)

Consider $f:\mathbb{R}\\to\mathbb{R}$ defined by $f(x)=2x+3$.

  1. Injectivity: Assume $f(x_{1})=f(x_{2})$. Then $2x_{1}+3=2x_{2}+3\Rightarrow 2x_{1}=2x_{2}\Rightarrow x_{1}=x_{2}$. Hence $f$ is one‑one.
  2. Surjectivity: Let $y\\in\mathbb{R}$. Choose $x=\frac{y-3}{2}$. Then $f(x)=2\left(\frac{y-3}{2}\right)+3=y$. Thus every $y$ has a pre‑image; $f$ is onto.
  3. Since $f$ is both injective and surjective, it is bijective and possesses an inverse $f^{-1}(y)=\frac{y-3}{2}$.

Function notation, algebraic and graphical representation

Definition: A function $f$ from a set $A$ to a set $B$ is a rule that assigns to each element $x\in A$ exactly one element $y\in B$, denoted $y=f(x)$. The set $A$ is called the domain, $B$ the codomain, and the set of all actual values $\{f(x):x\in A\}$ is the range.

  • Domain – all permissible inputs; its unit is the unit of the independent variable (e.g., seconds, meters).
  • Codomain – the set in which outputs are expected; its unit is the unit of the dependent variable.
  • Range – actual set of outputs, a subset of the codomain.

Function notation

Given a rule, we write it as $f(x)=\text{expression \in }x$. To evaluate, replace $x$ by the required argument:

  1. Identify the rule $f(x)$.
  2. Substitute the argument $a$ for $x$.
  3. Simplify the resulting expression to obtain $f(a)$.

Example: If $f(x)=2x+3$, then $f(5)=2\times5+3=13$.

Graphical representation

The graph of $y=f(x)$ is the set of points $(x,f(x))$ in the Cartesian plane. A curve passes the vertical line test if every vertical line $x=c$ meets the curve at most once; this guarantees a well‑defined function.

$x$$f(x)$
$-2$$f(-2)$
$0$$f(0)$
$2$$f(2)$

Edge cases and restrictions

  • If the rule involves a denominator, the domain excludes values that make the denominator zero.
  • If a square‑root appears, the radicand must be non‑negative for real‑valued functions.
  • Multi‑valued relations (e.g., $y^2=x$) are not functions unless a single branch is selected.

Solved example

Let $f:\mathbb{R}\to\mathbb{R}$ be defined by $f(x)=\frac{x^{2}-1}{x-1}$.

  1. Simplify the expression: $x^{2}-1=(x-1)(x+1)$, so $f(x)=\frac{(x-1)(x+1)}{x-1}=x+1$, provided $x\neq1$.
  2. Domain: all real numbers except $x=1$ (division by zero).
  3. Evaluate $f(2)$ using the simplified form: $f(2)=2+1=3$.
  4. Discuss $x=1$: the original formula is undefined, so $x=1$ is a removable discontinuity; the function can be redefined as $g(x)=x+1$ with $g(1)=2$ to make it continuous.

This example illustrates how algebraic manipulation reveals the true rule, how domain restrictions arise, and how the graphical plot of $y=x+1$ would have a hole at $(1,2)$.

Binary operations and their properties

Definition: A $\text{binary operation}$ on a set $S$ is a rule that assigns to every ordered pair $(a,b)$ of elements of $S$ a unique element $a\star b\in S$. The operation is said to be closed on $S$ if $a\star b$ always belongs to $S$.

Common properties of a binary operation $\star$ on $S$ are listed below:

  • Closure: $\forall a,b\in S,\;a\star b\in S$.
  • Associativity: $\forall a,b,c\in S,\;(a\star b)\star c = a\star (b\star c)$.
  • Commutativity: $\forall a,b\in S,\;a\star b = b\star a$.
  • Identity element: An element $e\in S$ such that $\forall a\in S,\;e\star a = a\star e = a$.
  • Inverse element: For each $a\in S$, an element $a^{-1}\in S$ satisfying $a\star a^{-1}=a^{-1}\star a = e$, where $e$ is the identity.
  • Idempotent: $\forall a\in S,\;a\star a = a$.
  • Distributivity (over another operation $\circ$): $a\star (b\circ c)= (a\star b)\circ (a\star c)$ and similarly on the right.

Edge cases:

  • If closure fails, $\star$ is not a valid operation on $S$ (e.g., subtraction on $\mathbb{N}$).
  • Non‑associative operations (e.g., subtraction, division) cannot be rearranged without parentheses.
  • An operation may be commutative but lack an identity (e.g., $a\star b = a+b+1$ on $\mathbb{Z}$).

Table of symbols:

PropertyMathematical form
Closure$\forall a,b\in S,\;a\star b\in S$
Associativity$\forall a,b,c\in S,\;(a\star b)\star c = a\star (b\star c)$
Commutativity$\forall a,b\in S,\;a\star b = b\star a$

Example (modular addition):

Let $S=\{0,1,2,3,4\}$ and define $a\star b = (a+b)\bmod 5$.

  1. Closure: $(a+b)\bmod 5$ always lies in $S$.
  2. Associativity: $((a\star b)\star c) = ((a+b)\bmod5 + c)\bmod5 = (a+b+c)\bmod5 = a\star (b\star c)$.
  3. Commutativity: $a\star b = (a+b)\bmod5 = (b+a)\bmod5 = b\star a$.
  4. Identity: $e=0$, because $a\star 0 = (a+0)\bmod5 = a$.
  5. Inverse: For each $a$, the inverse is $a^{-1}= (5-a)\bmod5$; e.g., $3^{-1}=2$ since $3\star2 =5\bmod5=0$.

Thus the operation $\star$ on $S$ satisfies closure, associativity, commutativity, possesses an identity and inverses, making $(S,\star)$ a finite abelian group. No SI unit is associated with abstract binary operations, as they are dimensionless algebraic constructs.

Special functions: polynomial, rational, exponential and logarithmic

Special Functions: Polynomial, Rational, Exponential and Logarithmic

In Class‑12 mathematics a function is a rule that assigns to each element of a set $D$ (domain) a unique element of a set $R$ (range). The following four families are called special functions because they appear repeatedly in calculus and applications.

  • Polynomial function: $f(x)=a_n x^{n}+a_{n-1}x^{n-1}+ \dots +a_1 x + a_0$, where $a_i\in\mathbb{R}$ and $n\in\mathbb{N}_0$. The degree of the polynomial is $n$. It is defined for all real $x$; hence $D= \mathbb{R}$ and $R$ is the set of all real values taken by the expression.
  • Rational function: $f(x)=\dfrac{p(x)}{q(x)}$, where $p(x)$ and $q(x)$ are polynomials and $q(x)\neq0$. The domain is $D=\{x\in\mathbb{R}\mid q(x)\neq0\}$. Points where $q(x)=0$ are called poles.
  • Exponential function: $f(x)=a\,b^{x}$ with $a\neq0$, $b>0$, $b\neq1$. The domain is $\mathbb{R}$ and the range is $\{y\mid y\neq0\}$ if $a>0$ (or $y\neq0$ with sign of $a$).
  • Logarithmic function: $f(x)=\log_{b}x$, $b>0$, $b\neq1$, $x>0$. It is the inverse of the exponential function. Domain $D=(0,\infty)$, range $R=\mathbb{R}$.

Key Theorem (Inverse Relation)

If $f$ is one‑to‑one on $D$, then its inverse $f^{-1}$ exists and satisfies $f^{-1}(f(x))=x$ for all $x\in D$. For exponential and logarithmic functions the theorem gives $ \log_{b}(b^{x})=x$ and $b^{\log_{b}x}=x$.

Example

Find the domain and range of $f(x)=\dfrac{2x+3}{x-1}$.

  1. Domain: set denominator $\neq0$. Solve $x-1\neq0\;\Rightarrow\;x\neq1$. Hence $D=\mathbb{R}\setminus\{1\}$.
  2. Rewrite $f(x)=\dfrac{2x+3}{x-1}=2+\dfrac{5}{x-1}$. As $x\to\pm\infty$, $f(x)\to2$, so $y=2$ is a horizontal asymptote but never attained.
  3. Since $\dfrac{5}{x-1}$ can take any real value except $0$, $f(x)$ can take any real number except $2$. Thus $R=\mathbb{R}\setminus\{2\}$.

This example illustrates the typical domain restriction for rational functions and the method of finding range using algebraic manipulation.
