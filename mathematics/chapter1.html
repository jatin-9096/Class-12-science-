Chapter 01: Relations and Functions

Chapter Overview

In this chapter, we delve into the fundamental concepts of relations and functions, which form the bedrock of higher mathematics. We will explore various types of relations, including reflexive, symmetric, and transitive, leading to the definition of equivalence relations. Subsequently, we will study functions, their types (one-one, onto, bijective), and operations such as composition and inverse functions. These concepts are crucial for understanding calculus, algebra, and discrete mathematics.

Key Definitions

Relation

A relation $R$ from a non-empty set $A$ to a non-empty set $B$ is a subset of the Cartesian product $A \times B$. If $(a,b) \in R$, we say that $a$ is related to $b$, written as $aRb$.

Domain, Codomain, and Range

  • The domain of a relation $R$ is the set of all first elements of the ordered pairs in $R$.
  • The codomain of a relation from $A$ to $B$ is the entire set $B$.
  • The range of a relation $R$ is the set of all second elements of the ordered pairs in $R$, which is a subset of the codomain.

Types of Relations on a Set $A$

  • Empty Relation: A relation $R = \emptyset \subseteq A \times A$. No element of $A$ is related to any element of $A$.
  • Universal Relation: A relation $R = A \times A$. Every element of $A$ is related to every element of $A$.
  • Reflexive Relation: A relation $R$ on $A$ is reflexive if $(a, a) \in R$ for every $a \in A$.
  • Symmetric Relation: A relation $R$ on $A$ is symmetric if $(a, b) \in R \implies (b, a) \in R$, for all $a, b \in A$.
  • Transitive Relation: A relation $R$ on $A$ is transitive if $(a, b) \in R$ and $(b, c) \in R \implies (a, c) \in R$, for all $a, b, c \in A$.
  • Equivalence Relation: A relation $R$ on $A$ is an equivalence relation if it is reflexive, symmetric, and transitive.

Function

A relation $f$ from a set $A$ to a set $B$ is called a function (or mapping) if every element of set $A$ has one and only one image in set $B$. We write $f: A \to B$.

Types of Functions

  • One-one (Injective) Function: A function $f: A \to B$ is one-one if $f(x_1) = f(x_2) \implies x_1 = x_2$ for all $x_1, x_2 \in A$.
  • Onto (Surjective) Function: A function $f: A \to B$ is onto if for every $y \in B$, there exists an $x \in A$ such that $f(x) = y$. The range of $f$ is equal to the codomain $B$.
  • Bijective Function: A function $f: A \to B$ is bijective if it is both one-one and onto.

Composition of Functions

Let $f: A \to B$ and $g: B \to C$ be two functions. The composition of $f$ and $g$, denoted by $g \circ f$, is defined as the function $g \circ f: A \to C$ given by $(g \circ f)(x) = g(f(x))$ for all $x \in A$.

Inverse Function

A function $f: A \to B$ is invertible if there exists a function $g: B \to A$ such that $g \circ f = I_A$ and $f \circ g = I_B$, where $I_A$ and $I_B$ are identity functions on $A$ and $B$ respectively. The function $g$ is called the inverse of $f$ and is denoted by $f^{-1}$. A function is invertible if and only if it is bijective.

Essential Formulas and Theorems

Number of Relations

If set $A$ has $m$ elements and set $B$ has $n$ elements, then the total number of relations from $A$ to $B$ is $2^{mn}$.

Number of Functions

If set $A$ has $m$ elements and set $B$ has $n$ elements, then the total number of functions from $A$ to $B$ is $n^m$.

Composition Associativity

If $f: A \to B$, $g: B \to C$, and $h: C \to D$ are functions, then $(h \circ g) \circ f = h \circ (g \circ f)$.

Inverse Property

If $f: A \to B$ is bijective, then $f^{-1}: B \to A$ exists and is unique. Also, $(f^{-1})^{-1} = f$.

Important CBSE Board Exam Standard Questions

Question 1: Relation Properties

Show that the relation $R$ in the set $A = \{1, 2, 3, 4, 5, 6\}$ defined by $R = \{(a, b) : b = a + 1\}$ is neither reflexive, nor symmetric, nor transitive.

Solution:

For the given relation $R = \{(a, b) : b = a + 1\}$ on the set $A = \{1, 2, 3, 4, 5, 6\}$.

  • Reflexivity: For $R$ to be reflexive, $(a, a) \in R$ for all $a \in A$. This means $a = a + 1$, which is false for any $a \in A$. For example, $(1, 1) \notin R$ as $1 \neq 1 + 1$. Therefore, $R$ is not reflexive.
  • Symmetry: For $R$ to be symmetric, if $(a, b) \in R$, then $(b, a) \in R$. Let $(a, b) \in R$. Then $b = a + 1$. For $(b, a)$ to be in $R$, we would need $a = b + 1$. Substituting $b = a + 1$ into $a = b + 1$, we get $a = (a + 1) + 1 \implies a = a + 2$, which is false. For example, $(1, 2) \in R$ since $2 = 1 + 1$, but $(2, 1) \notin R$ since $1 \neq 2 + 1$. Therefore, $R$ is not symmetric.
  • Transitivity: For $R$ to be transitive, if $(a, b) \in R$ and $(b, c) \in R$, then $(a, c) \in R$. Let $(a, b) \in R$ and $(b, c) \in R$. This implies $b = a + 1$ and $c = b + 1$. Substituting the value of $b$ from the first equation into the second, we get $c = (a + 1) + 1 \implies c = a + 2$. For $(a, c)$ to be in $R$, we would need $c = a + 1$. But we found $c = a + 2$. Thus, $a + 2 = a + 1 \implies 2 = 1$, which is false. For example, $(1, 2) \in R$ and $(2, 3) \in R$, but $(1, 3) \notin R$ since $3 \neq 1 + 1$. Therefore, $R$ is not transitive.

Question 2: Invertibility of a Function

Consider $f: \mathbb{R} \to \mathbb{R}$ given by $f(x) = 2x - 3$. Show that $f$ is invertible. Find $f^{-1}$.

Solution:

To show $f$ is invertible, we need to prove it is both one-one (injective) and onto (surjective).

  • Injectivity (One-one): Let $x_1, x_2 \in \mathbb{R}$ such that $f(x_1) = f(x_2)$. $2x_1 - 3 = 2x_2 - 3$ $2x_1 = 2x_2$ $x_1 = x_2$. Since $f(x_1) = f(x_2) \implies x_1 = x_2$, the function $f$ is one-one.
  • Surjectivity (Onto): Let $y \in \mathbb{R}$ be an arbitrary element in the codomain. We need to find an $x \in \mathbb{R}$ such that $f(x) = y$. $f(x) = y \implies 2x - 3 = y$ $2x = y + 3$ $x = \frac{y + 3}{2}$. Since for every $y \in \mathbb{R}$, $x = \frac{y+3}{2}$ is also a real number, there exists an $x$ in the domain $\mathbb{R}$ for every $y$ in the codomain $\mathbb{R}$. Thus, the function $f$ is onto.

Since $f$ is both one-one and onto, it is bijective, and hence invertible.

Finding $f^{-1}$:

From the surjectivity step, we have $x = \frac{y + 3}{2}$. To find $f^{-1}(x)$, we simply replace $y$ with $x$. Therefore, $f^{-1}(x) = \frac{x + 3}{2}$.

Quick Revision Summary

  • A relation is any subset of a Cartesian product of two sets.
  • Reflexive, Symmetric, Transitive properties define an Equivalence Relation.
  • A function is a special relation where each input has exactly one output.
  • A function is one-one (injective) if distinct elements in the domain map to distinct elements in the codomain.
  • A function is onto (surjective) if every element in the codomain is the image of at least one element in the domain.
  • A function is bijective if it is both one-one and onto.
  • A function is invertible if and only if it is bijective.
  • Composition of functions involves applying one function after another, e.g., $(g \circ f)(x) = g(f(x))$.
