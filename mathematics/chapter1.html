1. Complete Conceptual Framework & Definitions

Fundamental Theoretical Principles

1.1 Foundational Set-Theoretic Underpinnings and Cartesian Dynamics

The architecture of higher mathematics, specifically analysis and abstract algebra, is anchored upon the formalization of relationships between collections of mathematical objects. In Class 11, the preliminary concept of a set was established as a well-defined collection of distinct objects, denoted typically by uppercase Roman letters $A, B, X, Y$, with set membership symbolized by $\in$. The progression into Class 12 demands an epistemological shift from static collections to dynamic mappings and structural classifications.

Let $A$ and $B$ be two non-empty sets. The Cartesian Product, denoted by $A \times B$, is the set of all possible ordered pairs $(a, b)$ such that the first component $a$ belongs to $A$ and the second component $b$ belongs to $B$. Formally, this set-builder construction is defined as:

$$A \times B = \{(a, b) : a \in A \land b \in B\}$$

If the cardinality of set $A$ is $|A| = n(A) = p$ and the cardinality of set $B$ is $|B| = n(B) = q$, where $p, q \in \mathbb{N} \cup \{0\}$, then the fundamental principle of counting dictates that the cardinality of the Cartesian product is:

$$|A \times B| = |A| \cdot |B| = p \cdot q$$

The order within the pair is inviolable; that is, $(a, b) = (c, d) \iff a = c \land b = d$. Consequently, unless $A = B$ or at least one of the sets is empty ($\emptyset$), the Cartesian product is non-commutative: $A \times B \ne B \times A$.

When $A = B$, the product $A \times A$ is abbreviated as $A^2$. In Euclidean geometry, $\mathbb{R} \times \mathbb{R} = \mathbb{R}^2$ represents the two-dimensional Cartesian coordinate plane. A binary relation $R$ from a set $A$ to a set $B$ is formally defined as an arbitrary subset of the Cartesian product $A \times B$. Symbolically:

$$R \subseteq A \times B \iff R \in \mathcal{P}(A \times B)$$

where $\mathcal{P}(A \times B)$ denotes the power set of $A \times B$. If an element $a \in A$ is related to an element $b \in B$ under the relation $R$, we write $(a, b) \in R$ or, in infix notation, $a \, R \, b$. If $(a, b) \notin R$, we write $a \!\not R \, b$.

The combinatorial consequence of this definition is immediate: since the power set of any finite set $S$ possesses $2^{|S|}$ elements, the total number of distinct binary relations that can be constructed from a set $A$ with $|A| = p$ to a set $B$ with $|B| = q$ is precisely:

$$N_{\text{relations}} = |\mathcal{P}(A \times B)| = 2^{|A \times B|} = 2^{pq}$$

For a relation defined on a single set $A$ (meaning $R \subseteq A \times A$), where $|A| = n$, the total number of possible relations is $2^{n^2}$.

1.1.1 Structural Components: Domain, Range, Codomain, and Inverse

To completely specify a relation $R \subseteq A \times B$, three structural sets must be delineated:

  • Domain ($\operatorname{Dom}(R)$): The set of all first coordinates of the ordered pairs belonging to $R$: $$\operatorname{Dom}(R) = \{a \in A : \exists\, b \in B \text{ such that } (a, b) \in R\} \subseteq A$$
  • Range ($\operatorname{Ran}(R)$ or $\operatorname{Im}(R)$): The set of all second coordinates of the ordered pairs belonging to $R$: $$\operatorname{Ran}(R) = \{b \in B : \exists\, a \in A \text{ such that } (a, b) \in R\} \subseteq B$$
  • Codomain: The entire target set $B$, regardless of whether every element of $B$ is mapped to by an element in $A$. Hence, $\operatorname{Ran}(R) \subseteq \operatorname{Codomain}(R) = B$.

Given a relation $R \subseteq A \times B$, the Inverse Relation, denoted by $R^{-1} \subseteq B \times A$, is obtained by reversing the order of every ordered pair in $R$:

$$R^{-1} = \{(b, a) \in B \times A : (a, b) \in R\}$$

It directly follows from this inversion that:

$$\operatorname{Dom}(R^{-1}) = \operatorname{Ran}(R) \quad \text{and} \quad \operatorname{Ran}(R^{-1}) = \operatorname{Dom}(R)$$

1.1.2 Extremal and Trivial Relations

Two extremal subsets exist for any product $A \times B$:

  1. The Empty (or Void) Relation ($\emptyset$): Since the empty set is a subset of every set, $\emptyset \subseteq A \times B$. In this relation, no element of $A$ is related to any element of $B$: $$\emptyset = \{(a, b) \in A \times B : \text{False}\}$$
  2. The Universal Relation ($U$): The full Cartesian product $A \times B$ is itself a subset of $A \times B$. Here, every element of $A$ is related to every element of $B$: $$U = A \times B = \{(a, b) : a \in A \land b \in B\}$$

Both the empty relation and the universal relation are often referred to as trivial relations.

1.2 Rigorous Taxonomy of Relations on a Set

In Class 12 CBSE examinations, questions routinely hinge upon identifying, proving, or disproving specific structural invariants of a relation $R$ defined on an underlying set $A$ ($R \subseteq A \times A$). We evaluate three primary properties: Reflexivity, Symmetry, and Transitivity, alongside their complementary and exclusionary forms.

1.2.1 Reflexivity and Its Nuances

Definition: A relation $R$ on a set $A$ is said to be reflexive if every element of $A$ is related to itself. Formally:

$$\forall x \in A \implies (x, x) \in R$$

Examiner's Warning on Logical Negation: To disprove reflexivity, one must demonstrate the existence of at least one counterexample where an element fails to relate to itself:

$$\exists x \in A \text{ such that } (x, x) \notin R \implies R \text{ is not reflexive.}$$

The Identity Relation ($\Delta_A$ or $I_A$): The identity relation on $A$ is defined strictly as:

$$I_A = \{(x, x) : x \in A\}$$

A crucial distinction that CBSE examiners test: For a relation $R$ to be reflexive, it must contain the identity relation as a subset, i.e., $I_A \subseteq R$. A relation containing additional elements $(x, y)$ where $x \ne y$ remains reflexive so long as all $(x, x)$ are preserved. Conversely, the identity relation $I_A$ contains only pairs of the form $(x, x)$ and nothing else. Therefore, every identity relation is reflexive, but not every reflexive relation is an identity relation.

Irreflexivity (Strict Non-Reflexivity): A relation $R$ on $A$ is irreflexive if no element is related to itself:

$$\forall x \in A \implies (x, x) \notin R \iff R \cap I_A = \emptyset$$

Caution: "Not reflexive" is not synonymous with "irreflexive". A relation can be neither reflexive nor irreflexive if it contains $(a, a)$ for some elements $a \in A$ but lacks $(b, b)$ for some other elements $b \in A$.

1.2.2 Symmetry, Anti-Symmetry, and Asymmetry

Definition: A relation $R$ on a set $A$ is said to be symmetric if, whenever an ordered pair belongs to $R$, its reverse ordered pair also belongs to $R$. Formally:

$$\forall x, y \in A, \quad (x, y) \in R \implies (y, x) \in R$$

In the language of relation inversion, a relation is symmetric if and only if it equals its own inverse:

$$R \text{ is symmetric } \iff R = R^{-1}$$

Anti-Symmetry: A relation $R$ on a set $A$ is said to be anti-symmetric if:

$$\forall x, y \in A, \quad ((x, y) \in R \land (y, x) \in R) \implies x = y$$

Equivalently, if $x \ne y$, then $(x, y)$ and $(y, x)$ cannot both belong to $R$. Classic examples include the order relation "$\le$" on the set of real numbers $\mathbb{R}$, where $x \le y$ and $y \le x \implies x = y$, and the set containment relation "$\subseteq$" on $\mathcal{P}(X)$, where $A \subseteq B$ and $B \subseteq A \implies A = B$.

Asymmetry: A relation $R$ on $A$ is asymmetric if:

$$\forall x, y \in A, \quad (x, y) \in R \implies (y, x) \notin R$$

Asymmetry is equivalent to being both anti-symmetric and irreflexive.

1.2.3 Transitivity: The Conditional Premise

Definition: A relation $R$ on a set $A$ is said to be transitive if, whenever an element $x$ is related to $y$, and $y$ is related to $z$, it necessarily implies that $x$ is related to $z$. Formally:

$$\forall x, y, z \in A, \quad ((x, y) \in R \land (y, z) \in R) \implies (x, z) \in R$$

The Vacuous Truth Condition (Examiner Trap): Transitivity is formulated as a conditional statement: $P \implies Q$, where $P \equiv ((x, y) \in R \land (y, z) \in R)$ and $Q \equiv ((x, z) \in R)$. In classical mathematical logic, the implication $P \implies Q$ is true whenever the premise $P$ is false.

Therefore, if there do not exist elements $x, y, z \in A$ such that $(x, y) \in R$ and $(y, z) \in R$ simultaneously, the condition is satisfied vacuously. For example, consider the set $A = \{1, 2, 3\}$ and the relation $R = \{(1, 2)\}$. Here, $(1, 2) \in R$, but there is no ordered pair starting with $2$ (i.e., no $(2, k) \in R$). The premise cannot be fulfilled, meaning no contradiction can be established. Thus, $R = \{(1, 2)\}$ is transitive. Students frequently forfeit marks by asserting that such relations are non-transitive due to a perceived "lack of steps."

To disprove transitivity, one must provide a specific triplet of elements $a, b, c \in A$ such that:

$$(a, b) \in R \quad \land \quad (b, c) \in R \quad \land \quad (a, c) \notin R$$

1.3 Equivalence Relations, Equivalence Classes, and Partition Theory

An equivalence relation represents the abstract mathematical realization of "sameness" or qualitative indistinguishability under a specified criterion.

Formal Definition: A binary relation $R$ on a set $A$ is an equivalence relation if and only if it satisfies all three axioms:

  1. Reflexivity: $\forall a \in A, \; (a, a) \in R$
  2. Symmetry: $\forall a, b \in A, \; (a, b) \in R \implies (b, a) \in R$
  3. Transitivity: $\forall a, b, c \in A, \; ((a, b) \in R \land (b, c) \in R) \implies (a, c) \in R$

1.3.1 Key Theorems Governing Equivalence Relations

Theorem 1: The intersection of two equivalence relations on a set $A$ is also an equivalence relation on $A$.

Rigorous Proof: Let $R$ and $S$ be two equivalence relations on $A$. We analyze $R \cap S$:

  • Reflexivity: Let $a \in A$ be arbitrary. Since $R$ is reflexive, $(a, a) \in R$. Since $S$ is reflexive, $(a, a) \in S$. By set intersection definition, $(a, a) \in R \cap S$. Thus, $R \cap S$ is reflexive.
  • Symmetry: Let $(a, b) \in R \cap S$. Then $(a, b) \in R$ and $(a, b) \in S$. Because $R$ and $S$ are symmetric, $(b, a) \in R$ and $(b, a) \in S$. Therefore, $(b, a) \in R \cap S$, establishing symmetry.
  • Transitivity: Let $(a, b) \in R \cap S$ and $(b, c) \in R \cap S$. This implies: $$((a, b) \in R \land (a, b) \in S) \quad \text{and} \quad ((b, c) \in R \land (b, c) \in S)$$ Grouping by relations: $((a, b) \in R \land (b, c) \in R) \implies (a, c) \in R$ (since $R$ is transitive). Similarly, $((a, b) \in S \land (b, c) \in S) \implies (a, c) \in S$ (since $S$ is transitive). Hence, $(a, c) \in R \cap S$, proving transitivity.

Since $R \cap S$ is reflexive, symmetric, and transitive, it is an equivalence relation on $A$. $\blacksquare$

Theorem 2: The union of two equivalence relations on a set $A$ is NOT necessarily an equivalence relation on $A$.

Counterexample: Let $A = \{1, 2, 3\}$. Define:

$$R = \{(1, 1), (2, 2), (3, 3), (1, 2), (2, 1)\}$$ $$S = \{(1, 1), (2, 2), (3, 3), (2, 3), (3, 2)\}$$

Both $R$ and $S$ are reflexive, symmetric, and transitive, hence they are equivalence relations. Now consider their union:

$$R \cup S = \{(1, 1), (2, 2), (3, 3), (1, 2), (2, 1), (2, 3), (3, 2)\}$$

Notice that $(1, 2) \in R \cup S$ and $(2, 3) \in R \cup S$. However, for $R \cup S$ to be transitive, we must have $(1, 3) \in R \cup S$. Inspection reveals $(1, 3) \notin R \cup S$. Thus, transitivity fails, and $R \cup S$ is not an equivalence relation.

1.3.2 Equivalence Classes: Definitions and Invariants

Let $R$ be an equivalence relation defined on a non-empty set $A$. Let $a \in A$. The equivalence class determined by the representative element $a$, denoted by $[a]$, or alternatively $\bar{a}$ or $C(a)$, is the set of all elements in $A$ that are related to $a$ under $R$:

$$[a] = \{x \in A : (x, a) \in R\}$$

By symmetry of $R$, $(x, a) \in R \iff (a, x) \in R$, so $[a] = \{x \in A : (a, x) \in R\}$.

Fundamental Properties of Equivalence Classes:

  1. Non-emptiness: $\forall a \in A, \; a \in [a]$. This follows immediately from reflexivity, $(a, a) \in R$. Hence, an equivalence class is never empty: $[a] \ne \emptyset$.
  2. Equivalence of Classes: For any $a, b \in A$, the following statements are logically equivalent:

    $$(a, b) \in R \iff [a] = [b] \iff [a] \cap [b] \ne \emptyset$$

  3. Disjointness or Identity: Any two equivalence classes are either strictly pairwise disjoint or completely identical:

    $$\forall a, b \in A, \quad \text{either } [a] \cap [b] = \emptyset \quad \text{or} \quad [a] = [b]$$

    Proof: Assume $[a] \cap [b] \ne \emptyset$. Then there exists $x \in A$ such that $x \in [a]$ and $x \in [b]$. By definition, $(x, a) \in R$ and $(x, b) \in R$. By symmetry, $(a, x) \in R$. Applying transitivity to $(a, x) \in R$ and $(x, b) \in R$ yields $(a, b) \in R$.

    Now let $y \in [a]$ be arbitrary. Then $(y, a) \in R$. Since $(a, b) \in R$, by transitivity we obtain $(y, b) \in R \implies y \in [b]$. Thus, $[a] \subseteq [b]$. Reversing the roles by symmetry yields $[b] \subseteq [a]$. Consequently, $[a] = [b]$. Thus, if they share even a single element, they are identical. $\blacksquare$

1.3.3 The Fundamental Theorem of Equivalence Relations (Partition Theory)

A partition $\mathcal{P}$ of a non-empty set $A$ is a collection of non-empty, pairwise disjoint subsets $\{A_i\}_{i \in I}$ of $A$ such that their union covers the entire set $A$:

  1. $A_i \ne \emptyset$ for all $i \in I$
  2. $A_i \cap A_j = \emptyset$ whenever $i \ne j$ (mutually disjoint)
  3. $\bigcup_{i \in I} A_i = A$ (collectively exhaustive)

The Fundamental Theorem: An equivalence relation $R$ on a set $A$ partitions the set $A$ into a collection of mutually disjoint equivalence classes whose union is $A$. Conversely, every partition of $A$ uniquely defines an equivalence relation on $A$ for which the partition blocks are the equivalence classes.

The set of all equivalence classes is known as the Quotient Set of $A$ modulo $R$, denoted by:

$$A / R = \{[a] : a \in A\}$$

1.3.4 Combinatorial Enumeration of Relations on Finite Sets

Let $A$ be a finite set with $|A| = n$.

Type of Relation Counting Formula Mathematical Derivation / Logic
Total Relations $2^{n^2}$ Each of the $n^2$ ordered pairs in $A \times A$ can be independently included or excluded ($2^{n^2}$).
Reflexive Relations $2^{n(n-1)}$ All $n$ diagonal pairs $(x, x)$ must be included (1 choice). The remaining $n^2 - n = n(n-1)$ off-diagonal pairs can be freely included or excluded ($2^{n(n-1)}$).
Symmetric Relations $2^{\frac{n(n+1)}{2}}$ There are $n$ diagonal pairs with 2 choices each. The $\frac{n(n-1)}{2}$ unordered off-diagonal pairs $\{x, y\}$ dictate that $(x, y)$ and $(y, x)$ must enter or exit together ($2^{\frac{n(n-1)}{2}}$). Total = $2^n \cdot 2^{\frac{n(n-1)}{2}} = 2^{\frac{n(n+1)}{2}}$.
Reflexive & Symmetric $2^{\frac{n(n-1)}{2}}$ All $n$ diagonal pairs are forced to be present ($1^n = 1$). The $\frac{n(n-1)}{2}$ off-diagonal symmetrical pairs have 2 choices each.
Equivalence Relations $B_n$ (Bell Number) Corresponds bijectively to partitions of a set of size $n$. Recurrence: $B_{n+1} = \sum_{k=0}^{n} \binom{n}{k} B_k$, with $B_0 = 1, B_1 = 1, B_2 = 2, B_3 = 5, B_4 = 15$.

1.4 Functions as Single-Valued Relations

A function (or mapping) $f$ from a set $A$ to a set $B$, denoted $f: A \to B$, is a specialized subset of $A \times B$ conforming to two foundational existence and uniqueness conditions:

  1. Existence (Totality): Every element in the domain $A$ must be associated with an element in the codomain $B$: $$\forall x \in A, \; \exists\, y \in B \text{ such that } (x, y) \in f$$
  2. Uniqueness (Single-Valuedness): No element in $A$ can be associated with more than one element in $B$: $$\forall x \in A \text{ and } \forall y_1, y_2 \in B, \; ((x, y_1) \in f \land (x, y_2) \in f) \implies y_1 = y_2$$

When $(x, y) \in f$, we write $f(x) = y$, where $y$ is called the image of $x$ under $f$, and $x$ is called a pre-image of $y$ under $f$.

Total Functions Count: If $|A| = m$ and $|B| = n$, each of the $m$ distinct domain elements can be mapped independently to any of the $n$ codomain elements. Thus:

$$N_{\text{functions}} = n^m = |B|^{|A|}$$

1.5 Comprehensive Classification of Functions

Functions are classified by the structural mapping between domain and codomain elements. CBSE questions routinely demand analytical proofs confirming or refuting these classifications.

1.5.1 Injective (One-One) Functions

Definition: A function $f: A \to B$ is called injective (or one-to-one) if distinct elements of $A$ map to distinct images in $B$.

$$\forall x_1, x_2 \in A, \quad x_1 \ne x_2 \implies f(x_1) \ne f(x_2)$$

Contrapositive Algebraic Criterion (Examiner Proof Technique): In formal board examination proofs, establishing the conditional contrapositive is the required approach:

$$\forall x_1, x_2 \in A, \quad f(x_1) = f(x_2) \implies x_1 = x_2$$

If $f(x_1) = f(x_2)$ allows any non-trivial solution where $x_1 \ne x_2$, the function is many-one.

Calculus Criterion (Monotonicity Test): Let $f: I \to \mathbb{R}$ be a differentiable function on an open interval $I \subseteq \mathbb{R}$.

  • If the first derivative is strictly positive throughout the interval, i.e., $f'(x) > 0 \; \forall x \in I$ (strictly increasing), or strictly negative throughout the interval, i.e., $f'(x) < 0 \; \forall x \in I$ (strictly decreasing), then $f$ is strictly monotonic on $I$.
  • Every strictly monotonic function is guaranteed to be injective on its domain.
  • If $f'(x)$ changes sign across the domain, there exist distinct points having the same image, proving the function is not injective (many-one).

Geometric Criterion (The Horizontal Line Test): A function $y = f(x)$ graphed in the Cartesian plane is injective if and only if every horizontal line $y = k$ (where $k \in \operatorname{Codomain}(f)$) intersects the graph at most once. If any horizontal line intersects the graph at two or more distinct points, those coordinates represent distinct inputs $x_1 \ne x_2$ producing identical output $f(x_1) = f(x_2) = k$, confirming the function is many-one.

Cardinality Constraint for Injectivity: For an injective function $f: A \to B$ to exist between finite sets, the target set must contain at least as many elements as the domain:

$$|A| \le |B|$$

If $|A| = m$ and $|B| = n$ with $m \le n$, the number of possible injective functions corresponds to permutations:

$$N_{\text{injective}} = {}^{n}P_m = \frac{n!}{(n-m)!}$$

If $m > n$, by Dirichlet's Box (Pigeonhole) Principle, $N_{\text{injective}} = 0$.

1.5.2 Surjective (Onto) Functions

Definition: A function $f: A \to B$ is called surjective (or onto) if every element of the codomain $B$ has at least one corresponding pre-image in the domain $A$.

$$\forall y \in B, \; \exists\, x \in A \text{ such that } f(x) = y$$

Equivalently, a function is surjective if and only if its range equals its codomain:

$$\operatorname{Ran}(f) = f(A) = B$$

If $\operatorname{Ran}(f) \subsetneq B$, there exists at least one element $y \in B$ lacking any pre-image in $A$. In this case, the function is termed into.

Analytical Proof Algorithm for Surjectivity:

  1. Set up the equation $y = f(x)$, treating $y$ as an arbitrary variable belonging to the codomain $B$.
  2. Perform algebraic operations to invert the equation, expressing $x$ explicitly in terms of $y$: $x = g(y)$.
  3. Analyze whether for every possible value $y \in B$, the resulting $x$ is guaranteed to:
    • Be mathematically defined (no zero denominators, no real roots of negative numbers, etc.).
    • Belong strictly to the specified domain set $A$.
  4. Confirm by back-substitution that $f(g(y)) = y$. If any value $y \in B$ yields an $x \notin A$ or undefined expression, surjectivity fails.

Cardinality Constraint for Surjectivity: For a surjective function $f: A \to B$ to exist between finite sets, the domain must contain at least as many elements as the codomain:

$$|A| \ge |B|$$

If $|A| = m$ and $|B| = n$ with $m < n$, then $N_{\text{surjective}} = 0$.

When $m \ge n$, the number of surjective functions can be calculated using Stirling Numbers of the Second Kind $S(m, n)$ or the Principle of Inclusion-Exclusion (PIE):

$$N_{\text{surjective}} = \sum_{k=0}^{n} (-1)^k \binom{n}{k} (n-k)^m = n! \, S(m, n)$$

1.5.3 Bijective (One-One and Onto) Functions

Definition: A function $f: A \to B$ is called bijective (or a one-to-one correspondence) if it is simultaneously injective and surjective:

$$f \text{ is bijective} \iff (f \text{ is one-one}) \land (f \text{ is onto})$$

Cardinality Equivalence for Finite Sets: If sets $A$ and $B$ are finite, a bijection can exist between them if and only if:

$$|A| = |B| = n$$

Under this condition ($|A| = |B| = n$), the following statements are logically equivalent:

  • $f: A \to B$ is injective.
  • $f: A \to B$ is surjective.
  • $f: A \to B$ is bijective.

The number of bijective functions between two finite sets of identical size $n$ is given by:

$$N_{\text{bijective}} = n!$$

1.6 Composition of Functions: Structural Mechanics

Function composition represents the sequential chained evaluation of mappings.

Definition: Let $f: A \to B$ and $g: B \to C$ be two functions. The composite function, denoted by $g \circ f$ (read as "$g$ circle $f$" or "$g$ composed with $f$"), is a mapping from $A$ to $C$ defined by:

$$(g \circ f)(x) = g(f(x)), \quad \forall x \in A$$

Existence Criterion: The composite function $g \circ f$ is mathematically defined if and only if the range of the inner function $f$ is a subset of the domain of the outer function $g$:

$$\operatorname{Ran}(f) \subseteq \operatorname{Dom}(g)$$

If $\operatorname{Ran}(f) \not\subseteq \operatorname{Dom}(g)$, $g(f(x))$ cannot be evaluated for elements $x$ whose image $f(x)$ falls outside the domain of $g$. In such cases, the domain of $g \circ f$ must be restricted:

$$\operatorname{Dom}(g \circ f) = \{x \in \operatorname{Dom}(f) : f(x) \in \operatorname{Dom}(g)\}$$

1.6.1 Structural Properties of Function Composition

  1. Non-Commutativity: In general, function composition does not commute: $$g \circ f \ne f \circ g$$ Even when both operations exist (e.g., $f: A \to A$ and $g: A \to A$), $g(f(x))$ and $f(g(x))$ typically evaluate to completely distinct functional expressions.
  2. Associativity: Function composition is strictly associative. Let $f: A \to B$, $g: B \to C$, and $h: C \to D$. Then: $$h \circ (g \circ f) = (h \circ g) \circ f$$ Proof: Let $x \in A$. $$\big(h \circ (g \circ f)\big)(x) = h\big((g \circ f)(x)\big) = h\big(g(f(x))\big)$$ $$\big((h \circ g) \circ f\big)(x) = (h \circ g)(f(x)) = h\big(g(f(x))\big)$$ Since both mappings have identical domains ($A$), identical codomains ($D$), and map every $x \in A$ to the same value in $D$, the equality holds. $\blacksquare$
  3. Interaction with Identity Functions: Let $f: A \to B$. If $I_A: A \to A$ and $I_B: B \to B$ are the identity functions on sets $A$ and $B$ respectively: $$f \circ I_A = f \quad \text{and} \quad I_B \circ f = f$$

1.6.2 Inheritance of Mapping Properties Through Composition

Theorem 3 (Preservation of Injectivity): If $f: A \to B$ and $g: B \to C$ are both injective, then the composite function $g \circ f: A \to C$ is also injective.

Proof: Let $x_1, x_2 \in A$. Assume:

$$(g \circ f)(x_1) = (g \circ f)(x_2) \implies g(f(x_1)) = g(f(x_2))$$

Since $g$ is injective, $g(u) = g(v) \implies u = v$. Applying this where $u = f(x_1)$ and $v = f(x_2)$:

$$f(x_1) = f(x_2)$$

Since $f$ is also injective, $f(x_1) = f(x_2) \implies x_1 = x_2$. Hence, $g \circ f$ is injective. $\blacksquare$

Theorem 4 (Preservation of Surjectivity): If $f: A \to B$ and $g: B \to C$ are both surjective, then $g \circ f: A \to C$ is also surjective.

Proof: Let $z \in C$ be arbitrary. Since $g: B \to C$ is surjective, there exists an element $y \in B$ such that $g(y) = z$. Since $f: A \to B$ is surjective, for that element $y \in B$, there exists an element $x \in A$ such that $f(x) = y$. Substituting $y = f(x)$ into the first expression:

$$g(f(x)) = z \implies (g \circ f)(x) = z$$

Thus, for every $z \in C$, there exists an $x \in A$ such that $(g \circ f)(x) = z$. Hence, $g \circ f$ is surjective. $\blacksquare$

Theorem 5 (Preservation of Bijectivity): If $f: A \to B$ and $g: B \to C$ are bijections, then $g \circ f: A \to C$ is also a bijection. (Follows directly from Theorems 3 and 4).

1.6.3 Converse Inferences from Composite Functions

Board examinations frequently feature questions testing the converse conditions:

  • If $g \circ f$ is injective: Then the inner function $f$ must be injective. The outer function $g$ is not required to be injective.
    Proof: Suppose $f$ were not injective. Then $\exists x_1 \ne x_2$ such that $f(x_1) = f(x_2)$. Applying $g$ yields $g(f(x_1)) = g(f(x_2)) \implies (g \circ f)(x_1) = (g \circ f)(x_2)$, which directly contradicts the injectivity of $g \circ f$.
  • If $g \circ f$ is surjective: Then the outer function $g$ must be surjective. The inner function $f$ is not required to be surjective.
    Proof: Suppose $g$ were not surjective. Then $\exists z \in C$ such that no $y \in B$ satisfies $g(y) = z$. Since the range of $f$ is a subset of $B$, there cannot exist any $x \in A$ such that $g(f(x)) = z$, contradicting the surjectivity of $g \circ f$.

1.7 Invertibility of Functions and Inverse Mechanics

The concept of function inversion reverses the causal mapping of an operation.

Formal Definition: A function $f: A \to B$ is said to be invertible if there exists a function $g: B \to A$ such that:

$$g \circ f = I_A \quad \text{and} \quad f \circ g = I_B$$

The function $g$ is called the inverse of $f$, uniquely denoted as $f^{-1}: B \to A$.

The Fundamental Invertibility Theorem: A function $f: A \to B$ is invertible if and only if it is a bijection (both injective and surjective).

Proof ($\implies$ Direction): Assume $f$ is invertible. Then there exists $g: B \to A$ such that $g \circ f = I_A$ and $f \circ g = I_B$.

  • Since $g \circ f = I_A$ and $I_A$ is injective, by Section 1.6.3, the inner function $f$ must be injective.
  • Since $f \circ g = I_B$ and $I_B$ is surjective, by Section 1.6.3, the outer function $f$ must be surjective.
  • Therefore, $f$ is both injective and surjective, which means it is bijective.

Proof ($\impliedby$ Direction): Assume $f: A \to B$ is bijective.

  • Since $f$ is surjective, for every $y \in B$, there exists at least one $x \in A$ such that $f(x) = y$.
  • Since $f$ is injective, this element $x$ is unique.
  • Thus, we can define a rule $g: B \to A$ that maps each $y \in B$ to this unique $x \in A$, so $g(y) = x \iff f(x) = y$.
  • Then $(g \circ f)(x) = g(f(x)) = g(y) = x = I_A(x)$ for all $x \in A$, meaning $g \circ f = I_A$.
  • Similarly, $(f \circ g)(y) = f(g(y)) = f(x) = y = I_B(y)$ for all $y \in B$, meaning $f \circ g = I_B$.
  • Therefore, $f$ is invertible and $g = f^{-1}$. $\blacksquare$

1.7.1 Structural Properties of Inverse Functions

  1. Uniqueness of the Inverse: If a function possesses an inverse, that inverse is unique.
    Proof: Assume $g_1$ and $g_2$ are both inverses of $f: A \to B$. Then: $$g_1 = g_1 \circ I_B = g_1 \circ (f \circ g_2) = (g_1 \circ f) \circ g_2 = I_A \circ g_2 = g_2$$ Hence, $g_1 = g_2$. $\blacksquare$
  2. Involution Property: If $f: A \to B$ is a bijection, then $f^{-1}: B \to A$ is also a bijection, and its inverse is the original function: $$(f^{-1})^{-1} = f$$
  3. The Reversal Law for Composition: Let $f: A \to B$ and $g: B \to C$ be invertible functions. Then the composite function $g \circ f: A \to C$ is also invertible, and its inverse is given by: $$(g \circ f)^{-1} = f^{-1} \circ g^{-1}$$ Rigorous Verification Proof: We test whether $(f^{-1} \circ g^{-1})$ satisfies the inversion axioms with $(g \circ f)$: $$(f^{-1} \circ g^{-1}) \circ (g \circ f) = f^{-1} \circ (g^{-1} \circ g) \circ f = f^{-1} \circ I_B \circ f = f^{-1} \circ f = I_A$$ $$(g \circ f) \circ (f^{-1} \circ g^{-1}) = g \circ (f \circ f^{-1}) \circ g^{-1} = g \circ I_B \circ g^{-1} = g \circ g^{-1} = I_C$$ Since both left- and right-composition produce their respective identity mappings, the reversal law holds. $\blacksquare$

1.7.2 Geometric Characterization of Invertibility

Analytically, if a point $(a, b)$ lies on the curve $y = f(x)$, then by definition $f(a) = b$. From the invertibility condition:

$$f(a) = b \iff f^{-1}(b) = a$$

This indicates that the point $(b, a)$ lies on the curve $y = f^{-1}(x)$. In Cartesian coordinate geometry, the coordinate transformation $(x, y) \mapsto (y, x)$ represents an orthogonal reflection across the identity line:

$$y = x$$

Consequently, the graph of $y = f^{-1}(x)$ is the mirror reflection of the graph of $y = f(x)$ across the line $y = x$. Intersections between $y = f(x)$ and $y = f^{-1}(x)$, if they exist for monotonically increasing functions, must lie along the axis of symmetry $y = x$.

1.8 Theory of Binary Operations

A binary operation represents an algebraic abstraction of arithmetic operations like addition and multiplication.

Formal Definition: A binary operation $*$ on a non-empty set $A$ is a function from the Cartesian product $A \times A$ into $A$:

$$*: A \times A \to A$$

We denote the image of an ordered pair $(a, b) \in A \times A$ under $*$ as $a * b$ rather than $*((a, b))$.

Closure Property: The fact that the codomain of $*$ is $A$ constitutes the closure property:

$$\forall a, b \in A \implies a * b \in A$$

If any pair $(a, b) \in A \times A$ produces a value outside $A$, then $*$ is not a binary operation on $A$. For example, normal subtraction ($-$) is a binary operation on $\mathbb{Z}$ (since $a - b \in \mathbb{Z}$), but it is not a binary operation on the natural numbers $\mathbb{N}$ (since $2 - 5 = -3 \notin \mathbb{N}$).

Total Number of Binary Operations: Let $|A| = n$. The domain of $*$ is $A \times A$, which contains $n^2$ elements. The codomain is $A$, containing $n$ elements. Hence, the total number of binary operations that can be defined on $A$ is:

$$N_{\text{binary operations}} = |A|^{|A \times A|} = n^{n^2}$$

1.8.1 Axiomatic Algebraic Properties

  1. Commutativity: A binary operation $*$ on a set $A$ is commutative if the order of the operands does not affect the outcome: $$\forall a, b \in A, \quad a * b = b * a$$ Counting Commutative Binary Operations: For a set of size $n$, a commutative operation is determined by its values on the diagonal elements ($n$ choices) and the strictly upper triangular elements ($\frac{n^2 - n}{2}$ choices). This yields: $$N_{\text{commutative}} = n^{\frac{n(n+1)}{2}}$$
  2. Associativity: A binary operation $*$ on a set $A$ is associative if operational grouping does not affect the outcome: $$\forall a, b, c \in A, \quad (a * b) * c = a * (b * c)$$ Associativity ensures expressions like $a * b * c$ can be evaluated without parentheses.
  3. Identity Element: Let $*$ be a binary operation on $A$. An element $e \in A$ is called the identity element for $*$ if: $$\forall a \in A, \quad a * e = e * a = a$$ Theorem (Uniqueness of Identity): If an identity element exists for a binary operation, it is unique.
    Proof: Assume $e_1$ and $e_2$ are both identity elements for $*$ on $A$.
    • Evaluating $e_1 * e_2$ viewing $e_1$ as identity: $e_1 * e_2 = e_2$
    • Evaluating $e_1 * e_2$ viewing $e_2$ as identity: $e_1 * e_2 = e_1$
    Therefore, $e_1 = e_2$. $\blacksquare$
  4. Invertible Elements and Inverses: Let $*$ be a binary operation on $A$ with identity element $e \in A$. An element $a \in A$ is said to be invertible with respect to $*$ if there exists an element $b \in A$ such that: $$a * b = b * a = e$$ The element $b$ is called the inverse of $a$, denoted by $a^{-1}$.
    Theorem (Uniqueness of Inverse): Let $*$ be an associative binary operation on $A$ with identity $e$. If an element $a \in A$ is invertible, its inverse is unique.
    Proof: Assume $b_1$ and $b_2$ are both inverses of $a$. $$b_1 = b_1 * e = b_1 * (a * b_2) = (b_1 * a) * b_2 = e * b_2 = b_2$$ Thus, the inverse is unique. $\blacksquare$

1.8.2 Cayley Tables (Operation Tables) for Finite Sets

When a set $A = \{a_1, a_2, \dots, a_n\}$ is finite, a binary operation $*$ can be fully represented using an $n \times n$ matrix called a Cayley Table. The element located at the intersection of row $a_i$ and column $a_j$ is the value $a_i * a_j$.

Diagnostic Properties from Cayley Tables:

  • Closure: Every entry inside the table must be an element belonging to set $A$.
  • Commutativity: The Cayley table must be symmetric across its main diagonal (running from top-left to bottom-right). That is, entry $(i, j)$ must match entry $(j, i)$ for all $i, j$.
  • Identity Element ($e$): The identity element corresponds to an element whose row matches the column headers identically in sequence, and whose column matches the row headers identically in sequence.
  • Invertibility: If an identity element $e$ exists, an element $a_i$ is invertible if and only if the identity element $e$ appears at least once in row $a_i$ and column $a_i$ such that the row and column coordinates are symmetric.

1.9 Rigorous CBSE Examination Analysis & Structural Pitfalls

To achieve full marks on relation and function proofs in CBSE Class 12 board assessments, solutions must follow established structural conventions. Examiners frequently deduct marks for common oversights:

Common Trap 1: Conflating "Showing" with "Proving"

Students often provide a specific numeric example to demonstrate that a property holds generally:

Examiner Note: A single numerical example can disprove a property by providing a counterexample. However, a single numerical example cannot prove a property for an infinite set. General proofs must use arbitrary algebraic variables ($x, y, z \in A$).

Common Trap 2: Domain and Codomain Inattention

A formula alone does not define a function; the domain and codomain are fundamental to its identity. For example, consider the squaring operation:

  • $f: \mathbb{R} \to \mathbb{R}, \; f(x) = x^2$: Neither injective (since $f(-2) = f(2) = 4$) nor surjective (negative numbers have no real pre-images).
  • $f: [0, \infty) \to \mathbb{R}, \; f(x) = x^2$: Injective, but not surjective (range is $[0, \infty) \ne \mathbb{R}$).
  • $f: \mathbb{R} \to [0, \infty), \; f(x) = x^2$: Surjective, but not injective.
  • $f: [0, \infty) \to [0, \infty), \; f(x) = x^2$: Bijective and therefore invertible, with $f^{-1}(x) = \sqrt{x}$.

Common Trap 3: The Premise Fallacy in Transitivity

Consider the relation $R = \{(a, b) \in \mathbb{R} \times \mathbb{R} : 1 + ab > 0\}$.

  • Reflexive: For any $a \in \mathbb{R}$, $1 + a \cdot a = 1 + a^2 > 0$ (since $a^2 \ge 0$). Thus $(a, a) \in R$. Holds.
  • Symmetric: If $(a, b) \in R$, then $1 + ab > 0 \implies 1 + ba > 0 \implies (b, a) \in R$. Holds.
  • Transitive: Many students assume this is transitive without testing carefully chosen counterexamples. Let $a = -1$, $b = 0$, $c = 2$:
    • $(a, b) = (-1, 0) \implies 1 + (-1)(0) = 1 > 0$ (True, so $(-1, 0) \in R$)
    • $(b, c) = (0, 2) \implies 1 + (0)(2) = 1 > 0$ (True, so $(0, 2) \in R$)
    • Check $(a, c) = (-1, 2) \implies 1 + (-1)(2) = 1 - 2 = -1 \ngtr 0$ (False, so $(-1, 2) \notin R$)
    Thus, transitivity fails.

Common Trap 4: Assuming Left and Right Operations Match Without Checking

For a binary operation $*$ that has not been proved commutative, both conditions must be verified separately:

$$\text{Identity: } a * e = a \quad \text{AND} \quad e * a = a$$ $$\text{Inverse: } a * b = e \quad \text{AND} \quad b * a = e$$

Verifying only one direction forfeits procedural marks in CBSE evaluations.

Derivation 1: Total Number of Reflexive Relations on a Set with $n$ Elements

Theorem: Let $A$ be a finite set such that $|A| = n$. The total number of reflexive relations on $A$ is $2^{n(n-1)}$.

Proof:

Step 1: Determine the cardinality of the Cartesian Product $A \times A$.

A relation $R$ on set $A$ is defined as an arbitrary subset of the Cartesian product $A \times A$:

$$|A \times A| = |A| \times |A| = n \times n = n^2$$

Step 2: Partition the Cartesian Product into diagonal and non-diagonal pairs.

The set $A \times A$ can be partitioned into two disjoint subsets:

  • Diagonal elements ($D$): Elements of the form $(a_i, a_i)$ for all $i \in \{1, 2, \dots, n\}$. $$|D| = n$$
  • Non-diagonal elements ($D'$): Elements of the form $(a_i, a_j)$ where $i \neq j$. $$|D'| = |A \times A| - |D| = n^2 - n = n(n-1)$$

Step 3: Apply the condition for reflexivity.

By definition, a relation $R \subseteq A \times A$ is reflexive if and only if:

$$\forall a_i \in A, \quad (a_i, a_i) \in R$$

Thus, every diagonal element of $D$ must unconditionally be included in $R$. For each element in $D$, the number of choices is exactly $1$:

$$\text{Choices for diagonal elements} = 1^n = 1$$

Step 4: Count combinations for non-diagonal pairs.

For each non-diagonal ordered pair $(a_i, a_j) \in D'$ (where $i \neq j$), reflexivity imposes no restriction. Each pair may either be included in $R$ or excluded from $R$. Hence, there are $2$ independent choices per pair:

$$\text{Choices for non-diagonal elements} = \underbrace{2 \times 2 \times \cdots \times 2}_{n(n-1) \text{ times}} = 2^{n(n-1)}$$

Step 5: Compute the total product.

By the fundamental principle of counting:

$$N_{\text{ref}} = 1 \times 2^{n(n-1)} = 2^{n(n-1)}$$

$\blacksquare$

Derivation 2: Total Number of Symmetric Relations on a Set with $n$ Elements

Theorem: Let $A$ be a finite set such that $|A| = n$. The total number of symmetric relations on $A$ is $2^{\frac{n(n+1)}{2}}$.

Proof:

Step 1: Structural condition for symmetry.

A relation $R$ on $A$ is symmetric if and only if:

$$(a_i, a_j) \in R \iff (a_j, a_i) \in R \quad \forall a_i, a_j \in A$$

Step 2: Grouping of elements in $A \times A$.

Consider the matrix representation of $A \times A$ of size $n \times n$:

  • Diagonal pairs $(a_i, a_i)$: There are $n$ such pairs. Here, $(a_i, a_i)$ is its own transpose. Inclusion of $(a_i, a_i)$ in $R$ is independent of all other pairs. Hence, there are $2$ options (include or exclude) for each of the $n$ diagonal pairs.
  • Off-diagonal symmetric pairs $\{(a_i, a_j), (a_j, a_i)\}$ ($i < j$): The total number of off-diagonal pairs is $n^2 - n$. Since $(a_i, a_j) \in R \iff (a_j, a_i) \in R$, the pairs $(a_i, a_j)$ and $(a_j, a_i)$ must be chosen together:
    • Option 1: Both $(a_i, a_j) \in R$ and $(a_j, a_i) \in R$.
    • Option 2: Neither $(a_i, a_j) \in R$ nor $(a_j, a_i) \in R$.
    Thus, each unordered pair $\{a_i, a_j\}$ with $i \neq j$ provides exactly $2$ choices.

Step 3: Count the total number of independent symmetric decision units.

The number of unordered pairs of distinct elements is $\binom{n}{2} = \frac{n(n-1)}{2}$.

Total independent decisions $k$ required to construct a symmetric relation is the sum of diagonal pairs and distinct off-diagonal pairs:

$$k = n + \frac{n(n-1)}{2} = \frac{2n + n^2 - n}{2} = \frac{n^2 + n}{2} = \frac{n(n+1)}{2}$$

Step 4: Total symmetric relations.

Since each independent decision has $2$ choices:

$$N_{\text{sym}} = 2^k = 2^{\frac{n(n+1)}{2}}$$

$\blacksquare$

Derivation 3: Associativity of Function Composition

Theorem: Let $f: A \to B$, $g: B \to C$, and $h: C \to D$ be functions. Then:

$$h \circ (g \circ f) = (h \circ g) \circ f$$

Proof:

Step 1: Verify domains and codomains of both composite functions.

The inner compositions have mappings:

$$(g \circ f): A \to C \implies h \circ (g \circ f): A \to D$$ $$(h \circ g): B \to D \implies (h \circ g) \circ f: A \to D$$

Both composite functions possess identical domain $A$ and identical codomain $D$.

Step 2: Evaluate point-wise equality for an arbitrary element $x \in A$.

By the formal definition of composite functions, $(u \circ v)(t) = u(v(t))$:

Evaluate Left Hand Side (LHS):

$$\text{LHS} = [h \circ (g \circ f)](x) = h((g \circ f)(x))$$

Substitute the inner expansion $(g \circ f)(x) = g(f(x))$:

$$\text{LHS} = h(g(f(x)))$$

Evaluate Right Hand Side (RHS):

$$\text{RHS} = [((h \circ g) \circ f)](x) = (h \circ g)(f(x))$$

Let $y = f(x) \in B$. By definition of $(h \circ g)$:

$$(h \circ g)(y) = h(g(y)) = h(g(f(x)))$$ $$\implies \text{RHS} = h(g(f(x)))$$

Step 3: Conclusion.

$$\text{LHS} = \text{RHS} = h(g(f(x))) \quad \forall x \in A$$

Hence, $h \circ (g \circ f) = (h \circ g) \circ f$.

$\blacksquare$

Derivation 4: Invertibility of Composite Function: $(g \circ f)^{-1} = f^{-1} \circ g^{-1}$

Theorem: Let $f: A \to B$ and $g: B \to C$ be invertible (bijective) functions. Then $g \circ f$ is invertible, and its inverse is given by $(g \circ f)^{-1} = f^{-1} \circ g^{-1}$.

Proof:

Step 1: Statement of Criterion for Invertibility.

A function $\phi: X \to Y$ is the two-sided inverse of $\psi: Y \to X$ if and only if:

$$\phi \circ \psi = I_Y \quad \text{and} \quad \psi \circ \phi = I_X$$

Here, $g \circ f: A \to C$. To prove that $f^{-1} \circ g^{-1}: C \to A$ is the inverse of $g \circ f$, we must establish:

$$(f^{-1} \circ g^{-1}) \circ (g \circ f) = I_A \quad \text{and} \quad (g \circ f) \circ (f^{-1} \circ g^{-1}) = I_C$$

Step 2: Verification of the Left Composition.

Applying the associativity of function composition:

$$\big(f^{-1} \circ g^{-1}\big) \circ (g \circ f) = f^{-1} \circ \big(g^{-1} \circ (g \circ f)\big)$$ $$\phantom{\big(f^{-1} \circ g^{-1}\big) \circ (g \circ f)} = f^{-1} \circ \big((g^{-1} \circ g) \circ f\big)$$

Since $g$ is invertible, $g^{-1} \circ g = I_B$ (the identity function on set $B$):

$$\phantom{\big(f^{-1} \circ g^{-1}\big) \circ (g \circ f)} = f^{-1} \circ (I_B \circ f)$$

Because $I_B \circ f = f$:

$$\phantom{\big(f^{-1} \circ g^{-1}\big) \circ (g \circ f)} = f^{-1} \circ f$$

Since $f$ is invertible, $f^{-1} \circ f = I_A$ (the identity function on set $A$):

$$\big(f^{-1} \circ g^{-1}\big) \circ (g \circ f) = I_A$$

Step 3: Verification of the Right Composition.

Using associativity symmetrically:

$$(g \circ f) \circ \big(f^{-1} \circ g^{-1}\big) = g \circ \big(f \circ (f^{-1} \circ g^{-1})\big)$$ $$\phantom{(g \circ f) \circ \big(f^{-1} \circ g^{-1}\big)} = g \circ \big((f \circ f^{-1}) \circ g^{-1}\big)$$

Since $f \circ f^{-1} = I_B$:

$$\phantom{(g \circ f) \circ \big(f^{-1} \circ g^{-1}\big)} = g \circ (I_B \circ g^{-1})$$ $$\phantom{(g \circ f) \circ \big(f^{-1} \circ g^{-1}\big)} = g \circ g^{-1} = I_C$$

Step 4: Conclusion.

Since both conditions hold identically, the function $(f^{-1} \circ g^{-1})$ is the unique inverse of $(g \circ f)$:

$$(g \circ f)^{-1} = f^{-1} \circ g^{-1}$$

$\blacksquare$

Derivation 5: Fundamental Theorem of Equivalence Relations (Disjoint Equivalence Classes)

Theorem: Let $R$ be an equivalence relation on a non-empty set $A$. For any $a, b \in A$, the equivalence classes $[a]$ and $[b]$ are either identical or mutually disjoint:

$$[a] = [b] \iff (a, b) \in R \quad \text{and} \quad [a] \cap [b] \neq \emptyset \implies [a] = [b]$$

Proof:

Part 1: Prove that $[a] \cap [b] \neq \emptyset \implies [a] = [b]$.

Assume $[a] \cap [b] \neq \emptyset$. Therefore, there exists at least one element $x \in A$ such that:

$$x \in [a] \quad \text{and} \quad x \in [b]$$

By the definition of an equivalence class $[y] = \{z \in A : (z, y) \in R\}$:

$$(x, a) \in R \quad \text{and} \quad (x, b) \in R$$

Since $R$ is symmetric:

$$(x, a) \in R \implies (a, x) \in R$$

Now, applying transitivity with $(a, x) \in R$ and $(x, b) \in R$:

$$(a, b) \in R$$

Part 2: Prove $[a] \subseteq [b]$.

Let $y$ be an arbitrary element in $[a]$. Then:

$$(y, a) \in R$$

Using $(y, a) \in R$ and $(a, b) \in R$, by transitivity:

$$(y, b) \in R \implies y \in [b]$$

Because every element of $[a]$ belongs to $[b]$:

$$[a] \subseteq [b]$$

Part 3: Prove $[b] \subseteq [a]$.

Since $(a, b) \in R$, symmetry ensures that $(b, a) \in R$. Let $z$ be an arbitrary element in $[b]$:

$$(z, b) \in R$$

By transitivity with $(z, b) \in R$ and $(b, a) \in R$:

$$(z, a) \in R \implies z \in [a]$$

Therefore:

$$[b] \subseteq [a]$$

Part 4: Conclusion.

Since $[a] \subseteq [b]$ and $[b] \subseteq [a]$, we establish:

$$[a] = [b]$$

Consequently, two equivalence classes are either completely disjoint or identical.

$\blacksquare$

Derivation 6: Number of Surjective (Onto) Functions via Principle of Inclusion-Exclusion (PIE)

Theorem: Let $|A| = m$ and $|B| = n$, where $m \ge n \ge 1$. The number of surjective functions $f: A \to B$ is:

$$S(m, n) = \sum_{r=0}^{n} (-1)^r \binom{n}{r} (n-r)^m = n^m - \binom{n}{1}(n-1)^m + \binom{n}{2}(n-2)^m - \cdots + (-1)^{n-1}\binom{n}{n-1}(1)^m$$

Proof:

Step 1: Define the universal set and deficient properties.

Let $U$ be the set of all possible functions from $A$ to $B$. The total cardinality is:

$$|U| = n^m$$

Let $B = \{b_1, b_2, \dots, b_n\}$. For each index $i \in \{1, 2, \dots, n\}$, define the condition $P_i$ that an element $b_i$ is not in the range of the function:

$$A_i = \{f: A \to B \mid b_i \notin f(A)\}$$

A function is surjective if and only if its range equals $B$, meaning it satisfies none of the conditions $P_1, P_2, \dots, P_n$. Therefore, the number of surjective functions is:

$$S(m, n) = \left| \bigcap_{i=1}^{n} A_i^c \right| = |U| - \left| \bigcup_{i=1}^{n} A_i \right|$$

Step 2: Apply the Principle of Inclusion-Exclusion (PIE).

$$\left| \bigcup_{i=1}^{n} A_i \right| = \sum_{1 \le i \le n} |A_i| - \sum_{1 \le i < j \le n} |A_i \cap A_j| + \sum_{1 \le i < j < k \le n} |A_i \cap A_j \cap A_k| - \cdots + (-1)^{n-1} |A_1 \cap \dots \cap A_n|$$

Step 3: Evaluate intersection terms for $r$ missing elements.

If $r$ specific elements $\{b_{i_1}, \dots, b_{i_r}\}$ are excluded from the range, the function must map all $m$ elements of $A$ into the remaining $n - r$ elements of $B$:

$$|A_{i_1} \cap A_{i_2} \cap \dots \cap A_{i_r}| = (n - r)^m$$

The number of distinct ways to choose $r$ excluded elements from $n$ elements is given by the binomial coefficient $\binom{n}{r}$.

Thus, the sum over all selections of $r$ elements is:

$$S_r = \sum_{1 \le i_1 < \dots < i_r \le n} |A_{i_1} \cap \dots \cap A_{i_r}| = \binom{n}{r}(n - r)^m$$

Step 4: Summing the alternating terms.

Substituting $S_r$ into the PIE formula:

$$\left| \bigcup_{i=1}^{n} A_i \right| = \binom{n}{1}(n-1)^m - \binom{n}{2}(n-2)^m + \binom{n}{3}(n-3)^m - \dots + (-1)^{n-1}\binom{n}{n}(0)^m$$

Subtracting this union from the universal set $|U| = n^m = \binom{n}{0}(n-0)^m$ yields:

$$S(m, n) = \binom{n}{0}n^m - \binom{n}{1}(n-1)^m + \binom{n}{2}(n-2)^m - \dots + (-1)^n \binom{n}{n}(0)^m$$ $$S(m, n) = \sum_{r=0}^{n} (-1)^r \binom{n}{r} (n-r)^m$$

$\blacksquare$
