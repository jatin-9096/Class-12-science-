1. Complete Conceptual Framework & Definitions

Fundamental Theoretical Principles

1. Foundational Architecture: Cartesian Products and Binary Relations

The architecture of modern function theory rests upon the axiomatic construction of set theory. Let $A$ and $B$ be two non-empty sets defined within a universal discourse $\mathcal{U}$. The Cartesian Product of $A$ and $B$, denoted by $A \times B$, is the collection of all ordered pairs $(a, b)$ such that the first coordinate is an element of $A$ and the second coordinate is an element of $B$. Formally, this is written as:

$$A \times B = \{(a, b) : a \in A \land b \in B\}$$

The structural property of an ordered pair dictates that $(a, b) = (c, d)$ if and only if $a = c$ and $b = d$. Consequently, unless $A = B$ or at least one of the sets is empty, the Cartesian product is non-commutative: $A \times B \neq B \times A$.

Cardinality Axiom: Let $|A| = n(A) = m$ and $|B| = n(B) = n$, where $m, n \in \mathbb{N}_0$. The cardinality of the Cartesian product is given by:

$$|A \times B| = |A| \cdot |B| = m \cdot n$$

The power set $\mathcal{P}(A \times B)$ contains every subset of $A \times B$. The cardinality of this power set is precisely:

$$|\mathcal{P}(A \times B)| = 2^{|A \times B|} = 2^{mn}$$

1.1 Formal Definition of a Binary Relation

A binary relation $R$ from a set $A$ to a set $B$ is formally defined as any arbitrary subset of the Cartesian product $A \times B$. That is:

$$R \subseteq A \times B \iff R \in \mathcal{P}(A \times B)$$

If an ordered pair $(a, b) \in R$, we denote this relationally as $a \, R \, b$, which reads “$a$ is related to $b$ under $R$”. Conversely, if $(a, b) \notin R$, we write $a \!\not\!R \, b$. When $B = A$, $R \subseteq A \times A$ is strictly referred to as a binary relation on the set $A$ (or an endorelation on $A$). The total number of distinct relations that can be defined on a set $A$ containing $n$ elements is:

$$N_{\text{relations}} = 2^{|A \times A|} = 2^{n^2}$$

1.2 Domain, Range, Co-Domain, and Inverse of a Relation

  • Domain of $R$ ($\operatorname{Dom}(R)$): The set of all first components of the ordered pairs belonging to $R$. $$\operatorname{Dom}(R) = \{a \in A : \exists\, b \in B \text{ such that } (a, b) \in R\} \subseteq A$$
  • Range of $R$ ($\operatorname{Ran}(R)$): The set of all second components of the ordered pairs belonging to $R$. $$\operatorname{Ran}(R) = \{b \in B : \exists\, a \in A \text{ such that } (a, b) \in R\} \subseteq B$$
  • Co-Domain of $R$: The entire target set $B$, irrespective of whether every element in $B$ participates in the relation. Hence, $\operatorname{Ran}(R) \subseteq \text{Co-Domain}(R) = B$.
  • Inverse Relation ($R^{-1}$): If $R \subseteq A \times B$, the inverse relation $R^{-1} \subseteq B \times A$ is obtained by reversing the order of every pair in $R$: $$R^{-1} = \{(b, a) \in B \times A : (a, b) \in R\}$$ Fundamental properties include: $\operatorname{Dom}(R^{-1}) = \operatorname{Ran}(R)$ and $\operatorname{Ran}(R^{-1}) = \operatorname{Dom}(R)$, with $(R^{-1})^{-1} = R$.

2. Exhaustive Taxonomy of Binary Relations on a Set

In advanced board-level analysis, binary relations on a single set $A$ ($R \subseteq A \times A$) are classified according to foundational behavioral properties: reflexivity, symmetry, and transitivity. First, consider the trivial boundary cases.

2.1 Extreme and Trivial Relations

1. The Empty (Void) Relation ($\emptyset$): Since the empty set is a subset of every set, $\emptyset \subseteq A \times A$. In the void relation, no element of $A$ is related to any element of $A$: $$\emptyset = \{\} \subset A \times A$$

2. The Universal Relation ($U$): The entire Cartesian product $A \times A$ forms a relation where every element of $A$ is related to every element of $A$: $$U = A \times A$$ Both the empty relation and the universal relation are often referred to as trivial relations.

3. The Identity Relation ($I_A$): Defined strictly as the set of all diagonal pairs where each element is related only and exclusively to itself: $$I_A = \{(a, a) : a \in A\}$$ If $|A| = n$, then $|I_A| = n$. The identity relation must not be confused with a reflexive relation, which allows additional non-diagonal elements.

2.2 Core Structural Classifications

Axiom of Reflexivity

A relation $R$ on a set $A$ is called reflexive if every element of $A$ is related to itself. Formally: $$\forall a \in A, \quad (a, a) \in R$$ Equivalently, $I_A \subseteq R$. If there exists even a single element $x \in A$ such that $(x, x) \notin R$, then $R$ is strictly non-reflexive.

Combinatorial Counting: In a set of cardinality $n$, the Cartesian product $A \times A$ contains $n^2$ elements: $n$ diagonal pairs of the form $(a, a)$ and $n^2 - n$ non-diagonal pairs. For a relation to be reflexive, all $n$ diagonal elements must be present (1 choice each), whereas each of the remaining $n(n - 1)$ pairs can either be included or excluded (2 choices each). Thus: $$N_{\text{reflexive}} = 1^n \times 2^{n(n-1)} = 2^{n^2 - n}$$

Axiom of Symmetry

A relation $R$ on a set $A$ is called symmetric if whenever an element $a$ is related to an element $b$, then $b$ must necessarily be related to $a$. Formally: $$\forall a, b \in A, \quad (a, b) \in R \implies (b, a) \in R$$ In algebraic operator form: $R$ is symmetric if and only if $R = R^{-1}$.

Combinatorial Counting: The $n$ diagonal pairs can be independently included or excluded ($2^n$ ways). The remaining $n^2 - n$ non-diagonal pairs form $\frac{n(n-1)}{2}$ symmetric couples $\{(a, b), (b, a)\}$. For symmetry, both must be included together or both omitted (2 choices per couple). Thus: $$N_{\text{symmetric}} = 2^n \times 2^{\frac{n(n-1)}{2}} = 2^{n + \frac{n(n-1)}{2}} = 2^{\frac{n(n+1)}{2}}$$

Axiom of Transitivity

A relation $R$ on a set $A$ is called transitive if whenever $(a, b) \in R$ and $(b, c) \in R$, it logically necessitates that $(a, c) \in R$. Formally: $$\forall a, b, c \in A, \quad \Big((a, b) \in R \land (b, c) \in R\Big) \implies (a, c) \in R$$

Vacuous Truth Condition (The Examiner's Trap): The implication $P \implies Q$ is logically TRUE whenever the antecedent $P$ is false. Therefore, if there are no pairs in $R$ of the form $(a, b)$ and $(b, c)$ with $a \neq b$, the condition for transitivity cannot be violated. For example, the singleton relation $R = \{(1, 2)\}$ on $A = \{1, 2, 3\}$ is vacuously transitive because there is no pair starting with $2$ to trigger the conditional requirement.

2.3 Secondary and Antisymmetric Relations

Antisymmetric Relation: A relation $R$ on $A$ is called antisymmetric if for all $a, b \in A$: $$\Big((a, b) \in R \land (b, a) \in R\Big) \implies a = b$$ Equivalently, if $a \neq b$, then $(a, b)$ and $(b, a)$ cannot both belong to $R$. It is critical to recognize that antisymmetry is not the logical negation of symmetry. A relation can be both symmetric and antisymmetric (e.g., the identity relation $I_A$), or neither symmetric nor antisymmetric.

Asymmetric Relation: A relation $R$ is strictly asymmetric if $(a, b) \in R \implies (b, a) \notin R$. This implies that an asymmetric relation contains no diagonal pairs $(a, a)$ whatsoever, meaning it is strictly irreflexive and antisymmetric.

Relation Type Defining Formal Condition Total Count on Set of Size $n$
Total Relations Any subset $R \subseteq A \times A$ $2^{n^2}$
Reflexive $(a, a) \in R, \quad \forall a \in A$ $2^{n(n-1)}$
Symmetric $(a, b) \in R \implies (b, a) \in R$ $2^{\frac{n(n+1)}{2}}$

3. Equivalence Relations, Partitions, and Modular Arithmetic

A relation $R$ on a set $A$ is classified as an Equivalence Relation if and only if it satisfies all three primary axioms simultaneously:

$R$ is Reflexive $\quad \bigwedge \quad$ $R$ is Symmetric $\quad \bigwedge \quad$ $R$ is Transitive

3.1 Equivalence Classes and their Canonical Properties

Let $R$ be an equivalence relation on a non-empty set $A$. For any element $a \in A$, the equivalence class of $a$, denoted by $[a]$, or $cl(a)$, or $\bar{a}$, is the set of all elements in $A$ that are related to $a$ under $R$:

$$[a] = \{x \in A : (x, a) \in R\}$$

The Fundamental Theorems of Equivalence Classes:

  1. Non-emptiness: Since $R$ is reflexive, $(a, a) \in R$ for all $a \in A$. Therefore, $a \in [a]$, proving that no equivalence class is empty: $[a] \neq \emptyset$.
  2. Coincidence vs. Disjointness: For any two elements $a, b \in A$, either their equivalence classes are identical or they are mutually disjoint. That is: $$[a] = [b] \iff (a, b) \in R \quad \text{and} \quad [a] \cap [b] = \emptyset \iff (a, b) \notin R$$ Analytical Proof: Suppose $[a] \cap [b] \neq \emptyset$. Then there exists $x \in [a] \cap [b]$, meaning $(x, a) \in R$ and $(x, b) \in R$. By symmetry, $(a, x) \in R$. Applying transitivity to $(a, x) \in R$ and $(x, b) \in R$ yields $(a, b) \in R$. Now take any $y \in [a]$. Then $(y, a) \in R$. Since $(a, b) \in R$, transitivity gives $(y, b) \in R$, meaning $y \in [b]$. Hence, $[a] \subseteq [b]$. By mirror symmetry, $[b] \subseteq [a]$. Therefore, $[a] = [b]$.
  3. Exhaustive Partitioning: The union of all equivalence classes reconstructs the entire fundamental set $A$: $$\bigcup_{a \in A} [a] = A$$

3.2 The Fundamental Theorem of Equivalence Relations

An equivalence relation $R$ on a set $A$ partitions $A$ into a family of mutually disjoint, non-empty subsets whose union is $A$. Conversely, given any arbitrary partition $\mathcal{P} = \{A_i\}_{i \in I}$ of $A$ such that:

$$(1)\; A_i \neq \emptyset \quad \forall i, \qquad (2)\; A_i \cap A_j = \emptyset \;(\forall i \neq j), \qquad (3)\; \bigcup_{i \in I} A_i = A$$

There exists a unique equivalence relation $R$ on $A$ whose equivalence classes are precisely the cells $A_i$ of the partition, defined by: $$x \, R \, y \iff x \text{ and } y \text{ belong to the same cell } A_i$$

The number of equivalence relations on a finite set of $n$ elements is identical to the number of partitions of that set, given by the Bell Number $B_n$. The Bell numbers satisfy the recurrence relation: $$B_{n+1} = \sum_{k=0}^{n} \binom{n}{k} B_k, \quad \text{with } B_0 = 1$$ For instance: $B_1 = 1$, $B_2 = 2$, $B_3 = 5$, $B_4 = 15$, and $B_5 = 52$.

3.3 Rigorous Algebraic Exemplars (CBSE Prototype Questions)

Exemplar 1: Congruence Modulo $m$ on $\mathbb{Z}$

Let $m \in \mathbb{Z}^+$. Define a relation $R$ on the set of integers $\mathbb{Z}$ by $a \, R \, b \iff a \equiv b \pmod m \iff m \mid (a - b)$.

  • Reflexivity: For all $a \in \mathbb{Z}$, $a - a = 0 = 0 \cdot m$. Thus $m \mid (a - a)$, which implies $(a, a) \in R$. Reflexive.
  • Symmetry: Let $(a, b) \in R$. Then $m \mid (a - b) \implies a - b = k \cdot m$ for some $k \in \mathbb{Z}$. It follows that $b - a = -k \cdot m = (-k) m$. Since $-k \in \mathbb{Z}$, $m \mid (b - a)$, so $(b, a) \in R$. Symmetric.
  • Transitivity: Let $(a, b) \in R$ and $(b, c) \in R$. Then $a - b = k_1 m$ and $b - c = k_2 m$ for $k_1, k_2 \in \mathbb{Z}$. Adding the two yields: $(a - b) + (b - c) = (k_1 + k_2)m \implies a - c = (k_1 + k_2)m$. Since $k_1 + k_2 \in \mathbb{Z}$, $m \mid (a - c)$, so $(a, c) \in R$. Transitive.

Hence, congruence modulo $m$ is an equivalence relation. It partitions $\mathbb{Z}$ into $m$ distinct equivalence classes: $[0], [1], [2], \dots, [m-1]$.

Exemplar 2: Product Space Coordinate Relations

Let $A = \mathbb{N} \times \mathbb{N}$. Define a relation $R$ on $A$ by $((a, b), (c, d)) \in R \iff a + d = b + c$.

  • Reflexivity: $\forall (a, b) \in \mathbb{N} \times \mathbb{N}$, since addition is commutative in $\mathbb{N}$, $a + b = b + a$. Thus $((a, b), (a, b)) \in R$. Reflexive.
  • Symmetry: Let $((a, b), (c, d)) \in R$. Then $a + d = b + c \implies c + b = d + a \implies c + b = a + d$. Rewriting in relation standard form gives $c + b = d + a$, hence $((c, d), (a, b)) \in R$. Symmetric.
  • Transitivity: Let $((a, b), (c, d)) \in R$ and $((c, d), (e, f)) \in R$. Then: $$a + d = b + c \quad \text{and} \quad c + f = d + e$$ Adding both algebraic equalities: $$(a + d) + (c + f) = (b + c) + (d + e) \implies a + f + (c + d) = b + e + (c + d)$$ Subtracting $(c + d)$ from both sides: $a + f = b + e$. Thus $((a, b), (e, f)) \in R$. Transitive.

Since $R$ is reflexive, symmetric, and transitive, it is an equivalence relation on $\mathbb{N} \times \mathbb{N}$.

4. Advanced Function Theory: Morphisms, Classifications, and Densities

A function (or mapping) $f: A \to B$ is a special type of binary relation $f \subseteq A \times B$ that satisfies two structural axioms:

  1. Totality (Existence): Every element of the domain must possess an image. $\forall x \in A, \, \exists y \in B \text{ such that } (x, y) \in f$.
  2. Uniqueness (Well-definedness): No element of the domain may map to more than one distinct element in the codomain. $\Big((x, y_1) \in f \land (x, y_2) \in f\Big) \implies y_1 = y_2$.

We write $f(x) = y$ to indicate that $y$ is the unique image of $x$ under $f$, and $x$ is the pre-image of $y$.

4.1 Injective Functions (One-One Mappings)

A function $f: A \to B$ is called injective (or one-one) if distinct elements in the domain always have distinct images in the codomain.

Formal Analytical Criterion (Direct Method): $$\forall x_1, x_2 \in A, \quad f(x_1) = f(x_2) \implies x_1 = x_2$$ Equivalent Contrapositive Criterion: $$\forall x_1, x_2 \in A, \quad x_1 \neq x_2 \implies f(x_1) \neq f(x_2)$$

Calculus Criterion for Injectivity: Let $f: I \to \mathbb{R}$ be a differentiable function on an interval $I \subseteq \mathbb{R}$. If the derivative $f'(x)$ is strictly positive ($f'(x) > 0$) or strictly negative ($f'(x) < 0$) everywhere on $I$ (except possibly at isolated points where $f'(x) = 0$ without changing sign), then $f$ is strictly monotonic and therefore injective.

Geometric Test (Horizontal Line Test): A function $f: \mathbb{R} \to \mathbb{R}$ is injective if and only if every horizontal line $y = k$ ($k \in \mathbb{R}$) intersects the Cartesian graph of $y = f(x)$ at at most one point.

4.2 Surjective Functions (Onto Mappings)

A function $f: A \to B$ is called surjective (or onto) if every element of the codomain $B$ is the image of at least one element of the domain $A$.

Formal Analytical Criterion: $$\forall y \in B, \quad \exists\, x \in A \quad \text{such that} \quad f(x) = y$$ $$\text{Equivalently: } \operatorname{Ran}(f) = B$$

If $\operatorname{Ran}(f) \subset B$ and $\operatorname{Ran}(f) \neq B$, the function is called into. Proving surjectivity algebraically requires choosing an arbitrary parameter $y \in B$, solving the equation $y = f(x)$ explicitly for $x$ in terms of $y$, and verifying that the resulting expression for $x$ exists and belongs to $A$ for every $y \in B$.

4.3 Bijective Functions (One-One and Onto Mappings)

A function $f: A \to B$ is called bijective (or a one-to-one correspondence) if it is simultaneously injective and surjective:

$f$ is Bijective $\iff \Big(f \text{ is Injective} \land f \text{ is Surjective}\Big)$

For finite sets $A$ and $B$, the existence of a bijection guarantees that $|A| = |B|$. If $|A| = |B| = n$, the following conditions are logically equivalent:

  • $f: A \to B$ is injective.
  • $f: A \to B$ is surjective.
  • $f: A \to B$ is bijective.

Crucial Warning: This equivalence fails completely for infinite sets. For example, consider $f: \mathbb{N} \to \mathbb{N}$ defined by $f(x) = x + 1$. Here $f$ is injective, but it is not surjective because $1 \in \mathbb{N}$ has no pre-image.

4.4 Combinatorial Enumeration of Mappings

Let $|A| = n$ and $|B| = m$.

5. Composition of Functions and the Mechanics of Invertibility

5.1 Compositional Mechanics

Let $f: A \to B$ and $g: B \to C$ be two mappings. The composite function, denoted by $g \circ f$ (read as “$g$ circle $f$” or “$g$ composed with $f$”), is a mapping from $A$ to $C$ defined by:

$$(g \circ f)(x) = g(f(x)), \quad \forall x \in A$$

Existence Criterion: The composite function $g \circ f$ is well-defined if and only if the range of the inner function is a subset of the domain of the outer function:

$$\operatorname{Ran}(f) \subseteq \operatorname{Dom}(g)$$

Similarly, $f \circ g$ exists if and only if $\operatorname{Ran}(g) \subseteq \operatorname{Dom}(f)$. In general, function composition is non-commutative: $$g \circ f \neq f \circ g$$

5.2 Foundational Theorems of Composition

  • Associativity: Function composition is strictly associative. If $f: A \to B$, $g: B \to C$, and $h: C \to D$, then: $$h \circ (g \circ f) = (h \circ g) \circ f$$
  • Preservation of Injectivity: If both $f: A \to B$ and $g: B \to C$ are injective, then the composite function $g \circ f: A \to C$ is also injective.
    Proof: Assume $(g \circ f)(x_1) = (g \circ f)(x_2) \implies g(f(x_1)) = g(f(x_2))$. Since $g$ is injective, this implies $f(x_1) = f(x_2)$. Since $f$ is injective, this implies $x_1 = x_2$. Hence, $g \circ f$ is injective.
  • Preservation of Surjectivity: If both $f: A \to B$ and $g: B \to C$ are surjective, then $g \circ f: A \to C$ is also surjective.
    Proof: Let $z \in C$. Since $g$ is surjective, $\exists y \in B$ such that $g(y) = z$. Since $f$ is surjective, for this $y \in B$, $\exists x \in A$ such that $f(x) = y$. Thus $(g \circ f)(x) = g(f(x)) = g(y) = z$. Hence, $g \circ f$ is surjective.
  • The Composition Inference Lemmas (Board Exam Favorites):
    1. If $g \circ f$ is injective, then the inner function $f$ must be injective. (However, $g$ need not be injective).
    2. If $g \circ f$ is surjective, then the outer function $g$ must be surjective. (However, $f$ need not be surjective).

5.3 Invertibility Criterion and Inverse Functions

A function $f: A \to B$ is said to be invertible if there exists an inverse function $g: B \to A$ such that:

$$g \circ f = I_A \quad \text{and} \quad f \circ g = I_B$$

Where $I_A$ and $I_B$ are the identity functions on $A$ and $B$, respectively ($I_A(x) = x, \, \forall x \in A$). The function $g$ is uniquely determined and is denoted by $f^{-1}$.

The Fundamental Invertibility Theorem

A function $f: A \to B$ is invertible if and only if $f$ is a bijective function (both one-one and onto).

Proof ($\implies$ Direction): Assume $f$ is invertible. Then there exists $g: B \to A$ such that $g \circ f = I_A$ and $f \circ g = I_B$.
1. Injectivity: Let $f(x_1) = f(x_2)$. Apply $g$ to both sides: $g(f(x_1)) = g(f(x_2)) \implies (g \circ f)(x_1) = (g \circ f)(x_2) \implies I_A(x_1) = I_A(x_2) \implies x_1 = x_2$. Thus $f$ is injective.
2. Surjectivity: Let $y \in B$. Since $f \circ g = I_B$, we have $(f \circ g)(y) = I_B(y) \implies f(g(y)) = y$. Letting $x = g(y) \in A$, we have found an $x$ such that $f(x) = y$. Thus $f$ is surjective.
Since $f$ is both injective and surjective, it is bijective.

The Reversal Law for Inversion: If $f: A \to B$ and $g: B \to C$ are invertible, then the composite function $g \circ f: A \to C$ is invertible, and its inverse is given by the reversal law:

$$(g \circ f)^{-1} = f^{-1} \circ g^{-1}$$

Proof: Compute $(f^{-1} \circ g^{-1}) \circ (g \circ f) = f^{-1} \circ (g^{-1} \circ g) \circ f = f^{-1} \circ I_B \circ f = f^{-1} \circ f = I_A$. Similarly, $(g \circ f) \circ (f^{-1} \circ g^{-1}) = I_C$. By uniqueness of the inverse, $(g \circ f)^{-1} = f^{-1} \circ g^{-1}$.

6. Abstract Algebraic Structures: Binary Operations

6.1 Axiomatic Definition

A binary operation $*$ on a non-empty set $A$ is a function $*: A \times A \to A$. We denote the image of an ordered pair $(a, b)$ under $*$ as $a * b$.

The Closure Axiom: The defining property of a binary operation is closure: $$\forall a, b \in A, \quad a * b \in A$$ If any pair $(a, b) \in A \times A$ produces an element outside $A$, then $*$ is not a binary operation on $A$. For instance, subtraction is a valid binary operation on $\mathbb{Z}$, but it is not a binary operation on $\mathbb{N}$ because $3 - 5 = -2 \notin \mathbb{N}$.

6.2 Structural Algebraic Axioms

1. Commutativity: A binary operation $*$ on $A$ is commutative if the order of operands does not affect the outcome: $$\forall a, b \in A, \quad a * b = b * a$$

2. Associativity: A binary operation $*$ on $A$ is associative if grouping does not affect the evaluation of repeated operations: $$\forall a, b, c \in A, \quad (a * b) * c = a * (b * c)$$

3. Existence of an Identity Element: An element $e \in A$ is an identity element for the binary operation $*$ if: $$\forall a \in A, \quad a * e = e * a = a$$ Uniqueness Theorem: If an identity element exists, it is unique.
Proof: Suppose $e_1$ and $e_2$ are both identities. Treating $e_1$ as identity gives $e_1 * e_2 = e_2$. Treating $e_2$ as identity gives $e_1 * e_2 = e_1$. Thus $e_1 = e_2$.

4. Invertibility of Elements: Given an operation $*$ on $A$ with identity element $e$, an element $a \in A$ is said to be invertible if there exists an element $b \in A$ such that: $$a * b = b * a = e$$ The element $b$ is called the inverse of $a$, denoted by $a^{-1}$.
Uniqueness of the Inverse: If $*$ is associative and an inverse exists, it is unique.
Proof: Suppose $b_1$ and $b_2$ are both inverses of $a$. Then $b_1 = b_1 * e = b_1 * (a * b_2) = (b_1 * a) * b_2 = e * b_2 = b_2$.

6.3 Cayley Operation Tables (Finite Sets)

For a finite set $A = \{a_1, a_2, \dots, a_n\}$, a binary operation $*$ can be completely characterized by an $n \times n$ matrix called a Cayley Table:

  • Checking Commutativity: The operation is commutative if and only if the Cayley table is symmetric about its main diagonal.
  • Identifying the Identity Element: An element $e$ is the identity if its corresponding row matches the header row and its corresponding column matches the header column.
  • Identifying Invertible Elements: An element $a_i$ is invertible if the identity element $e$ appears in row $a_i$ (and symmetrically in column $a_i$).

7. CBSE Board Examination Traps, Fallacies, and Rubrics

Trap 1: The Transitivity Pitfall with Ordered Pairs

Common Error: Students often check pairs like $(a, b)$ and $(b, c)$ where $a, b, c$ are distinct, but overlook cases where $a = c$.
The Classic Counterexample: Consider $R = \{(1, 2), (2, 1)\}$ on $A = \{1, 2, 3\}$.
Many students incorrectly claim $R$ is transitive because $(1, 2) \in R$ and $(2, 1) \in R$. However, transitivity requires that $(1, 1) \in R$. Since $(1, 1) \notin R$, the relation is NOT transitive.

Trap 2: Proving Surjectivity Without Codomain Domain Checks

Common Error: Solving $y = f(x)$ to get an algebraic formula for $x$, but failing to verify that $x$ always belongs to the specified domain for every possible $y$ in the codomain.
Case Study: Let $f: \mathbb{Z} \to \mathbb{Z}$ be defined by $f(x) = 2x + 1$.
Setting $y = 2x + 1$ yields $x = \frac{y - 1}{2}$. While this gives a real value for any $y \in \mathbb{R}$, for an even integer such as $y = 2$, we get $x = \frac{1}{2} \notin \mathbb{Z}$.
Because $x$ does not belong to the domain $\mathbb{Z}$, $y = 2$ has no valid pre-image. Thus, $f$ is NOT surjective. Omitting the membership check $x \in \operatorname{Dom}(f)$ results in lost marks on board exams.

Trap 3: Confusing Identity Relations with Reflexive Relations

Common Error: Treating identity and reflexive relations as interchangeable.
Every identity relation $I_A$ is reflexive, but a reflexive relation need not be the identity relation. An identity relation requires $(a, b) \in R \iff a = b$ (meaning only diagonal pairs are allowed). A reflexive relation requires $(a, a) \in R$ for all $a \in A$, but it may also contain other pairs $(a, b)$ with $a \neq b$.

7.1 Definitive Step-by-Step Board Exam Proof Rubrics

To secure full marks on long-answer questions (4 to 6 marks), students must write proofs with complete algebraic and logical rigor:

Standard Solution Structure: Invertibility Proof

Problem: Show that $f: \mathbb{R} \setminus \{3\} \to \mathbb{R} \setminus \{1\}$ defined by $f(x) = \frac{x - 2}{x - 3}$ is bijective, and find $f^{-1}$.

Step 1: Injectivity (One-One)
Let $x_1, x_2 \in \mathbb{R} \setminus \{3\}$ such that $f(x_1) = f(x_2)$.
$\implies \frac{x_1 - 2}{x_1 - 3} = \frac{x_2 - 2}{x_2 - 3}$
$\implies (x_1 - 2)(x_2 - 3) = (x_2 - 2)(x_1 - 3)$
$\implies x_1 x_2 - 3x_1 - 2x_2 + 6 = x_1 x_2 - 3x_2 - 2x_1 + 6$
$\implies -3x_1 - 2x_2 = -3x_2 - 2x_1$
$\implies -x_1 = -x_2 \implies x_1 = x_2$.
Therefore, $f$ is strictly injective.

Step 2: Surjectivity (Onto)
Let $y \in \mathbb{R} \setminus \{1\}$. We must find $x \in \mathbb{R} \setminus \{3\}$ such that $f(x) = y$.
$y = \frac{x - 2}{x - 3} \implies y(x - 3) = x - 2$
$\implies xy - 3y = x - 2 \implies xy - x = 3y - 2$
$\implies x(y - 1) = 3y - 2 \implies x = \frac{3y - 2}{y - 1}$.
Since $y \neq 1$, this $x$ is a well-defined real number.
Check domain membership ($x \neq 3$): If $\frac{3y - 2}{y - 1} = 3 \implies 3y - 2 = 3y - 3 \implies -2 = -3$, which is impossible.
Thus, for every $y \in \mathbb{R} \setminus \{1\}$, there exists $x = \frac{3y - 2}{y - 1} \in \mathbb{R} \setminus \{3\}$ such that $f(x) = y$.
Therefore, $f$ is surjective.

Step 3: Bijectivity and Inverse
Since $f$ is both injective and surjective, it is bijective and therefore invertible.
The inverse function is: $f^{-1}: \mathbb{R} \setminus \{1\} \to \mathbb{R} \setminus \{3\}$, defined by:
$$f^{-1}(x) = \frac{3x - 2}{x - 1}$$

Derivation 1: Combinatorial Count of Reflexive and Symmetric Relations

Objective: Prove from first principles that the number of reflexive relations on set $A$ with $|A| = n$ is $2^{n(n-1)}$, and the number of symmetric relations is $2^{\frac{n(n+1)}{2}}$.

Part A: Reflexive Relations

Let $A = \{a_1, a_2, \dots, a_n\}$. The Cartesian product $A \times A$ consists of $n^2$ ordered pairs, which can be decomposed into two mutually disjoint subsets:

$$D = \{(a_i, a_i) \mid 1 \le i \le n\}, \quad |D| = n \quad \text{(Diagonal elements)}$$ $$D^c = \{(a_i, a_j) \mid 1 \le i \ne j \le n\}, \quad |D^c| = n^2 - n = n(n-1) \quad \text{(Off-diagonal elements)}$$

By definition, a relation $R$ on $A$ is reflexive if and only if:

$$\forall a_i \in A, \quad (a_i, a_i) \in R \implies D \subseteq R$$

Therefore, for each pair in $D$, there is exactly $1$ choice (it must be included). For each of the $n(n-1)$ pairs in $D^c$, there are $2$ independent choices (included or excluded). Thus:

$$N_{\text{ref}} = 1^n \times 2^{n(n-1)} = 2^{n(n-1)}$$
Part B: Symmetric Relations

A relation $R$ is symmetric if $(a_i, a_j) \in R \iff (a_j, a_i) \in R$. Consider the representation of $A \times A$ as an $n \times n$ coordinate grid:

  1. The diagonal contains $n$ pairs $(a_i, a_i)$. For each diagonal pair, $(a_i, a_i) \in R$ has $2$ independent choices (include or exclude), since its transpose is itself.
  2. The off-diagonal pairs partition into $\dfrac{n^2 - n}{2} = \binom{n}{2}$ unordered pairs of symmetric positions: $\{(a_i, a_j), (a_j, a_i)\}$ where $i < j$.

For each symmetric pair $\{(a_i, a_j), (a_j, a_i)\}$, symmetry dictates that either both pairs belong to $R$ or neither does. Hence, there are $2$ consistent binary choices per pair:

$$N_{\text{sym}} = 2^n \times 2^{\binom{n}{2}} = 2^{n + \frac{n(n-1)}{2}} = 2^{\frac{2n + n^2 - n}{2}} = 2^{\frac{n(n+1)}{2}}$$
Derivation 2: Disjointness and Identity of Equivalence Classes

Theorem: Let $R$ be an equivalence relation on set $A$. For any $a, b \in A$, the equivalence classes $[a]$ and $[b]$ are either identical or completely disjoint:

$$[a] = [b] \iff (a, b) \in R \quad \text{and} \quad [a] \cap [b] = \emptyset \iff (a, b) \notin R$$
Step 1: Prove $(a, b) \in R \implies [a] = [b]$

Assume $(a, b) \in R$. We show mutual set containment $[a] \subseteq [b]$ and $[b] \subseteq [a]$.

Let $x \in [a]$. By definition of an equivalence class:

$$(x, a) \in R$$

Since $(a, b) \in R$ by assumption, and $R$ satisfies transitivity:

$$(x, a) \in R \land (a, b) \in R \implies (x, b) \in R \implies x \in [b]$$

Thus, $[a] \subseteq [b]$.

Conversely, let $y \in [b] \implies (y, b) \in R$. Since $(a, b) \in R$, by symmetry we have $(b, a) \in R$. Applying transitivity:

$$(y, b) \in R \land (b, a) \in R \implies (y, a) \in R \implies y \in [a]$$

Thus, $[b] \subseteq [a]$. Since $[a] \subseteq [b]$ and $[b] \subseteq [a]$, we establish:

$$[a] = [b]$$
Step 2: Prove $[a] \cap [b] \ne \emptyset \implies [a] = [b]$

Assume $[a] \cap [b] \ne \emptyset$. Then there exists at least one element $c \in A$ such that:

$$c \in [a] \cap [b] \implies c \in [a] \quad \text{and} \quad c \in [b]$$

This implies $(c, a) \in R$ and $(c, b) \in R$. Applying symmetry to $(c, a) \in R$ yields $(a, c) \in R$. Now apply transitivity:

$$(a, c) \in R \land (c, b) \in R \implies (a, b) \in R$$

By the result established in Step 1, $(a, b) \in R \implies [a] = [b]$.

Contrapositively, if $[a] \ne [b]$, then $[a] \cap [b] = \emptyset$. Hence, any two equivalence classes are either identical or pairwise disjoint.

Derivation 3: Composition Invertibility and the Reversal Rule

Theorem: Let $f: A \to B$ and $g: B \to C$ be bijective functions. Then the composite function $(g \circ f): A \to C$ is invertible, and its inverse is given by:

$$(g \circ f)^{-1} = f^{-1} \circ g^{-1}$$
Step 1: Verification of Invertibility (Bijectivity of $g \circ f$)

To prove $g \circ f$ is injective, assume $(g \circ f)(x_1) = (g \circ f)(x_2)$ for $x_1, x_2 \in A$:

$$g(f(x_1)) = g(f(x_2))$$

Since $g$ is injective ($g(u) = g(v) \implies u = v$):

$$f(x_1) = f(x_2)$$

Since $f$ is injective ($f(x_1) = f(x_2) \implies x_1 = x_2$):

$$x_1 = x_2 \implies g \circ f \text{ is injective.}$$

To prove $g \circ f$ is surjective, let $z \in C$. Since $g: B \to C$ is surjective, there exists $y \in B$ such that $g(y) = z$. Since $f: A \to B$ is surjective, for this $y \in B$ there exists $x \in A$ such that $f(x) = y$. Substituting yields:

$$(g \circ f)(x) = g(f(x)) = g(y) = z$$

Hence, $g \circ f$ is surjective. Being both injective and surjective, $g \circ f$ is bijective and therefore invertible.

Step 2: Algebraic Verification of the Inverse Map

Let $h = f^{-1} \circ g^{-1}: C \to A$. We verify the left and right identity criteria: $h \circ (g \circ f) = I_A$ and $(g \circ f) \circ h = I_C$.

Evaluating the left composition on arbitrary $x \in A$ (using associativity of composition):

$$\begin{aligned} (h \circ (g \circ f))(x) &= \left((f^{-1} \circ g^{-1}) \circ (g \circ f)\right)(x) \\ &= \left(f^{-1} \circ (g^{-1} \circ g) \circ f\right)(x) \\ &= \left(f^{-1} \circ I_B \circ f\right)(x) \\ &= (f^{-1} \circ f)(x) \\ &= I_A(x) = x \end{aligned}$$

Evaluating the right composition on arbitrary $z \in C$:

$$\begin{aligned} ((g \circ f) \circ h)(z) &= \left((g \circ f) \circ (f^{-1} \circ g^{-1})\right)(z) \\ &= \left(g \circ (f \circ f^{-1}) \circ g^{-1}\right)(z) \\ &= \left(g \circ I_B \circ g^{-1}\right)(z) \\ &= (g \circ g^{-1})(z) \\ &= I_C(z) = z \end{aligned}$$

By uniqueness of the inverse mapping, $(g \circ f)^{-1} = f^{-1} \circ g^{-1}$.

Derivation 4: Cardinality of Surjective Mappings via Inclusion-Exclusion (PIE)

Objective: Derive the closed-form expression for the number of onto functions from a set $A$ of $m$ elements to a set $B$ of $n$ elements ($m \ge n$).

Step 1: Set-Theoretic Formulation of Non-Surjectivity

Let $B = \{b_1, b_2, \dots, b_n\}$. The total universe of functions from $A$ to $B$ is:

$$|\mathcal{U}| = n^m$$

For each $i \in \{1, 2, \dots, n\}$, define the property $P_i$ that the element $b_i$ is omitted from the range of $f$. Let $A_i$ denote the set of functions missing $b_i$:

$$A_i = \{f: A \to B \mid b_i \notin f(A)\}$$

A function is surjective if and only if it does not satisfy any property $P_i$. Thus, the number of surjective functions is:

$$N_{\text{surj}} = \left| \bigcap_{i=1}^{n} A_i^c \right| = |\mathcal{U}| - \left| \bigcup_{i=1}^{n} A_i \right|$$
Step 2: Evaluating Cardinalities of Intersections

Consider the intersection of any $k$ sets $A_{i_1} \cap A_{i_2} \cap \dots \cap A_{i_k}$. Functions belonging to this intersection must map elements of $A$ exclusively to the remaining $(n - k)$ elements of $B$:

$$|A_{i_1} \cap A_{i_2} \cap \dots \cap A_{i_k}| = (n - k)^m$$

The number of ways to choose $k$ elements from the $n$ available codomain targets is given by the binomial coefficient $\binom{n}{k}$. Therefore:

$$S_k = \sum_{1 \le i_1 < \dots < i_k \le n} |A_{i_1} \cap \dots \cap A_{i_k}| = \binom{n}{k}(n - k)^m$$
Step 3: Expansion via Principle of Inclusion-Exclusion

By the Principle of Inclusion-Exclusion:

$$\left| \bigcup_{i=1}^{n} A_i \right| = \sum_{k=1}^{n} (-1)^{k-1} S_k = \sum_{k=1}^{n} (-1)^{k-1} \binom{n}{k} (n - k)^m$$

Subtracting this value from $|\mathcal{U}| = n^m = \binom{n}{0}(n - 0)^m$ yields:

$$N_{\text{surj}} = \binom{n}{0}n^m - \sum_{k=1}^{n} (-1)^{k-1} \binom{n}{k} (n - k)^m = \sum_{k=0}^{n} (-1)^k \binom{n}{k} (n - k)^m$$

Setting $r = k$, we obtain the canonical standard formula:

$$N_{\text{surj}} = \sum_{r=0}^{n} (-1)^r \binom{n}{r} (n - r)^m$$

Special Case ($m = n$): If $m = n$, all surjective functions are bijective, giving:

$$\sum_{r=0}^{n} (-1)^r \binom{n}{r} (n - r)^n = n!$$
