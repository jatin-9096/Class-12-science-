Definition of relation and basic concepts

Definition of a Relation

A relation $R$ from a set $A$ to a set $B$ is a subset of the Cartesian product $A\\times B$. In other words, $R\\subseteq A\\times B$ and each element of $R$ is an ordered pair $(a,b)$ with $a\\in A$ and $b\\in B$.

Domain and Range

  • Domain of $R$, denoted $\\operatorname{Dom}(R)$, is the set of all first components of the ordered pairs in $R$: $\\operatorname{Dom}(R)=\\{a\\in A\\mid \\exists b\\in B,(a,b)\\in R\\}$.
  • Range of $R$, denoted $\\operatorname{Ran}(R)$, is the set of all second components: $\\operatorname{Ran}(R)=\\{b\\in B\\mid \\exists a\\in A,(a,b)\\in R\\}$.

Special Types of Relations

  • Reflexive: $\\forall a\\in A,(a,a)\\in R$.
  • Symmetric: $\\forall a,b\\in A,(a,b)\\in R\\Rightarrow (b,a)\\in R$.
  • Transitive: $\\forall a,b,c\\in A,(a,b)\\in R\\land (b,c)\\in R\\Rightarrow (a,c)\\in R$.
  • Equivalence Relation: a relation that is reflexive, symmetric, and transitive simultaneously.

Definition of a Function

A relation $f$ from $A$ to $B$ is called a function (or mapping) if every element of $A$ appears as the first component of exactly one ordered pair in $f$. Symbolically, $\\forall a\\in A,\\exists!\\,b\\in B$ such that $(a,b)\\in f$.

Based on the behaviour of the mapping we classify functions as:

  • One‑to‑One (Injective): $\\forall a_1,a_2\\in A,(f(a_1)=f(a_2)\\Rightarrow a_1=a_2)$.
  • Onto (Surjective): $\\forall b\\in B,\\exists a\\in A$ such that $f(a)=b$.
  • One‑to‑One onto (Bijective): both injective and surjective.
  • Many‑One: two or more distinct elements of $A$ have the same image in $B$.

Edge Cases

  • The empty set $\\emptyset$ can be a domain; the empty relation $\\emptyset\\subseteq A\\times B$ has $\\operatorname{Dom}(\\emptyset)=\\operatorname{Ran}(\\emptyset)=\\emptyset$.
  • A relation on a single‑element set $\\{a\\}$ may be reflexive $(a,a)$, non‑reflexive $\\emptyset$, or both depending on definition.
  • A function with domain $\\emptyset$ is called the empty function; it vacuously satisfies the definition of a function.

Solved Example

Let $A=\\{1,2,3\\}$ and $B=\\{a,b\\}$. Define $R=\\{(1,a),(2,a),(2,b),(3,b)\\}$.

Ordered PairDomain ElementRange Element
$(1,a)$$1$$a$
$(2,a)$$2$$a$
$(2,b)$$2$$b$
$(3,b)$$3$$b$

Find $\\operatorname{Dom}(R)$ and $\\operatorname{Ran}(R)$. Determine whether $R$ is a function.

Solution:

  • $\\operatorname{Dom}(R)=\\{1,2,3\\}$ because each element of $A$ appears as a first component.
  • $\\operatorname{Ran}(R)=\\{a,b\\}$ because both $a$ and $b$ appear as second components.
  • To be a function, each $a\\in A$ must have exactly one image. Here $2$ is associated with both $a$ and $b$, violating uniqueness. Hence $R$ is not a function.

Understanding these foundational concepts is essential before moving to more advanced topics such as composition of functions, inverse relations, and binary operations.

Types of relations: reflexive, symmetric, transitive, equivalence and partial order

Types of Relations: Reflexive, Symmetric, Transitive, Equivalence and Partial Order

A relation $R$ on a non‑empty set $A$ is a subset of the Cartesian product $A\times A$. For any ordered pair $(a,b)\in R$, we say that $a$ is related to $b$ and write $aRb$. The nature of $R$ is characterised by four fundamental properties – reflexivity, symmetry, transitivity and antisymmetry – which combine to give two important classes of relations: equivalence relations and partial orders.

1. Reflexive Relation

  • Definition: $R$ is reflexive if \[\forall a\in A,\;(a,a)\in R.\]
  • Interpretation: every element of $A$ is related to itself.

2. Symmetric Relation

  • Definition: $R$ is symmetric if \[\forall a,b\in A,\;(a,b)\in R\;\Rightarrow\;(b,a)\in R.\]
  • Interpretation: the direction of the relation can be reversed without leaving the set.

3. Transitive Relation

  • Definition: $R$ is transitive if \[\forall a,b,c\in A,\;(a,b)\in R\land(b,c)\in R\;\Rightarrow\;(a,c)\in R.\]
  • Interpretation: a two‑step connection implies a direct connection.

4. Antisymmetric Relation

  • Definition: $R$ is antisymmetric if \[\forall a,b\in A,\;(a,b)\in R\land(b,a)\in R\;\Rightarrow\;a=b.\]
  • Note: antisymmetry does not forbid $(a,b)$ and $(b,a)$ simultaneously, but forces $a$ and $b$ to be identical.

5. Equivalence Relation

  • An equivalence relation satisfies reflexivity, symmetry and transitivity together.
  • Consequences: $A$ is partitioned into disjoint equivalence classes.

6. Partial Order

  • A partial order is a relation that is reflexive, antisymmetric and transitive.
  • Such a relation defines a poset $(A,\leq)$ where $a\leq b$ denotes $ (a,b)\in R$.

Summary Table

PropertySymbolic ConditionTypical Example
Reflexive$\forall a\in A,(a,a)\in R$Equality $=$ on $\mathbb{R}$
Symmetric$\forall a,b,(a,b)\in R\Rightarrow(b,a)\in R$Congruence modulo $n$
Transitive$\forall a,b,c,(a,b)\in R\land(b,c)\in R\Rightarrow(a,c)\in R$Less‑than or equal $\leq$
Antisymmetric$\forall a,b,(a,b)\in R\land(b,a)\in R\Rightarrow a=b$Divisibility on $\mathbb{N}$

Edge Cases

  • Empty relation $\emptyset$: vacuously transitive and symmetric but not reflexive (unless $A=\emptyset$).
  • Universal relation $A\times A$: reflexive and symmetric but not antisymmetric unless $|A|=1$.

Solved Example

Let $A=\{1,2,3\}$ and $R=\{(1,1),(2,2),(3,3),(1,2),(2,1)\}$.

  1. Reflexive? Check $(a,a)$ for all $a\in A$: all three are present ⇒ Yes.
  2. Symmetric? Since $(1,2)\in R$ and $(2,1)\in R$, and no other off‑diagonal pairs exist, the condition holds ⇒ Yes.
  3. Transitive? Need to verify all possible chains.
    - $(1,2)$ and $(2,1)$ give $(1,1)$ which is in $R$.
    - $(2,1)$ and $(1,2)$ give $(2,2)$ which is in $R$.
    No other chains produce a new pair, so $R$ is transitive.
  4. Antisymmetric? Since $(1,2)\in R$ and $(2,1)\in R$ but $1\neq2$, antisymmetry fails.

Conclusion: $R$ is reflexive, symmetric and transitive ⇒ $R$ is an equivalence relation. It is not a partial order because antisymmetry is violated.

Key Takeaway for Exams

  • Always test each property separately using the definitions.
  • For equivalence, verify all three properties; for partial order, replace symmetry with antisymmetry.
  • Remember edge cases – the empty and universal relations often appear in multiple‑choice questions.

Representation of relations: matrix and digraph

Definition of a Relation

A relation $R$ from a set $A$ to a set $B$ is a subset of the Cartesian product $A\times B$. In other words, $R\subseteq A\times B$ and an ordered pair $(a,b)\in R$ signifies that $a\in A$ is related to $b\in B$.

Matrix Representation

  • Let $A=\{a_{1},a_{2},\dots ,a_{m}\}$ and $B=\{b_{1},b_{2},\dots ,b_{n}\}$.
  • The relation matrix $M_{R}$ is an $m\times n$ matrix whose entry $m_{ij}$ is defined as
    $$m_{ij}=\begin{cases}1,&\text{if }(a_{i},b_{j})\in R,\\0,&\text{otherwise.}\end{cases}$$
  • Properties:
    • If $R$ is a relation on a single set $A$, then $M_{R}$ is a square $|A|\times|A|$ matrix.
    • The matrix is symmetric iff $R$ is symmetric.
    • The diagonal entries $m_{ii}=1$ indicate reflexivity.

Step‑by‑Step Construction of $M_{R}$

  1. List the elements of the domain set $A$ as rows in a fixed order.
  2. List the elements of the codomain set $B$ as columns in a fixed order.
  3. For each ordered pair $(a_{i},b_{j})$, place $1$ in cell $(i,j)$ if the pair belongs to $R$, otherwise place $0$.

Digraph (Directed Graph) Representation

  • Vertices correspond to the elements of $A\cup B$ (or just $A$ when $R$ is on $A$).
  • An arrow (directed edge) from vertex $a_{i}$ to vertex $b_{j}$ is drawn iff $(a_{i},b_{j})\in R$.
  • Loops (arrows from a vertex to itself) represent reflexive pairs.

Edge Cases and Remarks

  • If $R=\emptyset$, the matrix is an all‑zero matrix and the digraph has no edges.
  • If $R=A\times B$, the matrix is an all‑one matrix and the digraph is a complete bipartite digraph.
  • For relations on a set $A$, the matrix can be used to test properties: symmetry ($M_{R}=M_{R}^{T}$), antisymmetry (if $m_{ij}=m_{ji}=1$ then $i=j$), transitivity (requires $M_{R}^{2}\le M_{R}$ element‑wise).

Solved Example

Let $A=\{1,2,3\}$, $B=\{a,b\}$ and $R=\{(1,a),(2,b),(3,a)\}$.

Step 1: Order the rows as $1,2,3$ and columns as $a,b$.

Step 2: Fill the matrix:

$a$$b$
$1$$1$$0$
$2$$0$$1$
$3$$1$$0$

Thus $M_{R}=\begin{pmatrix}1&0\\0&1\\1&0\end{pmatrix}$.

Step 3: Draw the digraph. Vertices: $1,2,3,a,b$. Draw arrows $1\rightarrow a$, $2\rightarrow b$, $3\rightarrow a$. No loops appear because no pair of the form $(x,x)$ is present.

This example illustrates how the same relation can be visualised algebraically (matrix) and graphically (digraph), a skill frequently tested in CBSE Class 12 examinations.

Operations on relations: composition, inverse and powers

Definition of a Relation

A relation $R$ from set $A$ to set $B$ is a subset of the Cartesian product $A\times B$, i.e. $R\subseteq A\times B$. An ordered pair $(a,b)\in R$ is read as “$a$ is related to $b$”.

Composition of Relations

For $R\subseteq A\times B$ and $S\subseteq B\times C$, the composition $S\circ R$ is defined as

$$S\circ R=\{(a,c)\mid \exists\,b\in B\;[(a,b)\in R\land(b,c)\in S]\}$$

Thus $S\circ R\subseteq A\times C$. The operation is associative:

$$ (T\circ S)\circ R = T\circ (S\circ R) $$

for any compatible relations $R,S,T$.

Inverse (or Converse) of a Relation

The inverse of $R$, denoted $R^{-1}$, swaps each ordered pair:

$$ R^{-1}=\{(b,a)\mid (a,b)\in R\} $$

Key properties:

  • $ (R^{-1})^{-1}=R $
  • $ (S\circ R)^{-1}=R^{-1}\circ S^{-1} $

Powers of a Relation

For a relation $R\subseteq A\times A$, the $n^{\text{th}}$ power $R^{n}$ is defined recursively:

$$ R^{1}=R,\qquad R^{n+1}=R^{n}\circ R $$

Thus $R^{2}=R\circ R$, $R^{3}=R\circ R\circ R$, etc. $R^{0}$ is the identity relation on $A$:

$$ I_{A}=\{(a,a)\mid a\in A\} $$

and satisfies $I_{A}\circ R=R\circ I_{A}=R$.

Edge Cases and Remarks

  • Empty relation: If $R=\emptyset$, then $R^{-1}=\emptyset$, $R\circ S=\emptyset$, and $R^{n}=\emptyset$ for all $n\ge1$.
  • Non‑matching domains: Composition $S\circ R$ is defined only when the codomain of $R$ equals the domain of $S$. If they do not match, the composition is undefined.
  • Infinite powers: For a finite set $A$, the sequence $R,R^{2},R^{3},\dots$ eventually stabilises because there are only $|A|^{2}$ possible ordered pairs.

Worked Example

Let $A=\{1,2,3\}$, $R=\{(1,2),(2,3)\}$ and $S=\{(2,1),(3,2)\}$.

  1. Find $S\circ R$: We need $b$ such that $(a,b)\in R$ and $(b,c)\in S$.
    • For $(1,2)\in R$, $b=2$. Since $(2,1)\in S$, we obtain $(1,1)\in S\circ R$.
    • For $(2,3)\in R$, $b=3$. Since $(3,2)\in S$, we obtain $(2,2)\in S\circ R$.

    Hence $S\circ R=\{(1,1),(2,2)\}$.

  2. Find $R^{-1}$: Swap each pair of $R$:

    3. $$ R^{-1}=\{(2,1),(3,2)\} $$

  3. Find $R^{2}=R\circ R$: Look for $b$ with $(a,b)\in R$ and $(b,c)\in R$.
    • From $(1,2)\in R$ we need a pair starting with $2$; $(2,3)\in R$ gives $(1,3)\in R^{2}$.

    No other chain exists, so $R^{2}=\{(1,3)\}$.

Summary of Important Laws

LawExpression
Inverse of inverse$ (R^{-1})^{-1}=R $
Inverse of composition$ (S\circ R)^{-1}=R^{-1}\circ S^{-1} $
Associativity$ (T\circ S)\circ R = T\circ (S\circ R) $
Identity element$ I_{A}\circ R = R\circ I_{A}=R $

Definition and classification of functions: one‑one, onto, bijective

Definition of a Function

A relation $f$ from a set $A$ to a set $B$ is called a function if for every $x\in A$ there exists a unique $y\in B$ such that $(x,y)\in f$. We denote $y=f(x)$.

One‑to‑One (Injective)

  • Definition: $f:A\to B$ is injective if $f(x_1)=f(x_2)\implies x_1=x_2$.
  • Equivalent condition: $x_1\neq x_2\implies f(x_1)\neq f(x_2)$.
  • Graphical test: Horizontal line test.

Onto (Surjective)

  • Definition: $f:A\to B$ is surjective if for every $y\in B$ there exists $x\in A$ with $f(x)=y$.
  • Image of $f$ equals codomain: $\operatorname{Im}(f)=B$.

Bijective

  • Definition: $f$ is bijective iff it is both injective and surjective.
  • Consequences: Inverse function $f^{-1}:B\to A$ exists and satisfies $f^{-1}(f(x))=x$ and $f(f^{-1}(y))=y$.

Step‑by‑Step Derivation of Injectivity Criterion

Assume $f$ is injective. Take arbitrary $x_1,x_2\in A$ with $x_1\neq x_2$. By definition, $f(x_1)\neq f(x_2)$. Conversely, if $f(x_1)\neq f(x_2)$ for all $x_1\neq x_2$, then $f(x_1)=f(x_2)$ would imply $x_1=x_2$, proving injectivity.

Edge Cases

  • Empty domain: Any function with $A=\emptyset$ is vacuously injective and surjective onto $B=\emptyset$.
  • Singleton codomain: Any function $f:A\to\{b\}$ is surjective but injective only if $|A|\le1$.

Worked Example

Let $f:\mathbb{R}\to\mathbb{R}$ be defined by $f(x)=2x+3$.

  • Injectivity: Suppose $f(x_1)=f(x_2)\Rightarrow 2x_1+3=2x_2+3\Rightarrow 2x_1=2x_2\Rightarrow x_1=x_2$. Hence $f$ is injective.
  • Surjectivity: For any $y\in\mathbb{R}$, solve $y=2x+3\Rightarrow x=\frac{y-3}{2}\in\mathbb{R}$. Thus $f$ is surjective.
  • Conclusion: $f$ is bijective and has inverse $f^{-1}(y)=\frac{y-3}{2}$.

Key Takeaway

To classify a function, verify the uniqueness of outputs for distinct inputs (injectivity) and the coverage of the codomain (surjectivity). A bijective function guarantees a one‑to‑one correspondence and the existence of a well‑defined inverse.

Composition of functions and inverse functions

Composition of Functions

Let $f:A\to B$ and $g:B\to C$ be two functions. The composition $g\circ f$ is defined by $$(g\circ f)(x)=g(f(x))\quad\forall x\in A.$$ The domain of $g\circ f$ is $A$ and its codomain is $C$. The composition is associative: $$(h\circ(g\circ f))=(h\circ g)\circ f$$ for $f:A\to B$, $g:B\to C$, $h:C\to D$. The identity function $I_A:A\to A$, $I_A(x)=x$, satisfies $I_B\circ f=f$ and $f\circ I_A=f$ for all $f:A\to B$.

Inverse Functions

A function $f:A\to B$ is one‑to‑one (injective) if $f(x_1)=f(x_2)\Rightarrow x_1=x_2$ and onto (surjective) if $\forall y\in B\,\exists x\in A$ such that $f(x)=y$. Only bijective functions admit a two‑sided inverse $f^{-1}:B\to A$ defined by $f^{-1}(y)=x$ whenever $f(x)=y$. The inverse satisfies $f^{-1}\circ f=I_A$ and $f\circ f^{-1}=I_B$.

Derivation of Inverse of a Linear Function

Consider $f(x)=mx+b$ with $m\neq0$. Solve $y=mx+b$ for $x$: $x=\frac{y-b}{m}$. Hence $$f^{-1}(y)=\frac{y-b}{m}.$$ The inverse is again linear with slope $\frac{1}{m}$ and intercept $-\frac{b}{m}$.

Edge Cases

  • Domain mismatch: If $\operatorname{codom}(f)\nsubseteq\operatorname{dom}(g)$, $g\circ f$ is undefined.
  • Non‑bijective function: Constant functions have no inverse because they are not injective.
  • Quadratic example: $q(x)=x^2$ is not one‑to‑one on $\mathbb{R}$. Restricting to $x\ge0$ yields a bijection onto $[0,\infty)$ with inverse $q^{-1}(y)=\sqrt{y}$.

Example

Let $f(x)=2x+3$ and $g(x)=x^2$. Compute $f\circ g$ and $g\circ f$:

CompositionExpression
$f\circ g$$f(g(x))=2(x^2)+3=2x^2+3$
$g\circ f$$g(f(x))=(2x+3)^2=4x^2+12x+9$

Inverse of $f$ is $f^{-1}(y)=\frac{y-3}{2}$. Since $g$ is not bijective on $\mathbb{R}$, $g^{-1}$ does not exist globally; restricting to $x\ge0$ gives $g^{-1}(y)=\sqrt{y}$.

These concepts are central to solving functional equations, analyzing transformations, and understanding the structure of mappings in higher mathematics.

Binary operations and their properties

Binary Operation on a set $S$ is a rule that assigns to every ordered pair $(a,b)$ of elements of $S$ a unique element $a\star b$ of $S$. The symbol $\star$ denotes any operation such as $+$, $\times$, $\circ$, etc. The operation must satisfy the closure property: $\forall a,b\in S,\;a\star b\in S$.

Important Properties

  • Commutativity: $a\star b = b\star a$ for all $a,b\in S$.
  • Associativity: $(a\star b)\star c = a\star (b\star c)$ for all $a,b,c\in S$.
  • Identity Element: An element $e\in S$ such that $e\star a = a\star e = a$ for every $a\in S$. If it exists, it is unique.
  • Inverse: For a given $a\in S$, an element $a^{-1}\in S$ satisfying $a\star a^{-1}=a^{-1}\star a = e$, where $e$ is the identity.
  • Distributivity (when two operations $\star$ and $\oplus$ are defined on $S$): $a\star (b\oplus c)= (a\star b)\oplus (a\star c)$ and $(a\oplus b)\star c = (a\star c)\oplus (b\star c)$.

Edge Cases and Remarks

  • If closure fails, the rule is not a binary operation on $S$ (e.g., subtraction on $mathbb{N}$).
  • An operation may be commutative but not associative (e.g., subtraction on $mathbb{Z}$).
  • Identity may not exist; for example, $a\star b = a-b$ on $mathbb{R}$ has no element $e$ satisfying $e\star a = a$ for all $a$.
  • When an identity exists, inverses are not guaranteed unless the operation is also associative (group structure).

Summary Table

PropertyMathematical Formulation
Closure$\forall a,b\in S,\;a\star b\in S$
Commutativity$\forall a,b\in S,\;a\star b = b\star a$
Associativity$\forall a,b,c\in S,\;(a\star b)\star c = a\star (b\star c)$
Identity$\exists e\in S$ such that $\forall a\in S,\;e\star a = a\star e = a$
Inverse$\forall a\in S,\;\exists a^{-1}\in S$ with $a\star a^{-1}=a^{-1}\star a = e$
Distributivity$a\star(b\oplus c) = (a\star b)\oplus (a\star c)$

Solved Example

Let $S=\{0,1,2,3,4\}$ and define $a\star b = (a+b)\bmod 5$. Verify the properties.

  1. Closure: For any $a,b\in S$, $a+b$ is an integer between $0$ and $8$. Reducing modulo $5$ yields a result in $\{0,1,2,3,4\}=S$.
  2. Commutativity: $a\star b = (a+b)\bmod5 = (b+a)\bmod5 = b\star a$.
  3. Associativity: $ (a\star b)\star c = ((a+b)\bmod5 + c)\bmod5 = (a+b+c)\bmod5 = a\star (b\star c)$.
  4. Identity: Choose $e=0$. Then $a\star 0 = (a+0)\bmod5 = a$ and $0\star a = a$.
  5. Inverse: For each $a$, the element $a^{-1}= (5-a)\bmod5$ satisfies $a\star a^{-1}= (a+(5-a))\bmod5 =0=e$. For example, $3^{-1}=2$ because $3\star2 = (3+2)\bmod5 =0$.

Thus the operation $\star$ on $S$ is a binary operation that is closed, commutative, associative, possesses an identity element $0$, and every element has a unique inverse. This structure is precisely the cyclic group $(\mathbb{Z}_5,+)$.

Special functions and their graphs

Special Functions and Their Graphs – CBSE Class 12

1. Definition

Special functions are functions that arise naturally in mathematics and physics and have well‑studied properties. In CBSE Class 12, the main special functions are the trigonometric, inverse trigonometric, exponential, logarithmic, hyperbolic and inverse hyperbolic functions. Each function is defined on a specific domain and has a characteristic range.

2. Trigonometric Functions

  • sin x, cos x, tan x – defined for all real $x$ (tan x has vertical asymptotes at $x=\frac{pi}{2}+kpi$). Domain: $mathbb{R}$; Range: $[-1,1]$ for sin x and cos x, $mathbb{R}$ for tan x.
  • Graph: periodic with period $2pi$; sin x and cos x are shifted by $\frac{pi}{2}$.

3. Inverse Trigonometric Functions

  • sin^{-1}x, cos^{-1}x, tan^{-1}x – defined for $xin[-1,1]$ for sin^{-1} and cos^{-1}, $xinmathbb{R}$ for tan^{-1}. Range: $[-\frac{pi}{2},\frac{pi}{2}]$ for sin^{-1} and tan^{-1}, $[0,pi]$ for cos^{-1}.

4. Exponential and Logarithmic Functions

  • e^x – domain $mathbb{R}$, range $(0,infty)$. Graph passes through $(0,1)$, asymptote $y=0$.
  • ln x – domain $(0,infty)$, range $mathbb{R}$. Graph passes through $(1,0)$, asymptote $x=0$.

5. Hyperbolic Functions

  • sinh x = \frac{e^x-e^{-x}}{2}, cosh x = \frac{e^x+e^{-x}}{2}. Domain $mathbb{R}$, range $[-1,1]$ for sinh x, $[1,infty)$ for cosh x.

6. Laws and Theorems

  • Trigonometric Identities – e.g., $sin^2x+cos^2x=1$, $tanx=\frac{sinx}{cosx}$, $sin(2x)=2sinxcosx$.
  • Inverse Relations – $sin(sin^{-1}x)=x$, $sin^{-1}(sinx)=x$ for $xin[-\frac{pi}{2},\frac{pi}{2}]$.
  • Derivative Rules – $\frac{d}{dx}sinx=cosx$, $\frac{d}{dx}lnx=\frac{1}{x}$, $\frac{d}{dx}e^x=e^x$.

7. SI Units

  • Angle measured in radians (rad). 1 rad = $\frac{180}{pi}$ degrees.
  • For trigonometric functions, the argument must be in radians for calculus.

8. Edge Cases

  • Vertical asymptotes of tan x at $x=\frac{pi}{2}+kpi$.
  • Discontinuity of ln x at $x=0$.
  • Domain restrictions for inverse trig functions.

9. Solved Example – Graph of $y=tanx$

Domain: $x\neq\frac{pi}{2}+kpi$, $kinmathbb{Z}$. Range: $mathbb{R}$. Asymptotes: $x=\frac{pi}{2}+kpi$. Period: $pi$. Key points: $tan0=0$, $tan\frac{pi}{4}=1$, $tan(-\frac{pi}{4})=-1$. Plotting these points and drawing the curve between asymptotes gives the standard tan x graph.

10. Derivative Example – $y=lnx$

Using the definition of derivative: $\frac{d}{dx}lnx=lim_{h\to0}\frac{ln(x+h)-lnx}{h}=\frac{1}{x}$. Thus the slope of the tangent at any point $(a,ln a)$ is $\frac{1}{a}$.

These concise definitions, derivations, and examples provide a solid foundation for understanding special functions and their graphs in CBSE Class 12 Mathematics.

Transformations of functions and graphical tests

Transformations of Functions and Graphical Tests – CBSE Class 12

In this chapter we study how a basic function $f(x)$ can be altered by algebraic operations and how the resulting graph can be examined using graphical tests.

1. Translation

  • Horizontal shift: $g(x)=f(x-h)$ moves the graph $h$ units right if $h>0$ and left if $h<0$.
  • Vertical shift: $g(x)=f(x)+k$ moves the graph $k$ units up if $k>0$ and down if $k<0$.
  • Combined shift: $g(x)=f(x-h)+k$.

2. Reflection

  • About the $x$‑axis: $g(x)=-f(x)$.
  • About the $y$‑axis: $g(x)=f(-x)$.
  • About the origin: $g(x)=-f(-x)$.

3. Scaling (Dilation)

  • Vertical scaling: $g(x)=a,f(x)$ stretches the graph by factor $|a|$ if $|a|>1$ and compresses if $|a|<1$. If $a<0$ a reflection about the $x$‑axis also occurs.
  • Horizontal scaling: $g(x)=f(bx)$ compresses horizontally by factor $|b|$ if $|b|>1$ and stretches if $|b|<1$. If $b<0$ a reflection about the $y$‑axis also occurs.

4. Rotation (about the origin)

  • For a rotation by angle $\theta$, the new coordinates are $x'=xcos\theta+ysin\theta$, $y'=-xsin\theta+ycos\theta$. The transformed function is $g(x')=f(x)$.

Graphical Tests

  • Domain & Range: Determine all $x$ for which $f(x)$ is defined and the set of possible $y$ values.
  • Intercepts: Solve $f(x)=0$ for $x$‑intercepts and $f(0)$ for $y$‑intercept.
  • Symmetry: Even if $f(-x)=f(x)$; odd if $f(-x)=-f(x)$.
  • Asymptotes: Vertical if $lim_{x\to a}f(x)=pminfty$; horizontal if $lim_{x opminfty}f(x)=L$.
  • Continuity & Differentiability: Check limits from left and right; if $f'(x)$ exists.

Example

Transform $f(x)=x^{2}$ to $g(x)=-2(x-3)^{2}+5$.

  1. Start with $f(x)=x^{2}$.
  2. Horizontal shift right by $3$: $f_{1}(x)=f(x-3)=(x-3)^{2}$.
  3. Vertical stretch by factor $2$ and reflection about $x$‑axis: $f_{2}(x)= -2,f_{1}(x)=-2(x-3)^{2}$.
  4. Vertical shift up by $5$: $g(x)=f_{2}(x)+5=-2(x-3)^{2}+5$.

Graphically, the vertex moves from $(0,0)$ to $(3,5)$, the parabola opens downwards, and its width is halved compared to $f(x)=x^{2}$.

All transformations preserve the shape locally but alter position, orientation, and scale, which can be verified using the graphical tests listed above.

Applications of functions in solving equations and functional equations

Definition: A function $f$ from a set $A$ to a set $B$ is a rule that assigns to each element $x\in A$ a unique element $y\in B$, denoted $y=f(x)$. The set $A$ is called the domain and $B$ the codomain; the set of actual values $\{f(x):x\in A\}$ is the range.

Key properties used in applications:

  • One‑to‑one (injective): $f(x_1)=f(x_2)\Rightarrow x_1=x_2$.
  • Onto (surjective): For every $y\in B$ there exists $x\in A$ such that $f(x)=y$.
  • Inverse function: If $f$ is bijective, the inverse $f^{-1}$ satisfies $f^{-1}(f(x))=x$ and $f(f^{-1}(y))=y$.
  • Composition: $(g\circ f)(x)=g(f(x))$.

Functional equations in solving equations: Many algebraic equations can be rewritten as functional equations, allowing the use of function properties to obtain solutions. A classic example is the Cauchy equation $f(x+y)=f(x)+f(y)$. If $f$ is assumed continuous (or bounded on an interval), the only solutions are linear functions $f(x)=kx$, where $k$ is a constant. This theorem is often invoked to solve problems where an unknown expression appears both inside and outside a function.

Theorem (Cauchy – linearity under continuity): If $f:\mathbb{R}\to\mathbb{R}$ satisfies $f(x+y)=f(x)+f(y)$ for all real $x,y$ and $f$ is continuous at even a single point, then $f(x)=kx$ for some constant $k$.

Edge cases: Without the continuity (or boundedness) hypothesis, there exist highly pathological solutions that are not expressible by elementary formulas. In competitive exams these cases are usually excluded by explicitly stating continuity, monotonicity, or boundedness.

Typical steps to solve a functional equation:

  1. Identify the domain and codomain.
  2. Substitute convenient values (e.g., $x=0$, $y=0$, $y=-x$) to obtain simple relations.
  3. Check for injectivity or surjectivity using the given condition.
  4. If a linear form is suspected, assume $f(x)=ax+b$ and determine $a,b$ by comparison.
  5. Verify that the obtained function satisfies the original equation for all admissible $x,y$.

Solved example: Find all functions $f:\mathbb{R}\to\mathbb{R}$ such that
$$f(x)+f(1-x)=1\quad\text{for all }x\in\mathbb{R}.$$

Solution:

  1. Replace $x$ by $1-x$ to get $f(1-x)+f(x)=1$, which is the same equation; thus the relation is symmetric.
  2. Set $x=\frac12$: $f\left(\frac12\right)+f\left(\frac12\right)=1\Rightarrow f\left(\frac12\right)=\frac12$.
  3. Assume a linear form $f(x)=ax+b$. Substituting, $ax+b + a(1-x)+b = a x + b + a - a x + b = a + 2b = 1$.
  4. Thus $a+2b=1$. No other condition on $a$ appears, so $a$ can be any real number and $b=\frac{1-a}{2}$.
  5. Therefore the family of solutions is $f(x)=ax+\frac{1-a}{2}$, $a\in\mathbb{R}$. Direct substitution confirms the result.

Summary table of common functional‑equation techniques:

TechniqueWhen to use
Substitution $x=0$ or $y=0$To obtain values of $f(0)$ or simplify the equation.
Symmetry $x\to c-x$When the equation involves $x$ and $c-x$ (as in the example).
