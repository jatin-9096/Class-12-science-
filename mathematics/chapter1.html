1. Complete Conceptual Framework & Definitions

Fundamental Theoretical Principles

As a Senior CBSE Board Examiner and Textbook Author for Class 12 Mathematics, it is imperative to establish a profoundly rigorous and conceptually robust foundation for the very first chapter. 'Chapter 1: Relations and Functions' is not merely an introductory topic; it is the bedrock upon which the entire edifice of higher mathematics, particularly Calculus, Discrete Mathematics, and Abstract Algebra, is constructed. A thorough understanding here ensures clarity in subsequent chapters involving continuity, differentiability, integration, and even advanced topics in engineering and computer science. This chapter transitions students from the concrete world of arithmetic and basic algebra to the more abstract realm of mathematical structures and mappings. Our objective is to dissect every nuance, every definition, and every implication with unparalleled precision.

1.1. Introduction to the Abstract Landscape: Sets as the Foundation

Before delving into relations and functions, it is crucial to revisit and solidify our understanding of 'sets'. In mathematics, a set is a well-defined collection of distinct objects. These objects are called elements or members of the set. The concept of 'well-defined' is paramount; it means that there is a clear criterion for determining whether an object belongs to the set or not. For instance, "the collection of all tall students in a class" is not a well-defined set because "tall" is subjective, whereas "the collection of all students in Class 12 scoring above 90% in Mathematics" is well-defined. We typically denote sets using capital letters (A, B, C, etc.) and their elements using lowercase letters (a, b, c, etc.). The membership of an element 'x' in a set 'A' is denoted by 'x ∈ A', while 'x ∉ A' signifies that 'x' is not an an element of 'A'. **Methods of Representing a Set:** 1. **Roster or Tabular Form:** All the elements of the set are listed, separated by commas, and enclosed within curly braces. * Example: A = {1, 2, 3, 4, 5} (Set of first five natural numbers). * Example: B = {a, e, i, o, u} (Set of vowels in the English alphabet). * Note: The order of elements does not matter, and elements are not repeated. 2. **Set-Builder Form (Property Method):** A descriptive property that uniquely defines the elements of the set is used. * Syntax: {x : P(x)} or {x | P(x)}, where 'x' represents an element and 'P(x)' is the property it satisfies. * Example: A = {x : x is a natural number and x ≤ 5}. This is equivalent to A = {1, 2, 3, 4, 5}. * Example: B = {x : x is a vowel in the English alphabet}. This is equivalent to B = {a, e, i, o, u}. * This method is particularly powerful for defining infinite sets or sets with complex membership rules. **Types of Sets:** * **Empty Set (Null Set, Void Set):** A set containing no elements. Denoted by ∅ or {}. * Example: {x : x is an even prime number greater than 2} = ∅. * **Finite Set:** A set whose elements can be counted, meaning the process of counting its elements comes to an end. * Example: {1, 2, 3, 4, 5}. * **Infinite Set:** A set whose elements cannot be counted; the counting process would never end. * Example: The set of all natural numbers, N = {1, 2, 3, ...}. * **Singleton Set:** A set containing exactly one element. * Example: {x : x is an even prime number} = {2}. **Subsets and Supersets:** * A set A is a **subset** of a set B, denoted by A ⊆ B, if every element of A is also an element of B. * If A ⊆ B and A ≠ B, then A is a **proper subset** of B, denoted by A ⊂ B. * If A ⊆ B, then B is a **superset** of A, denoted by B ⊇ A. * Every set is a subset of itself (A ⊆ A). * The empty set is a subset of every set (∅ ⊆ A). * **Power Set:** The collection of all subsets of a set A is called the power set of A, denoted by P(A). If a set A has 'n' elements, then its power set P(A) has 2n elements. * Example: If A = {1, 2}, then P(A) = {∅, {1}, {2}, {1, 2}}. **Operations on Sets (Brief Recap):** * **Union (∪):** A ∪ B = {x : x ∈ A or x ∈ B}. (Elements belonging to A, or B, or both). * **Intersection (∩):** A ∩ B = {x : x ∈ A and x ∈ B}. (Elements common to both A and B). * **Difference (-):** A - B = {x : x ∈ A and x ∉ B}. (Elements in A but not in B). * **Complement (' or ᶜ):** A' = U - A, where U is the universal set. (Elements not in A but in the universal set). These operations are visually represented using Venn diagrams, which provide an intuitive graphical understanding.

1.2. Ordered Pairs and the Cartesian Product

The concept of an 'ordered pair' is fundamental to understanding relations. Unlike elements in a set where order does not matter, an ordered pair specifies the order of its components. An ordered pair (a, b) is distinct from (b, a) unless a = b. Formally, (a, b) = (c, d) if and only if a = c and b = d. The **Cartesian Product** of two non-empty sets A and B, denoted by A × B, is the set of all possible ordered pairs (a, b) such that 'a' is an element of A and 'b' is an element of B. Mathematically: A × B = {(a, b) | a ∈ A and b ∈ B}. **Key Properties of Cartesian Product:** 1. If n(A) is the number of elements in set A and n(B) is the number of elements in set B, then the number of elements in A × B is n(A × B) = n(A) × n(B). 2. A × B ≠ B × A, unless A = B or A = ∅ or B = ∅. This implies that the Cartesian product is generally not commutative. 3. If A or B is an empty set, then A × B = ∅. 4. If A or B is an infinite set, and the other is non-empty, then A × B is also an infinite set. **Examples:** * Let A = {1, 2} and B = {x, y}. A × B = {(1, x), (1, y), (2, x), (2, y)}. B × A = {(x, 1), (x, 2), (y, 1), (y, 2)}. Notice A × B ≠ B × A. * The Cartesian product can be extended to three sets: A × B × C = {(a, b, c) | a ∈ A, b ∈ B, c ∈ C}. These are ordered triplets. For example, if A = B = C = R (set of real numbers), then R × R × R = R³ represents the set of all points in three-dimensional space, (x, y, z). * R × R = R² represents the Cartesian plane, where each point (x, y) is an ordered pair of real numbers. The Cartesian product provides the universal set of all possible pairings between elements of two sets. This forms the domain from which relations are defined.

1.3. Relations: Linking Elements Across Sets

A **relation** is fundamentally a connection or association between elements of two or more sets. In the context of mathematics, a relation R from a non-empty set A to a non-empty set B is defined as any subset of the Cartesian product A × B. Formally: R ⊆ A × B. If (a, b) ∈ R, we say that 'a' is related to 'b' under the relation R, and we often write this as 'a R b'. Conversely, if (a, b) ∉ R, then 'a' is not related to 'b'. **Key Terminologies Associated with Relations:** * **Domain of R:** The set of all first components (elements from A) of the ordered pairs in R. Domain(R) = {a ∈ A | (a, b) ∈ R for some b ∈ B}. * **Codomain of R:** The entire set B. * **Range of R:** The set of all second components (elements from B) of the ordered pairs in R. Range(R) = {b ∈ B | (a, b) ∈ R for some a ∈ A}. Note that Range(R) ⊆ Codomain(R). **Number of Relations:** If n(A) = p and n(B) = q, then n(A × B) = pq. Since a relation R is a subset of A × B, the total number of possible relations from A to B is 2n(A × B) = 2pq. **Example:** Let A = {1, 2, 3} and B = {x, y}. A × B = {(1, x), (1, y), (2, x), (2, y), (3, x), (3, y)}. A relation R from A to B could be R = {(1, x), (2, y)}. Here, Domain(R) = {1, 2}, Range(R) = {x, y}, and Codomain(R) = {x, y}. Another relation could be R₂ = {(a, b) ∈ A × B | a is odd}. R₂ = {(1, x), (1, y), (3, x), (3, y)}. Domain(R₂) = {1, 3}, Range(R₂) = {x, y}. Often, relations are defined on a single set A, meaning the relation is a subset of A × A. This is particularly important for classifying types of relations.

1.3.1. Types of Relations on a Set A

Let R be a relation on a non-empty set A (i.e., R ⊆ A × A). 1. **Empty Relation (Void Relation):** A relation R on set A is called an empty relation if no element of A is related to any element of A. In other words, R = ∅ ⊆ A × A. * Example: Let A = {1, 2, 3}. R = {(a, b) ∈ A × A | a + b = 7}. Since the maximum sum of any two elements in A is 3+3=6, no pair (a, b) will satisfy a+b=7. Thus, R = ∅. 2. **Universal Relation:** A relation R on set A is called a universal relation if every element of A is related to every element of A. In other words, R = A × A. * Example: Let A = {1, 2, 3}. R = {(a, b) ∈ A × A | |a - b| ≥ 0}. Since the absolute difference between any two real numbers (and thus any two elements from A) is always non-negative, this condition is always satisfied. Thus, R = A × A. The empty relation and the universal relation are sometimes referred to as **trivial relations**. 3. **Reflexive Relation:** A relation R on set A is said to be reflexive if every element of A is related to itself. That is, for every a ∈ A, (a, a) ∈ R. * Example: Let A = {1, 2, 3}. R = {(1, 1), (2, 2), (3, 3), (1, 2)}. This relation is reflexive because (1, 1), (2, 2), and (3, 3) are all present in R. * Non-example: R' = {(1, 1), (2, 2)}. This is not reflexive on A because (3, 3) ∉ R'. * Example from Geometry: "is congruent to" on the set of all triangles. Any triangle is congruent to itself. 4. **Symmetric Relation:** A relation R on set A is said to be symmetric if, whenever (a, b) ∈ R, then (b, a) ∈ R for all a, b ∈ A. * Example: Let A = {1, 2, 3}. R = {(1, 2), (2, 1), (1, 1)}. This is symmetric because for (1, 2) ∈ R, (2, 1) ∈ R. (1, 1) doesn't need a separate check as its reverse is itself. * Non-example: R' = {(1, 2), (2, 3)}. This is not symmetric because (1, 2) ∈ R' but (2, 1) ∉ R'. * Example from Everyday Life: "is a sibling of" on the set of people. If A is a sibling of B, then B is a sibling of A. 5. **Transitive Relation:** A relation R on set A is said to be transitive if, whenever (a, b) ∈ R and (b, c) ∈ R, then (a, c) ∈ R for all a, b, c ∈ A. * Example: Let A = {1, 2, 3}. R = {(1, 2), (2, 3), (1, 3), (1, 1)}. * (1, 2) ∈ R and (2, 3) ∈ R ⇒ (1, 3) ∈ R (satisfied). * This relation is transitive. * Non-example: R' = {(1, 2), (2, 3)}. This is not transitive because (1, 2) ∈ R' and (2, 3) ∈ R' but (1, 3) ∉ R'. * Example from Set Theory: "is a subset of" on the power set of a given set. If A ⊆ B and B ⊆ C, then A ⊆ C.

1.3.2. Equivalence Relation and Equivalence Classes

A relation R on a set A is called an **Equivalence Relation** if it is simultaneously: (i) Reflexive (ii) Symmetric (iii) Transitive **Example:** Let A be the set of all triangles in a plane. Let R be the relation "is similar to" (denoted by ~). * **Reflexive:** Every triangle is similar to itself (ΔT ~ ΔT). So, R is reflexive. * **Symmetric:** If ΔT₁ ~ ΔT₂, then ΔT₂ ~ ΔT₁. So, R is symmetric. * **Transitive:** If ΔT₁ ~ ΔT₂ and ΔT₂ ~ ΔT₃, then ΔT₁ ~ ΔT₃. So, R is transitive. Since R is reflexive, symmetric, and transitive, "is similar to" is an equivalence relation. **Equivalence Classes:** An equivalence relation partitions the set A into disjoint subsets called **equivalence classes**. For an equivalence relation R on A, the equivalence class of an element a ∈ A, denoted by [a] or {a}R, is the set of all elements in A that are related to 'a'. Formally: [a] = {x ∈ A | (x, a) ∈ R}. **Properties of Equivalence Classes:** 1. Every element 'a' belongs to its own equivalence class, i.e., a ∈ [a]. 2. Two equivalence classes [a] and [b] are either identical or disjoint. That is, [a] = [b] or [a] ∩ [b] = ∅. 3. The union of all distinct equivalence classes is the entire set A. Essentially, an equivalence relation divides the set into non-overlapping groups where all elements within a group are related to each other, and no element in one group is related to an element in another group. **Example (Equivalence Classes):** Let A = {1, 2, 3, 4, 5, 6}. Let R be the relation "is congruent to modulo 2" on A. That is, (a, b) ∈ R if a - b is an even integer. * **Reflexive:** a - a = 0, which is even. So, R is reflexive. * **Symmetric:** If a - b is even, then b - a = -(a - b) is also even. So, R is symmetric. * **Transitive:** If a - b is even and b - c is even, then (a - b) + (b - c) = a - c is even. So, R is transitive. Hence, R is an equivalence relation. Now, let's find the equivalence classes: * [1] = {x ∈ A | x - 1 is even} = {1, 3, 5} (all odd numbers in A). * [2] = {x ∈ A | x - 2 is even} = {2, 4, 6} (all even numbers in A). Notice that [1] = [3] = [5], and [2] = [4] = [6]. Also, [1] ∩ [2] = ∅, and [1] ∪ [2] = {1, 2, 3, 4, 5, 6} = A. The equivalence relation partitions A into two disjoint sets: the set of odd numbers and the set of even numbers.

1.4. Functions: A Special Type of Relation

A **function** is a special kind of relation where each element in the domain set is mapped to exactly one element in the codomain set. This "one and only one" rule is what distinguishes a function from a general relation. Formally, a relation f from a non-empty set A to a non-empty set B is called a function if: 1. Every element of A is related to some element of B. (i.e., Domain(f) = A). 2. Each element of A has a unique image in B. That is, if (x, y₁) ∈ f and (x, y₂) ∈ f, then y₁ = y₂. We denote a function f from A to B as f: A → B. * The set A is called the **Domain** of the function. * The set B is called the **Codomain** of the function. * The set of all actual images of the elements of A under f is called the **Range** of the function. Range(f) = {f(x) | x ∈ A}. Note that Range(f) ⊆ Codomain(f). If f: A → B and (a, b) ∈ f, we write f(a) = b. Here, 'b' is called the image of 'a' under f, and 'a' is called the pre-image of 'b'. **Distinction from Relations:** * Every function is a relation, but not every relation is a function. * A relation might have an element in its domain mapped to multiple elements in the codomain (e.g., {(1, 2), (1, 3)} is a relation but not a function). * A relation might not map all elements of its domain (i.e., its domain might be a proper subset of A). For a function, the domain must be the entire set A. **Vertical Line Test (for functions represented graphically):** If every vertical line drawn through the graph intersects the graph at most once, then the graph represents a function. If any vertical line intersects the graph at more than one point, it is not a function. This visually demonstrates the "unique image" property.

1.4.1. Types of Functions

Functions are categorized based on how elements of the domain are mapped to elements of the codomain. 1. **One-to-One Function (Injective Function):** A function f: A → B is said to be one-to-one if distinct elements of A have distinct images in B. * Formally: If f(x₁) = f(x₂), then x₁ = x₂ for all x₁, x₂ ∈ A. * Equivalently: If x₁ ≠ x₂, then f(x₁) ≠ f(x₂) for all x₁, x₂ ∈ A. * Example: f: N → N given by f(x) = x + 1. If f(x₁) = f(x₂), then x₁ + 1 = x₂ + 1 ⇒ x₁ = x₂. Thus, f is one-to-one. * **Horizontal Line Test (for injectivity):** If every horizontal line drawn through the graph intersects the graph at most once, then the function is one-to-one. 2. **Many-to-One Function:** A function f: A → B is said to be many-to-one if two or more distinct elements of A have the same image in B. * Formally: There exist x₁, x₂ ∈ A such that x₁ ≠ x₂ but f(x₁) = f(x₂). * Example: f: Z → N given by f(x) = x². Here, f(2) = 4 and f(-2) = 4. Since 2 ≠ -2 but f(2) = f(-2), f is many-to-one. 3. **Onto Function (Surjective Function):** A function f: A → B is said to be onto if every element in the codomain B is the image of at least one element in the domain A. In other words, the range of f is equal to its codomain (Range(f) = B). * Formally: For every y ∈ B, there exists at least one x ∈ A such that f(x) = y. * Example: f: N → {1, 4, 9, ...} (the set of perfect squares) given by f(x) = x². For every y in the codomain, its square root is in N, so it has a pre-image. Thus, f is onto. * Non-example: f: N → N given by f(x) = x + 1. The element 1 in the codomain N has no pre-image in N (x+1=1 ⇒ x=0, but 0 ∉ N). So, this function is not onto. 4. **Into Function:** A function f: A → B is said to be an into function if there is at least one element in the codomain B that is not the image of any element in the domain A. In other words, the range of f is a proper subset of the codomain B (Range(f) ⊂ B). * Example: f: Z → N given by f(x) = x². The range is {0, 1, 4, 9, ...}. The codomain is N = {1, 2, 3, 4, ...}. Range(f) is a proper subset of N (e.g., 2 and 3 are in N but have no integer pre-image). Thus, f is into. 5. **Bijective Function (One-to-One and Onto):** A function f: A → B is said to be bijective if it is both one-to-one (injective) and onto (surjective). * This means every element in A has a unique image in B, and every element in B has exactly one pre-image in A. * Example: f: R → R given by f(x) = 2x + 3. * **Injectivity:** If f(x₁) = f(x₂), then 2x₁ + 3 = 2x₂ + 3 ⇒ 2x₁ = 2x₂ ⇒ x₁ = x₂. So, f is one-to-one. * **Surjectivity:** For any y ∈ R (codomain), we need to find an x ∈ R (domain) such that f(x) = y. So, 2x + 3 = y ⇒ 2x = y - 3 ⇒ x = (y - 3) / 2. Since y ∈ R, (y - 3) / 2 is also in R. Thus, every y has a pre-image. So, f is onto. * Since f is both one-to-one and onto, it is bijective. * Bijective functions are extremely important because they are precisely the functions that possess inverse functions.

1.5. Composition of Functions: Chaining Mappings

The concept of composing functions allows us to combine two or more functions to create a new function. If we have a function f that maps elements from set A to set B, and another function g that maps elements from set B to set C, we can define a composite function that maps directly from A to C. Let f: A → B and g: B → C be two functions. The **composition of f and g**, denoted by g o f (read as "g composed with f" or "g of f"), is a function from A to C defined by: (g o f)(x) = g(f(x)) for all x ∈ A. **Conditions for Composition:** For g o f to be defined, the range of the inner function f must be a subset of the domain of the outer function g. That is, Range(f) ⊆ Domain(g). In our definition, since Domain(g) is B and Codomain(f) is B, this condition is implicitly satisfied if the codomain of f is exactly the domain of g. If Range(f) is not a subset of Domain(g), then g o f is not defined for all x ∈ A. **Example:** Let A = {1, 2, 3}, B = {p, q, r}, C = {x, y, z}. Let f: A → B be defined by f(1) = p, f(2) = q, f(3) = r. Let g: B → C be defined by g(p) = x, g(q) = y, g(r) = z. Then g o f: A → C is defined as: (g o f)(1) = g(f(1)) = g(p) = x (g o f)(2) = g(f(2)) = g(q) = y (g o f)(3) = g(f(3)) = g(r) = z **Properties of Function Composition:** 1. **Non-Commutativity:** In general, f o g ≠ g o f. The order of composition matters. * Example: f(x) = x² and g(x) = x + 1. (f o g)(x) = f(g(x)) = f(x + 1) = (x + 1)² = x² + 2x + 1. (g o f)(x) = g(f(x)) = g(x²) = x² + 1. Clearly, (f o g)(x) ≠ (g o f)(x). * Furthermore, g o f might be defined while f o g is not, or vice versa, depending on domain/codomain compatibility. 2. **Associativity:** If f: A → B, g: B → C, and h: C → D are three functions, then the composition is associative: h o (g o f) = (h o g) o f. This means the grouping of compositions doesn't change the final result. 3. **Identity Function:** The identity function I_A: A → A is defined by I_A(x) = x for all x ∈ A. If f: A → B is a function, then f o I_A = f and I_B o f = f. The identity function acts like the multiplicative identity '1' in numbers.

1.6. Invertible Functions and Inverse of a Function

An **invertible function** is a function that can be "undone" or "reversed" by another function. This reversal is possible only when the original function establishes a perfect one-to-one correspondence between its domain and codomain. A function f: A → B is said to be **invertible** if there exists another function g: B → A such that: 1. g o f = I_A (the identity function on set A), and 2. f o g = I_B (the identity function on set B). The function g is then called the **inverse** of f, and is uniquely denoted by f⁻¹. **Condition for Invertibility:** A function f: A → B is invertible if and only if it is **bijective** (i.e., both one-to-one and onto). * **Necessity (If f is invertible, then f is bijective):** * *Injectivity:* Assume f(x₁) = f(x₂). Since f is invertible, f⁻¹ exists. Apply f⁻¹ to both sides: f⁻¹(f(x₁)) = f⁻¹(f(x₂)). By definition of inverse, I_A(x₁) = I_A(x₂), which implies x₁ = x₂. Thus, f is injective. * *Surjectivity:* For any y ∈ B, we need to show there's an x ∈ A such that f(x) = y. Since f⁻¹: B → A, for any y ∈ B, f⁻¹(y) is an element in A. Let x = f⁻¹(y). Then f(x) = f(f⁻¹(y)) = I_B(y) = y. Thus, f is surjective. * **Sufficiency (If f is bijective, then f is invertible):** If f is bijective, then for every y ∈ B, there exists a unique x ∈ A such that f(x) = y (one-to-one ensures uniqueness, onto ensures existence). We can define a function g: B → A by g(y) = x. * Then, (g o f)(x) = g(f(x)) = g(y) = x = I_A(x). * And, (f o g)(y) = f(g(y)) = f(x) = y = I_B(y). Since g o f = I_A and f o g = I_B, f is invertible and g = f⁻¹. **Steps to find the inverse of a function f(x):** 1. Write y = f(x). 2. Swap x and y: x = f(y). (This represents reflection across the line y=x). 3. Solve the equation for y in terms of x. The resulting expression for y is f⁻¹(x). 4. Verify that f is bijective in its given domain and codomain. **Example:** Find the inverse of f: R → R given by f(x) = 2x + 3. 1. Let y = 2x + 3. 2. Swap x and y: x = 2y + 3. 3. Solve for y: x - 3 = 2y y = (x - 3) / 2. So, f⁻¹(x) = (x - 3) / 2. We already showed f(x) = 2x+3 is bijective, so its inverse exists. * Verification: (f o f⁻¹)(x) = f(f⁻¹(x)) = f((x - 3) / 2) = 2 * ((x - 3) / 2) + 3 = (x - 3) + 3 = x. (f⁻¹ o f)(x) = f⁻¹(f(x)) = f⁻¹(2x + 3) = ((2x + 3) - 3) / 2 = 2x / 2 = x. Both compositions yield the identity function, confirming f⁻¹(x) = (x - 3) / 2 is the inverse. **Graphical Interpretation of Inverse Functions:** The graph of an inverse function f⁻¹ is a reflection of the graph of f across the line y = x. This is because swapping x and y coordinates (which is what we do algebraically) corresponds to this geometric transformation.

1.7. Binary Operations: Structuring Sets with Operations

A **binary operation** on a set is a rule that combines two elements of the set to produce another element of the same set. It's essentially a function that takes two inputs from a set and returns an output that is also in the same set. Formally, a binary operation * (often read as 'star') on a non-empty set A is a function *: A × A → A. For any (a, b) ∈ A × A, we denote the image *(a, b) as a * b. **Examples of Binary Operations:** * Addition (+) on the set of natural numbers N: For any a, b ∈ N, a + b ∈ N. So, + is a binary operation on N. * Multiplication (×) on the set of real numbers R: For any a, b ∈ R, a × b ∈ R. So, × is a binary operation on R. * Subtraction (-) on N is NOT a binary operation: 2 - 3 = -1 ∉ N. * Union (∪) on the power set P(S) of a set S: For any A, B ∈ P(S), A ∪ B ∈ P(S). So, ∪ is a binary operation on P(S).

1.7.1. Properties of Binary Operations

Let * be a binary operation on a set A. 1. **Commutativity:** A binary operation * on a set A is said to be **commutative** if a * b = b * a for all a, b ∈ A. * Example: Addition (+) and multiplication (×) are commutative on R (e.g., 2 + 3 = 3 + 2, 2 × 3 = 3 × 2). * Non-example: Subtraction (-) is not commutative on Z (e.g., 2 - 3 ≠ 3 - 2). * Non-example: Matrix multiplication is generally not commutative. 2. **Associativity:** A binary operation * on a set A is said to be **associative** if (a * b) * c = a * (b * c) for all a, b, c ∈ A. * Example: Addition (+) and multiplication (×) are associative on R (e.g., (2 + 3) + 4 = 2 + (3 + 4), (2 × 3) × 4 = 2 × (3 × 4)). * Non-example: Subtraction (-) is not associative on Z (e.g., (5 - 3) - 1 = 2 - 1 = 1, but 5 - (3 - 1) = 5 - 2 = 3. So, (5 - 3) - 1 ≠ 5 - (3 - 1)). 3. **Identity Element:** An element e ∈ A is called an **identity element** for the binary operation * on A if a * e = e * a = a for all a ∈ A. An identity element, if it exists, is unique. * Example: For addition (+) on R, 0 is the identity element (a + 0 = 0 + a = a). * Example: For multiplication (×) on R, 1 is the identity element (a × 1 = 1 × a = a). * Example: For the operation 'max' (maximum) on R, there is no identity element. 4. **Inverse Element:** Let * be a binary operation on A with an identity element e. An element b ∈ A is called the **inverse** of an element a ∈ A if a * b = b * a = e. The inverse of an element 'a' is usually denoted by a⁻¹. * Example: For addition (+) on R, the inverse of 'a' is '-a' because a + (-a) = (-a) + a = 0 (identity element). * Example: For multiplication (×) on R (excluding 0), the inverse of 'a' is '1/a' because a × (1/a) = (1/a) × a = 1 (identity element). * An element might not have an inverse. For example, in (N, +), 0 is not in N, so no inverse exists. For (Z, ×), only 1 and -1 have inverses (themselves).

1.8. Graphical Variations and Interpretations for Functions

Visualizing functions is crucial for developing an intuitive understanding of their properties. Graphs provide a powerful tool to analyze domain, range, injectivity, surjectivity, and invertibility. 1. **Domain and Range on a Graph:** * The **domain** of a function y = f(x) is the set of all possible x-values for which the function is defined. Graphically, this corresponds to the projection of the graph onto the x-axis. * The **range** of a function y = f(x) is the set of all possible y-values that the function takes. Graphically, this corresponds to the projection of the graph onto the y-axis. 2. **Vertical Line Test (Function Test):** As mentioned earlier, a curve in the Cartesian plane represents a function if and only if no vertical line intersects the curve at more than one point. This ensures that each input (x-value) has exactly one output (y-value). 3. **Horizontal Line Test (Injectivity Test):** A function f is one-to-one (injective) if and only if no horizontal line intersects its graph at more than one point. If a horizontal line intersects the graph at two or more points, it means distinct x-values have the same y-value, hence it's many-to-one. 4. **Surjectivity and Graph:** Determining surjectivity from a graph requires knowing the specified codomain. If the range of the function (projection onto the y-axis) covers the entire specified codomain, then the function is surjective. For example, if f: R → R, and the graph spans all possible y-values from -∞ to +∞, it is surjective. If the codomain was [0, ∞) for f(x) = x², then it would be surjective, but if the codomain was R, it would not be surjective. 5. **Graphing Inverse Functions:** The graphs of f(x) and f⁻¹(x) are symmetric with respect to the line y = x. This means if you fold the paper along the line y = x, the graph of f will perfectly superimpose on the graph of f⁻¹. For example, the graph of y = eˣ and y = ln(x) (natural logarithm, the inverse of eˣ) are reflections across y = x. 6. **Transformations of Graphs (Brief Overview for contextual understanding):** While not strictly part of Chapter 1, understanding how graphs transform helps in visualizing functions. * **Vertical Shifts:** f(x) + c moves the graph up by c units; f(x) - c moves it down. * **Horizontal Shifts:** f(x + c) moves the graph left by c units; f(x - c) moves it right. * **Vertical Stretches/Compressions:** c * f(x) stretches (c > 1) or compresses (0 < c < 1) vertically. * **Horizontal Stretches/Compressions:** f(c * x) compresses (c > 1) or stretches (0 < c < 1) horizontally. * **Reflections:** -f(x) reflects across the x-axis; f(-x) reflects across the y-axis. This comprehensive breakdown of Relations and Functions forms the essential foundation for Class 12 Mathematics. Students must internalize these definitions, concepts, and their interrelations with utmost clarity. The rigor applied here will pay dividends in their journey through advanced mathematical topics. The ability to precisely define, identify properties, and apply these concepts is non-negotiable for success in board examinations and beyond.

Step-by-Step Derivations

1. Derivation of Electric Field due to a Point Charge

To find the electric field at a point P due to a point charge $q$ located at the origin.

Let a source charge $q$ be placed at the origin. We want to find the electric field $\vec{E}$ at a point P located at a distance $r$ from the origin. According to Coulomb's Law, if we place a small positive test charge $q_0$ at point P, the electrostatic force $\vec{F}$ exerted by $q$ on $q_0$ is given by:

$$ \vec{F} = \frac{1}{4\pi\epsilon_0} \frac{q q_0}{r^2} \hat{r} $$

where $\hat{r}$ is the unit vector pointing from $q$ to $q_0$.

The electric field $\vec{E}$ at point P is defined as the force per unit test charge:

$$ \vec{E} = \frac{\vec{F}}{q_0} $$

Substituting the expression for $\vec{F}$:

$$ \vec{E} = \frac{1}{q_0} \left( \frac{1}{4\pi\epsilon_0} \frac{q q_0}{r^2} \hat{r} \right) $$

The test charge $q_0$ cancels out:

$$ \vec{E} = \frac{1}{4\pi\epsilon_0} \frac{q}{r^2} \hat{r} $$

In terms of magnitude, the electric field is:

$$ E = \frac{1}{4\pi\epsilon_0} \frac{|q|}{r^2} $$

The direction of $\vec{E}$ is radially outward if $q$ is positive and radially inward if $q$ is negative.

2. Derivation of Electric Field on the Axial Line of an Electric Dipole

Consider an electric dipole consisting of two point charges, $-q$ and $+q$, separated by a small distance $2a$. Let the center of the dipole be at the origin. The charge $-q$ is at $(-a, 0)$ and $+q$ is at $(a, 0)$ along the x-axis. We want to find the electric field at a point P on the axial line (x-axis) at a distance $r$ from the center of the dipole.

The electric field at P due to the charge $+q$ (located at $x=+a$) is $\vec{E}_{+q}$. The distance from $+q$ to P is $(r-a)$. Since P is on the right of $+q$, $\vec{E}_{+q}$ points along the positive x-axis.

$$ E_{+q} = \frac{1}{4\pi\epsilon_0} \frac{q}{(r-a)^2} $$

The electric field at P due to the charge $-q$ (located at $x=-a$) is $\vec{E}_{-q}$. The distance from $-q$ to P is $(r+a)$. Since P is on the right of $-q$, $\vec{E}_{-q}$ points along the negative x-axis (towards $-q$).

$$ E_{-q} = \frac{1}{4\pi\epsilon_0} \frac{q}{(r+a)^2} $$

The net electric field $\vec{E}_{axial}$ at point P is the vector sum of $\vec{E}_{+q}$ and $\vec{E}_{-q}$. Since they are along the same line but in opposite directions, we can subtract their magnitudes (assuming positive x-direction as positive):

$$ E_{axial} = E_{+q} - E_{-q} $$ $$ E_{axial} = \frac{q}{4\pi\epsilon_0} \left[ \frac{1}{(r-a)^2} - \frac{1}{(r+a)^2} \right] $$

Combine the terms in the bracket:

$$ E_{axial} = \frac{q}{4\pi\epsilon_0} \left[ \frac{(r+a)^2 - (r-a)^2}{(r-a)^2 (r+a)^2} \right] $$ $$ E_{axial} = \frac{q}{4\pi\epsilon_0} \left[ \frac{(r^2+a^2+2ra) - (r^2+a^2-2ra)}{((r-a)(r+a))^2} \right] $$ $$ E_{axial} = \frac{q}{4\pi\epsilon_0} \left[ \frac{r^2+a^2+2ra - r^2-a^2+2ra}{(r^2-a^2)^2} \right] $$ $$ E_{axial} = \frac{q}{4\pi\epsilon_0} \left[ \frac{4ra}{(r^2-a^2)^2} \right] $$

Rearrange the terms to introduce the electric dipole moment $p = q \cdot (2a)$:

$$ E_{axial} = \frac{1}{4\pi\epsilon_0} \frac{2 \cdot (2aq) \cdot r}{(r^2-a^2)^2} $$ $$ E_{axial} = \frac{1}{4\pi\epsilon_0} \frac{2pr}{(r^2-a^2)^2} $$

For an ideal or short dipole, where the distance $r$ is much larger than the half-length of the dipole $a$ ($r \gg a$), we can neglect $a^2$ in the denominator:

$$ r^2-a^2 \approx r^2 $$

So, the expression simplifies to:

$$ E_{axial} \approx \frac{1}{4\pi\epsilon_0} \frac{2pr}{(r^2)^2} = \frac{1}{4\pi\epsilon_0} \frac{2pr}{r^4} $$ $$ E_{axial} = \frac{1}{4\pi\epsilon_0} \frac{2p}{r^3} $$

The direction of the electric field on the axial line is along the direction of the dipole moment $\vec{p}$ (from $-q$ to $+q$).

3. Derivation of Electric Field due to an Infinitely Long Straight Uniformly Charged Wire using Gauss's Law

Consider an infinitely long, thin, straight wire with a uniform linear charge density $\lambda$ (charge per unit length). We want to find the electric field at a distance $r$ from the wire.

  1. Symmetry: Due to the cylindrical symmetry of the wire, the electric field $\vec{E}$ must be radial (perpendicular to the wire) and its magnitude must be the same at all points equidistant from the wire.
  2. Gaussian Surface: To apply Gauss's Law, we choose a cylindrical Gaussian surface of radius $r$ (the distance at which we want to find $\vec{E}$) and length $L$, coaxial with the wire.
  3. Electric Flux Calculation: The Gaussian cylinder has three surfaces: two flat circular end caps and one curved cylindrical surface.
    • For the end caps: The electric field $\vec{E}$ is radial (perpendicular to the wire), while the area vector $d\vec{A}$ for the end caps is parallel to the wire. Thus, $\vec{E} \cdot d\vec{A} = E dA \cos(90^\circ) = 0$. The flux through the end caps is zero.
    • For the curved cylindrical surface: The electric field $\vec{E}$ is everywhere perpendicular to the wire, which means it is parallel to the area vector $d\vec{A}$ of any small element on the curved surface. So, $\vec{E} \cdot d\vec{A} = E dA \cos(0^\circ) = E dA$. Since $E$ is constant over the curved surface (by symmetry), the total flux through the curved surface is: $$ \Phi_E = \int E dA = E \int dA = E (2\pi r L) $$ where $2\pi r L$ is the area of the curved surface of the cylinder.
    The total electric flux through the entire Gaussian surface is: $$ \Phi_E = 0 + 0 + E(2\pi r L) = E(2\pi r L) $$
  4. Charge Enclosed: The charge enclosed by the Gaussian cylinder of length $L$ is given by the linear charge density $\lambda$ multiplied by the length $L$: $$ Q_{enclosed} = \lambda L $$
  5. Applying Gauss's Law: According to Gauss's Law, the total electric flux through a closed surface is equal to the total charge enclosed divided by the permittivity of free space ($\epsilon_0$): $$ \Phi_E = \frac{Q_{enclosed}}{\epsilon_0} $$ Substitute the expressions for $\Phi_E$ and $Q_{enclosed}$: $$ E(2\pi r L) = \frac{\lambda L}{\epsilon_0} $$ Cancel out $L$ from both sides: $$ E(2\pi r) = \frac{\lambda}{\epsilon_0} $$ Finally, solve for $E$: $$ E = \frac{\lambda}{2\pi\epsilon_0 r} $$

The direction of the electric field is radially outward for a positively charged wire and radially inward for a negatively charged wire.
