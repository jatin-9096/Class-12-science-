1. Complete Conceptual Framework & Definitions

Fundamental Theoretical Principles

Mathematics, at its core, is the language of patterns and relationships. As we delve into Class 12 Mathematics, Chapter 1, 'Relations and Functions', we embark on a journey that lays the foundational bedrock for numerous advanced concepts, including Calculus, Abstract Algebra, and Discrete Mathematics. This chapter serves as a critical bridge, extending the foundational understanding of sets from Class 11 and rigorously defining the intricate ways in which elements within or between sets can be connected. A profound grasp of these principles is not merely for examination success but is indispensable for developing a coherent mathematical thought process and for modeling complex phenomena in science, engineering, economics, and computer science. Our exploration begins with a revisit to the concept of **Cartesian Products**, which provides the universal framework for establishing any relationship between two sets. Recall that for any two non-empty sets A and B, the Cartesian product A × B is defined as the set of all possible ordered pairs (a, b) where 'a' is an element of A and 'b' is an element of B. Symbolically, A × B = {(a, b) : a ∈ A, b ∈ B}. This ordered pairing is crucial because it introduces directionality and distinguishes between (a, b) and (b, a) unless a = b. For instance, if A = {1, 2} and B = {x, y}, then A × B = {(1, x), (1, y), (2, x), (2, y)}. The cardinality of A × B is |A| × |B|. This fundamental concept underpins the very definition of a relation.

1.1. Relations: The Interconnections of Elements

A **Relation** is formally defined as any subset of the Cartesian product of two sets. If R is a relation from set A to set B, then R ⊆ A × B. If (a, b) ∈ R, we say that 'a' is related to 'b', often denoted as a R b. The set A is called the **domain** of the relation, and the set B is called the **codomain** of the relation. The set of all second elements of the ordered pairs in R is called the **range** of the relation. The range is always a subset of the codomain. For example, let A = {1, 2, 3} and B = {2, 4, 6}. Consider the relation R from A to B defined as "is half of". Then R = {(1, 2), (2, 4), (3, 6)}. Here, Domain = A = {1, 2, 3}. Codomain = B = {2, 4, 6}. Range = {2, 4, 6}. Note that the range happens to be equal to the codomain in this specific example, but this is not always the case.

1.1.1. Types of Relations on a Set

When a relation R is defined from a set A to itself (i.e., R ⊆ A × A), it's called a relation 'on A'. Such relations are particularly significant and form the basis for classifying elements within a single set. **Core Law 1: Reflexivity** A relation R on a set A is said to be **Reflexive** if every element of A is related to itself. **Condition:** For all a ∈ A, (a, a) ∈ R. **Example:** Let A = {1, 2, 3}. R = {(1, 1), (2, 2), (3, 3), (1, 2)}. This relation is reflexive because (1,1), (2,2), and (3,3) are present. **Counter-example:** R' = {(1, 1), (2, 2), (1, 2)} on A = {1, 2, 3}. This is not reflexive because (3, 3) ∉ R'. **Real-world analogy:** "Is equal to" on a set of numbers (x = x). "Is a sibling of" is NOT reflexive (you are not your own sibling). **Core Law 2: Symmetry** A relation R on a set A is said to be **Symmetric** if whenever an element 'a' is related to an element 'b', then 'b' is also related to 'a'. **Condition:** For all a, b ∈ A, if (a, b) ∈ R, then (b, a) ∈ R. **Example:** Let A = {1, 2, 3}. R = {(1, 2), (2, 1), (1, 1)}. This is symmetric because for (1, 2) there is (2, 1), and (1, 1) is its own symmetric pair. **Counter-example:** R' = {(1, 2), (2, 3)} on A = {1, 2, 3}. This is not symmetric because (1, 2) ∈ R' but (2, 1) ∉ R'. **Real-world analogy:** "Is a sibling of" (if A is a sibling of B, then B is a sibling of A). "Is friends with" (often symmetric). "Is taller than" is NOT symmetric. **Core Law 3: Transitivity** A relation R on a set A is said to be **Transitive** if whenever an element 'a' is related to 'b' and 'b' is related to 'c', then 'a' is also related to 'c'. **Condition:** For all a, b, c ∈ A, if (a, b) ∈ R and (b, c) ∈ R, then (a, c) ∈ R. **Example:** Let A = {1, 2, 3}. R = {(1, 2), (2, 3), (1, 3), (1, 1)}. This is transitive. For (1, 2) and (2, 3), we have (1, 3) ∈ R. The reflexive pair (1,1) does not violate transitivity. **Counter-example:** R' = {(1, 2), (2, 3)} on A = {1, 2, 3}. This is not transitive because (1, 2) ∈ R' and (2, 3) ∈ R', but (1, 3) ∉ R'. **Real-world analogy:** "Is a descendant of" (if A is a descendant of B, and B is a descendant of C, then A is a descendant of C). "Is less than" on numbers (if a < b and b < c, then a < c). "Is friends with" is NOT necessarily transitive (A is friends with B, B is friends with C, but A might not be friends with C). **Other Important Types of Relations:** * **Empty Relation (or Void Relation):** A relation R on set A is empty if no element of A is related to any element of A. R = ∅ ⊂ A × A. **Example:** R = {(a, b) ∈ A × A : a + b = 100, where A = {1, 2, 3}}. This is an empty relation if no two elements sum to 100. * **Universal Relation:** A relation R on set A is universal if every element of A is related to every element of A. R = A × A. **Example:** R = {(a, b) ∈ A × A : a + b > 0, where A = {1, 2, 3}}. This would be a universal relation if all sums are positive.

1.1.2. Equivalence Relations and Equivalence Classes

A relation R on a set A is called an **Equivalence Relation** if it is simultaneously reflexive, symmetric, and transitive. Equivalence relations are profoundly important as they partition a set into disjoint subsets, where all elements within a subset are considered "equivalent" to each other with respect to the given relation. **Example:** Let L be the set of all lines in a plane. Consider the relation R on L defined as l₁ R l₂ if l₁ is parallel to l₂. 1. **Reflexive:** Every line is parallel to itself (l || l). So, (l, l) ∈ R for all l ∈ L. 2. **Symmetric:** If l₁ is parallel to l₂, then l₂ is parallel to l₁ (l₁ || l₂ ⇒ l₂ || l₁). So, if (l₁, l₂) ∈ R, then (l₂, l₁) ∈ R. 3. **Transitive:** If l₁ is parallel to l₂ and l₂ is parallel to l₃, then l₁ is parallel to l₃ (l₁ || l₂ and l₂ || l₃ ⇒ l₁ || l₃). So, if (l₁, l₂) ∈ R and (l₂, l₃) ∈ R, then (l₁, l₃) ∈ R. Since R is reflexive, symmetric, and transitive, it is an equivalence relation. The concept of an **Equivalence Class** emerges directly from an equivalence relation. For an equivalence relation R on a set A, the equivalence class of an element a ∈ A, denoted by [a] or {a}R, is the set of all elements in A that are related to 'a'. **Definition:** [a] = {x ∈ A : (x, a) ∈ R}. **Properties of Equivalence Classes:** 1. Every element 'a' belongs to its own equivalence class, i.e., a ∈ [a]. This follows from reflexivity. 2. For any two elements a, b ∈ A, their equivalence classes [a] and [b] are either identical or disjoint. That is, [a] = [b] if (a, b) ∈ R, and [a] ∩ [b] = ∅ if (a, b) ∉ R. 3. The union of all distinct equivalence classes is the entire set A. These properties demonstrate that an equivalence relation **partitions** the set A into disjoint subsets, each of which is an equivalence class. This partitioning is a fundamental concept in abstract algebra and discrete mathematics. **Example (continued):** For the relation "is parallel to" on the set of lines L, the equivalence class of a line 'l' ([l]) consists of all lines in the plane that are parallel to 'l'. Geometrically, these are all lines having the same slope.

1.2. Functions: Unique and Directed Mappings

While every function is a relation, not every relation is a function. A **Function** is a special type of relation that satisfies two crucial conditions for every element in its domain: 1. Every element in the domain must be related to some element in the codomain. 2. Each element in the domain must be related to *exactly one* element in the codomain. Formally, a function f from a set A to a set B (denoted f: A → B) is a relation from A to B such that: 1. For every x ∈ A, there exists some y ∈ B such that (x, y) ∈ f. 2. If (x, y₁) ∈ f and (x, y₂) ∈ f, then y₁ = y₂. The element y is called the image of x under f, denoted by f(x). The set A is the **domain** of f, B is the **codomain** of f, and the set of all images of elements of A under f is the **range** of f, denoted by R_f = {f(x) : x ∈ A}. The range is always a subset of the codomain. **Graphical Interpretation of Functions (for Real-valued Functions):** For functions where both domain and codomain are subsets of real numbers (f: R → R), the concept of a vertical line test is invaluable. A graph represents a function if and only if no vertical line intersects the graph at more than one point. This visually enforces the "exactly one output for each input" condition.

1.2.1. Types of Functions (Based on Mapping Properties)

The classification of functions is crucial for understanding their behavior and for operations like finding inverses. **Core Law 4: Injectivity (One-to-One Function)** A function f: A → B is said to be **Injective** or **One-to-One** if distinct elements in the domain A have distinct images in the codomain B. **Condition:** For all x₁, x₂ ∈ A, if f(x₁) = f(x₂), then x₁ = x₂. Equivalently, if x₁ ≠ x₂, then f(x₁) ≠ f(x₂). **Example:** f: N → N defined by f(x) = x + 2. Assume f(x₁) = f(x₂). Then x₁ + 2 = x₂ + 2, which implies x₁ = x₂. Thus, f is injective. **Counter-example:** f: R → R defined by f(x) = x². f(2) = 4 and f(-2) = 4. Here, 2 ≠ -2 but f(2) = f(-2). So, f is not injective. **Graphical Test (Horizontal Line Test):** A function is injective if and only if no horizontal line intersects its graph at more than one point. **Core Law 5: Surjectivity (Onto Function)** A function f: A → B is said to be **Surjective** or **Onto** if every element in the codomain B is the image of at least one element in the domain A. In other words, the range of f is equal to its codomain (Range(f) = B). **Condition:** For every y ∈ B, there exists at least one x ∈ A such that f(x) = y. **Example:** f: R → R defined by f(x) = 2x - 3. Let y be an arbitrary element in the codomain R. We need to find an x ∈ R such that f(x) = y. 2x - 3 = y ⇒ 2x = y + 3 ⇒ x = (y + 3)/2. Since for every y, we can find a corresponding x in R, f is surjective. **Counter-example:** f: R → R defined by f(x) = x². If we take y = -1 in the codomain R, there is no real number x such that x² = -1. So, the range is [0, ∞), which is a proper subset of the codomain R. Thus, f is not surjective. **Core Law 6: Bijectivity (One-to-One and Onto Function)** A function f: A → B is said to be **Bijective** if it is both injective (one-to-one) and surjective (onto). Bijective functions are exceptionally important because they establish a perfect pairing between the elements of the domain and codomain, implying that an inverse function exists. **Example:** f: R → R defined by f(x) = ax + b, where a ≠ 0. This function is both injective and surjective, hence bijective. **Other Classifications:** * **Into Function:** A function f: A → B is called an 'into' function if it is not surjective, meaning there is at least one element in the codomain B that is not an image of any element in A (Range(f) ⊂ B).

1.2.2. Composition of Functions

The idea of combining functions to create new functions is known as function composition. Let f: A → B and g: B → C be two functions. The **composition of f and g**, denoted as g o f (read as "g circle f" or "g of f"), is a function from A to C defined by: **(g o f)(x) = g(f(x)) for all x ∈ A.** **Condition for Composition:** The composition g o f is defined only if the **range of f is a subset of the domain of g**. In the formal definition above, this condition is implicitly met since the codomain of f is B, which is the domain of g. If the codomain of f is a larger set than the domain of g, then the range of f must still be contained within the domain of g for g o f to be defined. **Properties of Function Composition:** 1. **Associativity:** If f: A → B, g: B → C, and h: C → D are three functions, then (h o g) o f = h o (g o f). 2. **Not Commutative (Generally):** In general, f o g ≠ g o f. Even if both are defined, they usually yield different results. **Example:** Let f(x) = x + 1 and g(x) = x². (f o g)(x) = f(g(x)) = f(x²) = x² + 1. (g o f)(x) = g(f(x)) = g(x + 1) = (x + 1)². Clearly, x² + 1 ≠ (x + 1)². 3. **Identity Function:** If f: A → B is a function, and I_A is the identity function on A (I_A(x) = x for all x ∈ A) and I_B is the identity function on B (I_B(y) = y for all y ∈ B), then f o I_A = f and I_B o f = f.

1.2.3. Inverse of a Function

The concept of an inverse function allows us to "undo" the action of a function. A function f: A → B has an **inverse function** if and only if f is a **bijective function** (i.e., both one-to-one and onto). If f is bijective, its inverse is denoted by f⁻¹: B → A. **Definition:** Let f: A → B be a bijective function. The inverse function f⁻¹: B → A is defined such that for every y ∈ B, f⁻¹(y) = x if and only if f(x) = y. Essentially, if f maps x to y, then f⁻¹ maps y back to x. **Properties of Inverse Functions:** 1. If f is bijective, then f⁻¹ is also bijective. 2. (f⁻¹ o f)(x) = x for all x ∈ A. This means f⁻¹ o f = I_A (the identity function on A). 3. (f o f⁻¹)(y) = y for all y ∈ B. This means f o f⁻¹ = I_B (the identity function on B). 4. The inverse of the inverse is the original function: (f⁻¹)⁻¹ = f. 5. For composite functions, the inverse follows a "reverse order" rule: (g o f)⁻¹ = f⁻¹ o g⁻¹. **Finding the Inverse of a Function (Algebraic Method):** Let y = f(x). 1. Rewrite the equation y = f(x) in terms of x. That is, solve for x in terms of y. This will give you x = f⁻¹(y). 2. Replace y with x to express the inverse function in the standard variable form, i.e., f⁻¹(x). **Example:** Find the inverse of f(x) = 2x + 3. 1. Let y = 2x + 3. 2. Solve for x: y - 3 = 2x ⇒ x = (y - 3) / 2. 3. So, f⁻¹(y) = (y - 3) / 2. Replacing y with x, we get f⁻¹(x) = (x - 3) / 2. (Before finding the inverse, it's crucial to verify that f(x) = 2x + 3 is indeed bijective from R to R. It is, as it's a linear function with non-zero slope). **Graphical Interpretation of Inverse Functions:** The graph of f⁻¹(x) is a reflection of the graph of f(x) across the line y = x. This is because if (a, b) is a point on the graph of f(x) (meaning f(a) = b), then (b, a) is a point on the graph of f⁻¹(x) (meaning f⁻¹(b) = a). Reflecting (a, b) across y = x yields (b, a).

1.3. Binary Operations: Structuring Sets

The final conceptual pillar of Chapter 1 often involves the introduction of **Binary Operations**. A binary operation on a set A is a rule that combines any two elements of A to produce another element of A. Formally, a binary operation * on a non-empty set A is a function from A × A to A. Symbolically, *: A × A → A. We typically denote *(a, b) as a * b. **Core Law 7: Closure** The definition itself implies **closure**: for any a, b ∈ A, the result a * b must also be an element of A. If it's not, then '*' is not a binary operation on A. **Example:** Addition (+) is a binary operation on the set of natural numbers N because for any a, b ∈ N, a + b ∈ N. **Counter-example:** Subtraction (-) is NOT a binary operation on N because, for example, 3 ∈ N and 5 ∈ N, but 3 - 5 = -2 ∉ N. Subtraction IS a binary operation on Z (integers), Q (rationals), R (reals).

1.3.1. Properties of Binary Operations

Binary operations possess several key properties that dictate their behavior and structure algebraic systems. **Core Law 8: Commutativity** A binary operation * on a set A is said to be **Commutative** if the order of the operands does not affect the result. **Condition:** For all a, b ∈ A, a * b = b * a. **Example:** Addition (+) on R is commutative (a + b = b + a). Multiplication (×) on R is commutative (a × b = b × a). **Counter-example:** Subtraction (-) on R is not commutative (a - b ≠ b - a unless a = b). Division (÷) on R is not commutative. Matrix multiplication is generally not commutative. **Core Law 9: Associativity** A binary operation * on a set A is said to be **Associative** if, for three elements, the grouping of operands does not affect the result. **Condition:** For all a, b, c ∈ A, (a * b) * c = a * (b * c). **Example:** Addition (+) on R is associative ((a + b) + c = a + (b + c)). Multiplication (×) on R is associative ((a × b) × c = a × (b × c)). **Counter-example:** Subtraction (-) on R is not associative ((5 - 3) - 1 = 2 - 1 = 1, but 5 - (3 - 1) = 5 - 2 = 3). **Core Law 10: Existence of Identity Element** An element e ∈ A is called an **Identity Element** for a binary operation * on A if, when combined with any element a ∈ A, it leaves 'a' unchanged. **Condition:** For all a ∈ A, a * e = e * a = a. An identity element, if it exists, is unique. **Example:** For addition (+) on R, the identity element is 0 because a + 0 = 0 + a = a. For multiplication (×) on R, the identity element is 1 because a × 1 = 1 × a = a. **Counter-example:** For subtraction (-) on R, there is no identity element. If there were, a - e = a and e - a = a. From a - e = a, e = 0. But from e - a = a, 0 - a = a, which means -a = a, implying a = 0. This doesn't hold for all a. **Core Law 11: Existence of Inverse Element** Let * be a binary operation on A with an identity element 'e'. An element b ∈ A is called the **Inverse** of an element a ∈ A if, when 'a' is combined with 'b', the result is the identity element 'e'. The inverse of 'a' is often denoted as a⁻¹ (if the operation is multiplicative) or -a (if the operation is additive). **Condition:** For all a ∈ A, there exists b ∈ A such that a * b = b * a = e. **Example:** For addition (+) on R, for every a ∈ R, its inverse is -a ∈ R because a + (-a) = (-a) + a = 0 (the identity element). For multiplication (×) on R (excluding 0), for every a ∈ R, a ≠ 0, its inverse is 1/a ∈ R because a × (1/a) = (1/a) × a = 1 (the identity element). **Counter-example:** For multiplication on N (natural numbers), 1 is the identity. The inverse of 2 is 1/2, which is not in N. So, not all elements in N have an inverse under multiplication. Understanding these properties allows mathematicians to categorize sets with binary operations into various algebraic structures (like groups, rings, fields), which are fundamental to higher mathematics.

1.4. Interplay and Applications

The concepts introduced in Chapter 1 are not isolated. Relations provide the general framework, functions specify a deterministic and unique relationship, and binary operations define how elements within a set interact. * **Computer Science:** Data structures like graphs and trees are essentially visual representations of relations. Functions are vital in programming (input-output mapping, algorithm design). Binary operations are fundamental to logic gates, arithmetic operations in CPUs, and cryptography. * **Physics:** Functions describe the motion of objects (position as a function of time), force fields, and wave propagation. Relations can describe causality or dependencies between physical quantities. * **Economics:** Supply-demand curves are functions. Cost and revenue are functions of production. Relations can model trade agreements or market interdependencies. * **Statistics:** Regression models establish functional relationships between variables. Correlation quantifies specific types of relations. In essence, this chapter equips us with the precise language and analytical tools to describe connections, dependencies, and transformations—tools that are foundational for understanding, analyzing, and modeling the world around us with mathematical rigor. The emphasis on rigorous definitions, conditions, and proofs of properties for each type of relation, function, and binary operation is paramount. Mastery of these concepts will unlock the complexities of subsequent chapters, particularly calculus, where functions and their properties are central to understanding change and accumulation.

Exhaustive Formula Table

This table lists key definitions, formulas, and conditions relevant to Chapter 1: Relations and Functions in Class 12 Mathematics.

Variables & Units

  • $A, B, C$: Sets
  • $R$: A relation (e.g., $R \subseteq A \times A$ for a relation on set $A$)
  • $f, g, h$: Functions
  • $x, y, z$: Elements of sets
  • $I_A, I_B$: Identity functions on sets $A, B$
  • $*$: A binary operation
  • SI Units: Not applicable for these pure mathematical concepts.

Formulas & Definitions

  1. Relation ($R$ from $A$ to $B$):

    A subset of the Cartesian product $A \times B$.

    • Domain of $R$ (on $A \times B$): $\{a \in A \mid (a,b) \in R \text{ for some } b \in B\}$
    • Range of $R$ (on $A \times B$): $\{b \in B \mid (a,b) \in R \text{ for some } a \in A\}$
  2. Types of Relations (on a set $A$):
    • Empty Relation ($\emptyset$): $R = \emptyset \subseteq A \times A$.
    • Universal Relation: $R = A \times A$.
    • Reflexive: For every $a \in A$, $(a,a) \in R$.
    • Symmetric: For every $a, b \in A$, if $(a,b) \in R$, then $(b,a) \in R$.
    • Transitive: For every $a, b, c \in A$, if $(a,b) \in R$ and $(b,c) \in R$, then $(a,c) \in R$.
    • Equivalence Relation: A relation that is reflexive, symmetric, and transitive.
    • Equivalence Class of $a$ (denoted $[a]$): For an equivalence relation $R$ on $A$, the set of all elements $b \in A$ such that $(a,b) \in R$. $[a] = \{b \in A \mid (a,b) \in R\}$.
  3. Function ($f: A \to B$):

    A relation from $A$ to $B$ such that every element of $A$ is related to exactly one element of $B$.

    • Domain of $f$: Set $A$.
    • Codomain of $f$: Set $B$.
    • Range of $f$: $\{f(x) \mid x \in A\}$. (The range is a subset of the codomain: Range $f \subseteq B$).
  4. Types of Functions:
    • One-to-One (Injective): A function $f: A \to B$ is injective if $f(x_1) = f(x_2) \implies x_1 = x_2$ for all $x_1, x_2 \in A$.
    • Onto (Surjective): A function $f: A \to B$ is surjective if for every $y \in B$, there exists at least one $x \in A$ such that $f(x) = y$. (This means the Range of $f$ = Codomain $B$).
    • Bijective (One-to-One and Onto): A function that is both injective and surjective.
  5. Composition of Functions:
    • Given $f: A \to B$ and $g: B \to C$, the composite function $g \circ f: A \to C$ is defined as: $$(g \circ f)(x) = g(f(x)) \quad \text{for all } x \in A$$
    • Condition: The codomain of the first function ($f$) must be the same as the domain of the second function ($g$) for $g \circ f$ to be defined.
    • Property: Composition of functions is associative: $h \circ (g \circ f) = (h \circ g) \circ f$.
  6. Inverse of a Function:
    • A function $f: A \to B$ is invertible if and only if it is bijective.
    • If $f$ is invertible, its inverse function $f^{-1}: B \to A$ satisfies:
      • $(f^{-1} \circ f)(x) = x$ for all $x \in A$ (i.e., $f^{-1} \circ f = I_A$, the identity function on $A$)
      • $(f \circ f^{-1})(y) = y$ for all $y \in B$ (i.e., $f \circ f^{-1} = I_B$, the identity function on $B$)
    • Key Property: $(g \circ f)^{-1} = f^{-1} \circ g^{-1}$ (where $f$ and $g$ are bijective).
  7. Binary Operations ($*: A \times A \to A$):
    • A binary operation $*$ on a set $A$ is a function that maps each ordered pair $(a,b)$ of elements of $A$ to a unique element $a*b \in A$.
    • Commutative: An operation $*$ is commutative if $a * b = b * a$ for all $a, b \in A$.
    • Associative: An operation $*$ is associative if $(a * b) * c = a * (b * c)$ for all $a, b, c \in A$.
    • Identity Element ($e$): An element $e \in A$ is an identity element for $*$ if $a * e = e * a = a$ for all $a \in A$.
    • Inverse Element ($b$ for $a$): Given an identity element $e$, an element $b \in A$ is the inverse of $a \in A$ if $a * b = b * a = e$. The inverse of $a$ is often denoted by $a^{-1}$.

Step-by-Step Derivations

1. Proof of the inverse of a composite function: $(g \circ f)^{-1} = f^{-1} \circ g^{-1}$

This derivation proves a fundamental property of inverse functions for composite mappings.

Given:
Let $f: A \to B$ and $g: B \to C$ be two bijective functions. Since $f$ and $g$ are bijective, their inverses $f^{-1}: B \to A$ and $g^{-1}: C \to B$ exist. The composite function $g \circ f: A \to C$ is also bijective (a standard result, implying its invertibility). Thus, $(g \circ f)^{-1}: C \to A$ exists.

To Prove: $(g \circ f)^{-1} = f^{-1} \circ g^{-1}$

Proof:
To prove that two functions are equal, we must show they have the same domain, codomain, and map every element in their domain to the same element in their codomain. Both $(g \circ f)^{-1}$ and $(f^{-1} \circ g^{-1})$ have domain $C$ and codomain $A$. We need to show that for any arbitrary element $z \in C$, they produce the same output.

Let $z \in C$. We want to find $(g \circ f)^{-1}(z)$. Let $(g \circ f)^{-1}(z) = x$. By the definition of an inverse function ($h^{-1}(z) = x \iff h(x) = z$): $$ (g \circ f)(x) = z $$ By the definition of composite function ($ (g \circ f)(x) = g(f(x)) $): $$ g(f(x)) = z $$ Since $g^{-1}$ is the inverse of $g$, we can apply $g^{-1}$ to both sides. Recall that $g^{-1}(g(y)) = y$ for any $y$ in the domain of $g$. Here, $f(x)$ plays the role of $y$: $$ g^{-1}(g(f(x))) = g^{-1}(z) $$ $$ f(x) = g^{-1}(z) $$ Now, since $f^{-1}$ is the inverse of $f$, we can apply $f^{-1}$ to both sides. Recall that $f^{-1}(f(y)) = y$ for any $y$ in the domain of $f$: $$ f^{-1}(f(x)) = f^{-1}(g^{-1}(z)) $$ $$ x = f^{-1}(g^{-1}(z)) $$ By the definition of composition of functions ($ (h \circ k)(a) = h(k(a)) $), we can write $f^{-1}(g^{-1}(z))$ as $(f^{-1} \circ g^{-1})(z)$: $$ x = (f^{-1} \circ g^{-1})(z) $$ Since we initially defined $x = (g \circ f)^{-1}(z)$, we have successfully shown that: $$ (g \circ f)^{-1}(z) = (f^{-1} \circ g^{-1})(z) $$ As this holds for any arbitrary $z \in C$, and both functions have the same domain and codomain, we conclude that the functions themselves are equal: $$ (g \circ f)^{-1} = f^{-1} \circ g^{-1} $$ Hence Proved.

2. Derivation: Methodology for Proving a Relation is an Equivalence Relation

Concept: A relation $R$ on a non-empty set $A$ is an equivalence relation if it simultaneously satisfies three properties: reflexivity, symmetry, and transitivity.

Methodology Steps:
Let $R$ be a relation defined on a non-empty set $A$. To prove $R$ is an equivalence relation, follow these three steps rigorously:

  • Step 1: Check for Reflexivity

    Condition: For every element $a \in A$, the ordered pair $(a,a)$ must be an element of $R$. Mathematically: $ \forall a \in A, (a,a) \in R $

    Proof Strategy:
    Pick an arbitrary element $a$ from the set $A$. Then, demonstrate that $a$ satisfies the condition that defines the relation $R$ with respect to itself. If the defining property of $R$ holds when both components of the ordered pair are $a$, then $R$ is reflexive. Ensure this holds for all elements in $A$.

  • Step 2: Check for Symmetry

    Condition: For every pair of elements $a, b \in A$, if $(a,b) \in R$, then it must imply that $(b,a) \in R$. Mathematically: $ \forall a, b \in A, (a,b) \in R \implies (b,a) \in R $

    Proof Strategy:
    Assume that an arbitrary ordered pair $(a,b)$ is in $R$. This means $a$ and $b$ satisfy the specific defining property of the relation $R$. Based on this assumption, logically show that the property must also hold if the order of $a$ and $b$ is reversed (i.e., $(b,a) \in R$). If this implication holds, then $R$ is symmetric.

  • Step 3: Check for Transitivity

    Condition: For every triplet of elements $a, b, c \in A$, if $(a,b) \in R$ and $(b,c) \in R$, then it must imply that $(a,c) \in R$. Mathematically: $ \forall a, b, c \in A, [(a,b) \in R \text{ and } (b,c) \in R] \implies (a,c) \in R $

    Proof Strategy:
    Assume that two arbitrary pairs, $(a,b) \in R$ and $(b,c) \in R$, exist. This means $a,b$ satisfy the defining property of $R$, and $b,c$ also satisfy it. Using these two assumptions, logically derive and demonstrate that $a$ and $c$ must also satisfy the defining property of $R$ (i.e., $(a,c) \in R$). If this implication holds, then $R$ is transitive.

Conclusion: If and only if all three conditions (reflexive, symmetric, and transitive) are satisfied, then $R$ is classified as an equivalence relation. If any one of these conditions fails, $R$ is not an equivalence relation.

3. Derivation: Methodology for Proving a Function is Injective (One-to-One)

Concept: A function $f: A \to B$ is injective if every distinct element in the domain $A$ maps to a distinct element in the codomain $B$. In simpler terms, no two different elements in the domain have the same image in the codomain.

Mathematical Definition: A function $f$ is injective if for any $x_1, x_2 \in A$, whenever $f(x_1) = f(x_2)$, it must imply that $x_1 = x_2$.

Methodology Steps:
Let $f: A \to B$ be a function defined by $f(x) = \text{expression in } x$. To prove its injectivity, follow these steps:

  • Step 1: Assume $f(x_1) = f(x_2)$

    Select two arbitrary elements, $x_1$ and $x_2$, from the domain $A$. Make the assumption that their images under the function $f$ are equal: $$ f(x_1) = f(x_2) $$

  • Step 2: Algebraically Manipulate the Equation

    Substitute the actual functional expression for $f(x_1)$ and $f(x_2)$ into the assumed equality. Then, perform valid algebraic operations (e.g., addition, subtraction, multiplication, division, squaring, taking roots, etc.) on both sides of the equation to simplify it.

  • Step 3: Show that $x_1 = x_2$

    The primary goal of the algebraic manipulation in Step 2 is to logically deduce that $x_1$ must be equal to $x_2$. If you successfully arrive at the conclusion $x_1 = x_2$, then the function $f$ is injective.

Example Illustration: To prove $f(x) = 2x+3$ is injective for $f: \mathbb{R} \to \mathbb{R}$:

  1. Assume $f(x_1) = f(x_2)$ for $x_1, x_2 \in \mathbb{R}$.
  2. Substitute the function definition: $$ 2x_1 + 3 = 2x_2 + 3 $$
  3. Simplify the equation: $$ 2x_1 = 2x_2 $$ $$ x_1 = x_2 $$

Since $x_1 = x_2$ was obtained from the assumption $f(x_1) = f(x_2)$, the function $f(x) = 2x+3$ is injective.

4. Derivation: Methodology for Proving a Function is Surjective (Onto)

Concept: A function $f: A \to B$ is surjective if every element in the codomain $B$ has at least one pre-image in the domain $A$. In other words, the range of the function is equal to its codomain.

Mathematical Definition: A function $f$ is surjective if for every $y \in B$, there exists at least one $x \in A$ such that $f(x) = y$.

Methodology Steps:
Let $f: A \to B$ be a function defined by $f(x) = \text{expression in } x$. To prove its surjectivity, follow these steps:

  • Step 1: Take an arbitrary element $y$ from the codomain $B$

    Let $y$ be an arbitrary element belonging to the codomain $B$. The goal is to show that we can always find an $x \in A$ that maps to this $y$.

  • Step 2: Set $f(x) = y$ and solve for $x$ in terms of $y$

    Write down the equation $y = f(x)$ using the specific definition of the function $f$. Then, algebraically rearrange this equation to express $x$ as a function of $y$. Let this derived expression be $x_0 = \text{expression in } y$.

  • Step 3: Verify that $x_0$ exists in the domain $A$ for all $y \in B$

    Crucially, check two conditions for the derived expression $x_0$:

    1. Ensure that the expression $x_0$ is mathematically well-defined (e.g., no division by zero, no square roots of negative numbers) for all possible values of $y$ within the given codomain $B$.
    2. Confirm that this $x_0$ falls within the specified domain $A$ of the function.

  • Step 4: Verify that $f(x_0) = y$

    Substitute the expression for $x_0$ (found in Step 2) back into the original function $f(x)$ and confirm that the result is indeed $y$. If $f(x_0) = y$ is true, and the conditions in Step 3 are met, then the function $f$ is surjective.

Example Illustration: To prove $f(x) = 2x+3$ is surjective for $f: \mathbb{R} \to \mathbb{R}$:

  1. Let $y \in \mathbb{R}$ (the codomain) be an arbitrary element.
  2. Set $f(x) = y$ and solve for $x$: $$ 2x + 3 = y $$ $$ 2x = y - 3 $$ $$ x = \frac{y-3}{2} $$
  3. Verify existence in domain: For any $y \in \mathbb{R}$, $x = \frac{y-3}{2}$ is always a real number. Therefore, $x \in \mathbb{R}$ (the domain) exists for every $y \in \mathbb{R}$.
  4. Verify $f(x) = y$: Substitute the expression for $x$ back into $f(x)$: $$ f\left(\frac{y-3}{2}\right) = 2\left(\frac{y-3}{2}\right) + 3 $$ $$ = (y-3) + 3 $$ $$ = y $$

Since for every $y$ in the codomain $\mathbb{R}$, there exists an $x$ in the domain $\mathbb{R}$ such that $f(x)=y$, the function $f(x) = 2x+3$ is surjective.

5. Derivation: Methodology for Finding the Inverse of a Bijective Function

Concept: If a function $f: A \to B$ is bijective (i.e., both one-to-one and onto), then an inverse function, denoted $f^{-1}: B \to A$, exists. The inverse function 'undoes' the action of the original function, meaning $f(f^{-1}(y)) = y$ for all $y \in B$ and $f^{-1}(f(x)) = x$ for all $x \in A$.

Methodology Steps:
Let $f: A \to B$ be a bijective function defined by $f(x) = \text{expression in } x$. (The bijectivity of $f$ must be established or given before attempting to find its inverse).

  • Step 1: Set $y = f(x)$

    Replace the notation $f(x)$ with $y$ in the given functional definition. This helps in conceptualizing the input and output relationship for the inverse function. $$ y = f(x) $$

  • Step 2: Solve the equation for $x$ in terms of $y$

    Algebraically manipulate the equation $y = f(x)$ to isolate $x$ on one side. This means expressing $x$ solely as a function of $y$. The result will be in the form: $$ x = \text{expression in } y $$

  • Step 3: Replace $x$ with $f^{-1}(y)$

    By the definition of an inverse function, if $y = f(x)$, then $x = f^{-1}(y)$. Therefore, the expression for $x$ found in Step 2 is precisely the definition of the inverse function with $y$ as its independent variable: $$ f^{-1}(y) = \text{expression in } y $$

  • Step 4: (Optional but Customary) Replace $y$ with $x$

    It is standard practice to write functions using $x$ as the independent variable. To align with this convention, replace every instance of $y$ with $x$ in the expression for $f^{-1}(y)$ to obtain the inverse function in terms of $x$: $$ f^{-1}(x) = \text{expression in } x $$

  • Step 5: Verify the Inverse (Optional but Highly Recommended)

    To confirm that the derived function is indeed the inverse, perform the composition tests:

    1. Check if $(f \circ f^{-1})(x) = x$.
    2. Check if $(f^{-1} \circ f)(x) = x$.
    If both compositions result in the identity function (i.e., return the input unchanged), then $f^{-1}$ is the correct inverse of $f$.

Example Illustration: To find the inverse of $f(x) = 2x+3$ for $f: \mathbb{R} \to \mathbb{R}$ (which is known to be bijective):

  1. Set $y = f(x)$: $$ y = 2x + 3 $$
  2. Solve for $x$ in terms of $y$: $$ y - 3 = 2x $$ $$ x = \frac{y-3}{2} $$
  3. Replace $x$ with $f^{-1}(y)$: $$ f^{-1}(y) = \frac{y-3}{2} $$
  4. Replace $y$ with $x$: $$ f^{-1}(x) = \frac{x-3}{2} $$
  5. Verification:
    • $(f \circ f^{-1})(x) = f(f^{-1}(x)) = f\left(\frac{x-3}{2}\right) = 2\left(\frac{x-3}{2}\right) + 3 = (x-3) + 3 = x$.
    • $(f^{-1} \circ f)(x) = f^{-1}(f(x)) = f^{-1}(2x+3) = \frac{(2x+3)-3}{2} = \frac{2x}{2} = x$.
    Both compositions yield $x$, confirming that $f^{-1}(x) = \frac{x-3}{2}$ is the correct inverse function.
