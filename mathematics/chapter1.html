1. Complete Conceptual Framework & Definitions

Fundamental Theoretical Principles

**Introduction: The Unifying Language of Mathematics – Relations and Functions** Welcome, aspiring mathematicians, to the foundational chapter of Class 12 Mathematics: Relations and Functions. As a Senior CBSE Board Examiner and Textbook Author, I cannot stress enough the profound significance of this chapter. It is not merely a collection of definitions and procedures; rather, it is the bedrock upon which the edifice of advanced mathematics, particularly calculus, linear algebra, and discrete mathematics, is constructed. The concepts explored here provide a rigorous framework for understanding how quantities interact, how patterns emerge, and how abstract ideas can be precisely modeled. At its heart, mathematics is the study of relationships and patterns. From the simplest arithmetic operations to the most complex differential equations, every mathematical expression or concept fundamentally describes how elements or quantities relate to one another. 'Relations' give us a formal way to describe connections between objects, while 'Functions' represent a very special, deterministic kind of relationship, where each input has exactly one output. This deterministic nature makes functions invaluable tools for modeling phenomena across science, engineering, economics, and even social sciences. Mastering this chapter means acquiring a powerful conceptual toolkit that will unlock deeper insights throughout your mathematical journey. **I. Recapitulation of Foundational Concepts from Class XI: Building Blocks of Abstract Thought** Before delving into the intricacies of Class 12 topics, it is imperative to ensure a firm grasp of the fundamental concepts from Class XI, particularly those pertaining to sets and the Cartesian product. These are the elementary 'particles' of our mathematical universe in this context. **1. Sets:** A **set** is a well-defined collection of distinct objects. These objects are called **elements** or **members** of the set. The term "well-defined" is crucial; it means that given any object, we can definitively determine whether it belongs to the set or not. Sets are typically denoted by capital letters (e.g., A, B, C), and their elements are enclosed in curly braces {}. * **Examples:** * The set of natural numbers, N = {1, 2, 3, ...} * The set of integers, Z = {..., -2, -1, 0, 1, 2, ...} * The set of real numbers, R * A finite set, A = {apple, banana, cherry} * **Key Notations:** * `a ∈ A` means 'a is an element of set A'. * `a ∉ A` means 'a is not an element of set A'. * `∅` or `{}` denotes the **empty set**, which contains no elements. * `A ⊆ B` means 'A is a **subset** of B' (every element of A is also an element of B). * `A ⊂ B` means 'A is a **proper subset** of B' (A is a subset of B, and A ≠ B). **2. Cartesian Product of Sets:** The **Cartesian product** of two non-empty sets A and B, denoted by `A × B` (read as "A cross B"), is the set of all possible ordered pairs `(a, b)` where `a ∈ A` and `b ∈ B`. The term "ordered pair" implies that the order of the elements matters; i.e., `(a, b)` is generally not the same as `(b, a)` unless `a = b`. * **Formal Definition:** `A × B = { (a, b) | a ∈ A and b ∈ B }` * **Example:** If A = {1, 2} and B = {x, y}, then: * `A × B = { (1, x), (1, y), (2, x), (2, y) }` * `B × A = { (x, 1), (x, 2), (y, 1), (y, 2) }` * Observe that `A × B ≠ B × A`. * **Cardinality:** If a set A has `m` elements and a set B has `n` elements, then the Cartesian product `A × B` will have `m × n` ordered pairs. That is, `n(A × B) = n(A) × n(B)`. * **Cartesian Product of a Set with Itself:** For a set A, `A × A = { (a₁, a₂) | a₁, a₂ ∈ A }`. This is particularly important for defining relations 'on' a single set. **3. Relations as Subsets of Cartesian Products:** Having understood sets and their Cartesian product, we can now formally define a **relation**. A **relation** R from a non-empty set A to a non-empty set B is a subset of the Cartesian product `A × B`. * **Formal Definition:** `R ⊆ A × B`. * If `(a, b) ∈ R`, we say that `a` is related to `b`, often denoted as `a R b`. * **Domain of a Relation:** The set of all first elements of the ordered pairs in R. * `Domain(R) = { a | (a, b) ∈ R for some b ∈ B }` * **Codomain of a Relation:** The entire set B. * **Range of a Relation:** The set of all second elements of the ordered pairs in R. * `Range(R) = { b | (a, b) ∈ R for some a ∈ A }` * **Maximum Number of Relations:** If `n(A) = m` and `n(B) = n`, then `n(A × B) = mn`. Since a relation is any subset of `A × B`, the total number of possible relations from A to B is `2^(mn)`. * **Example:** Let A = {1, 2, 3} and B = {2, 4, 6}. * `A × B = { (1,2), (1,4), (1,6), (2,2), (2,4), (2,6), (3,2), (3,4), (3,6) }` * Consider a relation `R` from A to B defined as "is a divisor of". * `R = { (1,2), (1,4), (1,6), (2,2), (2,4), (2,6), (3,6) }` * `Domain(R) = {1, 2, 3}` * `Codomain(R) = {2, 4, 6}` * `Range(R) = {2, 4, 6}` **II. Types of Relations: Classifying Connections** In Class 12, our focus shifts predominantly to relations defined 'on' a single set A, meaning `R ⊆ A × A`. This allows for a deeper exploration of internal structure and properties within a set. The classification of relations based on their intrinsic properties is a cornerstone of abstract algebra and discrete mathematics. **1. Empty Relation (or Void Relation):** A relation R on a set A is called an **empty relation** if no element of A is related to any element of A. In other words, R is the empty set `∅`. * **Formal Definition:** `R = ∅ ⊆ A × A` * **Conditions:** This occurs when the defining property of the relation can never be satisfied by any pair of elements from the set A. * **Example:** Let A = {1, 2, 3, 4}. Let `R` be the relation on A defined as `R = { (a, b) | a, b ∈ A, a - b = 10 }`. * Since the maximum difference between any two elements in A is `4 - 1 = 3`, and the minimum difference is `1 - 4 = -3`, no pair `(a, b)` will satisfy `a - b = 10`. * Thus, `R = ∅`, which is an empty relation. **2. Universal Relation:** A relation R on a set A is called a **universal relation** if every element of A is related to every element of A. In other words, `R = A × A`. * **Formal Definition:** `R = A × A` * **Conditions:** This occurs when the defining property of the relation is universally true for all possible pairs of elements from the set A. * **Example:** Let A = {1, 2, 3}. Let `R` be the relation on A defined as `R = { (a, b) | a, b ∈ A, |a - b| ≥ 0 }`. * Since the absolute difference between any two real numbers (and thus any two integers) is always greater than or equal to 0, this condition is true for all possible pairs in `A × A`. * Thus, `R = { (1,1), (1,2), (1,3), (2,1), (2,2), (2,3), (3,1), (3,2), (3,3) } = A × A`, which is a universal relation. **3. Reflexive Relation:** A relation R on a set A is said to be **reflexive** if every element of A is related to itself. * **Formal Definition:** For every `a ∈ A`, `(a, a) ∈ R`. * **Conditions/Implications:** This means that the "identity pairs" must be present for *all* elements in the domain set. If even one element `x ∈ A` does not have `(x, x) ∈ R`, the relation is not reflexive. * **Examples:** * On the set of real numbers R, `R = { (a, b) | a = b }` (is equal to) is reflexive because `a = a` for all `a ∈ R`. * On the set of lines in a plane, `R = { (l₁, l₂) | l₁ || l₂ }` (is parallel to) is reflexive because every line is parallel to itself. * On the set of triangles, `R = { (T₁, T₂) | T₁ ≅ T₂ }` (is congruent to) is reflexive. * **Non-examples:** * On the set of integers Z, `R = { (a, b) | a < b }` (is less than) is not reflexive because `a < a` is false for any integer `a`. * On the set A = {1, 2, 3}, `R = { (1,1), (2,2), (1,3) }` is not reflexive because `(3,3) ∉ R`. **4. Symmetric Relation:** A relation R on a set A is said to be **symmetric** if, whenever an element `a` is related to an element `b`, then `b` is also related to `a`. * **Formal Definition:** For all `a, b ∈ A`, if `(a, b) ∈ R`, then `(b, a) ∈ R`. * **Conditions/Implications:** This property signifies a two-way connection. If the relation holds in one direction, it must also hold in the reverse direction. * **Examples:** * On the set of real numbers R, `R = { (a, b) | a = b }` is symmetric because if `a = b`, then `b = a`. * On the set of lines in a plane, `R = { (l₁, l₂) | l₁ || l₂ }` is symmetric because if `l₁ || l₂`, then `l₂ || l₁`. * On the set of people, `R = { (P₁, P₂) | P₁ is a sibling of P₂ }` is symmetric (assuming "sibling" implies full or half sibling) because if P₁ is a sibling of P₂, then P₂ is a sibling of P₁. * **Non-examples:** * On the set of integers Z, `R = { (a, b) | a < b }` is not symmetric because if `a < b`, then `b < a` is false. For example, `(2, 5) ∈ R` since `2 < 5`, but `(5, 2) ∉ R` since `5 < 2` is false. * On the set of people, `R = { (P₁, P₂) | P₁ is a child of P₂ }` is not symmetric. If P₁ is a child of P₂, P₂ cannot be a child of P₁. **5. Transitive Relation:** A relation R on a set A is said to be **transitive** if, whenever an element `a` is related to `b`, and `b` is related to `c`, then `a` is also related to `c`. * **Formal Definition:** For all `a, b, c ∈ A`, if `(a, b) ∈ R` and `(b, c) ∈ R`, then `(a, c) ∈ R`. * **Conditions/Implications:** This property describes a "chaining" effect. If a connection exists from A to B, and from B to C, then a direct connection (or an implied connection) must exist from A to C. * **Examples:** * On the set of real numbers R, `R = { (a, b) | a < b }` is transitive because if `a < b` and `b < c`, then `a < c`. * On the set of lines in a plane, `R = { (l₁, l₂) | l₁ || l₂ }` is transitive because if `l₁ || l₂` and `l₂ || l₃`, then `l₁ || l₃`. * On the set of sets, `R = { (S₁, S₂) | S₁ ⊆ S₂ }` (is a subset of) is transitive because if `S₁ ⊆ S₂` and `S₂ ⊆ S₃`, then `S₁ ⊆ S₃`. * **Non-examples:** * On the set of people, `R = { (P₁, P₂) | P₁ is a friend of P₂ }` is generally not transitive. If A is a friend of B, and B is a friend of C, it does not necessarily mean A is a friend of C. * On the set of integers Z, `R = { (a, b) | a + b = 5 }`. * ` (1, 4) ∈ R` (since 1+4=5) * ` (4, 1) ∈ R` (since 4+1=5) * But `(1, 1) ∉ R` (since 1+1 ≠ 5), so it is not transitive. (Here `a=1, b=4, c=1`. If (1,4) in R and (4,1) in R, then (1,1) should be in R for transitivity). **6. Equivalence Relation:** A relation R on a set A is called an **equivalence relation** if it is simultaneously **reflexive, symmetric, and transitive**. * **Significance:** Equivalence relations are profoundly important in mathematics as they partition a set into disjoint subsets, where all elements within a given subset are "equivalent" to each other based on the relation. These subsets are called **equivalence classes**. * **Example 1:** On the set of integers Z, let `R = { (a, b) | a - b is an even integer }`. * **Reflexive:** `a - a = 0`, which is an even integer. So `(a, a) ∈ R` for all `a ∈ Z`. * **Symmetric:** If `(a, b) ∈ R`, then `a - b = 2k` for some integer `k`. Then `b - a = -(a - b) = -2k = 2(-k)`, which is also an even integer. So `(b, a) ∈ R`. * **Transitive:** If `(a, b) ∈ R` and `(b, c) ∈ R`, then `a - b = 2k₁` and `b - c = 2k₂` for integers `k₁, k₂`. * Adding these equations: `(a - b) + (b - c) = 2k₁ + 2k₂` * `a - c = 2(k₁ + k₂)` * Since `k₁ + k₂` is an integer, `a - c` is an even integer. So `(a, c) ∈ R`. * Since R is reflexive, symmetric, and transitive, it is an equivalence relation. * **Example 2:** On the set of lines in a plane, `R = { (l₁, l₂) | l₁ || l₂ }` (is parallel to) is an equivalence relation. * Reflexive: `l₁ || l₁`. * Symmetric: If `l₁ || l₂`, then `l₂ || l₁`. * Transitive: If `l₁ || l₂` and `l₂ || l₃`, then `l₁ || l₃`. **7. Equivalence Classes and Partition of a Set:** If R is an equivalence relation on a set A, then for any element `a ∈ A`, the set of all elements `x ∈ A` such that `x R a` (i.e., `(x, a) ∈ R`) is called the **equivalence class of a**, denoted by `[a]`. * **Formal Definition:** `[a] = { x ∈ A | (x, a) ∈ R }` * **Properties of Equivalence Classes:** 1. Every element `a ∈ A` belongs to some equivalence class (specifically, `a ∈ [a]` due to reflexivity). Thus, the union of all equivalence classes is A. 2. Any two distinct equivalence classes are disjoint. That is, if `[a] ≠ [b]`, then `[a] ∩ [b] = ∅`. 3. `[a] = [b]` if and only if `(a, b) ∈ R`. * These properties imply that an equivalence relation **partitions** the set A into disjoint, non-empty subsets, whose union is A. Each subset is an equivalence class. * **Continuing Example 1 (a - b is even):** * `[0] = { x ∈ Z | x - 0 is even } = { ..., -4, -2, 0, 2, 4, ... }` (the set of even integers) * `[1] = { x ∈ Z | x - 1 is even } = { ..., -3, -1, 1, 3, 5, ... }` (the set of odd integers) * Notice that `[0] = [2] = [-4]`, etc. (all even integers belong to the same class). * Notice that `[1] = [3] = [-1]`, etc. (all odd integers belong to the same class). * The set Z is partitioned into two disjoint equivalence classes: the set of even integers and the set of odd integers. `Z = [0] ∪ [1]` and `[0] ∩ [1] = ∅`. **III. Functions: Deep Dive into Special Relations** As mentioned, functions are special types of relations that are fundamental to virtually all branches of mathematics and its applications. They represent a deterministic mapping from one set to another. **1. Function: A Rigorous Definition:** A relation `f` from a set A to a set B is called a **function** if every element of set A has one and only one image in set B. * **Notation:** `f: A → B` (read as "f is a function from A to B"). * **Domain:** The set A is called the **domain** of the function f. * **Codomain:** The set B is called the **codomain** of the function f. * **Range:** The set of all images of elements of A under f is called the **range** of the function f. * `Range(f) = { f(x) | x ∈ A }`. * Note that `Range(f) ⊆ Codomain(f)`. * **Key Conditions for a Function (from relation R ⊆ A × B to be a function):** 1. **Existence:** Every element in the domain A must be associated with some element in the codomain B. (i.e., for every `x ∈ A`, there exists a `y ∈ B` such that `(x, y) ∈ f`). 2. **Uniqueness:** No element in the domain A can be associated with more than one element in the codomain B. (i.e., if `(x, y₁) ∈ f` and `(x, y₂) ∈ f`, then `y₁ = y₂`). * **Example:** Let A = {1, 2, 3}, B = {a, b, c, d}. * `f = { (1, a), (2, b), (3, c) }` is a function. * Domain = {1, 2, 3} * Codomain = {a, b, c, d} * Range = {a, b, c} * `g = { (1, a), (1, b), (2, c) }` is NOT a function because element '1' from the domain has two images ('a' and 'b'). This violates the uniqueness condition. * `h = { (1, a), (2, b) }` is NOT a function if the domain is specified as A = {1, 2, 3} because element '3' from the domain has no image. This violates the existence condition (every element in A must be mapped). **2. Types of Functions (Class XII Specific): Classifying Mappings** The classification of functions based on how elements of the domain and codomain are mapped is crucial for understanding their properties and applications, particularly for inverse functions. **a. One-to-One Function (Injective Function):** A function `f: A → B` is said to be **one-to-one** (or injective) if distinct elements of A have distinct images in B. * **Formal Definition:** For all `x₁, x₂ ∈ A`, if `f(x₁) = f(x₂)`, then `x₁ = x₂`. (The contrapositive is also useful: if `x₁ ≠ x₂`, then `f(x₁) ≠ f(x₂)`). * **Intuitive Explanation:** No two different elements in the domain map to the same element in the codomain. Each element in the range has a unique preimage in the domain. * **Algebraic Test/Proof Method:** To prove a function is injective, assume `f(x₁) = f(x₂)` and algebraically show that this implies `x₁ = x₂`. To show it's not injective, find two distinct values `x₁ ≠ x₂` such that `f(x₁) = f(x₂)`. * **Graphical Test (Horizontal Line Test):** A function `y = f(x)` is injective if and only if no horizontal line intersects its graph at more than one point. * **Examples:** * `f: R → R` given by `f(x) = 2x + 3`. * Assume `f(x₁) = f(x₂)`. Then `2x₁ + 3 = 2x₂ + 3`, which implies `2x₁ = 2x₂`, and thus `x₁ = x₂`. Hence, f is injective. * Graphically, this is a straight line with a positive slope; any horizontal line intersects it exactly once. * `f: N → N` given by `f(x) = x²`. * Assume `f(x₁) = f(x₂)`. Then `x₁² = x₂²`. Since the domain is N (natural numbers, positive integers), `x₁` and `x₂` must be positive, so `x₁ = x₂`. Hence, f is injective. * **Non-examples:** * `f: R → R` given by `f(x) = x²`. * This is not injective because `f(-2) = 4` and `f(2) = 4`, but `-2 ≠ 2`. * Graphically, a horizontal line (e.g., `y=4`) intersects the parabola `y=x²` at two points. * `f: R → R` given by `f(x) = sin(x)`. * Not injective, e.g., `sin(0) = 0` and `sin(π) = 0`, but `0 ≠ π`. **b. Onto Function (Surjective Function):** A function `f: A → B` is said to be **onto** (or surjective) if every element in the codomain B is the image of at least one element in the domain A. In other words, the range of the function is equal to its codomain (`Range(f) = B`). * **Formal Definition:** For every `y ∈ B`, there exists at least one `x ∈ A` such that `f(x) = y`. * **Intuitive Explanation:** Every element in the codomain "gets hit" by at least one arrow from the domain. There are no "unmapped" elements in the codomain. * **Algebraic Test/Proof Method:** To prove a function is surjective, take an arbitrary `y` from the codomain B and show that you can find an `x` in the domain A such that `f(x) = y`. This usually involves solving `y = f(x)` for `x` in terms of `y` and then verifying if that `x` is in the domain A. To show it's not surjective, find an element `y` in the codomain for which no `x` in the domain maps to it. * **Graphical Interpretation:** If the codomain is R, the graph of the function must extend infinitely in both positive and negative y-directions, covering all possible y-values. If the codomain is a restricted interval (e.g., `[0, ∞)`), the graph must cover exactly that interval on the y-axis. * **Examples:** * `f: R → R` given by `f(x) = 2x + 3`. * Let `y ∈ R` (codomain). We need to find `x ∈ R` (domain) such that `f(x) = y`. * `2x + 3 = y` * `2x = y - 3` * `x = (y - 3) / 2`. Since `y` is a real number, `(y - 3) / 2` is always a real number. So for every `y` in the codomain, there is an `x` in the domain. Hence, f is surjective. * `f: R → [0, ∞)` given by `f(x) = x²`. * Let `y ∈ [0, ∞)` (codomain). We need to find `x ∈ R` (domain) such that `f(x) = y`. * `x² = y` * `x = ±√y`. Since `y ≥ 0`, `√y` is a real number. So `x = ±√y` are real numbers and are in the domain R. Hence, f is surjective for this specific codomain. * **Non-examples:** * `f: R → R` given by `f(x) = x²`. * This is not surjective because the range is `[0, ∞)`, which is a proper subset of the codomain R. For any negative `y` (e.g., `y = -4`), there is no real `x` such that `x² = -4`. * `f: Z → Z` given by `f(x) = 2x`. * This is not surjective because the range is the set of even integers `{..., -4, -2, 0, 2, 4, ...}`, which is a proper subset of the codomain Z. No odd integer in the codomain has a preimage in the domain. **c. Bijective Function (One-to-One and Onto):** A function `f: A → B` is said to be **bijective** if it is both **one-to-one (injective)** and **onto (surjective)**. * **Significance:** Bijective functions establish a perfect one-to-one correspondence between the elements of the domain A and the elements of the codomain B. This means each element in A maps to a unique element in B, and every element in B is mapped from a unique element in A. * **Crucial Implication:** A function is bijective if and only if its **inverse function exists**. * **Example:** * `f: R → R` given by `f(x) = 2x + 3`. As demonstrated above, this function is both injective and surjective, hence it is bijective. * `f: [0, ∞) → [0, ∞)` given by `f(x) = x²`. * Injective for this restricted domain: If `x₁², x₂²` are in `[0, ∞)` and `x₁² = x₂²`, then `x₁ = x₂` since `x₁, x₂ ≥ 0`. * Surjective for this restricted codomain: For any `y ∈ [0, ∞)`, `x = √y` is in `[0, ∞)` and `f(√y) = y`. * Therefore, this function is bijective. **IV. Composition of Functions: Chaining Operations** Often, real-world problems or mathematical models involve applying one function after another. This concept is formalized through the **composition of functions**. **1. Definition of Composite Function:** Let `f: A → B` and `g: C → D` be two functions. The **composition of f and g**, denoted by `g o f` (read as "g composed with f" or "g of f"), is defined as the function `(g o f)(x) = g(f(x))`. * **Condition for Composition:** The function `g o f` is defined only if the **range of f is a subset of the domain of g** (i.e., `Range(f) ⊆ C`). If this condition is not met, `g(f(x))` would be undefined for some `x` where `f(x)` is not in the domain of `g`. * **Domain and Codomain of `g o f`:** If `f: A → B` and `g: B → C` (i.e., `B` is both codomain of `f` and domain of `g`), then `g o f: A → C`. The domain of `g o f` is A, and its codomain is C. * **Example:** Let `f: R → R` be `f(x) = x²` and `g: R → R` be `g(x) = x + 1`. * `(g o f)(x) = g(f(x)) = g(x²) = x² + 1`. * `(f o g)(x) = f(g(x)) = f(x + 1) = (x + 1)² = x² + 2x + 1`. * Notice that `g o f ≠ f o g` in general. **2. Properties of Composition of Functions:** * **Associativity:** Function composition is always associative. If `f: A → B`, `g: B → C`, and `h: C → D`, then `h o (g o f) = (h o g) o f`. * Proof: `[h o (g o f)](x) = h((g o f)(x)) = h(g(f(x)))`. * `[(h o g) o f](x) = (h o g)(f(x)) = h(g(f(x)))`. * Since both yield the same result, `h o (g o f) = (h o g) o f`. * **Non-Commutativity:** As seen in the example above, function composition is generally NOT commutative. `f o g ≠ g o f`. * **Identity Function:** Let `I_A` be the identity function on set A (i.e., `I_A(x) = x` for all `x ∈ A`). If `f: A → B`, then `f o I_A = f` and `I_B o f = f`. The identity function acts as a neutral element for composition. * **Bijectivity of Composite Functions:** * If `f` and `g` are both injective, then `g o f` is injective. * If `f` and `g` are both surjective, then `g o f` is surjective. * Consequently, if `f` and `g` are both bijective, then `g o f` is bijective. **V. Inverse of a Function: Undoing the Mapping** The concept of an inverse function is about reversing the mapping process of a function. It allows us to determine the input that produced a given output. **1. Definition of Inverse Function:** Let `f: A → B` be a function. A function `g: B → A` is said to be the **inverse of f** if: * `g o f = I_A` (where `I_A` is the identity function on set A, `I_A(x) = x`) * `f o g = I_B` (where `I_B` is the identity function on set B, `I_B(y) = y`) The inverse of `f` is usually denoted by `f⁻¹`. **2. Condition for Existence of an Inverse Function:** A function `f: A → B` has an inverse function `f⁻¹: B → A` **if and only if f is a bijective function** (i.e., f is both one-to-one and onto). * **Why Bijectivity is Necessary:** * **One-to-one (Injective):** If f is not injective, two distinct elements `x₁, x₂` in A map to the same `y` in B (`f(x₁) = f(x₂) = y`). Then `f⁻¹(y)` would have to map to both `x₁` and `x₂`, violating the uniqueness condition of a function. * **Onto (Surjective):** If f is not surjective, there exists at least one `y` in B that is not an image of any `x` in A. Then `f⁻¹(y)` would be undefined, violating the existence condition of a function. * This condition is absolute. Without bijectivity, an inverse function cannot be rigorously defined. **3. Finding the Inverse of a Function:** If `f(x)` is a bijective function, its inverse `f⁻¹(x)` can be found using the following steps: 1. Let `y = f(x)`. 2. Swap `x` and `y` in the equation: `x = f(y)`. This reflects the idea that the domain and range are swapped for the inverse. 3. Solve the new equation for `y` in terms of `x`. 4. The resulting expression for `y` is `f⁻¹(x)`. * **Example:** Find the inverse of `f: R → R` given by `f(x) = 2x + 3`. 1. Let `y = 2x + 3`. 2. Swap `x` and `y`: `x = 2y + 3`. 3. Solve for `y`: * `x - 3 = 2y` * `y = (x - 3) / 2` 4. So, `f⁻¹(x) = (x - 3) / 2`. * **Verification:** * `(f o f⁻¹)(x) = f(f⁻¹(x)) = f((x - 3) / 2) = 2((x - 3) / 2) + 3 = (x - 3) + 3 = x`. (Identity on R) * `(f⁻¹ o f)(x) = f⁻¹(f(x)) = f⁻¹(2x + 3) = ((2x + 3) - 3) / 2 = 2x / 2 = x`. (Identity on R) * This confirms `f⁻¹(x) = (x - 3) / 2` is indeed the inverse. **4. Properties of Inverse Functions:** * The inverse of a bijection is unique. * ` (f⁻¹)⁻¹ = f ` * **Reversal Law for Composition:** If `f: A → B` and `g: B → C` are two bijective functions, then `(g o f)⁻¹ = f⁻¹ o g⁻¹`. This is an important property that highlights the order reversal in inverse composition. * **Graphical Representation:** The graph of the inverse function `f⁻¹(x)` is a **reflection of the graph of f(x) about the line `y = x`**. This geometric property provides a powerful visual tool for understanding inverse relationships. * For `f(x) = 2x + 3`, its graph is a straight line. Its inverse `f⁻¹(x) = (x - 3) / 2` is also a straight line. If you plot both, you will see they are symmetric with respect to the line `y=x`. * For `f(x) = x²` defined on `[0, ∞)`, its inverse is `f⁻¹(x) = √x` defined on `[0, ∞)`. The graph of `y=x²` for `x ≥ 0` and `y=√x` for `x ≥ 0` are reflections of each other across `y=x`. **VI. Binary Operations: Building Algebraic Structures** The concept of a binary operation generalizes the familiar arithmetic operations like addition, subtraction, multiplication, and division to abstract sets. It forms the basis for defining algebraic structures such as groups, rings, and fields. **1. Definition of a Binary Operation:** A **binary operation** `*` on a non-empty set A is a function from `A × A` to A. * **Formal Definition:** `*: A × A → A`. * For every ordered pair `(a, b)` of elements in A, `a * b` is a unique element in A. * **Closure Property:** The definition itself implies that the set A is **closed** under the operation `*`. This means that if `a, b ∈ A`, then `a * b` must also be an element of A. If the result `a * b` falls outside the set A, then `*` is not a binary operation on A. * **Examples:** * Addition `+` on the set of integers Z: `+ : Z × Z → Z`. For any `a, b ∈ Z`, `a + b ∈ Z`. This is a binary operation. * Subtraction `-` on the set of natural numbers N: `- : N × N → N`. This is NOT a binary operation because, for example, `1 ∈ N` and `2 ∈ N`, but `1 - 2 = -1`, which is not in N. * Union `∪` on the power set `P(S)` of a set S: `∪ : P(S) × P(S) → P(S)`. If A, B are subsets of S, then `A ∪ B` is also a subset of S. This is a binary operation. **2. Properties of Binary Operations:** For a binary operation `*` on a set A: **a. Commutativity:** A binary operation `*` on a set A is said to be **commutative** if the order of the operands does not affect the result. * **Formal Definition:** For all `a, b ∈ A`, `a * b = b * a`. * **Examples:** * Addition `+` on R: `a + b = b + a`. * Multiplication `×` on R: `a × b = b × a`. * Union `∪` on `P(S)`: `A ∪ B = B ∪ A`. * **Non-examples:** * Subtraction `-` on Z: `a - b ≠ b - a` (e.g., `5 - 3 = 2`, but `3 - 5 = -2`). * Division `÷` on R (excluding 0): `a ÷ b ≠ b ÷ a`. **b. Associativity:** A binary operation `*` on a set A is said to be **associative** if the grouping of the operands does not affect the result when three or more elements are operated upon. * **Formal Definition:** For all `a, b, c ∈ A`, `(a * b) * c = a * (b * c)`. * **Examples:** * Addition `+` on R: `(a + b) + c = a + (b + c)`. * Multiplication `×` on R: `(a × b) × c = a × (b × c)`. * Intersection `∩` on `P(S)`: `(A ∩ B) ∩ C = A ∩ (B ∩ C)`. * **Non-examples:** * Subtraction `-` on Z: `(a - b) - c ≠ a - (b - c)`. * E.g., `(5 - 3) - 1 = 2 - 1 = 1`. * `5 - (3 - 1) = 5 - 2 = 3`. Here `1 ≠ 3`. * Division `÷` on R (excluding 0): `(a ÷ b) ÷ c ≠ a ÷ (b ÷ c)`. **c. Identity Element:** An element `e ∈ A` is called an **identity element** for a binary operation `*` on A if, for every `a ∈ A`, operating `a` with `e` (in either order) leaves `a` unchanged. * **Formal Definition:** There exists `e ∈ A` such that for all `a ∈ A`, `a * e = e * a = a`. * An identity element, if it exists, is unique. * **Examples:** * For addition `+` on R, the identity element is `0` because `a + 0 = 0 + a = a`. * For multiplication `×` on R, the identity element is `1` because `a × 1 = 1 × a = a`. * For union `∪` on `P(S)`, the identity element is `∅` (the empty set) because `A ∪ ∅ = ∅ ∪ A = A`. * **Non-examples:** * Subtraction `-` on Z has no identity element. If `a - e = a`, then `e = 0`. But `e - a = a` would imply `0 - a = a`, so `a = 0`. This is only true for `a=0`, not for all `a`. **d. Inverse Element:** For a given binary operation `*` on a set A with an identity element `e`, an element `a' ∈ A` is called the **inverse of an element a ∈ A** if, when operated with `a`, it yields the identity element `e`. * **Formal Definition:** For an element `a ∈ A`, an inverse `a' ∈ A` exists if `a * a' = a' * a = e`. * The inverse of an element `a` (if it exists) is often denoted by `a⁻¹`. * **Examples:** * For addition `+` on R (identity `e = 0`), the inverse of `a` is `-a` because `a + (-a) = (-a) + a = 0`. * For multiplication `×` on R (identity `e = 1`), the inverse of `a` (for `a ≠ 0`) is `1/a` because `a × (1/a) = (1/a) × a = 1`. Note that 0 does not have a multiplicative inverse. * For an invertible function `f` under composition (identity `I`), the inverse is `f⁻¹`. * **Non-examples:** * For multiplication `×` on Z, the element `2` does not have an inverse in Z because `1/2 ∉ Z`. * For multiplication `×` on N, only `1` has an inverse (itself). **Conclusion: The Enduring Legacy of Relations and Functions** This comprehensive exploration of 'Relations and Functions' equips you with the conceptual depth required not just to excel in your CBSE examinations but, more importantly, to think mathematically. From the fundamental idea of sets and their Cartesian product, we built up the sophisticated machinery of relations, classifying them by properties like reflexivity, symmetry, and transitivity, culminating in the powerful concept of equivalence relations and their ability to partition sets. We then refined relations into functions, introducing the critical distinctions of injectivity, surjectivity, and bijectivity, which are paramount for understanding composite and inverse functions. Finally, we abstracted operations themselves through binary operations, revealing the underlying algebraic structures of various number systems and mathematical constructs. Every theorem in calculus, every solution in linear algebra, and every model in discrete mathematics critically relies on these foundational ideas. As you progress, you will recognize these structures and properties recurring in increasingly complex contexts. Embrace the rigor, appreciate the elegance, and build a strong conceptual foundation here, for it is indeed the gateway to higher mathematics."

2.3. Step-by-Step Derivations

Here we provide detailed proofs for some of the key identities and derivatives of inverse trigonometric functions.

2.3.1. Derivation of $\sin^{-1}x + \cos^{-1}x = \pi/2$

Proof:

  1. Let $y = \sin^{-1}x$.
  2. By the definition of inverse sine, this implies $\sin y = x$.
  3. The principal value branch for $\sin^{-1}x$ is $[-\pi/2, \pi/2]$, so $y \in [-\pi/2, \pi/2]$.
  4. We know the trigonometric identity relating sine and cosine: $\sin \theta = \cos(\pi/2 - \theta)$.
  5. Substituting $y$ for $\theta$, we get $\sin y = \cos(\pi/2 - y)$.
  6. Therefore, from step 2, we have $x = \cos(\pi/2 - y)$.
  7. Now, we need to check the range of $(\pi/2 - y)$ to safely apply $\cos^{-1}$. Since $y \in [-\pi/2, \pi/2]$: $$ -\pi/2 \le y \le \pi/2 $$ Multiplying by $-1$ reverses the inequalities: $$ -\pi/2 \le -y \le \pi/2 $$ Adding $\pi/2$ to all parts: $$ 0 \le \pi/2 - y \le \pi $$
  8. The range $[0, \pi]$ is the principal value branch for $\cos^{-1}x$. Thus, we can apply $\cos^{-1}$ to both sides of $x = \cos(\pi/2 - y)$: $$ \cos^{-1}x = \pi/2 - y $$
  9. Substitute back $y = \sin^{-1}x$: $$ \cos^{-1}x = \pi/2 - \sin^{-1}x $$
  10. Rearranging the terms, we get the desired result: $$ \sin^{-1}x + \cos^{-1}x = \pi/2 $$
  11. Conditions: This identity holds for $x \in [-1, 1]$.

2.3.2. Derivation of $\tan^{-1}x + \tan^{-1}y = \tan^{-1}\left(\frac{x+y}{1-xy}\right)$

Proof:

  1. Let $A = \tan^{-1}x$ and $B = \tan^{-1}y$.
  2. By the definition of inverse tangent, this implies $x = \tan A$ and $y = \tan B$.
  3. The principal value branch for $\tan^{-1}$ is $(-\pi/2, \pi/2)$, so $A \in (-\pi/2, \pi/2)$ and $B \in (-\pi/2, \pi/2)$.
  4. Recall the sum formula for tangent from trigonometry: $$ \tan(A+B) = \frac{\tan A + \tan B}{1 - \tan A \tan B} $$
  5. Substitute $x = \tan A$ and $y = \tan B$ into the identity: $$ \tan(A+B) = \frac{x+y}{1-xy} $$
  6. Now, we need to apply $\tan^{-1}$ to both sides. For this, $A+B$ must lie within the principal value branch of $\tan^{-1}$, i.e., $(-\pi/2, \pi/2)$.
  7. Since $A, B \in (-\pi/2, \pi/2)$, it follows that $A+B \in (-\pi, \pi)$.
  8. Consider the condition $xy < 1$:
    • If $x>0, y>0$ and $xy<1$, then $A \in (0, \pi/2)$ and $B \in (0, \pi/2)$. Since $xy < 1$, $1-xy > 0$. Also, the maximum value of $A+B$ would be just under $\pi/2$ (e.g., if $x=1/\sqrt{3}, y=1/\sqrt{3}$, $A=\pi/6, B=\pi/6 \implies A+B=\pi/3$). This holds for $A+B \in (0, \pi/2)$.
    • If $x<0, y<0$ and $xy<1$, then $A \in (-\pi/2, 0)$ and $B \in (-\pi/2, 0)$. Since $xy < 1$, $1-xy > 0$. The minimum value of $A+B$ would be just above $-\pi/2$. This holds for $A+B \in (-\pi/2, 0)$.
    • If $x$ and $y$ have opposite signs, then $xy < 0$, which automatically satisfies $xy < 1$. In this case, $A+B \in (-\pi/2, \pi/2)$.
  9. Therefore, when $xy < 1$, $A+B$ lies in $(-\pi/2, \pi/2)$, and we can directly apply $\tan^{-1}$: $$ A+B = \tan^{-1}\left(\frac{x+y}{1-xy}\right) $$
  10. Substitute back $A = \tan^{-1}x$ and $B = \tan^{-1}y$: $$ \tan^{-1}x + \tan^{-1}y = \tan^{-1}\left(\frac{x+y}{1-xy}\right) $$
  11. Conditions: This identity primarily holds for $xy < 1$. For cases where $xy > 1$, additional $\pm \pi$ adjustments are needed, as listed in the formula table above.

2.3.3. Derivation of $2\tan^{-1}x = \sin^{-1}\left(\frac{2x}{1+x^2}\right)$

Proof:

  1. Let $y = \tan^{-1}x$.
  2. This implies $x = \tan y$.
  3. The principal value branch for $\tan^{-1}x$ is $(-\pi/2, \pi/2)$, so $y \in (-\pi/2, \pi/2)$.
  4. We know the trigonometric identity for $\sin(2y)$ in terms of $\tan y$: $$ \sin(2y) = \frac{2\tan y}{1+\tan^2 y} $$
  5. Substitute $x = \tan y$ into this identity: $$ \sin(2y) = \frac{2x}{1+x^2} $$
  6. Now, we need to apply $\sin^{-1}$ to both sides. For this, $2y$ must lie within the principal value branch of $\sin^{-1}$, i.e., $[-\pi/2, \pi/2]$.
  7. Since $y \in (-\pi/2, \pi/2)$, multiplying by 2 gives $2y \in (-\pi, \pi)$.
  8. For $\sin^{-1}$ to be directly applicable without range adjustment, we need $2y \in [-\pi/2, \pi/2]$. This corresponds to $y \in [-\pi/4, \pi/4]$.
  9. The condition $y \in [-\pi/4, \pi/4]$ means $\tan y \in [-1, 1]$. Since $x = \tan y$, this implies $x \in [-1, 1]$, or $|x| \le 1$.
  10. Under the condition $|x| \le 1$, we have $2y \in [-\pi/2, \pi/2]$. Thus, we can apply $\sin^{-1}$ to both sides of $\sin(2y) = \frac{2x}{1+x^2}$: $$ 2y = \sin^{-1}\left(\frac{2x}{1+x^2}\right) $$
  11. Substitute back $y = \tan^{-1}x$: $$ 2\tan^{-1}x = \sin^{-1}\left(\frac{2x}{1+x^2}\right) $$
  12. Conditions: This identity holds for $|x| \le 1$. (For $x>1$ or $x<-1$, adjustments by $\pi$ are needed for the equality to hold.)

2.3.4. Derivation of $\frac{d}{dx}(\sin^{-1}x) = \frac{1}{\sqrt{1-x^2}}$

Proof (using Implicit Differentiation):

  1. Let $y = \sin^{-1}x$.
  2. By the definition of inverse sine, we can write $x = \sin y$.
  3. Differentiate both sides of the equation $x = \sin y$ with respect to $x$: $$ \frac{d}{dx}(x) = \frac{d}{dx}(\sin y) $$
  4. The left side is $1$. For the right side, we use the chain rule (since $y$ is a function of $x$): $$ 1 = \cos y \cdot \frac{dy}{dx} $$
  5. Solve for $\frac{dy}{dx}$: $$ \frac{dy}{dx} = \frac{1}{\cos y} $$
  6. We need to express $\cos y$ in terms of $x$. We know the fundamental trigonometric identity $\sin^2 y + \cos^2 y = 1$.
  7. From this, $\cos^2 y = 1 - \sin^2 y$.
  8. Since we established $x = \sin y$, substitute $x$ into the equation: $$ \cos^2 y = 1 - x^2 $$
  9. Taking the square root of both sides: $$ \cos y = \pm\sqrt{1-x^2} $$
  10. Consider the principal value branch of $\sin^{-1}x$, which is $y \in [-\pi/2, \pi/2]$. In this interval, the cosine function, $\cos y$, is always positive (or zero at the endpoints). Therefore, we must choose the positive square root: $$ \cos y = \sqrt{1-x^2} $$
  11. Substitute this expression for $\cos y$ back into the equation for $\frac{dy}{dx}$: $$ \frac{dy}{dx} = \frac{1}{\sqrt{1-x^2}} $$
  12. Conditions: This derivation is valid for $|x| < 1$. The derivative is undefined at $x = \pm 1$ because the denominator becomes zero.

2.3.5. Derivation of $\frac{d}{dx}(\tan^{-1}x) = \frac{1}{1+x^2}$

Proof (using Implicit Differentiation):

  1. Let $y = \tan^{-1}x$.
  2. By the definition of inverse tangent, we can write $x = \tan y$.
  3. Differentiate both sides of the equation $x = \tan y$ with respect to $x$: $$ \frac{d}{dx}(x) = \frac{d}{dx}(\tan y) $$
  4. The left side is $1$. For the right side, we use the chain rule: $$ 1 = \sec^2 y \cdot \frac{dy}{dx} $$
  5. Solve for $\frac{dy}{dx}$: $$ \frac{dy}{dx} = \frac{1}{\sec^2 y} $$
  6. We need to express $\sec^2 y$ in terms of $x$. We know the trigonometric identity $1 + \tan^2 y = \sec^2 y$.
  7. Since we established $x = \tan y$, substitute $x$ into the identity: $$ \sec^2 y = 1 + x^2 $$
  8. Substitute this expression for $\sec^2 y$ back into the equation for $\frac{dy}{dx}$: $$ \frac{dy}{dx} = \frac{1}{1+x^2} $$
  9. Conditions: This derivation is valid for all $x \in \mathbb{R}$, as $1+x^2$ is always positive and non-zero.
