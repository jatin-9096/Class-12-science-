1. Complete Conceptual Framework & Definitions

Fundamental Theoretical Principles

1. Axiomatic Set-Theoretic Foundations & The Cartesian Architecture

The study of advanced relation theory and functional mapping in Class 12 Mathematics represents the structural bedrock upon which modern analysis, abstract algebra, and topology are erected. In senior secondary mathematics, relations and functions cease to be merely computational rules or input-output engines; they are re-conceptualized as well-defined subsets of Cartesian product spaces governed by rigorous predicate logic.

Let $A$ and $B$ be two non-empty sets defined within a universal universe of discourse $\mathcal{U}$. The Cartesian Product of $A$ and $B$, denoted by $A \times B$, is defined as the set of all ordered pairs $(a, b)$ such that the first coordinate is an element of $A$ and the second coordinate is an element of $B$:

$$A \times B = \{(a, b) : a \in A \land b \in B\}$$

The foundational axiom governing ordered pairs states that $(a, b) = (c, d)$ if and only if $a = c$ and $b = d$. This non-negotiable equality condition distinguishes ordered pairs from unordered sets, where $\{a, b\} = \{b, a\}$. Consequently, if $A \neq B$, then $A \times B \neq B \times A$, establishing the non-commutative nature of the Cartesian product operation under set equality. If the cardinalities of the constituent finite sets are $|A| = m$ and $|B| = n$, the fundamental counting principle asserts that the cardinality of their Cartesian product is:

$$|A \times B| = |A| \cdot |B| = m \cdot n$$

The power set $\mathcal{P}(A \times B)$ consists of all possible subsets of $A \times B$. Because any mathematical relation $R$ from $A$ to $B$ is formally defined as an arbitrary subset of the Cartesian product space, every element of $\mathcal{P}(A \times B)$ constitutes a distinct relation:

$$R \subseteq A \times B \iff R \in \mathcal{P}(A \times B)$$

Applying Cantor's power set cardinality theorem, the total number of distinct relations that can be defined from set $A$ to set $B$ is:

$$N_{\text{relations}} = |\mathcal{P}(A \times B)| = 2^{|A \times B|} = 2^{mn}$$

When a relation is defined from a set $A$ into itself, it is termed a homogeneous relation on $A$ (i.e., $R \subseteq A \times A$). For a finite set $A$ with $|A| = n$, the total number of possible relations on $A$ is precisely $2^{n^2}$.

2. Rigorous Taxonomy of Binary Relations on a Set

Let $A$ be an arbitrary non-empty set. A homogeneous binary relation $R$ on $A$ establishes a truth condition over the pairs in $A \times A$. We write $a \, R \, b$ to denote that $(a, b) \in R$, and $a \cancel{R} b$ to denote that $(a, b) \notin R$. A complete analytical breakdown requires examining the extreme relations before proceeding to structural properties.

2.1 Trivial and Extremal Relations

  • The Empty (or Void) Relation ($\emptyset$): The relation containing no ordered pairs whatsoever, $\emptyset \subseteq A \times A$. In set-builder notation: $$R = \{(a, b) \in A \times A : \Phi(a, b) \text{ is identically false } \forall a, b \in A\}$$ The empty relation is trivially symmetric and transitive (due to the principle of vacuous truth), but it fails to be reflexive on any non-empty set $A$.
  • The Universal Relation ($U = A \times A$): The relation containing every ordered pair constructible from $A$. It satisfies: $$\forall a, b \in A, \, (a, b) \in R$$ The universal relation is unconditionally reflexive, symmetric, and transitive, trivially constituting an equivalence relation. Both the empty relation and the universal relation are collectively referred to as trivial relations.
  • The Identity Relation ($I_A$): The relation where an element is related strictly and exclusively to itself: $$I_A = \{(a, b) \in A \times A : a = b\} = \{(a, a) : a \in A\}$$ The identity relation is the minimal equivalence relation on $A$. It must not be conflated with a generic reflexive relation, which permits additional non-diagonal elements.

2.2 Essential Algebraic Properties of Relations

To evaluate relations in Class 12 board examinations, students must master the canonical criteria for reflexivity, symmetry, transitivity, and antisymmetry.

A. Reflexivity

A relation $R$ on a set $A$ is defined as reflexive if and only if every element in $A$ is related to itself. Formally:

$$\forall a \in A, \quad (a, a) \in R$$

Crucial Analytical Distinction: For $R$ to be reflexive, the presence of the diagonal pair $(a, a)$ is mandatory for every element $a \in A$. If there exists even a single element $x \in A$ such that $(x, x) \notin R$, the relation is non-reflexive. Furthermore, while the identity relation $I_A$ allows only pairs of the form $(a, a)$, a reflexive relation $R$ merely requires $I_A \subseteq R$.

Combinatorial Derivation of Reflexive Relations: Consider a set $A$ such that $|A| = n$. The Cartesian product $A \times A$ contains $n^2$ elements, which can be partitioned into:

  1. $n$ diagonal elements of the form $(a_i, a_i)$.
  2. $n^2 - n = n(n - 1)$ non-diagonal elements of the form $(a_i, a_j)$ where $i \neq j$.

For a relation $R$ to be reflexive, all $n$ diagonal elements must be included with probability 1 (there is only $1$ choice for each diagonal element). Conversely, each of the $n(n - 1)$ non-diagonal elements may independently either belong to $R$ or not belong to $R$ ($2$ choices per pair). Hence, the total number of distinct reflexive relations on a set with $n$ elements is:

$$N_{\text{reflexive}} = 1^n \cdot 2^{n(n - 1)} = 2^{n(n - 1)}$$

B. Symmetry

A relation $R$ on a set $A$ is defined as symmetric if and only if the presence of an ordered pair $(a, b)$ in $R$ guarantees the presence of its inverted pair $(b, a)$ in $R$. Formally:

$$\forall a, b \in A, \quad (a, b) \in R \implies (b, a) \in R$$

In terms of inverse relations, if we define the inverse relation $R^{-1} = \{(b, a) : (a, b) \in R\}$, then $R$ is symmetric if and only if $R = R^{-1}$.

Logical Nuance: The symmetric property is an implication (conditional statement: $P \implies Q$). It does not mandate that $(a, b)$ must exist in $R$; it dictates that if $(a, b) \in R$, then $(b, a)$ must also belong to $R$. If $(a, b) \notin R$ and $(b, a) \notin R$, the conditional statement is vacuously true.

Combinatorial Derivation of Symmetric Relations: In $A \times A$, the $n$ diagonal pairs $(a_i, a_i)$ can each be independently included or excluded ($2^n$ configurations). The $n(n - 1)$ non-diagonal elements form $\frac{n(n - 1)}{2}$ symmetric pairs of the form $\{(a_i, a_j), (a_j, a_i)\}$. For each pair, there are 2 choices to preserve symmetry: either both are excluded, or both are included. Thus, the total number of symmetric relations on a set of cardinality $n$ is:

$$N_{\text{symmetric}} = 2^n \cdot 2^{\frac{n(n - 1)}{2}} = 2^{n + \frac{n(n - 1)}{2}} = 2^{\frac{n(n + 1)}{2}}$$

C. Transitivity

A relation $R$ on a set $A$ is defined as transitive if and only if whenever an element $a$ is related to $b$ and $b$ is related to $c$, it implies that $a$ is related to $c$. Formally:

$$\forall a, b, c \in A, \quad \Big( (a, b) \in R \land (b, c) \in R \Big) \implies (a, c) \in R$$

The Principle of Vacuous Transitivity: This is one of the most common scoring traps in CBSE examinations. If a relation contains a pair $(a, b) \in R$, but there exists no pair in $R$ whose first coordinate is $b$ (i.e., there is no $(b, c) \in R$), the hypothesis $((a, b) \in R \land (b, c) \in R)$ is false. By the classical truth table of logical implication ($\text{False} \implies \text{Anything} \equiv \text{True}$), the transitivity condition is satisfied vacuously.

For example, let $A = \{1, 2, 3\}$ and $R = \{(1, 2)\}$. Here, $(1, 2) \in R$, but there is no pair beginning with $2$. Therefore, the antecedent is never triggered, and $R$ is strictly transitive!

D. Antisymmetry

A relation $R$ on a set $A$ is defined as antisymmetric if:

$$\forall a, b \in A, \quad \Big( (a, b) \in R \land (b, a) \in R \Big) \implies a = b$$

Contrapositively, if $a \neq b$, then both $(a, b)$ and $(b, a)$ cannot simultaneously belong to $R$. Note that antisymmetry is not the logical negation of symmetry. A relation can be both symmetric and antisymmetric (e.g., the identity relation $I_A$), or neither symmetric nor antisymmetric.

3. Equivalence Relations, Partitions, and the Anatomy of Equivalence Classes

3.1 Definition of an Equivalence Relation

A binary relation $R$ on a non-empty set $A$ is designated as an Equivalence Relation if and only if it simultaneously satisfies three core criteria:

  1. Reflexivity: $(a, a) \in R, \quad \forall a \in A$.
  2. Symmetry: $(a, b) \in R \implies (b, a) \in R, \quad \forall a, b \in A$.
  3. Transitivity: $\big((a, b) \in R \land (b, c) \in R\big) \implies (a, c) \in R, \quad \forall a, b, c \in A$.

3.2 Canonical Proof: Congruence Modulo $m$

To illustrate the rigorous proof structure expected by examiners, consider the relation of congruence modulo $m$ ($m \in \mathbb{Z}^+$) on the set of integers $\mathbb{Z}$.

Definition: For $a, b \in \mathbb{Z}$, $a \equiv b \pmod m \iff m \mid (a - b)$, which means $(a - b) = km$ for some $k \in \mathbb{Z}$.

  • Reflexivity: Let $a \in \mathbb{Z}$ be arbitrary. Then: $$a - a = 0 = 0 \cdot m$$ Since $0 \in \mathbb{Z}$, $m \mid (a - a)$, and thus $(a, a) \in R$. Hence, $R$ is reflexive.
  • Symmetry: Let $a, b \in \mathbb{Z}$ such that $(a, b) \in R$. By definition: $$a - b = k_1 m \quad \text{for some } k_1 \in \mathbb{Z}$$ Multiplying both sides by $-1$: $$b - a = -(a - b) = -(k_1 m) = (-k_1)m$$ Since $k_1 \in \mathbb{Z}$, it follows that $k_2 = -k_1 \in \mathbb{Z}$. Therefore, $m \mid (b - a)$, which implies $(b, a) \in R$. Thus, $R$ is symmetric.
  • Transitivity: Let $a, b, c \in \mathbb{Z}$ such that $(a, b) \in R$ and $(b, c) \in R$. Then: $$a - b = k_1 m \quad \text{and} \quad b - c = k_2 m \quad (k_1, k_2 \in \mathbb{Z})$$ Summing these algebraic identities: $$(a - b) + (b - c) = k_1 m + k_2 m \implies a - c = (k_1 + k_2)m$$ Since $\mathbb{Z}$ is closed under addition, $k_3 = k_1 + k_2 \in \mathbb{Z}$. Consequently, $m \mid (a - c)$, yielding $(a, c) \in R$. Hence, $R$ is transitive.

Because $R$ is reflexive, symmetric, and transitive, it is an equivalence relation on $\mathbb{Z}$.

3.3 The Fundamental Theorem of Equivalence Relations

The profound significance of equivalence relations in pure mathematics lies in their one-to-one correspondence with set partitions.

Definition of an Equivalence Class: Let $R$ be an equivalence relation on set $A$. For any element $a \in A$, the equivalence class generated by $a$, denoted by $[a]$ or $\text{cl}(a)$, is the set of all elements in $A$ related to $a$ under $R$:

$$[a] = \{x \in A : (x, a) \in R\}$$

Theorem: An equivalence relation $R$ on a set $A$ partitions the set $A$ into pairwise disjoint subsets (equivalence classes) whose union is $A$.

Proof of Fundamental Lemmas:

  1. Lemma 1: $a \in [a]$.
    By reflexivity, $(a, a) \in R$. From the definition of $[a]$, it immediately follows that $a \in [a]$. Hence, no equivalence class is empty.
  2. Lemma 2: If $(a, b) \in R$, then $[a] = [b]$.
    Let $x \in [a] \implies (x, a) \in R$. Since $(a, b) \in R$, by transitivity, $(x, b) \in R \implies x \in [b]$. Hence, $[a] \subseteq [b]$.
    By symmetry, $(a, b) \in R \implies (b, a) \in R$. If $y \in [b] \implies (y, b) \in R$. By transitivity, $(y, a) \in R \implies y \in [a]$. Hence, $[b] \subseteq [a]$.
    By mutual inclusion, $[a] = [b]$.
  3. Lemma 3: Any two equivalence classes are either identical or disjoint.
    Formally: $[a] \cap [b] \neq \emptyset \implies [a] = [b]$.
    Suppose there exists an element $c \in [a] \cap [b]$. Then $c \in [a]$ and $c \in [b]$, which implies $(c, a) \in R$ and $(c, b) \in R$.
    By symmetry, $(a, c) \in R$. By transitivity with $(c, b) \in R$, we deduce $(a, b) \in R$.
    Applying Lemma 2, $(a, b) \in R \implies [a] = [b]$. Thus, two classes cannot partially intersect.
  4. Lemma 4: $\bigcup_{a \in A} [a] = A$.
    Since each $[a] \subseteq A$, the union $\bigcup_{a \in A} [a] \subseteq A$. Conversely, since for every $x \in A$, $x \in [x]$, we have $A \subseteq \bigcup_{a \in A} [a]$. Hence, the equality holds.

The set of all equivalence classes is called the Quotient Set of $A$ by $R$, denoted by:

$$A / R = \{[a] : a \in A\}$$

4. Rigorous Analytical Mapping Theory (Functions)

4.1 Structural Definition of a Function

In axiomatic mathematics, a function $f$ from set $A$ to set $B$ (denoted $f: A \to B$) is not a vague "rule," but a relation $f \subseteq A \times B$ conforming to two foundational axioms:

  1. Existence (Totality): Every element of the domain must possess an assignment. $$\forall x \in A, \quad \exists y \in B \quad \text{such that } (x, y) \in f$$
  2. Uniqueness (Well-Definedness): No element of the domain may possess multiple images. $$(x, y_1) \in f \land (x, y_2) \in f \implies y_1 = y_2$$

We designate $y$ as the unique image of $x$ under $f$, written $f(x) = y$. The set $A$ is the Domain ($\text{dom}(f)$), $B$ is the Codomain ($\text{codom}(f)$), and the actual subset of elements realized in $B$ constitutes the Range:

$$\text{Range}(f) = f(A) = \{f(x) \in B : x \in A\} \subseteq B$$

Total Number of Functions: If $|A| = m$ and $|B| = n$, every element of $A$ has $n$ independent choices in $B$. Thus, the total number of functions is:

$$N_{\text{functions}} = n^m = |B|^{|A|}$$

4.2 Classification of Functions: Injective, Surjective, and Bijective

A. Injective Functions (One-to-One / Injection)

A function $f: A \to B$ is said to be injective (or one-to-one) if distinct domain elements map to distinct codomain elements. Formally:

$$\forall x_1, x_2 \in A, \quad f(x_1) = f(x_2) \implies x_1 = x_2$$

The logically equivalent contrapositive statement is:

$$\forall x_1, x_2 \in A, \quad x_1 \neq x_2 \implies f(x_1) \neq f(x_2)$$

Analytical / Calculus Criteria for Real Functions: Let $f: I \to \mathbb{R}$ be a differentiable function defined over an open interval $I \subseteq \mathbb{R}$.

  • If the first derivative $f'(x) > 0$ strictly for all $x \in I$ (strictly monotonically increasing), or $f'(x) < 0$ strictly for all $x \in I$ (strictly monotonically decreasing), then $f$ is strictly injective on $I$.
  • If $f'(x) = 0$ at isolated critical points, the injectivity may still hold (e.g., $f(x) = x^3$). However, if $f'(x)$ changes sign over $I$, Rolle's Theorem guarantees that there exist $x_1 \neq x_2$ such that $f(x_1) = f(x_2)$, proving the function is many-one.

The Horizontal Line Test: A geometric representation $y = f(x)$ corresponds to an injective function if and only if every horizontal line $y = k$ ($k \in \mathbb{R}$) intersects the graph of $f$ at at most one point.

Counting Injections: If $|A| = m$ and $|B| = n$:

  • If $m > n$, by the Pigeonhole Principle, no injection can exist: $N_{\text{injective}} = 0$.
  • If $m \le n$, the number of injections equals the number of ways to assign $m$ distinct values out of $n$: $$N_{\text{injective}} = P(n, m) = \frac{n!}{(n - m)!}$$
B. Surjective Functions (Onto / Surjection)

A function $f: A \to B$ is said to be surjective (or onto) if every element in the codomain has at least one pre-image in the domain. Formally:

$$\forall y \in B, \quad \exists x \in A \quad \text{such that } f(x) = y$$

Set-theoretically, $f$ is surjective if and only if:

$$\text{Range}(f) = \text{Codomain}(B)$$

If $\text{Range}(f) \subsetneq B$, the function is classified as into.

Counting Surjections: Let $|A| = m$ and $|B| = n$. If $m < n$, no surjection can exist ($N_{\text{surjective}} = 0$). For $m \ge n$, the number of surjective functions is calculated using the Principle of Inclusion-Exclusion (PIE) or Stirling Numbers of the Second Kind $S(m, n)$:

$$N_{\text{surjective}} = \sum_{k=0}^{n} (-1)^{k} \binom{n}{k} (n - k)^m = n! \cdot S(m, n)$$

For the vital special case where $|A| = n$ and $|B| = 2$: $$N_{\text{surjective}} = 2^n - \binom{2}{1}1^n + \binom{2}{2}0^n = 2^n - 2$$

C. Bijective Functions (One-to-One and Onto / Bijection)

A function $f: A \to B$ is bijective if and only if it is simultaneously injective and surjective:

$$f \text{ is bijective} \iff (f \text{ is one-to-one}) \land (f \text{ is onto})$$

Cardinality Invariance: If $A$ and $B$ are finite sets, a bijection between $A$ and $B$ can exist if and only if $|A| = |B| = n$. Under this condition:

$$N_{\text{bijective}} = n!$$

5. Composition of Functions: Algebraic & Analytical Mechanics

5.1 Formal Definition and Existence Criteria

Let $f: A \to B$ and $g: B \to C$ be two mappings. The composite function, denoted by $g \circ f$ (read as "$g$ circle $f$" or "$g$ composed with $f$"), is a mapping from $A$ to $C$ defined by:

$$(g \circ f)(x) = g(f(x)), \quad \forall x \in A$$

Strict Compatibility Criterion: The composition $g \circ f$ is validly defined if and only if the range of the inner function $f$ is a subset of the domain of the outer function $g$:

$$\text{Range}(f) \subseteq \text{Domain}(g)$$

If this condition fails, $(g \circ f)(x)$ is undefined for elements whose images fall outside $\text{dom}(g)$. To resolve this, one must restrict $\text{dom}(f)$ to the set: $$A' = \{x \in A : f(x) \in \text{Domain}(g)\}$$

5.2 Foundational Theorems of Function Composition

Theorem 1 (Associativity): Function composition is associative. If $f: A \to B$, $g: B \to C$, and $h: C \to D$, then:

$$h \circ (g \circ f) = (h \circ g) \circ f$$

Proof: Let $x \in A$. Then: $$\big(h \circ (g \circ f)\big)(x) = h\big((g \circ f)(x)\big) = h\big(g(f(x))\big)$$ Similarly: $$\big((h \circ g) \circ f\big)(x) = (h \circ g)(f(x)) = h\big(g(f(x))\big)$$ Since the domains, codomains, and point-evaluations are identical for all $x \in A$, $h \circ (g \circ f) = (h \circ g) \circ f$.

Theorem 2 (Non-Commutativity): In general, function composition is non-commutative: $$g \circ f \neq f \circ g$$ Even when $A = B = C$, so that both compositions exist on the same domain and codomain, commutativity is an exceptional symmetry rather than the general rule.

Theorem 3 (Preservation of Injectivity and Surjectivity):

  1. If $f: A \to B$ and $g: B \to C$ are both injective, then $g \circ f: A \to C$ is injective.
    Proof: Let $x_1, x_2 \in A$ and assume $(g \circ f)(x_1) = (g \circ f)(x_2)$. $$g(f(x_1)) = g(f(x_2))$$ Because $g$ is injective, $g(u) = g(v) \implies u = v$. Hence: $$f(x_1) = f(x_2)$$ Because $f$ is injective, $f(x_1) = f(x_2) \implies x_1 = x_2$.
    Therefore, $g \circ f$ is injective.
  2. If $f: A \to B$ and $g: B \to C$ are both surjective, then $g \circ f: A \to C$ is surjective.
    Proof: Let $z \in C$ be an arbitrary element. Since $g: B \to C$ is surjective: $$\exists y \in B \quad \text{such that } g(y) = z$$ Since $f: A \to B$ is surjective, for this $y \in B$: $$\exists x \in A \quad \text{such that } f(x) = y$$ Substituting $y$ into the equation for $z$: $$(g \circ f)(x) = g(f(x)) = g(y) = z$$ Since for every $z \in C$, there exists $x \in A$ such that $(g \circ f)(x) = z$, $g \circ f$ is surjective.

Theorem 4 (Deductions from the Composite Function):

  1. If $g \circ f$ is injective, then $f$ must be injective. (Note: $g$ need not be injective).
    Proof: Suppose $f(x_1) = f(x_2)$ for some $x_1, x_2 \in A$. Applying the function $g$: $$g(f(x_1)) = g(f(x_2)) \implies (g \circ f)(x_1) = (g \circ f)(x_2)$$ Since $g \circ f$ is injective, it immediately forces $x_1 = x_2$. Hence, $f$ is injective.
  2. If $g \circ f$ is surjective, then $g$ must be surjective. (Note: $f$ need not be surjective).
    Proof: Let $z \in C$. Since $g \circ f$ is surjective, $\exists x \in A$ such that $(g \circ f)(x) = z$. This means $g(f(x)) = z$. Setting $y = f(x) \in B$, we have found an element $y \in B$ such that $g(y) = z$. Thus, $g$ is surjective.

6. Invertibility Theory and Inverse Mappings

6.1 Axiomatic Definition of Invertibility

A function $f: A \to B$ is defined to be invertible if and only if there exists another mapping $g: B \to A$ such that:

$$g \circ f = I_A \quad \text{and} \quad f \circ g = I_B$$

where $I_A: A \to A$ ($I_A(x) = x$) and $I_B: B \to B$ ($I_B(y) = y$) represent the identity mappings on sets $A$ and $B$, respectively. The function $g$ is denoted by $f^{-1}$.

6.2 The Fundamental Characterization Theorem

Theorem: A function $f: A \to B$ is invertible if and only if $f$ is a bijection.

Proof Part I: (Invertibility $\implies$ Bijectivity)
Suppose $f$ is invertible. Then there exists $g: B \to A$ such that $g \circ f = I_A$ and $f \circ g = I_B$.

  • To prove injectivity: Let $x_1, x_2 \in A$ such that $f(x_1) = f(x_2)$. Applying $g$ to both sides gives $g(f(x_1)) = g(f(x_2)) \implies (g \circ f)(x_1) = (g \circ f)(x_2) \implies I_A(x_1) = I_A(x_2) \implies x_1 = x_2$. Hence, $f$ is injective.
  • To prove surjectivity: Let $y \in B$ be arbitrary. We evaluate $f$ at the element $x = g(y) \in A$: $$f(x) = f(g(y)) = (f \circ g)(y) = I_B(y) = y$$ Thus, for any $y \in B$, there exists an element $x = g(y) \in A$ such that $f(x) = y$. Hence, $f$ is surjective.

Since $f$ is both injective and surjective, it is bijective.

Proof Part II: (Bijectivity $\implies$ Invertibility)
Suppose $f: A \to B$ is bijective.

  • Since $f$ is surjective, for every $y \in B$, the set of pre-images $\{x \in A : f(x) = y\}$ is non-empty.
  • Since $f$ is injective, this pre-image is unique.

We can therefore define a well-formed relation $g: B \to A$ by setting $g(y) = x$, where $x$ is the unique solution to $f(x) = y$.

  • For any $x \in A$, let $y = f(x)$. By definition of $g$, $g(y) = x$. Thus, $(g \circ f)(x) = g(f(x)) = g(y) = x = I_A(x)$. Hence, $g \circ f = I_A$.
  • For any $y \in B$, let $x = g(y)$. By definition, $x$ satisfies $f(x) = y$. Thus, $(f \circ g)(y) = f(g(y)) = f(x) = y = I_B(y)$. Hence, $f \circ g = I_B$.

Thus, $g$ is an inverse for $f$, proving that $f$ is invertible.

6.3 Properties of Inverse Mappings

  1. Uniqueness of the Inverse: If $f$ is invertible, its inverse is unique.
    Proof: Assume $g_1$ and $g_2$ are both inverses of $f$. Then: $$g_1 = g_1 \circ I_B = g_1 \circ (f \circ g_2) = (g_1 \circ f) \circ g_2 = I_A \circ g_2 = g_2$$
  2. Involution Property: $(f^{-1})^{-1} = f$.
  3. The Reversal Law (Shoes and Socks Rule): If $f: A \to B$ and $g: B \to C$ are invertible, then $g \circ f$ is invertible, and: $$(g \circ f)^{-1} = f^{-1} \circ g^{-1}$$ Proof: We compose $(g \circ f)$ with $(f^{-1} \circ g^{-1})$: $$\big((g \circ f) \circ (f^{-1} \circ g^{-1})\big) = g \circ (f \circ f^{-1}) \circ g^{-1} = g \circ I_B \circ g^{-1} = g \circ g^{-1} = I_C$$ Similarly: $$\big((f^{-1} \circ g^{-1}) \circ (g \circ f)\big) = f^{-1} \circ (g^{-1} \circ g) \circ f = f^{-1} \circ I_B \circ f = f^{-1} \circ f = I_A$$ By the uniqueness of the inverse, $(g \circ f)^{-1} = f^{-1} \circ g^{-1}$.

7. Abstract Binary Operations & Algebraic Systems

7.1 Formal Definition of a Binary Operation

A binary operation $*$ on a non-empty set $A$ is defined formally as a function that maps an ordered pair from $A \times A$ to an element of $A$:

$$*: A \times A \to A, \quad \text{where } *(a, b) \text{ is conventionally denoted as } a * b$$

The fact that the codomain of $*$ is $A$ itself ensures that the set $A$ is closed under $*$:

$$\forall a, b \in A, \quad a * b \in A$$

Total Number of Binary Operations: Let $|A| = n$. The domain of $*$ is $A \times A$, which has cardinality $n^2$. The codomain is $A$, which has cardinality $n$. Therefore, the total number of distinct binary operations is:

$$N_{\text{binary operations}} = |A|^{|A \times A|} = n^{n^2}$$

7.2 Core Structural Axioms

  • Commutativity: An operation $*$ on $A$ is commutative if: $$\forall a, b \in A, \quad a * b = b * a$$ Combinatorics: In a Cayley table (operation table) of size $n \times n$, commutativity forces the table to be symmetric across its principal diagonal. The diagonal contains $n$ elements, and there are $\frac{n(n - 1)}{2}$ positions above the diagonal. Total entries to be freely assigned: $$n + \frac{n(n - 1)}{2} = \frac{n(n + 1)}{2}$$ Each independent entry can take $n$ possible values. Hence, the number of commutative binary operations on a set of size $n$ is: $$N_{\text{commutative}} = n^{\frac{n(n + 1)}{2}}$$
  • Associativity: An operation $*$ on $A$ is associative if: $$\forall a, b, c \in A, \quad (a * b) * c = a * (b * c)$$
  • Identity Element: An element $e \in A$ is the identity element with respect to $*$ if: $$\forall a \in A, \quad a * e = e * a = a$$ Uniqueness of Identity: If $e_1$ and $e_2$ are both identity elements, then: $$e_1 * e_2 = e_1 \quad (\text{since } e_2 \text{ is identity})$$ $$e_1 * e_2 = e_2 \quad (\text{since } e_1 \text{ is identity})$$ Therefore, $e_1 = e_2$. The identity element, if it exists, is unique.
  • Invertible Elements: Given an identity element $e \in A$, an element $a \in A$ is invertible if there exists $b \in A$ such that: $$a * b = b * a = e$$ The element $b$ is called the inverse of $a$ and is denoted by $a^{-1}$. Under an associative operation, the inverse of an element is guaranteed to be unique: $$b_1 = b_1 * e = b_1 * (a * b_2) = (b_1 * a) * b_2 = e * b_2 = b_2$$

8. Common CBSE Examination Traps & Rigorous Proof Protocols

CBSE Marking Scheme: Non-Negotiable Requirements

Board examiners deduct marks for informal or incomplete proofs. To secure full marks in Chapter 1:

  • Universal Quantifier Omission: Writing $a - a = 0 = 0 \cdot m$ without stating $\forall a \in A$ loses marks. Mathematical statements are invalid without explicit domain declarations.
  • Counterexamples vs. General Proofs: Disproving a property (e.g., non-symmetry) requires a single concrete numerical counterexample (e.g., "$(1, 2) \in R$ because $1 \le 2^2$, but $(2, 1) \notin R$ because $2 \not\le 1^2$"). Conversely, proving a property requires general algebraic variables ($x, y, z \in A$) and must never be tested merely with sample numbers.
  • Transitivity Fallacy with Shared Indices: Checking transitivity requires verifying $((a, b) \in R \land (b, c) \in R) \implies (a, c) \in R$ when $a \neq c$ as well as when $a = c$. Students often test $(a, b)$ and $(b, a)$ and verify $(a, a) \in R$, but fail to test $(a, b)$ and $(b, c)$ with three distinct elements!
  • Surjectivity Proof Format: To prove a function $f: A \to B$ is onto, students must write:
    1. Let $y \in B$ (an arbitrary element of the codomain).
    2. Set $y = f(x)$ and solve for $x$ in terms of $y$: $x = \psi(y)$.
    3. Crucial Step: Formally verify that $\psi(y) \in A$ for all $y \in B$. If there exists any $y \in B$ for which $\psi(y) \notin A$ (or $\psi(y)$ is undefined, e.g., division by zero), $f$ is NOT surjective.
    4. Confirm that $f(\psi(y)) = y$.
  • Invertibility Justification: Demonstrating bijectivity is sufficient to prove invertibility. However, if the question explicitly asks to find $f^{-1}$ using compositions, students must evaluate both compositions: $$(f^{-1} \circ f)(x) = x = I_A(x) \quad \text{AND} \quad (f \circ f^{-1})(y) = y = I_B(y)$$ Showing only one composite direction yields an automatic deduction of marks.

9. Canonical Board Problem Archetypes (Step-by-Step Proofs)

Archetype 1: Real-Number Order Inequalities

Problem: Show that the relation $R$ in the set $\mathbb{R}$ of real numbers defined as $R = \{(a, b) : a \le b^2\}$ is neither reflexive, nor symmetric, nor transitive.

  • Non-Reflexive: A relation is reflexive if $(a, a) \in R, \, \forall a \in \mathbb{R}$.
    Consider $a = \frac{1}{2} \in \mathbb{R}$.
    We evaluate whether $a \le a^2$: $$\frac{1}{2} \le \left(\frac{1}{2}\right)^2 \iff \frac{1}{2} \le \frac{1}{4} \quad (\text{False})$$ Since $\left(\frac{1}{2}, \frac{1}{2}\right) \notin R$, the relation is not reflexive.
  • Non-Symmetric: A relation is symmetric if $(a, b) \in R \implies (b, a) \in R$.
    Consider $a = 1, b = 2$.
    $(1, 2) \in R$ because $1 \le 2^2 = 4$ (True).
    However, for the reverse pair $(2, 1)$, we check if $2 \le 1^2 = 1$ (False).
    Thus, $(1, 2) \in R$ but $(2, 1) \notin R$. The relation is not symmetric.
  • Non-Transitive: A relation is transitive if $(a, b) \in R \land (b, c) \in R \implies (a, c) \in R$.
    Choose $a = 2$, $b = -2$, and $c = -1$.
    1. Check $(a, b) = (2, -2)$: $2 \le (-2)^2 = 4$ (True, so $(2, -2) \in R$).
    2. Check $(b, c) = (-2, -1)$: $-2 \le (-1)^2 = 1$ (True, so $(-2, -1) \in R$).
    3. Check $(a, c) = (2, -1)$: $2 \le (-1)^2 = 1$ (False, so $(2, -1) \notin R$).
    Because $(2, -2) \in R$ and $(-2, -1) \in R$, yet $(2, -1) \notin R$, $R$ is not transitive.

Archetype 2: The Cartesian Coordinate Product Equivalence

Problem: Let $N \times N$ be the Cartesian product of natural numbers. Define a relation $R$ on $N \times N$ by $((a, b), (c, d)) \in R \iff a + d = b + c$. Prove that $R$ is an equivalence relation, and compute the equivalence class $[(2, 5)]$.

Proof: Here the underlying set is $S = \mathbb{N} \times \mathbb{N}$. Elements of $S$ are ordered pairs $(a, b)$ with $a, b \in \mathbb{N}$.

  • Reflexivity: Let $(a, b) \in \mathbb{N} \times \mathbb{N}$ be arbitrary.
    Since addition in $\mathbb{N}$ is commutative: $$a + b = b + a$$ By the definition of $R$, this immediately implies: $$((a, b), (a, b)) \in R, \quad \forall (a, b) \in \mathbb{N} \times \mathbb{N}$$ Hence, $R$ is reflexive.
  • Symmetry: Let $(a, b), (c, d) \in \mathbb{N} \times \mathbb{N}$ such that $((a, b), (c, d)) \in R$.
    By definition: $$a + d = b + c$$ By the symmetric and commutative properties of equality in $\mathbb{N}$: $$c + b = d + a \iff c + b = a + d \iff c + b = d + a$$ Rearranging to match the required relation format: $$c + b = d + a$$ This implies: $$((c, d), (a, b)) \in R$$ Hence, $R$ is symmetric.
  • Transitivity: Let $(a, b), (c, d), (e, f) \in \mathbb{N} \times \mathbb{N}$ such that: $$((a, b), (c, d)) \in R \implies a + d = b + c \quad \text{--- (Eq. 1)}$$ $$((c, d), (e, f)) \in R \implies c + f = d + e \quad \text{--- (Eq. 2)}$$ Adding both algebraic equations: $$(a + d) + (c + f) = (b + c) + (d + e)$$ Applying the associative and commutative properties of addition: $$(a + f) + (c + d) = (b + e) + (c + d)$$ By the additive cancellation law in $\mathbb{N}$: $$a + f = b + e$$ By definition of $R$, this yields: $$((a, b), (e, f)) \in R$$ Hence, $R$ is transitive.

Since $R$ is reflexive, symmetric, and transitive, it is an equivalence relation.

Determination of Equivalence Class $[(2, 5)]$:

$$[(2, 5)] = \{(x, y) \in \mathbb{N} \times \mathbb{N} : ((x, y), (2, 5)) \in R\}$$

By definition of the relation: $$x + 5 = y + 2 \implies y = x + 3$$ Since $x \in \mathbb{N} = \{1, 2, 3, 4, \dots\}$:

  • For $x = 1 \implies y = 1 + 3 = 4 \implies (1, 4)$
  • For $x = 2 \implies y = 2 + 3 = 5 \implies (2, 5)$
  • For $x = 3 \implies y = 3 + 3 = 6 \implies (3, 6)$
  • For $x = k \implies y = k + 3 \implies (k, k + 3)$

Thus, the complete equivalence class is: $$[(2, 5)] = \{(1, 4), (2, 5), (3, 6), (4, 7), \dots, (k, k + 3), \dots : k \in \mathbb{N}\}$$

Archetype 3: Rational Invertibility and Dynamic Domain Restrictions

Problem: Let $A = \mathbb{R} - \{3\}$ and $B = \mathbb{R} - \{1\}$. Consider the function $f: A \to B$ defined by: $$f(x) = \frac{x - 2}{x - 3}$$ Prove that $f$ is bijective, and obtain a formula for $f^{-1}$.

Step 1: Proof of Injectivity
Let $x_1, x_2 \in A$ such that $f(x_1) = f(x_2)$. $$\frac{x_1 - 2}{x_1 - 3} = \frac{x_2 - 2}{x_2 - 3}$$ Cross-multiplying: $$(x_1 - 2)(x_2 - 3) = (x_2 - 2)(x_1 - 3)$$ Expanding both sides: $$x_1 x_2 - 3x_1 - 2x_2 + 6 = x_1 x_2 - 3x_2 - 2x_1 + 6$$ Subtracting $(x_1 x_2 + 6)$ from both sides: $$-3x_1 - 2x_2 = -3x_2 - 2x_1$$ Rearranging like terms: $$-3x_1 + 2x_1 = -3x_2 + 2x_2 \implies -x_1 = -x_2 \implies x_1 = x_2$$ Since $f(x_1) = f(x_2) \implies x_1 = x_2$ for all $x_1, x_2 \in A$, $f$ is strictly injective (one-to-one).

Step 2: Proof of Surjectivity
Let $y \in B = \mathbb{R} - \{1\}$ be an arbitrary element. We seek an element $x \in A$ such that $f(x) = y$. $$y = \frac{x - 2}{x - 3}$$ Solving for $x$: $$y(x - 3) = x - 2 \implies yx - 3y = x - 2 \implies yx - x = 3y - 2$$ $$x(y - 1) = 3y - 2 \implies x = \frac{3y - 2}{y - 1}$$ Now, we must verify that $x \in A$:

  1. Since $y \in B$, $y \neq 1$, the denominator $(y - 1) \neq 0$. Thus, $x \in \mathbb{R}$ is always defined.
  2. Can $x = 3$? Assume for contradiction that $\frac{3y - 2}{y - 1} = 3$: $$3y - 2 = 3(y - 1) \implies 3y - 2 = 3y - 3 \implies -2 = -3 \quad (\text{Contradiction!})$$ Hence, $x \neq 3$ for any real $y$.

Therefore, for every $y \in B$, there exists $x = \frac{3y - 2}{y - 1} \in A$ such that: $$f(x) = f\left(\frac{3y - 2}{y - 1}\right) = \frac{\frac{3y - 2}{y - 1} - 2}{\frac{3y - 2}{y - 1} - 3} = \frac{(3y - 2) - 2(y - 1)}{(3y - 2) - 3(y - 1)} = \frac{3y - 2 - 2y + 2}{3y - 2 - 3y + 3} = \frac{y}{1} = y$$ This proves that $\text{Range}(f) = B$. Hence, $f$ is surjective (onto).

Conclusion & Inverse Function:
Since $f$ is both injective and surjective, it is bijective, and therefore invertible. The inverse function $f^{-1}: B \to A$ is given by:

$$f^{-1}(y) = \frac{3y - 2}{y - 1} \quad \text{or, expressing with dummy variable } x: \quad f^{-1}(x) = \frac{3x - 2}{x - 1}$$

CBSE Standard Multi-Step Derivations

Derivation 1: Combinatorial Formulas for Relation Classes on a Finite Set

Target Statements: Let $A$ be a set such that $|A| = n$. Prove that:
(i) Number of reflexive relations is $2^{n(n-1)}$.
(ii) Number of symmetric relations is $2^{\frac{n(n+1)}{2}}$.
(iii) Number of reflexive and symmetric relations is $2^{\frac{n(n-1)}{2}}$.

Step 1: Partitioning the Cartesian Product $A \times A$

The total number of ordered pairs in $A \times A$ is $|A \times A| = n^2$. We partition $A \times A$ into two disjoint subsets:

$$D = \{(a_i, a_i) \mid 1 \le i \le n\} \quad \text{(Diagonal elements)}$$ $$N = \{(a_i, a_j) \mid 1 \le i \neq j \le n\} \quad \text{(Non-diagonal elements)}$$ Clearly, $|D| = n$, and $|N| = n^2 - n = n(n-1)$.

Step 2: Proof for Reflexive Relations

A relation $R$ on $A$ is reflexive if and only if $\forall a_i \in A$, $(a_i, a_i) \in R$. Therefore, all $n$ elements of $D$ must be included in $R$. For each pair in $D$, there is only $1$ choice.

For the $n(n-1)$ pairs in $N$, each pair $(a_i, a_j)$ ($i \neq j$) may or may not be included in $R$ (independent choice of $2$ possibilities per pair). By the Fundamental Principle of Multiplication:

$$N_{\text{refl}} = 1^n \times 2^{n(n-1)} = 2^{n(n-1)}$$

Step 3: Proof for Symmetric Relations

A relation $R$ is symmetric if $(a_i, a_j) \in R \implies (a_j, a_i) \in R$.

For diagonal pairs $(a_i, a_i) \in D$: Each pair is its own reverse. There are $n$ such pairs, giving $2^n$ choices.

For non-diagonal pairs: Pairs are grouped into unordered pairs $\{(a_i, a_j), (a_j, a_i)\}$ where $i < j$. The number of such pairs is:

$$\binom{n}{2} = \frac{n(n-1)}{2}$$

For each unordered pair, there are 2 valid symmetric choices: either both $(a_i, a_j)$ and $(a_j, a_i)$ are in $R$, or neither is in $R$. Thus:

$$N_{\text{sym}} = 2^n \times 2^{\frac{n(n-1)}{2}} = 2^{n + \frac{n(n-1)}{2}} = 2^{\frac{2n + n^2 - n}{2}} = 2^{\frac{n(n+1)}{2}}$$

Step 4: Proof for Reflexive and Symmetric Relations

If $R$ is both reflexive and symmetric, all $n$ diagonal pairs must belong to $R$ (only $1$ choice each). The remaining $\frac{n(n-1)}{2}$ symmetric pairs in $N$ each have $2$ choices:

$$N_{\text{refl}\cap\text{sym}} = 1^n \times 2^{\frac{n(n-1)}{2}} = 2^{\frac{n(n-1)}{2}} \quad \blacksquare$$

Derivation 2: Number of Surjective (Onto) Functions via Principle of Inclusion-Exclusion (PIE)

Target Statement: Let $A$ and $B$ be finite sets with $|A| = m$ and $|B| = n$ such that $m \ge n \ge 1$. The total number of surjective functions from $A$ onto $B$ is given by:

$$N_{\text{surj}} = \sum_{r=0}^{n} (-1)^{n-r} \binom{n}{r} r^m = \sum_{k=0}^{n} (-1)^k \binom{n}{k} (n-k)^m$$

Step 1: Formal Setting and Universe Definition

Let $B = \{b_1, b_2, \dots, b_n\}$. Let $\mathcal{U}$ denote the universal set of all functions from $A$ to $B$. The total number of unrestricted functions is:

$$|\mathcal{U}| = n^m$$

Step 2: Defining Defect Properties

For each $i \in \{1, 2, \dots, n\}$, let $P_i$ denote the property that the element $b_i \in B$ is not in the range of the function $f$. Let $A_i \subseteq \mathcal{U}$ be the set of functions having property $P_i$:

$$A_i = \{f: A \to B \mid b_i \notin f(A)\} = \{f \mid f: A \to B \setminus \{b_i\}\}$$

A function $f$ is onto (surjective) if and only if it satisfies none of the properties $P_1, P_2, \dots, P_n$. Therefore:

$$N_{\text{surj}} = \left| \bigcap_{i=1}^n A_i^c \right|$$

Step 3: Application of the Principle of Inclusion-Exclusion

By PIE:

$$N_{\text{surj}} = |\mathcal{U}| - \sum_{1 \le i \le n} |A_i| + \sum_{1 \le i < j \le n} |A_i \cap A_j| - \dots + (-1)^n |A_1 \cap A_2 \cap \dots \cap A_n|$$

Step 4: Cardinality of Intersections

Consider the intersection of any $k$ sets $A_{i_1} \cap A_{i_2} \cap \dots \cap A_{i_k}$. This represents the set of functions whose range misses a specific set of $k$ elements, meaning the range is restricted to the remaining $n - k$ elements of $B$:

$$|A_{i_1} \cap A_{i_2} \cap \dots \cap A_{i_k}| = (n - k)^m$$

The number of ways to choose $k$ distinct elements from $n$ elements is $\binom{n}{k}$. Thus:

$$\sum_{1 \le i_1 < \dots < i_k \le n} |A_{i_1} \cap \dots \cap A_{i_k}| = \binom{n}{k} (n - k)^m$$

Step 5: Substitution and Variable Transformation

Substituting into the PIE formula:

$$N_{\text{surj}} = \sum_{k=0}^{n} (-1)^k \binom{n}{k} (n - k)^m$$

Substitute $r = n - k$, noting that when $k = 0 \implies r = n$, and when $k = n \implies r = 0$. Since $\binom{n}{k} = \binom{n}{n-r} = \binom{n}{r}$ and $(-1)^k = (-1)^{n-r}$:

$$N_{\text{surj}} = \sum_{r=0}^{n} (-1)^{n-r} \binom{n}{r} r^m \quad \blacksquare$$

Derivation 3: Associativity of Function Composition

Target Statement: Let $f: A \to B$, $g: B \to C$, and $h: C \to D$ be functions. Prove that:

$$(h \circ g) \circ f = h \circ (g \circ f)$$

Step 1: Domain and Codomain Agreement

Examine the left-hand composite mapping:

$$g \circ f: A \to C \implies h \circ (g \circ f): A \to D$$

Examine the right-hand composite mapping:

$$h \circ g: B \to D \implies (h \circ g) \circ f: A \to D$$ Both mappings have identical domain $A$ and identical codomain $D$.

Step 2: Pointwise Evaluation

Let $x \in A$ be an arbitrary element. By definition of function composition, $(u \circ v)(t) = u(v(t))$:

For the LHS:

$$((h \circ g) \circ f)(x) = (h \circ g)(f(x))$$

Let $y = f(x) \in B$. Then:

$$(h \circ g)(y) = h(g(y)) = h(g(f(x)))$$

For the RHS:

$$(h \circ (g \circ f))(x) = h((g \circ f)(x)) = h(g(f(x)))$$

Step 3: Conclusion

Since $((h \circ g) \circ f)(x) = (h \circ (g \circ f))(x)$ for all $x \in A$, the two functions are identically equal:

$$(h \circ g) \circ f = h \circ (g \circ f) \quad \blacksquare$$

Derivation 4: Reverse Law for Invertible Mappings

Target Statement: If $f: A \to B$ and $g: B \to C$ are invertible functions, prove that $g \circ f: A \to C$ is invertible and:

$$(g \circ f)^{-1} = f^{-1} \circ g^{-1}$$

Step 1: Criterion for Invertibility

A mapping $\phi: X \to Y$ is invertible with inverse $\psi: Y \to X$ if and only if:

$$\psi \circ \phi = I_X \quad \text{and} \quad \phi \circ \psi = I_Y$$ where $I_X, I_Y$ are identity mappings on $X$ and $Y$ respectively.

Step 2: Testing Left Composition

Let candidate inverse mapping be $\psi = (f^{-1} \circ g^{-1}): C \to A$. Compose $\psi$ on the left of $(g \circ f)$:

$$(f^{-1} \circ g^{-1}) \circ (g \circ f)$$ Using the associative property of function composition: $$(f^{-1} \circ g^{-1}) \circ (g \circ f) = f^{-1} \circ (g^{-1} \circ (g \circ f))$$ $$= f^{-1} \circ ((g^{-1} \circ g) \circ f)$$ Since $g$ is invertible, $g^{-1} \circ g = I_B$: $$= f^{-1} \circ (I_B \circ f) = f^{-1} \circ f$$ Since $f$ is invertible, $f^{-1} \circ f = I_A$: $$\therefore (f^{-1} \circ g^{-1}) \circ (g \circ f) = I_A$$

Step 3: Testing Right Composition

Compose $\psi$ on the right of $(g \circ f)$:

$$(g \circ f) \circ (f^{-1} \circ g^{-1}) = g \circ (f \circ (f^{-1} \circ g^{-1}))$$ $$= g \circ ((f \circ f^{-1}) \circ g^{-1})$$ Since $f \circ f^{-1} = I_B$: $$= g \circ (I_B \circ g^{-1}) = g \circ g^{-1} = I_C$$ $$\therefore (g \circ f) \circ (f^{-1} \circ g^{-1}) = I_C$$

Step 4: Conclusion

By the uniqueness of the inverse mapping:

$$(g \circ f)^{-1} = f^{-1} \circ g^{-1} \quad \blacksquare$$

Derivation 5: Fundamental Bijectivity Theorem of Invertibility

Target Statement: A function $f: X \to Y$ is invertible if and only if $f$ is bijective (both injective and surjective).

Part 1: Invertible $\implies$ Bijective

Assume $f$ is invertible. Then there exists $g: Y \to X$ such that $g \circ f = I_X$ and $f \circ g = I_Y$.

Injectivity: Suppose $f(x_1) = f(x_2)$ for $x_1, x_2 \in X$. Apply $g$ to both sides:

$$g(f(x_1)) = g(f(x_2)) \implies (g \circ f)(x_1) = (g \circ f)(x_2)$$ $$I_X(x_1) = I_X(x_2) \implies x_1 = x_2$$ Thus, $f$ is injective (one-one).

Surjectivity: Let $y \in Y$ be arbitrary. We must find $x \in X$ such that $f(x) = y$.

Choose $x = g(y) \in X$. Then:

$$f(x) = f(g(y)) = (f \circ g)(y) = I_Y(y) = y$$ Hence, every $y \in Y$ has a pre-image in $X$. Thus, $f$ is surjective (onto).

Therefore, $f$ is bijective.

Part 2: Bijective $\implies$ Invertible

Assume $f: X \to Y$ is bijective.

Since $f$ is surjective, for every $y \in Y$, there exists at least one $x \in X$ such that $f(x) = y$.

Since $f$ is injective, this $x$ is unique: if $f(x') = y$, then $f(x) = f(x') \implies x = x'$.

We can therefore define a well-defined function $g: Y \to X$ by the rule:

$$g(y) = x \iff f(x) = y$$

Now evaluate compositions:

$$\forall x \in X: (g \circ f)(x) = g(f(x)) = g(y) = x \implies g \circ f = I_X$$ $$\forall y \in Y: (f \circ g)(y) = f(g(y)) = f(x) = y \implies f \circ g = I_Y$$ Thus, $g$ is a valid two-sided inverse of $f$, proving $f$ is invertible with $f^{-1} = g$. $\blacksquare$

Derivation 6: Uniqueness of Identity and Inverse Elements in Binary Operations

Target Statement: Let $*$ be a binary operation on set $S$. Prove that:
(i) If an identity element exists, it is unique.
(ii) If $*$ is associative and has identity $e$, then the inverse of any invertible element $a \in S$ is unique.

Part 1: Proof of Uniqueness of Identity

Suppose $e_1$ and $e_2$ are both identity elements in $(S, *)$.

Since $e_1$ is an identity element, for any $x \in S$: $e_1 * x = x * e_1 = x$. Setting $x = e_2$:

$$e_1 * e_2 = e_2 \quad \text{--- (Equation 1)}$$

Since $e_2$ is an identity element, for any $x \in S$: $e_2 * x = x * e_2 = x$. Setting $x = e_1$:

$$e_1 * e_2 = e_1 \quad \text{--- (Equation 2)}$$

Equating Equations (1) and (2):

$$e_1 = e_2$$ Thus, the identity element is unique.

Part 2: Proof of Uniqueness of Inverse

Assume $*$ is associative: $(a * b) * c = a * (b * c)$ for all $a, b, c \in S$. Let $e$ be the identity.

Suppose an element $a \in S$ possesses two inverses, $b_1$ and $b_2$ in $S$. By definition of inverse:

$$a * b_1 = b_1 * a = e$$ $$a * b_2 = b_2 * a = e$$

Consider the expression $b_1 * (a * b_2)$:

$$b_1 * (a * b_2) = b_1 * e = b_1 \quad \text{--- (Equation 3)}$$

By associativity, we can rewrite the same expression as:

$$(b_1 * a) * b_2 = e * b_2 = b_2 \quad \text{--- (Equation 4)}$$

Since $(b_1 * a) * b_2 = b_1 * (a * b_2)$, equating Equations (3) and (4) gives:

$$b_1 = b_2$$ Therefore, the inverse element is strictly unique. $\blacksquare$
