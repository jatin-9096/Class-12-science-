Relation – definition, domain, range and representation

Definition of a Relation

A relation $R$ from a set $A$ to a set $B$ is any subset of the Cartesian product $A\times B$. In symbols, \[R\subseteq A\times B.\] Each element of $R$ is an ordered pair $(a,b)$ where $a\in A$ and $b\in B$.

Domain and Range

  • Domain of $R$ (denoted $\operatorname{Dom}(R)$) is the set of all first components of the ordered pairs in $R$: \[\operatorname{Dom}(R)=\{a\in A\mid \exists\,b\in B,(a,b)\in R\}.\]
  • Range of $R$ (denoted $\operatorname{Ran}(R)$) is the set of all second components: \[\operatorname{Ran}(R)=\{b\in B\mid \exists\,a\in A,(a,b)\in R\}.\]

Ways to Represent a Relation

  • Ordered‑pair list: Write all elements as $(a,b)$.
  • Mapping diagram: Draw two columns for $A$ and $B$ and join each $a\in A$ to its related $b\in B$ by an arrow.
  • Relation matrix: If $A=\{a_1,\dots,a_m\}$ and $B=\{b_1,\dots,b_n\}$, the matrix $M_R=[m_{ij}]$ is defined by \[m_{ij}=\begin{cases}1,&(a_i,b_j)\in R,\\0,&(a_i,b_j)\notin R.\end{cases}\]
  • Digraph (directed graph): Vertices are the elements of $A\cup B$; a directed edge $a\rightarrow b$ is drawn for each $(a,b)\in R$.

Important Properties (CBSE‑relevant)

  • For any two relations $R,S\subseteq A\times B$, \[\operatorname{Dom}(R\cup S)=\operatorname{Dom}(R)\cup\operatorname{Dom}(S),\quad \operatorname{Ran}(R\cup S)=\operatorname{Ran}(R)\cup\operatorname{Ran}(S).\]
  • If $R$ is empty, $\operatorname{Dom}(R)=\operatorname{Ran}(R)=\emptyset$ (edge case).
  • A relation need not be a function; a single element of $A$ may be related to more than one element of $B$.

Edge Cases to Remember

  • Empty relation: No ordered pairs; both domain and range are empty.
  • Repeated ordered pairs: In set notation repetitions are ignored; $(a,b)$ appears at most once.
  • Relation with elements outside the given sets: By definition all ordered pairs must have first component in $A$ and second in $B$; otherwise the pair is not part of the relation.

Solved Example (CBSE style)

Let $A=\{1,2,3\}$ and $B=\{a,b,c\}$. Define \[R=\{(1,a),(2,b),(3,c),(2,a)\}.\] Determine the domain, range, matrix and draw the digraph.

  1. Domain: Collect first components: $\{1,2,3\}$. Hence $\operatorname{Dom}(R)=\{1,2,3\}$.
  2. Range: Collect second components: $\{a,b,c\}$. Thus $\operatorname{Ran}(R)=\{a,b,c\}$.
  3. Matrix: Order $A$ as $1,2,3$ and $B$ as $a,b,c$.

Types of relations – reflexive, symmetric, transitive, equivalence and partial order

Definition of a relation A relation $R$ on a set $A$ is a subset of $A\\times A$. If $(a,b)\in R$ we write $aRb$.

Reflexive relation $R$ is reflexive on $A$ iff $\forall a\in A,\;(a,a)\in R$. In symbols: $\displaystyle\bigwedge_{a\in A}(a,a)\in R$.

Symmetric relation $R$ is symmetric iff $\forall a,b\in A,\;(a,b)\in R\Rightarrow(b,a)\in R$.

Transitive relation $R$ is transitive iff $\forall a,b,c\in A,\;(a,b)\in R\land(b,c)\in R\Rightarrow(a,c)\in R$.

Equivalence relation A relation that is reflexive, symmetric and transitive simultaneously. It partitions $A$ into disjoint equivalence classes.

Partial order A relation that is reflexive, antisymmetric (i.e., $aRb$ and $bRa$ imply $a=b$) and transitive. Such a relation is called a poset $(A,\le)$.

PropertySymbolic conditionExample
Reflexive$\forall a\in A,\;(a,a)\in R$$R=\{(x,x):x\in \mathbb{R}\}$
Symmetric$\forall a,b,\;(a,b)\in R\Rightarrow(b,a)\in R$$R=\{(a,b):a-b\text{ is even}\}$
Transitive$\forall a,b,c,\;(a,b)\in R\land(b,c)\in R\Rightarrow(a,c)\in R$$R=\{(a,b):a\le b\}$
Antisymmetric$\forall a,b,\;(a,b)\in R\land(b,a)\in R\Rightarrow a=b$$R=\{(a,b):a\le b\}$

Edge cases

  • If $A=\varnothing$, the empty relation $\varnothing$ is vacuously reflexive, symmetric, transitive, hence an equivalence relation.
  • The universal relation $A\\times A$ is reflexive and symmetric but not transitive in general; it fails to be a partial order because it is not antisymmetric.

Solved example

Let $A=\{1,2,3\}$ and $R=\{(1,1),(2,2),(3,3),(1,2),(2,1)\}$.

  1. Reflexive? All $(a,a)$ for $a\in A$ are present → Yes.
  2. Symmetric? $(1,2)\in R$ and $(2,1)\in R$; no other off‑diagonal pairs → Yes.
  3. Transitive? Check $(1,2)$ and $(2,1)$ → requires $(1,1)$ which is present; similarly $(2,1)$ and $(1,2)$ → requires $(2,2)$. No counter‑example, so $R$ is transitive.
  4. Since it is reflexive, symmetric and transitive, $R$ is an equivalence relation. The equivalence classes are $[1]=\{1,2\}$, $[2]=\{1,2\}$, $[3]=\{3\}$.
  5. Is $R$ a partial order? Antisymmetry fails because $(1,2)$ and $(2,1)$ are both in $R$ but $1\neq2$. Hence $R$ is not a partial order.

Thus the same relation can be an equivalence relation without being a partial order.

Function – definition, domain, codomain, range and classification (one‑one, onto, bijective, many‑one, etc.)

Definition of a Function

A function $f$ from a set $A$ (called the domain) to a set $B$ (called the codomain) is a rule that assigns to each element $x\in A$ exactly one element $y\in B$. This is denoted as $f:A\rightarrow B$ and $y=f(x)$. The set of all actual outputs $\{f(x):x\in A\}$ is called the range (or image) of $f$.

Domain, Codomain and Range

  • Domain ($\mathcal{D}_f$): the set of all admissible inputs. For a real‑valued function given by a formula, the domain is obtained by excluding values that make the expression undefined (e.g., division by zero, negative radicand for even roots).
  • Codomain ($\mathcal{C}_f$): the set in which the outputs are declared to lie. It is chosen by the problem‑setter and may be larger than the actual range.
  • Range (Image) ($\mathcal{R}_f$): $\mathcal{R}_f=\{f(x):x\in\mathcal{D}_f\}\subseteq\mathcal{C}_f$.

Classification of Functions

TypeDefinitionSymbolic Condition
One‑to‑One (Injective)Different inputs give different outputs.$\forall x_1,x_2\in\mathcal{D}_f,\;f(x_1)=f(x_2)\Rightarrow x_1=x_2$
Onto (Surjective)Every element of the codomain is hit by at least one input.$\forall y\in\mathcal{C}_f,\;\exists x\in\mathcal{D}_f$ such that $f(x)=y$
BijectiveBoth injective and surjective.Injective $\&$ Surjective
Many‑OneTwo or more distinct inputs may map to the same output.\(\exists x_1\neq x_2$ with $f(x_1)=f(x_2)$\)
ConstantAll inputs map to a single fixed output.$\exists c\in\mathcal{C}_f$ such that $f(x)=c\;\forall x\in\mathcal{D}_f$

Edge Cases and Remarks

  • If the domain is the empty set $\emptyset$, the function is called a null function. It is vacuously both injective and surjective onto any codomain.
  • A function can be injective but not surjective if $\mathcal{R}_f\subsetneq\mathcal{C}_f$ (e.g., $f:\mathbb{R}\to\mathbb{R},\;f(x)=e^x$).
  • Physical quantities often carry SI units; when a function models a physical law, the units of domain and codomain must be consistent (e.g., $v(t)=gt$ where $v$ is in m·s$^{-1}$ and $t$ in s).

Solved Example

Let $f:\mathbb{R}\rightarrow\mathbb{R}$ be defined by $f(x)=x^{2}$.

  1. Domain: All real numbers, $\mathcal{D}_f=\mathbb{R}$, because squaring is defined for every $x\in\mathbb{R}$.
  2. Codomain: Given as $\mathbb{R}$.
  3. Range: $$\mathcal{R}_f=\{x^{2}:x\in\mathbb{R}\}= [0,\infty).$$ Thus the range is a proper subset of the codomain.
  4. Injectivity: Choose $x_{1}=1$ and $x_{2}=-1$. Then $f(1)=f(-1)=1$ while $1\neq-1$. Hence $f$ is not one‑to‑one.
  5. Surjectivity: Since negative numbers are never obtained, $f$ is not onto $\mathbb{R}$.
  6. Conclusion: $f$ is a many‑one, non‑bijective function with domain $\mathbb{R}$, codomain $\mathbb{R}$ and range $[0,\infty)$.

Key Take‑aways for Exams

  • Always write down domain, codomain and range separately before classifying.
  • Use the formal definitions (injective, surjective) to justify your answer; a single counter‑example suffices to disprove injectivity or surjectivity.
  • Remember that bijectivity guarantees the existence of an inverse function $f^{-1}:\mathcal{C}_f\rightarrow\mathcal{D}_f$.
  • Check edge cases such as empty domain or constant functions, as they often appear in multiple‑choice questions.

Graphical representation of functions and the vertical line test

Graphical Representation of Functions and the Vertical Line Test

A function $f$ from a set $A$ (domain) to a set $B$ (codomain) assigns to each element $x\in A$ exactly one element $y\in B$, denoted $y=f(x)$. The set of ordered pairs $\{(x,f(x))\mid x\in A\}$ is called the graph of $f$ in the Cartesian plane.

How to plot a function:

  • Identify the domain $D$ (including any restrictions such as $x\neq 0$ for $\frac{1}{x}$).
  • Choose a convenient set of $x$‑values in $D$ (including critical points, intercepts, points where the derivative changes sign, etc.).
  • Compute the corresponding $y$‑values using the rule $y=f(x)$.
  • Mark each $(x,y)$ on the $xy$‑plane and join points smoothly where the function is continuous.

Vertical Line Test (VLT)

The VLT provides a visual criterion to decide whether a given curve represents a function $y=f(x)$.

Theorem (Vertical Line Test): A curve in the $xy$‑plane represents a function of $x$ if and only if every vertical line $x=k$ (where $k$ is any real number) intersects the curve at most once.

Proof Sketch:

  1. Assume the curve is the graph of a function $f$. By definition, for each $x=k$ there is a unique $y$, so the vertical line $x=k$ meets the graph at exactly one point (or none if $k\notin D$).
  2. Conversely, suppose every vertical line meets the curve at most once. Define $f(k)$ as the $y$‑coordinate of the intersection point when it exists. Uniqueness of the intersection guarantees that each $k$ in the projection of the curve onto the $x$‑axis has a single image, satisfying the definition of a function.

Edge Cases

  • Vertical segments: A curve containing a vertical segment fails the VLT because a vertical line coinciding with that segment meets the curve infinitely many times.
  • Disconnected graphs: The VLT applies locally; each component must satisfy the test. For example, $y=\sqrt{x}$ and $y=-\sqrt{x}$ together form a sideways parabola which fails the VLT.
  • Domain restrictions: If a curve is defined only for $x\ge0$, vertical lines with $x<0$ do not intersect, which is permissible.

Example

Determine whether the curve $y^2 = x$ represents $y$ as a function of $x$.

Solution:

  1. Rewrite: $y = \pm\sqrt{x}$, $x\ge0$.
  2. For a given $x>0$, the vertical line $x=k$ meets the curve at two points $(k,\sqrt{k})$ and $(k,-\sqrt{k})$.
  3. Since a vertical line intersects more than once, the curve fails the VLT.
  4. Hence $y$ is not a function of $x$ on the whole curve. However, each branch $y=\sqrt{x}$ and $y=-\sqrt{x}$ individually passes the VLT and thus defines a function.

Practical Tips for Exams

  • Always state the domain before drawing the graph.
  • Mark intercepts: set $x=0$ for $y$‑intercept, $y=0$ for $x$‑intercept.
  • Check monotonicity using $\frac{dy}{dx}$; monotonic intervals guarantee the VLT.
  • When given a curve, apply the VLT directly: imagine a vertical line sliding across the $x$‑axis.

Mastering the graphical representation and the vertical line test equips you to quickly verify functionhood, a prerequisite for further topics such as composition, inverses, and calculus in the CBSE Class 12 syllabus.

Composition of functions – definition, algebraic and graphical aspects

Definition: Let $f:A\rightarrow B$ and $g:C\rightarrow D$ be two functions. The composition of $f$ with $g$, denoted $f\circ g$, is defined only when the range of $g$ is a subset of the domain of $f$ (i.e., $g(C)\subseteq A$). For every $x\in C$, $$ (f\circ g)(x)=f\big(g(x)\big). $$ The resulting function $f\circ g$ maps $C$ into $D$ (or into $B$ if $f$ maps into $B$).

Algebraic Aspects

  • For functions expressed by formulas, composition is performed by substitution. If $f(x)=\frac{1}{x-1}$ and $g(x)=\sqrt{x+3}$, then $$ (f\circ g)(x)=f\big(g(x)\big)=\frac{1}{\sqrt{x+3}-1},\qquad x\ge-3,\;\sqrt{x+3}\neq1. $$
  • Domain of $f\circ g$: It is the set of all $x\in C$ such that $x$ belongs to the domain of $g$ and $g(x)$ belongs to the domain of $f$. This is obtained by intersecting the domain of $g$ with the pre‑image $g^{-1}(\text{Dom}(f))$.
  • Associativity: For three functions $f,g,h$ with compatible domains, $$ (f\circ g)\circ h = f\circ (g\circ h). $$ Proof: For any $x$, $$ ((f\circ g)\circ h)(x)= (f\circ g)(h(x))=f\big(g(h(x))\big)=f\big((g\circ h)(x)\big)=(f\circ (g\circ h))(x). $$ Thus composition is associative.
  • Non‑commutativity: In general, $f\circ g \neq g\circ f$. Example: with $f(x)=x^2$ and $g(x)=x+1$, $$ (f\circ g)(x)=(x+1)^2,\qquad (g\circ f)(x)=x^2+1. $$ These are different, showing that order matters.

Graphical Aspects

  • On the $xy$‑plane, the graph of $g$ is drawn first. For each $x$, the point $(x,g(x))$ is located; the $y$‑coordinate $g(x)$ then becomes the $x$‑coordinate for $f$. Thus the graph of $f\circ g$ can be obtained by "following" a point on $g$ horizontally to the $y$‑axis, then moving vertically according to $f$.
  • Visually, the composition corresponds to a two‑step mapping: $x\xrightarrow{\;g\;} g(x)\xrightarrow{\;f\;} f(g(x))$.

Edge Cases & Important Remarks

  • If $g$ is not onto $A$, some elements of $A$ may never be used in the composition; this does not affect the definition but restricts the domain.
  • If $f$ or $g$ is not a function (fails vertical line test), composition is undefined.
  • When $f$ or $g$ is a constant function, $f\circ g$ becomes constant, irrespective of the inner function.
  • Composition with the identity function $I(x)=x$ leaves the other function unchanged: $f\circ I = I\circ f = f$.

Solved Example

Let $$ f(x)=2x+3,\qquad g(x)=x^{2}. $$ Find $(f\circ g)(x)$, $(g\circ f)(x)$ and state their domains.

Solution:

  • $(f\circ g)(x)=f(g(x))=f(x^{2})=2x^{2}+3.$ Domain: $x\in\mathbb{R}$ because $g$ is defined for all real $x$ and $f$ accepts any real input.
  • $(g\circ f)(x)=g(f(x))=g(2x+3)=(2x+3)^{2}=4x^{2}+12x+9.$ Domain: again $\mathbb{R}$, since $f$ maps $\mathbb{R}$ to $\mathbb{R}$ and $g$ is defined for all real numbers.
  • Graphically, the curve $y=2x^{2}+3$ is a parabola opening upwards, shifted up by $3$. The curve $y=4x^{2}+12x+9$ is also a parabola, obtained by first shifting $y=2x$ upward by $3$ and then squaring.

Key Takeaways

  • Composition substitutes the output of one function as the input of another.
  • Domain of $f\circ g$ = ${x\in\text{Dom}(g): g(x)\in\text{Dom}(f)\}$.
  • Composition is associative but not commutative.
  • Graphical interpretation helps visualise the two‑step mapping.

Inverse of a function – existence, method of finding and properties

Definition (Inverse of a Function)
A function $f:A\rightarrow B$ is said to have an inverse function $f^{-1}:B\rightarrow A$ if for every $y\in B$ there exists a unique $x\in A$ such that $f(x)=y$. The inverse satisfies $f^{-1}(f(x))=x$ for all $x\in A$ and $f(f^{-1}(y))=y$ for all $y\in B$.

Existence Criteria (One‑to‑One Test)
A function possesses an inverse iff it is bijective (both one‑to‑one and onto).
For real‑valued functions the Horizontal Line Test is used: every horizontal line $y=c$ must intersect the graph of $f$ at most once.

Method of Finding $f^{-1}$

  • Write the relation $y=f(x)$.
  • Interchange $x$ and $y$: $x=f(y)$.
  • Solve the new equation for $y$ in terms of $x$; the resulting expression is $f^{-1}(x)$.
  • State the domain of $f^{-1}$, which equals the range of $f$, and its range, which equals the domain of $f$.

Properties of Inverse Functions

PropertyMathematical Form
Involution$\bigl(f^{-1}\bigr)^{-1}=f$
Composition$f\circ f^{-1}=I_{B},\; f^{-1}\circ f=I_{A}$
MonotonicityIf $f$ is strictly increasing (decreasing) on an interval, then $f^{-1}$ is also strictly increasing (decreasing) on the corresponding interval.
DerivativeIf $f$ is differentiable and $f'(x)\neq0$, then $\displaystyle\bigl(f^{-1}\bigr)'\bigl(f(x)\bigr)=\frac{1}{f'(x)}$.

Edge Cases & Remarks

  • If $f$ fails the horizontal line test (e.g., $f(x)=x^{2}$ on $\mathbb{R}$), it does not have a global inverse. Restricting the domain to an interval where $f$ is monotonic (e.g., $[0,\infty)$) restores invertibility.
  • Constant functions never have inverses because they are not one‑to‑one.
  • When solving for $y$, extraneous solutions may appear; always verify by substituting back into the original relation.

Solved Example

Find the inverse of $f(x)=\frac{2x-3}{5}$ and state its domain and range.

Solution:

  1. Write $y=\frac{2x-3}{5}$.
  2. Swap $x$ and $y$: $x=\frac{2y-3}{5}$.
  3. Solve for $y$:
    $5x=2y-3\;\Rightarrow\;2y=5x+3\;\Rightarrow\;y=\frac{5x+3}{2}$.
  4. Thus $f^{-1}(x)=\frac{5x+3}{2}$.
  5. Since $f$ is defined for all $x\in\mathbb{R}$, its range is $\mathbb{R}$; consequently the domain of $f^{-1}$ is $\mathbb{R}$ and its range is also $\mathbb{R}$.

Verification: $f\bigl(f^{-1}(x)\bigr)=\frac{2\left(\frac{5x+3}{2}\right)-3}{5}=x$ and $f^{-1}\bigl(f(x)\bigr)=\frac{5\left(\frac{2x-3}{5}\right)+3}{2}=x$, confirming correctness.

Binary operations – definition, examples and closure property

Definition: A binary operation on a non‑empty set $S$ is a rule \(\star\) that assigns to every ordered pair $(a,b)$ with $a,b\in S$ a unique element $a\star b\in S$. The set $S$ together with the rule $\star$ is denoted $(S,\star)$. The rule must be well defined for all ordered pairs; otherwise it is not a binary operation.

Closure property (or internal law): The defining requirement $a\star b\in S$ for every $a,b\in S$ is called the closure property. If the result of the rule ever lies outside $S$, the rule fails to be a binary operation on $S$.

Typical examples:

  • Addition $+$ on the set of integers $\mathbb Z$: for any $a,b\in\mathbb Z$, $a+b\in\mathbb Z$ (closed).
  • Multiplication $\times$ on the set of real numbers $\mathbb R$: $a\times b\in\mathbb R$ (closed).
  • Subtraction $-$ on the set of natural numbers $\mathbb N$ (including $0$) is not closed because $3-5=-2\notin\mathbb N$.
  • Division $\div$ on $\mathbb Q\setminus\{0\}$ is closed only when the divisor is non‑zero; otherwise the operation is undefined.

Edge cases and remarks:

  • If $S$ is a singleton, e.g. $S=\{c\}$, any rule $c\star c=c$ automatically satisfies closure.
  • When a rule is defined by a formula that involves an external set, one must explicitly verify that the output never leaves $S$.
  • Closure is a necessary but not sufficient condition for many algebraic structures; associativity, identity, and inverses are additional requirements.

Law/Theorem (Closure Test): Let $\star$ be a rule on $S$. Then $\star$ is a binary operation on $S$ iff \[\forall a,b\in S,\;a\star b\in S.\] This statement follows directly from the definition.

Solved example (modular addition):

Let $S=\{0,1,2\}$ and define $a\star b$ by the formula
$$a\star b\;=\;(a+b)\bmod 3.$$

We verify closure:

  • Take any $a,b\in S$. Their ordinary sum $a+b$ lies in $\{0,1,2,3,4\}$.
  • Reducing modulo $3$ yields a remainder $0,1$ or $2$, which is again an element of $S$.

Hence the rule is closed on $S$ and defines a binary operation.

Properties of binary operations – associativity, commutativity, identity and inverse elements

Definitions

  • Binary Operation – A rule that assigns to every ordered pair $(a,b)$ of elements from a set $S$ an element $a*b$ in $S$.
  • Associativity – $a*(b*c)=(a*b)*c$ for all $a,b,cin S$.
  • Commutativity – $a*b=b*a$ for all $a,bin S$.
  • Identity Element – $ein S$ such that $a*e=e*a=a$ for all $ain S$.
  • Inverse Element – For $ain S$ an element $a^{-1}in S$ with $a*a^{-1}=a^{-1}*a=e$.

Derivation of Associativity Law

Let $*$ be associative. Then for any $a,b,c,din S$:

$$((a*b)*c)*d = (a*b)*(c*d) = a*(b*(c*d))$$

Thus nested operations can be regrouped without affecting the result.

Commutativity Implies Symmetry

From $a*b=b*a$, we deduce $a*b=c$ iff $b*a=c$, ensuring order does not influence the outcome.

Uniqueness of Identity

Assume $e$ and $e'$ are both identities. Then $e=e*e'=e'$. Hence the identity is unique.

Existence of Inverses

If every element has an inverse, the operation is called a group operation. Inverse uniqueness follows from $a*a^{-1}=e$ and $a^{-1}*a=e$.

Edge Cases

  • Non‑existence of identity: e.g., $a*b=a+b$ on $mathbb{N}$ has no identity because $a+e=a$ has no solution in $mathbb{N}$.
  • Non‑existence of inverses: $a*b=acdot b$ on $mathbb{Z}^+$ has no inverse for $a>1$.
  • Associativity may fail: $a*b=a-b$ on $mathbb{R}$ is not associative.

Example: Operation on Integers

Define $a*b=a+b+ab$ for $a,binmathbb{Z}$.

Associativity Check

Compute $(a*b)*c$:

$$a*b=a+b+ab$$

Then $$(a*b)*c=(a+b+ab)+c+(a+b+ab)c$$

Similarly, $$a*(b*c)=a+(b+c+bc)+a(b+c+bc)$$

Expanding both expressions gives identical results, proving associativity.

Commutativity Check

$$a*b=a+b+ab=b+a+ba=b*a$$

Thus $*$ is commutative.

Identity Element

Find $e$ such that $a*e=a$:

$$a+e+ae=aimplies e+ae=0implies e(1+a)=0$$

For all $ainmathbb{Z}$, $e=0$ satisfies the equation. Hence $0$ is the identity.

Inverse Element

For $a$, solve $a*b=e=0$:

$$a+b+ab=0implies b(1+a)=-aimplies b=- rac{a}{1+a}$$

Since $ainmathbb{Z}$, $b$ is an integer iff $1+a$ divides $a$. Thus only $a=-1$ has no inverse; all other integers have inverses in $mathbb{Z}$.

Hence the set $mathbb{Z}setminus{-1}$ with this operation forms a group.

Conclusion

Understanding these properties allows students to classify algebraic structures (semigroups, monoids, groups) and solve problems efficiently in the CBSE Class 12 Mathematics curriculum.

Equivalence relations and partitions; partial order relations and Hasse diagrams

Definition (Relation): A relation $R$ from a set $A$ to a set $B$ is a subset of the Cartesian product $A\times B$. When $A=B$, $R$ is called a relation on $A$.

Equivalence Relation: A relation $R$ on a set $A$ is an equivalence relation iff it satisfies:

  • Reflexive: $\forall a\in A,\;(a,a)\in R$.
  • Symmetric: $\forall a,b\in A,\;(a,b)\in R \Rightarrow (b,a)\in R$.
  • Transitive: $\forall a,b,c\in A,\;(a,b)\in R\land(b,c)\in R \Rightarrow (a,c)\in R$.

Partition of a Set: A family $\{A_1,A_2,\dots ,A_k\}$ of non‑empty subsets of $A$ is a partition of $A$ if

  • $\bigcup_{i=1}^{k}A_i=A$ (covers $A$), and
  • $A_i\cap A_j=\emptyset$ for $i\neq j$ (pairwise disjoint).

Theorem: A relation $R$ on $A$ is an equivalence relation iff the set of its equivalence classes forms a partition of $A$.

Proof Sketch:

  1. If $R$ is an equivalence relation, define $[a]=\{x\in A\mid (a,x)\in R\}$. Reflexivity guarantees $a\in[a]$, symmetry and transitivity ensure $[a]=[b]$ or $[a]\cap[b]=\emptyset$. Hence the collection $\{[a]\mid a\in A\}$ is a partition.
  2. Conversely, given a partition $\{A_1,\dots ,A_k\}$, define $R=\bigcup_{i=1}^{k}(A_i\times A_i)$. By construction $R$ is reflexive, symmetric and transitive, thus an equivalence relation.

Partial Order Relation (Poset): A relation $\le$ on $A$ is a partial order if it is

  • Reflexive: $a\le a$ for all $a\in A$.
  • Antisymmetric: $a\le b$ and $b\le a$ imply $a=b$.
  • Transitive: $a\le b$ and $b\le c$ imply $a\le c$.

The ordered pair $(A,\le)$ is called a partially ordered set (poset).

Hasse Diagram Rules:

  • Place elements as vertices.
  • Draw an edge from $a$ to $b$ (with $a
  • Edges are drawn upward; the vertical position reflects the order.
  • Reflexive loops are omitted; transitive edges are omitted.

Edge Cases:

  • Empty set: The empty relation on $\emptyset$ is vacuously reflexive, symmetric and transitive, thus an equivalence relation; its partition is the empty family.
  • Universal relation $A\times A$: It is reflexive and symmetric but not antisymmetric, so it is an equivalence relation (all elements equivalent) but not a partial order.
  • Singleton set $\{a\}$: The only possible relation ${(a,a)}$ is both an equivalence relation and a partial order.

Solved Example – Equivalence Relation and Partition

Let $A=\{1,2,3,4\}$ and $R=\{(1,1),(2,2),(3,3),(4,4),(1,2),(2,1),(3,4),(4,3)\}$.

  1. Check reflexivity – all $(a,a)$ are present ✅.
  2. Check symmetry – $(1,2)\in R$ implies $(2,1)\in R$, similarly for $(3,4)$ ✅.
  3. Check transitivity – the only non‑trivial chains are $1R2$ and $2R1$, giving $1R1$ (already present); same for $3,4$ ✅.

Thus $R$ is an equivalence relation. Its equivalence classes are $[1]=\{1,2\}$ and $[3]=\{3,4\}$. Hence the partition of $A$ induced by $R$ is $\{\{1,2\},\{3,4\}\}$.

Solved Example – Partial Order and Hasse Diagram

Consider $B=\{a,b,c\}$ with relation $\le$ defined by $a\le a$, $b\le b$, $c\le c$, $a\le b$, $a\le c$.

  • Reflexive – true by definition.
  • Antisymmetric – there is no pair $x\neq y$ with $x\le y$ and $y\le x$.
  • Transitive – $a\le b$ and $b\le b$ give $a\le b$ (already), similarly for $c$; no violation.

Hence $(B,\le)$ is a poset. The covering relations are $a\prec b$ and $a\prec c$. The Hasse diagram is:

Only the minimal element $a$ is drawn at the bottom, with edges upward to $b$ and $c$, illustrating the Hasse diagram rules.
